# באקה סאן · ניהול הפקות

אפליקציית ווב (PWA) לניהול הפקות אירועים. עברית, צרפתית ואנגלית. נפתחת בטלפון ומתנהגת כמו אפליקציה.

## מה יש כאן

| תיקייה / קובץ | מה זה |
|---|---|
| `index.html`, `css/app.css` | הדף והעיצוב |
| `js/app.js` | השלד: שפה, ניווט, מעבר בין מסכים |
| `js/i18n.js` | כל הטקסטים בשלוש שפות |
| `js/store.js` | שכבת המידע. היום: המכשיר. בשלב הבא: הענן |
| `js/logic/office.js` | ההיגיון שנבדק במערכת הגוגל (Office.gs), כמו שהוא |
| `js/logic/core.js` | הכלל "בלי ערבית", טלפונים, קישורי וואטסאפ |
| `js/logic/extra.js` | היגיון חדש: תור חיוג, משימות לעובדים, חיפוש, "היום" |
| `js/screens/` | המסכים: היום, פנייה, תיקים (5 לשוניות), לקוחות, שיחות, משימות, ספקים, הצעות מחיר, סידור קבוצות, כספים, חיפוש, הגדרות |
| `js/logic/quotes.js`, `js/logic/groups.js` | היגיון חדש: הצעות בלי מחירון (ספק, עלות, רווח לשורה), רשימות מומלצות, סידור שולחנות/חדרים/אוטובוסים |
| `js/data/catalog.js` | הקטלוג בשלוש שפות (בלי מחירים) והרשימה המומלצת לכל סוג אירוע |
| `js/logic/rfq.js`, `js/screens/rfq.js` | הצורך מספר 1: בקשת הצעה לכמה ספקים מתבנית (מייל או וואטסאפ), מעקב מי לא ענה, קליטת הצעה מפורקת, טבלת השוואה ושיתוף ללקוח |
| `js/logic/approvals.js`, `js/screens/portal.js` | אישורים מהלקוח (משתתפים, תשלום, תוספת) עם תזכורות, דף לקוח בשלוש שפות, תזכורת תשלום לספק |
| `js/cloud.js` | החיבור לענן (Supabase): כניסה, דחיפה ומשיכה של שינויים, אחרון מנצח |
| `js/data/places.js` | 1,306 היישובים בארץ, לזיהוי מקום בהודעה |
| `js/data/demo.js` | נתוני דוגמה |
| `tests/` | בדיקות על ההיגיון |
| `supabase/schema.sql` | מבנה מסד הנתונים לענן (שלב 0) |

## כללים שהקוד אוכף

- שום הודעה לא נשלחת מהאפליקציה. וואטסאפ נפתח עם הטקסט, והמשתמשת לוחצת שליחה.
- טקסט עם אותיות ערביות לא נפתח בוואטסאפ.
- אין תזכורת שנתית ללקוחות.

## הרצה מקומית

```
python3 -m http.server 8765
```

ואז לפתוח בדפדפן:

```
http://localhost:8765/
```

## בדיקות

```
node --test tests/*.mjs
```
