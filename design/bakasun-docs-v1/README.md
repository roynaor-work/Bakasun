# מסמכי באקה סאן — v1

שש תבניות HTML בעברית RTL, מוכנות למילוי ולהדפסה ב־A4, לפי `design/bakasun-ui-v2`. כל התוכן המשתנה הוא מציין־מקום; אין נתוני לקוחות, ספקים, בנק או טלפונים. המסמכים סטטיים, ללא JavaScript, ללא שירות חיצוני וללא שמירת מידע.

## פתיחה והדפסה

1. פתחו את [גלריית המסמכים](index.html) בשרת מקומי ובחרו תבנית.
2. החליפו את הטקסט שבסוגריים מרובעים בעותק פרטי של התבנית. השאירו את תגיות `bdi` ואת מאפייני הכיווניות. אין לשמור מסמכים ממולאים בריפו.
3. בהדפסה בחרו A4 לאורך, קנה מידה 100%, שוליים ללא ותיבות כותרת עליונה/תחתונה של הדפדפן כבויות. השוליים הפנימיים כבר מוגדרים בתבנית. אפשר להפעיל גרפיקת רקע לקבלת הצבעים.
4. בדקו בתצוגה המקדימה שאין עמוד נוסף או תוכן חתוך. חמישה מסמכים הם בני עמוד אחד, והחוזה בן שני עמודים. קובצי ה־PDF המצורפים משמשים נקודת ייחוס.

שרת מקומי, מתיקיית הריפו:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory design/bakasun-docs-v1
```

כתובת הגלריה:

```text
http://127.0.0.1:8765/
```

## מילוי ושילוב

מפתחות השדות מופיעים במאפייני `data-field`. המילון [fields.json](fields.json) מגדיר את מציין־המקום ואת כיוונו. שדה משותף מופיע באותו מפתח בכמה מסמכים; לדוגמה `event_name`. שורות חוזרות מסומנות במפתחות ממוספרים, למשל `participant_1_name` או `line_1_amount`. אין מנוע תבניות או חישוב כספי בדפדפן: מערכת משלבת צריכה לספק את הנתונים והסכומים המאומתים.

בעת שילוב יש למלא באמצעות `textContent`, ולא באמצעות `innerHTML`. שדות טקסט משתמשים ב־`dir="auto"`; כמויות וסכומים ב־`dir="ltr"`. `bdi` מבודד כיווניות בין עברית, לטינית וסימני מטבע. יש לסנכרן את שדות האירוע בין עמודי החוזה.

הטבלאות כוללות שלוש שורות חיוב, תשעה שלבים בלו״ז ו־12 שורות משתתפים. לתוכן נוסף יש להוסיף גיליון `.sheet`, להעתיק את הכותרת והכותרת התחתונה ולעדכן את המספור. אין לדחוס טקסט ארוך באמצעות הקטנת גופן. מילוי מרובה שורות מחייב בדיקת הדפסה מחדש; ה־PDF המצורף מאמת את גרסת מצייני־המקום.

חשבונית זו היא טיוטה לתכנון בלבד: אין מספר חשבונית פיסקלי, פרטי מס או פרטי תשלום. ההפקה הסופית תיעשה במערכת חשבוניות. בחוזה יש מקומות להשלמת התנאים ולאישורם לפני חתימה.

## בנייה ובדיקות

נדרשים Node.js 20 ומעלה, Python 3, Chromium ו־Poppler (`pdfinfo`, `pdffonts`, `pdftotext`, `pdftoppm`). ליצירת דפי הסקירה נדרשת גם Pillow. קובצי ה־HTML/CSS עצמם אינם תלויים בכלים אלה.

מתוך תיקיית החבילה:

```sh
npm ci --ignore-scripts
```

```sh
node --test tests/*.test.mjs
```

אם Chromium מותקן במיקום אחר, הגדירו `CHROMIUM_PATH` לנתיב ההפעלה שלו. בהיעדר Chromium מערכתי אפשר להתקין את הדפדפן של Playwright:

```sh
npx playwright install chromium
```

בנייה מחודשת של ה־HTML והמילון:

```sh
python3 source/build.py
```

רנדר לסבב חדש, לדוגמה סבב 06:

```sh
node source/render.mjs 06
```

הרנדר מפיק PDF בפועל, ממיר כל עמוד ל־PNG באמצעות Poppler, בונה גיליון סקירה ותמונות גלריה, ומעתיק את קובצי ה־PDF האחרונים ל־`pdf/`. רק הסבב האחרון והקודם לו נשמרים ב־`iterations/`. רישומי המדידות של סבבים קודמים נשמרים כ־JSON קטן ב־`verification/`.

הבדיקות בודקות טעינה ללא שגיאות, תלות בנכסים מקומיים בלבד, RTL, גבולות תאים, הפרדה מהכותרת התחתונה, מספר עמודים, מידות A4, הטמעת גופנים, טקסט עברי בר־בחירה, הדפסה ללא רקעים, התאמת PDF למקור האחרון, תקציב נפח ושימור שני סבבים. בדיקות הפרטיות דורשות מצייני־מקום מדויקים ומשוות את הטקסט הקבוע לרשימה שנבדקה ב־[copy-allowlist.json](copy-allowlist.json). הן דוחות מילוי שדות, תוספת טקסט, כתובות דוא״ל ומזהים ארוכים; יש גם בדיקות שמזריקות תוכן סינתטי לזיכרון ומוודאות דחייה. הרשימה אינה מתעדכנת אוטומטית בבנייה או ברנדר.

## מקור העיצוב והרישוי

הצבעים, הגופן המקומי, המשקל הטיפוגרפי והפינות המעוגלות נגזרו מ־`design/bakasun-ui-v2/tokens.json`. להדפסה נבחר נייר לבן, עם הדגשות טרקוטה וירוק והפחתת מילויים. גופני Noto Sans Hebrew הועתקו עם [רישיון OFL](assets/fonts/LICENSE.txt). כל הנכסים נמצאים בחבילה; אין תלות בתיקיית העיצוב המקורית בזמן שימוש.

ראו [דוח האימות והציונים](REPORT.md).
