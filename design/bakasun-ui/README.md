# באקה סאן — הצעת מראה למסכי העבודה

4 בנובמבר 2026 · משימה 7 · עיצוב בלבד

ארבעה דפי HTML עצמאיים בעברית וב־RTL, עם מצב בהיר וכהה, אייקוני SVG וגופן עברי מוטמע. כל שמות הלקוחות, הספקים, המקומות, האירועים ומספרי המסמכים הם נתוני דמה שנכתבו להצעה. אין ייבוא ממאגרי המערכת.

## פתיחה ובדיקה

1. פתחו את [מסך היום](index.html) בדפדפן. אפשר לפתוח את הקובץ ישירות, ללא התקנה או שרת.
2. עברו בין ארבעת המסכים דרך התפריט התחתון בטלפון או תפריט הצד במחשב. כפתור הירח/השמש מחליף את מצב הצבע. בהתחלה נלקחת העדפת המכשיר; בהמשך נשמרת בחירת העיצוב בלבד.
3. נסו סינון וחיפוש בלוח ובחשבוניות, וארבע לשוניות בתיק האירוע. הכפתורים העסקיים מציגים חלונית הדגמה; סימון משימה משנה את המראה זמנית.
4. התוצאה הרצויה: ארבעת המסכים זמינים גם ללא רשת, הטקסט קריא בשני המצבים ואין גלילה אופקית. [צילומי הבהיר](screenshots/overview-light.png) ו[צילומי הכהה](screenshots/overview-dark.png) מציגים אותם זה לצד זה, בסדר מימין לשמאל: היום, לוח אירועים, תיק אירוע, חשבוניות.

| מסך | קובץ עצמאי | גודל |
|---|---|---|
| היום | [index.html](index.html) | 110,963 בתים |
| לוח אירועים | [events.html](events.html) | 112,677 בתים |
| תיק אירוע | [event.html](event.html) | 114,901 בתים |
| חשבוניות | [invoices.html](invoices.html) | 112,543 בתים |

כל קובץ כולל את ה־CSS, הסקריפט, האייקונים והגופנים שלו; אפשר להעביר גם דף יחיד ולצפות בו. קישורים בין המסכים מצריכים את ארבעת קובצי ה־HTML באותה תיקייה. אין CDN, שירות רקע או בקשות API. מדיניות CSP בדף חוסמת חיבורי רשת ומשאבים חיצוניים.

## מה משתנה לעומת היום

ההשוואה מתייחסת לקוד הקיים, בעיקר `css/app.css`, `js/screens/today.js`, `js/screens/board.js`, `js/screens/cases.js`, `js/screens/money.js` ו־`js/screens/receipts.js`.

| אזור | כיום | בהצעה |
|---|---|---|
| שפה חזותית | רקע חם, קורל, כרטיסים מעוגלים ומצב כהה כבר קיימים | בסיס קרם וירוק זית, קורל להחלטות ולפעולה הראשית, פחות הדגשות מתחרות וריווח עקבי |
| היום | רצף מקטעים לפי סוג מידע: אירועים, מעקבים, ספקים, שיחות ומשימות | שלושה מדדים קצרים, פעולה מרכזית אחת, משימות היום, האירוע הקרוב וסיכום הכסף |
| לוח אירועים | קנבן עם גלילה אופקית בטלפון ופעולות העברה | במחשב נשמר הקנבן; בטלפון בחירת שלב מציגה כרטיסים ברוחב מלא. ״כל השלבים״ מציג את כל העמודות ברצף אנכי |
| תיק אירוע | פרטים ולשוניות רבות לפי מודולים | כותרת עם תאריך, משתתפים ומוכנות; לשונית ״במבט אחד״ מרכזת קצוות פתוחים, תקציב, ספקים ועדכון אחרון |
| חשבוניות | מידע פיננסי מפוצל בין כספים, בקשות חשבונית וצילומי קבלות | הצעת מסך מעקב מרכזי: לגבייה, מתוכו באיחור, שולם החודש; סינון לפי מצב ושיוך לכל אירוע |
| שימוש בטלפון | תפריט תחתון קיים וקישורים נוספים במסכי המערכת | בהדגמה ארבעה יעדים קבועים, פקדים בגובה 44 פיקסלים לפחות, סכומים ותאריכים מבודדים בכיווניות נכונה |

המצב הכהה הוא שפה צבעונית מתוכננת, עם משטחים ירוקים כהים וטקסט בהיר, ולא היפוך אוטומטי של צבעי המסך.

## בדיקה ומסירה לחיבור עתידי

- עברו **48 בדיקות תצוגה**: ארבעה דפים × רוחבים 320, 360, 390, 430, 768, 1440 × שני מצבי צבע. לא נמצאו גלילה אופקית, פקדים החורגים מהמסך או שגיאות console/JavaScript. הפקדים הגלויים נבדקו גם לגובה לחיצה של 44 פיקסלים לפחות.
- הדפדפן הוגדר למצב offline. כל תגובת HTML סופקה ישירות מהקובץ המקומי; שום קובץ אח נוסף לא הוגש כמשאב. הגופנים והאייקונים נטענו מתוך הדף. **אפס בקשות חיצוניות**.
- נבדקו החלפת צבע ושימורו בניווט, העדפת מצב כהה של המכשיר, סינון משולב לפי שלב/סוג/חיפוש, מצב ריק, לשוניות עם מקלדת בכיוון RTL, סינון חשבוניות, סגירת דיאלוג ב־Escape וחזרת המיקוד, וסימון משימה זמני.
- [תוצאות הבדיקה](verification.json) כוללות את כל צירופי התצוגה. לא בוצעה בדיקת קורא מסך או בדיקת טלפון פיזי, ואין כאן הצהרת עמידה מלאה בתקן נגישות.
- אין שינוי בקוד המוצר, בענן, בנתונים, בגרסה או בפרסום האתר. `ops/CONTROL.md` עודכן לרישום והשלמת המשימה. דפי העיצוב אינם מחוברים לניווט או ל־service worker של האפליקציה.
- לפני חיבור למוצר יש למפות את רכיבי התצוגה למודולים הקיימים. מדד המוכנות והטיפול באיחוד מסך החשבוניות הם הצעת ממשק; הם לא נוספו ללוגיקה הקיימת. הסקריפט המדגים אינו מחליף את מנגנוני האישור והשליחה במערכת.

המקורות נמצאים ב־`source/`: קובץ CSS אחד, סקריפט תצוגה, מחולל HTML בפייתון, כלי צילום ואימות, ושני גופני Noto Sans Hebrew ברישיון SIL OFL המצורף. הגופנים מועתקים ללא שינוי; אין חבילות JavaScript נדרשות לפתיחת הדפים.

לבנייה חוזרת משורש המאגר:

```sh
python3 design/bakasun-ui/source/build.py
```

לצילום ולבדיקה חוזרת נדרשים Python Playwright, Pillow ו־Chromium מקומי. אפשר לבחור דפדפן באמצעות `BAKASUN_BROWSER`. כלי הצילום מגיש את התוכן בזיכרון במצב offline, ולכן אינו מצריך שרת HTTP:

```sh
python3 design/bakasun-ui/source/capture.py
```
