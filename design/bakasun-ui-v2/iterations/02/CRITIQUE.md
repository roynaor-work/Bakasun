# סבב 02 — תוכן התיק וזרימות עבודה

תוקנו הכפילות בניווט הלשוניות בנייד, יעדי המגע של הסכמה, שבירת שם הסביבה, סימון ״עוד״, הגדלת הטקסט וגופן כותרות התיעוד. נבדקו הצילומים החדשים של לשוניות כספים ותקציב בשני הכיוונים, והמעבר למידע בנייד קצר יותר.

| בדיקה | תוצאה |
|---|---|
| מסכים | 84 רינדורים; 0 חריגות פריסה |
| לשוניות | 52 מצבים: 13 × 2 כיוונים × 2 ערכות |
| axe | 56 בדיקות מסך + 52 לשוניות; 0 הפרות |
| זרימות | 16 עברו, 2 נכשלו |
| רשת וקונסול | 0 בקשות חיצוניות, 0 שגיאות |

ביקורת עצמית: (1) בדיקת ערכת הצבע חשפה שקישורים שנורמלו לכתובת מוחלטת לא מתעדכנים בהחלפת צבע נוספת; זה פגם אמיתי בניווט. (2) בדיקת הסינון השתמשה בבורר רחב שתפס גם כרטיסים עם data-kind; יש לדייק את כלי הבדיקה והקוד. (3) לשונית כספים של האירוע מציגה את סיכום כל החודש, בעוד שכותרת התיק מבטיחה מידע של אירוע אחד; נדרש תוכן ייעודי. (4) פירוט התקציב אינו כולל שורות מפורשות לניהול ורזרבה ולכן סכומי השורות לא מתיישבים ישירות עם הסיכום, גם שהסיכום נכון. (5) בחירת מסך פתיחה בהגדרות נשמרת אך אין עדיין פעולה שממחישה את הפתיחה שנבחרה. (6) בתצלומי כל הדף סרגל הנייד צף בגובה חלון הצילום; דרוש תצלום סקירה נוסף שמבודד את התוכן ולא מסתיר שורות.

המשך לסבב 03: לתקן את ארבעת פגמי ההתנהגות/תוכן, לדייק את בחירת סוג האירוע, להוסיף בדיקות חשבונאיות, ולשמור גם סקירת תוכן ללא הסרגל הצף. ציון ביניים: 7.5/10; לא למסירה.
