# סבב 09 — סמנטיקה של טבלאות בנייד

כותרות העמודה נשארות ב־DOM ובעץ הנגישות גם כשבמובייל השורות נפרסות ככרטיסים. הן מוסתרות חזותית באמצעות clipping במקום display:none. תוויות הכרטיסים הן span דקורטיבי עם aria-hidden כדי למנוע קריאה כפולה. ייצוא CSV מסיר רק את התוויות הדקורטיביות ומשאיר כותרת אחת ושורות נתונים נקיות.

זהו תיקון סמנטי ממוקד, ולכן מראה הכרטיסים נשאר כפי שנבדק בסבב 08. תאי היומן ומטרות המגע נשארים 44×44. דף התצוגה נפתח על סבב 09.

הבדיקות יבדקו בנוסף את עץ הנגישות בפועל בכל המסכים המכילים טבלאות ובחמש לשוניות התיק, בארבע מידות ובשני מצבי צבע. הקוד יוקפא לבדיקת היציבות לאחר השלמת הסבב. המגבלות של טלפון פיזי, קורא מסך אנושי ו־file:// בסביבת הענן יופיעו בדוח ולא יוסתרו באמצעות ציון עצמי.

הבדיקות הושלמו: 196 פריסות, 52 מצבי לשוניות, 0 חריגות, 0 הפרות axe. עץ הנגישות עבר 96 בדיקות ושמר את כל כותרות הטבלה גם במצב הכרטיסים; ה־CSV נבדק ללא תוויות כפולות. לא נדרש שינוי חזותי נוסף.

לפני סגירה יושלם סבב 10 לחבילת הפתיחה המקומית: הגופנים יוטמעו כ־data URI ב־CSS, כמו ברפרנס, כדי שלא יהיו כפופים לכללי טעינת font מקבצים נפרדים ב־file://. אין כאן טענה שהודגם כשל במוצר; זהו הסרת תלות לפני המסירה לדרישת HTML מקומי ללא שרת, משום שמדיניות הסביבה אינה מאפשרת בדיקת file:// ישירה. פיקסלי הגופן נשארים אותם נתוני TTF ברישיון המצורף. בדיקת היציבות תתחיל מחדש לאחר סבב זה.
