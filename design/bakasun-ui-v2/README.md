# סביבת אירועים — מערכת עיצוב 02

מערכת עיצוב סטטית בעברית, מבוססת על `../bakasun-ui`, עם 14 מסכי מוצר, 13 לשוניות בתיק אירוע, 68 אייקונים ו־8 איורים. כל הרשומות בדויות; אין חיבור לנתוני המוצר.

1. פותחים את [דף התצוגה האינטראקטיבי](preview.html) בדפדפן. אין התקנה, build, שרת, CDN או חיבור אינטרנט נדרשים.
2. בוחרים מסך, מצב צבע ומידת חלון. אפשר להגדיל, לשנות לשונית בתיק ולפתוח את המסך בנפרד.
3. בחלק התיעוד בוחרים סבב, מצב צבע ומרחק צילום. [הדוח](REPORT.md) מרכז תוצאות, ציונים ומשקלים.

אפשר להתחיל גם ישירות ב־[היום](index.html) או ב־[מערכת העיצוב](system.html). בנייד, ״עוד״ פותח את כל המסכים. במחשב יש תפריט צד; מקש `/` פותח מעבר מהיר למסך.

הטפסים יוצרים רשומות זמניות במסך הנוכחי, עם ביטול. חתימות ורשומות נשארות בזיכרון הדף בלבד ונעלמות ברענון; רק העדפות תצוגה נשמרות ב־localStorage תחת מפתח ייעודי. ייצוא CSV והדפסה הם מקומיים. אין שליחה, אישור עסקי, הפקת חשבונית מס, חתימה משפטית או תשלום.

הגופן מוטמע כ־data URI ב־CSS, עם קובצי מקור מקומיים: Noto Sans Hebrew במשקלים 400 ו־700. הודעת הרישיון המקורית נמצאת ב־[assets/fonts/LICENSE.txt](assets/fonts/LICENSE.txt). האייקונים והאיורים נוצרו עבור החבילה, ללא ספריית אייקונים מסחרית, לוגו, צילום אנשים או טקסטורת מוצר.

הבדיקות שומרות כל סבב ב־`iterations/NN/`: צילומי WebP, ביקורת, תוצאות JSON, חתימות SHA-256 וארכיון מצב ממשק מדויק. `near` הוא חלון מקורי, `far` צילום כל הדף המוקטן ל־50%, `close` הגדלה ל־150%. בתצלומי `content` בלבד הוסתרו סרגל הנייד וקישור הדילוג לצורך סקירת תוכן ללא כיסוי; הצילומים הרגילים נשמרו בנפרד.

בסביבת הענן המנוהלת Chromium חוסם כתובות file://. לכן האימות האוטומטי נעשה ב־offline עם route.fulfill שמחזיר את הקבצים המקומיים בזיכרון; לא פועל שרת ולא מבוצעת בקשת רשת. פתיחה ישירה ב־file:// דורשת דפדפן רגיל שמאפשר קבצים מקומיים; דף התצוגה כולל קישור לפתיחת כל מסך בנפרד גם כשדפדפן מגביל גישה בין מסגרות מקומיות.

קובצי המקור ב־`source/` מיועדים לתחזוקה ולא נדרשים לפתיחה. אפשר לייצר מחדש את 14 הדפים באמצעות `python3 design/bakasun-ui-v2/source/build.py`; אין צורך בכך כדי לצפות בתוצאה. כלי הבדיקה דורשים Python 3.12 ומעלה, Playwright, Pillow, Chromium ו־axe-core שמותקן מחוץ לריפו. הפקודות המלאות ותוצאותיהן בדוח.

בסביבה המנוהלת אפשר לבחור את Chromium הקיים דרך המתאם [source/browser-adapter.mjs](source/browser-adapter.mjs). הוא מפעיל את הדפדפן האמיתי ואינו מדמה בדיקות. לדוגמה, משורש הריפו:

```sh
ISLAND_PLAYWRIGHT="$PWD/design/bakasun-ui-v2/source/browser-adapter.mjs" CHROMIUM_PATH=/usr/bin/chromium npm test -- --test-reporter=tap
```

לבדיקות החבילה בלבד, לאחר התקנת כלי הבדיקה המקומיים:

```sh
python3 design/bakasun-ui-v2/source/quality.py
python3 design/bakasun-ui-v2/source/review.py --iteration 12 --extra-widths
python3 design/bakasun-ui-v2/source/flows.py --iteration 12
python3 design/bakasun-ui-v2/source/extended.py --iteration 12
python3 design/bakasun-ui-v2/source/signature_review.py --iteration 12
python3 design/bakasun-ui-v2/source/accessibility_tree.py
```

המספר 12 מיועד לבדיקה עתידית חדשה; כלי הרינדור מסרב לדרוס סבב קיים. הסבב הסופי שנמסר כעת הוא 11. הרצת הכלים אינה נדרשת לצפייה ב־HTML.
