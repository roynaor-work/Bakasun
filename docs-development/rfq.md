# השלמת בקשת הצעות מספקים

הבקשות ממשיכות להשתמש באוסף `links` הקיים, דרך `db.put`, ולכן נשמרות מקומית ומסתנכרנות דרך שכבת הענן הקיימת. אין שינוי סכמת Supabase או מחירון.

- טיוטת בקשה אינה בקשה שנשלחה. עריכת הנוסח נשמרת, וניתן לעצור ולהמשיך מכרטיס הספק.
- פתיחת מייל/וואטסאפ או העתקת נוסח אינן מסמנות שליחה. רק תשובה חיובית לשאלת השליחה מעדכנת תאריך וערוץ. אפשר לאשר גם שליחה ידנית לאחר העתקה.
- המתנה נספרת מהשליחה המקורית. תזכורת מאושרת נשמרת בנפרד ואינה מאפסת את זמן ההמתנה. קבלת הצעה מסיימת את ההמתנה.
- השוואה ממוינת בנפרד לכל שירות ומטבע, לפני מע״מ. אין המרת מטבעות. מחיר שלא צוין מסומן במפורש; סכום שחושב ממחיר למשתתף מסומן כחישוב. אין חיבור אוטומטי של רכיבים שעלולים להשתמש ביחידות שונות.
- מטבע, בסיס מע״מ ושיעור מע״מ נשמרים בהצעה. ברירת המחדל 18%, ניתנת לעריכה; שיעור מפורש בטקסט מזוהה. שדה העלות הקיים נשמר נטו כדי לא להוסיף מע״מ פעמיים בזרימת הכספים.
- ניתן לבחור חלופה לכל שירות; שינוי הבחירה מבטל רק את הבחירה הקודמת באותו שירות. הודעת דחייה מוצעת רק לחלופות של שירות שכבר נבחר לו ספק, ורק אישור שליחה מסמן ביטול.
- טלפון החתימה מגיע מהגדרת `bizPhone`. אם היא חסרה, מתבקשת הזנה ושמירה להגדרות. אין מספר ברירת מחדל בנוסחי RFQ.
- מסך ההשוואה והשיתוף בעברית, צרפתית ואנגלית. הטקסט החופשי של הספק נשמר כפי שהוזן; תרגום מלא עדיין תלוי במתרגם הדפדפן או בעריכה ידנית. הערות פנימיות וסימון מחיר אינם יוצאים בשיתוף ללקוח.
- `sw.js` עולה מ-v58 ל-v59 ושומר גם את המודולים החדשים לשימוש ללא חיבור. north/ ו-workout/ לא שונו.

## בדיקה בטלפון — לאחר מיזוג ופריסת GitHub Pages

קישור: https://roynaor-work.github.io/Bakasun/

1. פתחו **הגדרות ← בדיקת עדכון** וודאו שהגרסה היא `bakasun-v59`. בדקו את טלפון החתימה בהגדרות. עברו לאירוע בדיקה, **ספקים ← לבקש הצעות מכמה ספקים**, בחרו שני ספקי בדיקה ומלאו את התבנית. התוצאה: שתי טיוטות עם החתימה והטלפון שלכם.
2. פתחו טיוטת מייל או וואטסאפ ובחרו **לא** בשאלת השליחה. ודאו שהבקשה נשארת טיוטה; חזרו אליה ואשרו שליחה רק לאחר שבאמת שלחתם. התוצאה: רק הבקשה שאושרה מסומנת כממתינה לתשובה.
3. הזינו שתי הצעות בדיקה, אחת כולל מע״מ ואחת לפני מע״מ, בדקו/תקנו מטבע ושיעור מע״מ ושמרו. רעננו, בדקו את ההשוואה ובחרו ספק. שתפו את הטבלה בשפה המתאימה. התוצאה: הנתונים נשמרים, הסכומים מוצגים במטבע הנכון וללא הערות פנימיות בשיתוף.

## בדיקות אוטומטיות

מהשורש של המאגר:

```sh
node --test tests/*.mjs
```

כשהשרת המתועד פועל בפורט 8765, מתוך סביבה עם Playwright:

```sh
python3 tests/e2e/rfq_flow.py
```

## מגבלות הבדיקה

נבדקו 345 בדיקות Node, תהליך RFQ בנייד מדומה בשלוש שפות, בדיקת כל המסכים במחשב ובנייד, והתקנת v59/פתיחת מסך הספקים ללא חיבור ב-Chromium המקומי. בבדיקת ה-Service Worker נעשה רישום מפורש ב-loopback; באפליקציה הרישום האוטומטי פועל רק ב-HTTPS.

לא נבדקו טלפון פיזי, שליחת הודעות אמיתית, כניסה או סנכרון חי בשני מכשירים עם Supabase, מתרגם על המכשיר, מערכת תשלומים או פריסת GitHub Pages. בדיקות הדפדפן מיירטות את פתיחת המייל/וואטסאפ ואינן שולחות דבר.
