# Alpine Rush · תצוגה משחקית עם גרפיקה 5

1. לצפייה מיידית פתח את alpine-rush-v5.html שנמסר בנפרד. הקובץ העצמאי כולל נכסים, ספריות ואת מנוע קלוד; אינו כותב התקדמות באי.
2. להרצה מתוך התיקייה: node serve-preview.cjs ואז פתח את כתובת Local המודפסת. בחר מסלול ולחץ ״לדרך מהפסגה״. גרור או השתמש בחיצים; רווח להאצה ו־1–4 לטריקים כשנמצאים באוויר.
3. לקלוד: התחל ב־START-HERE-CLAUDE.md. שילוב נכסים מתבצע רק לפי INTEGRATION-MANIFEST.json.

התוצאה הצפויה היא מרוץ מול חמישה יריבים עם ספירה, דירוג, טריקים, מטבעות ותוצאה מהסימולציה. אין תוצאה קבועה מראש, ואין מטבעות או שיאים שנשמרים באי מהתצוגה הזו. גרסה 5 עדכנית; גרסה 4 נותרה כגרסת עיצוב היסטורית ולא נמחקה. PR #177 עדיין נפרד מחבילת הגרפיקה הזאת.
