# Alpine Rush · גרפיקה 5 · מסירה לקלוד

חלוקת העבודה שאישר רועי: Codex — גרפיקה ותצוגה; Claude — מנוע ושילוב המשחק. גרסה זו מחליפה את חבילת העיצוב 4. היא מוכנה לסקירת רועי, לא אושרה או מוזגה.

## מה נמסר

תצוגה משחקית מקומית שמריצה את המנוע שכתבת ב־PR #177, בראש 5bedb77129324ccc16435fe3a2f09815ab28f4b1. חמשת מודולי המנוע, המסלול, השליטה, הסאונד והשיאים נשמרו זהים בבייטים למקור. הדוח engine-check.json מוכיח זאת. שלושה מרוצים הסתיימו בבדיקת הרצה עצמאית; בדפדפן הושלם גם מרוץ עם טריק ומטבעות. זו אינה הדגמת תוצאה מבוימת כמו גרסאות 1–4, אך אין חיבור לשמירה או לתגמולים באי מתוך הקובץ המקומי.

שכבת הגרפיקה מחליפה את דמות הילד בדמות בוגרת עם קסדת ספורט, משקפי סקי, קרש לאורך כיוון הגלישה, IK לכיפוף רגליים, היגוי, אוויר, תפיסה ודחיסה בנחיתה. נוספים עצים עם נכס תמונה בשתי וערב, מצוקים עם מיפוי סלע בשלושה צירים, בקתות, מרקם שלג, תמונות רקע ליום ולדמדומים ותאורה מותאמת. נשמרים חתך הצינור, קו המסלול, המטבעות, הטריקים והמכשולים של המנוע הקיים.

## סדר העבודה

1. קרא את INTEGRATION-MANIFEST.json, ASSETS.md, QA.md ו־MERGE-AUDIT.md. הרץ node serve-preview.cjs ופתח את הכתובת המודפסת. אפשר גם לפתוח את קובץ alpine-rush-v5.html שנמסר לרועי בנפרד.
2. משוך את main ואת ענף PR #177 העדכניים ועבוד בענף שילוב נפרד. אל תשכתב את הענף המקורי ואל תשנה את הכותרת או התיאור שהועתקו מקובץ רועי ללא בקשה. הדוח המקומי זיהה 113 קבצים עם סימני התנגשות מול main 9f7fe88; אל תניח שזהו ראש main האחרון כשתתחיל. לא בוצע מיזוג או שינוי ב־PR על ידי Codex.
3. פתרון ההתנגשויות חייב לשמר עבודה חדשה במשחקים אחרים ובעיר. שינויי ענף הסנובורד כוללים החלפת תג גרסה בעשרות ייבואים משותפים, לצד חיבור אמיתי לתשתיות האי. אין לקבל אוטומטית את כל הצד שלנו או את כל הצד שלהם. פעל לפי מנגנון הגרסאות הקיים ב־main; אל תפיץ תג ישן על פני המאגר כדי להעלים התנגשויות.
4. העבר רק את קובצי הגרפיקה המסומנים ב־INTEGRATION-MANIFEST.json לנתיבי היעד. alpine-view.mjs מחליף את שכבת התצוגה בלבד ומשתמש ב־course וב־physics הקיימים. אל תעתיק את preview.mjs, index.html, balance.json, קובצי ההדגמה או עותקי המנוע מעל הקוד המעודכן בפרויקט. אל תשנה פיזיקה, AI, ניקוד, טריקים, מטבעות או שמירות כדי להתאים לגרפיקה.
5. חבר את alpine-polish.css אחרי העיצוב הקיים אם רועי מאשר את גוני הממשק. שמור את מסכי הפתיחה, הג׳ויסטיק, כפתורי הטריקים, תוצאת האי והניווט הקיימים. בנכסי התצוגה השתמש בנתיב assets/alpine-rush וב־vendor המשותף. שמור את זהות מודול Three בין התצוגה והלואדרים לפי מבנה הפרויקט המעודכן.
6. בצע בדיקות משחק ושליטה בשלושת המסלולים, אוויר מהשפה, טריקים ונחיתה, פגיעה, מטבעות, השהיה, ניסיון חוזר, יציאה בזמן טעינה, מודל חסר ומצב איכות קלה. הרץ בדיקות מאגר נדרשות ודווח על כשל קיים בנפרד. מדוד במכשיר פיזי אם זמין; אין בדוח המקומי מדידת FPS בטלפון.
7. החזר לרועי PR ממוקד וניתן לבדיקה מול main העדכני, ענף שנדחף, SHA מלא, צילומי מחשב וטלפון ותוצאות בדיקה. אין למזג בלי אישור רועי.

המראה עדיין דורש סקירה של רועי. אין בחבילה הרשאה לשלוח הודעה, לפרסם משחק או למזג.
