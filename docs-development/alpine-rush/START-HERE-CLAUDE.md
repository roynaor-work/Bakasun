# Alpine Rush — מסירת עיצוב ומימוש לקלוד

בקשת רועי מ־25.10.2026: משחק ברמת עיצוב גבוהה, דומה מאוד ל־[Ski Master](https://minigame.com/en/game/ski-master). חלוקת העבודה אושרה בשיחה: Codex אחראי לעיצוב ולתצוגה, Claude למנוע ולקוד המשחק.

## מה כבר נעשה

זו חבילת תצוגה ממשית בתלת־ממד: סביבה אלפינית, שישה גולשים עם שלד, התאמת לבוש וקסדות, קרשי סנובורד, צללים, עצים מושלגים, דגלים, סלעים, רמפה, פס האצה, מצלמה, חלקיקים וממשק בעברית. כל התלויות מקומיות.

`view.mjs` הוא קוד תצוגה שניתן לחבר למנוע. `demo.mjs` הוא ניגון עיצוב מבוים עם גרירה והמחשת אירועים. אין בו מנוע מרוץ, התנגשויות, AI, זכיות או שמירה. המספרים והתוצאות שלו אינם נתוני משחק אמיתיים. אין להעתיק את מנגנון הדירוג המבויים למשחק.

שם העבודה Alpine Rush והעיצוב הם הצעה מוכנה לסקירת רועי. טרם ניתן אישור סופי למראה. הקבצים לא מוזגו לפרויקט ולא פורסמו למשחק החי.

## סדר העבודה

1. קרא את `DESIGN.md`, את `CONTRACT.ts` ואת `ACCEPTANCE.md`. פתח את הדגמת העיצוב וצפה גם בגלישה, האצה, קפיצה, פגיעה, השהיה ותוצאה דרך ״כלי תצוגה״.
2. מאגר היעד, לפי ההקשר הקיים: `https://github.com/roynaor-work/Bakasun`, משפחת המשחקים ב־`workout/island/`. בדוק את main העדכני, `AGENTS.md`, `CLAUDE.md` ובקשות שינוי פתוחות לפני התחלה. זהו יעד השילוב המוצע; אם המאגר או הדרישות המעודכנות מגדירים יעד אחר, תעד זאת לפני שינוי קבצים משותפים.
3. פתח ענף עבודה חדש, ממוקד במשחק הסנובורד. השתמש בממשקי פתיחה, סיום וחזרה לאי הקיימים. אל תחליף את מרוץ המכוניות הקיים. למד את `minigames/racing-session.mjs`, `context.mjs` ואת מנגנון הרישום העדכני; אל תנחש שמות ממשקים מהזיכרון.
4. בצע קודם מרוץ שלם אחד: טעינה → פתיחה → ספירה → גלישה עם 5 יריבים → סיום מחושב → ניסיון חוזר / חזרה לאי. חבר את `view.mjs` ל־snapshot של המנוע לפי החוזה. השאר את ההדגמה ככלי פיתוח בלבד.
5. הוסף שלושה מסלולים מדורגים, בקרה על AI, התאוששות מפגיעה, האצה, רמפות, תוצאות ושמירת התקדמות. המספרים במסמך הם ערכי התחלה לכיול; אמת שהם מהנים והוגנים במשחק ממשי.
6. שלב את הגרפיקה, סאונד מקומי ושליטה לטלפון ולמחשב. פתח במשחק האמיתי ועמוד בבדיקות הקבלה. לפני PR עדכן מה־main העדכני ופתור התנגשויות נקודתית תוך שמירת שינויים אחרים.
7. מסור PR ממוקד אחד, צילומי מחשב וטלפון ודוח בדיקה. רועי סוקר וממזג. אין להציג קוד כעבודה זמינה ללא ענף שנדחף ו־SHA מלא; אם הדחיפה חסומה, ספק patch או bundle שניתן להוריד.

## תחום אחריות

| Codex — נמסר כאן | Claude — למימוש |
|---|---|
| כיוון אמנותי, סביבה, מצלמה, דמויות, חומרים, HUD ומסכים | מודל עולם, מהירות, היגוי, מסלול, זמן ודירוג |
| render(snapshot), איכות תצוגה ושחרור משאבי תלת־ממד | AI, התנגשויות, קפיצה, האצה, תנאי סיום |
| ניגון המחשה עצמאי ותיעוד חיבור | שלבים, תוצאה אמיתית, תגמולים ושמירות |
| מסגרות לטלפון ולמחשב | חיבור לאי, סאונד, מחזור חיים ובדיקות |

מותר להתאים את שכבת התצוגה לחוזה הסופי ולמגבלות הביצועים, תוך שימור הכיוון החזותי. שינוי משמעותי ברף המראה יוצג לרועי עם השוואה. אין לדרוס משחקים אחרים או לגעת בתוכן לימודי הדמות, באקה סאן או north כחלק מהמשימה.

## קבצים

- `index.html`, `style.css` — ממשק ומסכי הדגמה.
- `view.mjs` — שכבת תלת־ממד נפרדת.
- `demo.mjs` — ניגון המחשה בלבד; אינו מנוע לשילוב בייצור.
- `assets/rider.glb` — נכס הדמות הקיים בפרויקט, ללא שינוי בבייטים; התאמות לבוש נעשות בעותקי רשת בזיכרון.
- `vendor/` — Three.js r160 ו־GLTFLoader, ברישיון MIT המצורף.
- `CONTRACT.ts` — חוזה בין מנוע, תצוגה ובקר; אינו מנוע קיים.
- `DESIGN.md`, `ACCEPTANCE.md`, `ASSETS.md` — רף, בדיקות ומקורות.

לתצוגה מודולרית, הגש את התיקייה בשרת HTTP מקומי ופתח `index.html`. לצד ה־ZIP נמסר גם `alpine-rush-design.html`: קובץ צפייה עצמאי שבו הספריות והדמות משובצות, ללא התקנה וללא CDN.
