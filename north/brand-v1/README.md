# הרוח הצפונית — קיט מותג ותצוגת עיצוב v1

פותחים את [index.html](index.html) בדפדפן. אין התקנה, build או חיבור לרשת. יש לשמור את `north/brand-v1/` ואת `north/img/v4/` באותו מבנה תיקיות. גופנים, קוד ותמונות נמסרים מקומית.

- [בית](home.html): כותרת מצולמת, 12 מארזים, חיפוש, קטגוריות, שישה אירועים וכניסה לבונה.
- [מוצר](product.html#single-malt): שש זוויות, הגדלה לגודל טבעי, תכולה, גרסאות ומחירי הצעה. אפשר להחליף את ה־hash לכל מזהה ב־`catalog.json`.
- [בונה](builder.html): בסיס, עד חמש תוספות, אריזה וברכה עד 180 תווים; חזרה שומרת את הבחירות. הסיכום מקומי בזיכרון הדף.
- [דוח](REPORT.md), [טבלת כל הקבצים](weights.csv), [סקירת כל הצילומים](verification/visual-review.csv), [יומן](SESSION.md).

המסכים הם הצעת עיצוב עצמאית. הכפתורים מציגים בחירות וסיכום; אין הזמנה, חיוב או שליחת טופס. הנתונים אינם נשמרים לאחר רענון. פונקציית העתקה פועלת רק בעקבות לחיצה, עם גיבוי לבחירה ידנית אם הדפדפן חוסם גישה ללוח.

## מבנה

`assets/` כולל לוגו, וקטורים לאריזה, ארבע הדמיות חומר, גופני WOFF2 ורישיונותיהם. `icons/` כולל עשרה אייקוני SVG מקוריים. `catalog.json` הוא צילום מצב עובדתי של הקטלוג; `catalog.js` ו־`assets.js` הם נתונים מקומיים לטעינה כסקריפט רגיל. אין ES modules או `fetch` שיחייבו שרת בפתיחה מהדיסק.

כל תמונות המוצר והבאנרים ב־v4 נוצרו מחדש. 16 התמונות הקטנות תחת `assets/builder/` הן נגזרות מוקטנות של נכסי התוספות המקומיים ב־v3, לשימוש בבונה בלבד; הן אינן חלק מ־72 הצילומים החדשים.

## קובצי גרפיקה

- `assets/north-star.svg`: סמל צבעוני; `north-star-mono.svg`: סמל להפקה בצבע אחד, עם מרכז פתוח. צבע המילוי `currentColor`, ברירת המחדל שחורה.
- `packaging-sticker.svg`: קוטר גרפי מוצע 50 מ״מ.
- `greeting-label.svg`: הצעת תווית 90×55 מ״מ.
- `bag-artwork.svg`: שטח גרפי מוצע לחזית 240×300 מ״מ.
- `wrapping-pattern.svg`: משטח מוצע 500×700 מ״מ; מוטיב משני בן ארבע קרניים, מחזור 16 מ״מ. הכוכב בן שמונה הקרניים נשאר הסמל הראשי.

הלוגו הקנוני זהה בנתיבו במדבקה, בכרטיס ובחזית השקית. ההדמיות הן המחשת חומר, ולא מקור להעתקת גאומטריה. המידות הן הצעות לגרפיקה, אינן מדידת מארז. הקבצים אינם פריסות ייצור; יש להתאים bleed, חיתוך, צבעי דפוס/פנטון והטבעה לחומר ולספק שנבחרו.

## כלי אימות אופציונליים

התצוגה עצמה אינה משתמשת בכלים האלה. הם דורשים Node, Playwright, sharp ו־Chromium מותקנים בסביבת הבדיקה:

```sh
node north/brand-v1/tools/capture.cjs 10
NORTH_AXE_PATH=/absolute/path/axe.min.js node north/brand-v1/tools/verify.cjs verification
node north/brand-v1/tools/stress.cjs 10
node north/brand-v1/tools/measure.cjs verification
node north/brand-v1/tools/weights.cjs
```

אין לדרוס סבב קיים. `capture.cjs` מסרב לדרוס `checks.json` שכבר קיים. `weights.cjs` מעדכן מלאי קבצים בלי צורך בקובצי המקור הגולמיים. `prepare-assets.cjs` נועד לסביבת יצירת הצילומים ודורש את קובצי ה־PNG החיצוניים הרשומים ב־`generation.json`; הם אינם נמסרים בתוך הריפו.

בסביבת העבודה המנוהלת מדיניות Chromium חוסמת `file://`. לכן הבדיקות ממפות כתובות loopback לבתים מקומיים ישירות מתוך כלי האוטומציה, במצב offline וללא שרת מאזין; כל בקשה חיצונית נחסמת. מדיניות הדפדפן לא שונתה. התוצר משתמש בנתיבים יחסיים ובסקריפטים רגילים כדי לאפשר גם פתיחה ישירה בדפדפן שאינו חוסם אותה.

בדיקת היקף, קישורים, תמונות ונתונים (מתוך checkout עם היסטוריית בסיס המשימה), ולאחריה חתימת כל הבתים הסופיים:

```sh
node north/brand-v1/tools/audit.cjs
node north/brand-v1/tools/seal.cjs 09
sha256sum --quiet -c north/brand-v1/verification/SHA256SUMS
```

`seal.cjs` מוודא שקוד התצוגה תואם לחתימות סבב הרינדור, מעדכן את גדלי כל הקבצים ובודק כל חתימה. כל שינוי במסמך לאחר החתימה מחייב חתימה מחדש. קובץ החתימות אינו חותם על עצמו.
