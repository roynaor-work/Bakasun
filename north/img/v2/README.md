## שימוש בנכסים

- סיומת `-product.webp`: תמונה ראשית לשדה img; סיומת `-mood.webp`: תמונה שנייה לשדה img2.
- הנתיבים מהחנות מתחילים ב־`img/v2/`. המיפוי המלא נמצא בטבלה וב־manifest.json.
- בבאנרים ובגיבור נשאר אזור כהה בצד ימין לכותרת בעברית. אזור טקסט מומלץ: 65%–95% מרוחב התמונה, 15%–75% מגובהה, כשהתמונה מוצגת בשלמותה.
- להצגת כל תכולת המארז יש לשמור על יחס התמונה. אם נדרש חיתוך צר בנייד, כדאי להשתמש בתמונת המוצר/האווירה האנכית התואמת באמצעות picture, ולמקם את הכותרת מחוץ לתמונה.
- התיקייה כוללת נכסים, גלריית בדיקה ותיעוד. חיבור הנכסים לחנות נעשה דרך img/img2 ותמונות דף הבית.
