# צילום מוצר v4

72 תמונות מקוריות עבור 12 המארזים ב־`north/js/products.js`, ועוד שישה באנרים. גלריה מקומית אינטראקטיבית: [north/brand-v1/index.html](../../brand-v1/index.html#photography).

## שמות ומידות

| תפקיד | סיומת | מידה |
|---|---|---|
| ראשית | `-product.webp` | 800×1000 |
| אווירה | `-mood.webp` | 800×1000 |
| מבפנים / פריסת תכולה | `-inside.webp` | 800×1000 |
| אריזה | `-packaging.webp` | 800×1000 |
| שימוש | `-use.webp` | 800×1000 |
| יחס גודל | `-scale.webp` | 800×1000 |
| אירוע | `banner-{occasion}.webp` | 1024×384 |
| תמונה לרשימה | `thumbs/{id}-{role}.webp` | 320×400 |

המזהים הם: `single-malt`, `flask`, `shaker`, `old-fashioned`, `birthday`, `spa`, `honey`, `wine-cheese`, `gin-tonic`, `irish`, `home-bar`, `choc-wine`.

האירועים: `birthday`, `holiday`, `thanks`, `work`, `couple`, `host`. בכל באנר הפריטים משמאל ושטח כהה שקט מימין לכותרת HTML ב־RTL. אין טקסט צרוב בצילום.

כל WebP עד 200,000 בתים, עם צלע ארוכה עד 1024 פיקסלים. לרשימות יש להשתמש בתמונות `thumbs/`, ולהחליף למלאות בגלריית המוצר ובהגדלה. תמונות הרשימה נגזרות מהצילום המלא המתאים ואינן נספרות כצילום נוסף.

## עובדות והמחשה

התכולה נבדקה לפי מערך `contents`, בלי להסיק הרכב משם המארז. לכן אין גבינה בצילומי `wine-cheese`. צילומי `scale` ממחישים יחס לבקבוקים בלבד; אין מידות אריזה שנמדדו. אריזה, חומרים וגימור הם הצעת עיצוב. בצילומי אווירה ושימוש עשויים להופיע קרח, כלי הגשה, בד או משטחי סביבה שאינם תוספת לתכולה. באנרים הם סצנות אירוע, ולא הרכבי מארז חדשים.

התמונות הן הדמיות מקוריות שנוצרו ב־OpenAI image_gen; אינן תיעוד של מלאי שנבדק פיזית. הבקבוקים, הספרים והכרטיסים חלקים ללא מותג קריא. אין אנשים, ידיים או נתונים אישיים.

## מיפוי ובקרה

- `manifest.json`: כל נכס, תפקיד, מידות, משקל, SHA-256 וכיסוי שש הזוויות.
- `mapping.csv`: אותו מיפוי לעיון בגיליון.
- `thumbnails.json`: מלאי תמונות הרשימה ומשקליהן.
- `generation.json`: שמות קובצי המקור החיצוניים של יצירת הדימויים; PNG גולמיים נשארים מחוץ לריפו. ארבע הדמיות המותג ממופות כאן אך נמצאות ב־`north/brand-v1/assets/`.
- [ביקורת ידנית](../../brand-v1/verification/visual-review.csv): הערה וציון לכל 82 הדימויים הסופיים, עם חתימות התאמה.
- [REPORT.md](../../brand-v1/REPORT.md): סבבים, בדיקות, ציונים, משקלים וגבולות האימות.
