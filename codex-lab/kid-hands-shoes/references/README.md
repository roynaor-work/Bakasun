# תמונות היעד

תמונות מקור לא התקבלו בזמן הבנייה. אין כאן תמונה שנוצרה כדי להחליף אותן.

שמרו כאן את תמונות היעד והוסיפו `manifest.json`. כל נתיב יחסי לתיקייה זו. לכל אחד מהמבטים `front`, `side`, `back`, `threeQuarter`, `top`, `bottom` אפשר להגדיר תמונה נפרדת, או חיתוך מתוך גליון לפי `[x,y,width,height]` בפיקסלים של המקור.

```json
{
  "source": "תמונות היעד המקוריות של הילד",
  "views": {
    "front": { "path": "target-sheet.png", "crop": [0, 0, 400, 600] },
    "side": { "path": "side.png" },
    "back": "back.png",
    "threeQuarter": "three-quarter.png",
    "top": "top.png",
    "bottom": "bottom.png"
  }
}
```

הערכים בדוגמה הם להמחשת הסכמה בלבד, ולא חיתוכים שנמדדו. בחרו תמונה שמציגה את היד והנעל במבט הרלוונטי. אל תתייגו חזית נוספת כשלושה רבעים. מבט שאין עבורו מקור נשאר חסר; אין צורך להמציא אותו. `npm run capture` ייצור מחדש את `shots/comparison.png` ויתעד ב־`shots/metrics.json` אילו מבטים זמינים ומהם החיתוכים. תמונה חסרה או חיתוך מחוץ לגבולותיה מכשילים את הריצה.
