# חולצה ושרוולים במשטח רציף, שיער זורם וצורות פנים מעודכנות

הכתף והשרוול עדיין נקראו כחלקים חופפים, ובגב השיער נשאר דפוס של קווצות וגוונים. השינוי מאחד את החולצה והשרוולים גאומטרית, מחליף את מסלולי השיער ואת סדר גווניו בבחירות מאוירות, ומעדכן את שש הבעות הפנים — כולל חיוך שמח סגור ורך. כל השינויים מוגבלים ל־`codex-lab/kid-full/`; 31 העצמות ושלושת clips נשמרו.

**main כבר מכיל שש הבעות בעקבות PR #99.** ההשוואה כאן משתמשת ב־GLB הזה, 906,120 bytes ו־12,610 משולשים, עם אותן הבעות לפני ואחרי. ההרחבה אינה מוצגת כהוספת הבעות ראשונה. התיעוד הקודם ב־NOTES והתוצרים ההיסטוריים נשמרים.

## מדידות ואימות

| גרסה באותה סביבת מדידה | משולשים | שלוש ריצות FPS | חציון FPS | p95 מרבי ms | יחס max/min | קבלה |
| --- | ---: | --- | ---: | ---: | ---: | --- |
| main לפני — GLB עם שש הבעות | 12,610 | 56.40 / 55.20 / 56.59 | 56.40 | 33.30 | 1.0252 | עבר |
| אחרי — מקור mobile | 15,152 | 48.57 / 45.15 / 43.15 | 45.15 | 33.40 | 1.1256 | עבר |
| אחרי — GLB שנמסר ונטען מחדש | 15,152 | 57.00 / 55.79 / 55.00 | 55.79 | 33.30 | 1.0363 | עבר |

התקציב נשאר עד 20,000 משולשים, ≥40 FPS בכל ריצה, p95≤50ms ויחס≤1.15; כל שלוש הדגימות של כל הרצה נשמרו; הספים לא הוקלו. ב־NOTES מתועד גם אימות GLB קודם שעבר40 FPS אך נכשל ביחס היציבות, והרצה חוזרת באותם תנאים. בכל ריצה דפדפן ו־context חדשים, 390×844 CSS, DPR1 ו־buffer234×506, חימום 1s ומדידה 5s עם RAF ו־`gl.finish()`. שלוש התנוחות ושש ההבעות מתערבבות ברצף גם בבסיס.

בטלפון MSAA ו־`preserveDrawingBuffer` כבויים; בצילומי ההשוואה המלאים שניהם פעילים לשני הנכסים. סביבת המדידה היא ANGLE Vulkan עם ICD מפורש של SwiftShader ושלושת ה־workers הרגילים, תחת מכסת שני מעבדים ו־`taskset -c 0,1`. בכל שלוש ריצות המקור אומתו שלושה workers באמצעות CDP ותהליך ה־GPU החי; הוכחת כל הרצות המסירה: **שלושה workers אומתו בכל תשע הריצות הסופיות; קובץ ההגדרות מכיל שתי ירידות שורה אמיתיות, ו־CDP מצביע על תהליך ה־GPU שנבדק ב־/proc/task**. אלה מדידות תוכנה בענן בגודל מסך טלפון, ולא GPU של טלפון פיזי. זמן הבנייה החציוני של המקור **1,723ms**, עם **8 קריאות ציור**; טעינת GLB מודדת פעולה אחרת. שינוי הגדרות הרינדור וה־runtime אינו מאפשר לייחס יחס שיפור לטבלאות ההיסטוריות.

ה־GLB החדש: **1,018,408 bytes**, 31 עצמות, 2 skins, שש מטרות הבעה ושלושה clips. יצירת `exportClips` עברה לפני ניתוק ילדי המקור לסצנת הייצוא: כך נשמרים35 ערוצים בכל clip, כולל ערוץ weights ששויך קודם בטעות לעץ ריק. `stand` שומר שישה אפסים, והבדיקה לא הוקלה. אימות המסירה: **עבר — ללא כישלונות**; Khronos Validator: **0 שגיאות, 0 אזהרות ו־0 הערות מידע**. ב־63 זוגות מקור/טעינה הפרש RGB ממוצע מרבי0.000002894 מתוך255 ו־0% פיקסלים מעל8. קודקודים ונורמלים נבדקים לאחר morph→skin→world, גם במצבי ערבוב.

הבדיקות שומרות את תנאי main ומרחיבות אותם ל־150 מצבי מעבר בכל צפיפות, שש הבעות בשלוש תנוחות ו־21 דגימות clip מקור/GLB, עם שימוש חוזר ב־buffers ו־121 דגימות תנועה לכל clip. בדיקת UI כוללת מקלדת, קטיעת מעבר, שש תמונות תקינות, canvas אחד ו־390px ללא גלילה אופקית. שגיאות דפדפן ובקשות חיצוניות: **0 שגיאות, 0 אזהרות ו־0 בקשות חיצוניות**.

[NOTES](https://github.com/roynaor-work/Bakasun/blob/codex/kid-full-continuous-jersey-morph-review/codex-lab/kid-full/NOTES.md) מתעד לכל טכניקה פרמטרים, סיבה, לפני/אחרי וניסיונות שנכשלו: morph יחסי שאבד באיחוד, ראש מרחף, שיני מסור בפתחי הבגד, שיניים בהפתעה והרצות FPS שלא עברו. מדידות עם קובצי runtime בעלי תווי `\n` מילוליים, או שלושה workers כשהוגדר אחד, נפסלו כמדידות סופיות. worker יחיד נתן33.51/34.40/31.41 FPS ונכשל; שני workers ללא קיבוע נתנו44.20/44.00/51.77 ונכשלו ביחס, ועם קיבוע53.78/48.20/33.00 ונכשלו בריצה השלישית. תצורת שלושה workers מאומתים נמדדה מחדש באותו workload בלי שינוי הספים; מקור עבר כמפורט בטבלה. הדוחות המלאים ב־`shots/metrics.json`, `shots/verification.json`, `shots/glb-validation.json` ו־`shots/software-runtime.json`.

גישה לפיקסלי תמונות היעד: **כן — שלושת קובצי PNG המקוריים מתוך `codex-lab/ref/` נקראו ונצפו ישירות; ההשוואה משתמשת בפיקסלי המקור.**
