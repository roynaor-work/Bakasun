# C3D1: מעבדת ראש ילד

מעבדת לימוד עצמאית בתוך `codex-lab/kid-head/` בלבד, להשוואה בין בניות פרוצדורליות. אין שינוי בקובצי האפליקציה ואין למזג את ה־PR.

כוללת ראש עם לסת מוארכת, עיניים ואישונים, שתי גישות לשיער, toon וקווי מתאר, סיבוב בעכבר, ספריית Three.js מקומית, שישה ניסויי פרמטרים ו־48 צילומים בארבעה מבטים (כולל צילומי ראש בלבד). `npm run measure` מצלם ומודד; נדרשים תמונת יעד וחיתוכי ראש בקובץ target.json.

העבודה חלקית: תמונת היעד לא התקבלה, לכן לא בוצעו סבבי שיפור על סמך IoU, לא נבחרה גרסה מיטבית מדודה, והציונים בדוח הם null. NOTES.md מתעד את הפרמטרים, המגבלות וההמשך הדרוש. אין להציג את התוצר כהתאמה מאומתת לתמונה.

אימות: 334 בדיקות המאגר עברו; צילום 6×4 מבטים ללא שגיאות JavaScript; npm ci עבר; בדיקת מדידה סינתטית מאמתת IoU=1 לזהות וציונים נמוכים יותר לשינויים. הבדיקה הסינתטית אינה מדידת תמונת היעד.
