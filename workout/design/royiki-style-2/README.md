# האימון שלי — 38 האנימציות הנותרות

38 לולאות SVG עצמאיות, באותה שיטת איור והנפשה של [PR 244](https://github.com/roynaor-work/Bakasun/pull/244): דמות סגולה עם מספר 7, קווי מתאר כהים, מכנסיים כהים ונעליים כתומות. השפה החזותית וכלי הציור הועתקו מהתיקייה הקיימת והורחבו כאן. הפוזות וזמני המפתח מגיעים מהקטלוג הקיים.

הבחירה היא ההפרש המדויק בין `workout/js/exercises.js` לבין 12 המזהים ב־`../royiki-style/manifest.json`: יחד יש כיסוי ל־50 מתוך 50 תרגילים, ללא כפילויות. שתי מנות של 19, בסדר הקטלוג. כל SVG עד **60,000 בתים לפני דחיסה**; הגדול ביותר הוא `floor-wall-run.svg`, בגודל **57,064 בתים**.

## צפייה ומיפוי

1. פותחים את [דף התצוגה](index.html). לצפייה דרך שרת מקומי אפשר להריץ מהשורש `python3 -m http.server 8765` ולפתוח `http://localhost:8765/workout/design/royiki-style-2/`.
2. בוחרים הכול, מנה ראשונה או מנה שנייה; אפשר לסנן גם לפי קטגוריה. כפתורי ההרחבה פותחים תצוגה גדולה עם עצירה, גרירת זמן, הורדה והעתקת קוד הטמעה.
3. בודקים את [טבלת מזהה ← קובץ](mapping.md), המופיעה גם בתחתית הגלריה. [manifest.json](manifest.json) כולל גם גדלים, משך, מבט, אביזר, מנה ונתיב poster.

הגלריה מכילה את האיורים בתוך `catalog.js` כדי לפעול גם ללא רשת וללא `fetch`. עצירה נשמרת בכל כרטיס בזמן סינון והגדלה. העדפת הפחתת תנועה מתחילה עם אנימציות עצורות; כל תרגיל כולל גם poster סטטי. כמו בגלריה המקורית, כרטיסים מוסתרים והלשונית המוסתרת מפסיקים לנגן.

## תנועה ואביזרים

- מהירות הדגמה: 60% מקצב הקטלוג, כמו ב־PR 244. ריכוך smoothstep או עקומות Hermite מחזוריות עם משיקים התלויים בזמן.
- 40–96 מרווחי דגימה לכל מחזור; הדפדפן משלים את התנועה ברציפות באמצעות SMIL. הגבלת הדגימות מקטינה במיוחד את תרגילי ההחזקה הארוכים, ללא החלפת הדמות בתמונות או תלות בנגן.
- הדגימה האחרונה זהה לראשונה; סיבובים נסגרים גם מודולו סיבוב מלא. המסגור קבוע לאורך כל הלולאה.
- קיר, שני קירות, מדרגה, הדום וסימוני קפיצה מצוירים לפי `exercise.prop`. כפות הידיים בדחיפות על כיסא מותאמות למשטח ההדום.
- שינוי כיוון במסדרון הופך את הפנים והנעליים לפי `face`, והמספר 7 נשאר קריא.
- העומק של פוזות סיבובי הידיים ושל קיפול הברכיים לחזה מוקרן למישור האיור, כדי שהתנועה תהיה ברורה בדו־ממד.
- התאמות לדמות המלאה: מגע סוליה בהרמת עקבים ובקפיצות קפיץ, מגע ברכיים בשכיבות סמיכה על הברכיים, ומיקום הראש בשכיבות סמיכה באוהל.

כל אנימציה כוללת את האיור והתנועה שלה, ללא JavaScript, תמונות, גופנים, ספריות או בקשות חיצוניות. הרקע שקוף. אפשר להטמיע ב־`img`, ב־`object` או כ־SVG בתוך דף. בהטמעת כמה עותקים באותו DOM יש להקצות מזהים ייחודיים; הגלריה עושה זאת אוטומטית.

## בנייה ובדיקה

```sh
node workout/design/royiki-style-2/tools/build.mjs
node workout/design/royiki-style-2/tools/build.mjs --check
node workout/design/royiki-style-2/tools/verify.mjs
python3 workout/design/royiki-style-2/tools/browser-check.py
```

Node מספיק לבנייה ולבדיקת התקינות. בדיקת הדפדפן דורשת Python Playwright, Pillow ו־Chromium (`/usr/bin/chromium`, או `BAKASUN_BROWSER`), ומפעילה שרת מקומי זמני בעצמה.

תוצרי האימות ב־`verification/`: דוח תקינות, דוח דפדפן, תצוגות מחשב ונייד וגיליונות של 8 פריימים לכל תרגיל, בנפרד לכל מנה. נבדקים כיסוי מדויק, בנייה דטרמיניסטית, גודל גולמי, סגירת כל תכונת אנימציה, המשכיות מהירות במפתחות, 304 פריימים, 1,216 דגימות מסגור, הטמעה כ־`img`, סינון בשתי המנות, שליטה בזמן, הורדה, מזהים ייחודיים והפחתת תנועה. התוצאות המדויקות ומגבלות הסביבה מופיעות בדוחות.

הבדיקה היא ב־Chromium; בדיקה בטלפון וב־Safari/Firefox עדיין אינה מתועדת. ניווט `file://` עשוי להיחסם במדיניות הדפדפן המנוהל; במצב כזה הדוח מציין זאת ובודק גלריה מנותקת מרשת עם אותם קבצים מקומיים כתגובות Playwright.

התיקייה מספקת נכסים ותצוגה לביקורת. חיבור למסכי האימון מנוהל בנפרד בהתאם לחלוקת העבודה בחדר הבקרה.

בדיקות המאגר: `npm test` עבר — 3,170 בדיקות עברו, 0 נכשלו ו־47 בדיקות opt-in דולגו לפי הגדרות הפרויקט. ראו [דוח מסכם](verification/regression.json).
