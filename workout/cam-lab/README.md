# מעבדת מצלמה — סבב 2

ניסוי עצמאי. כל השינויים מוגבלים ל־`workout/cam-lab/` ול־`tests/`. אין שינוי באפליקציה, בקטלוג 50 התרגילים, בתוכניות, ב־service worker או בקוד הענן. הוראות סבב 1 והערותיו נקראו לפני המימוש; נשמרו ההקלות בעמידת ההתחלה, מרווחי הספים, ההחלקה וסובלנות הזיהוי ביחיד.

## פתיחה והצבה

לאחר מיזוג ופריסת GitHub Pages:

```text
https://roynaor-work.github.io/Bakasun/workout/cam-lab/
```

הכתובת אינה תצוגה מקדימה של ענף ה־PR. לפני מיזוג משתמשים בשרת HTTPS שמגיש את ענף הבדיקה, או ב־localhost במחשב.

1. בוחרים גיל/גובה הילד, תרגיל ומשתתפים. „לבד” והקלטת שלד כבויה הן ברירות המחדל. מאשרים מצלמה בלבד, ללא מיקרופון.
2. מניחים מכשיר יציב על הרצפה או כיסא, בלי הטיה לצד. מתחילים בכ־2–3 מטר ומכוונים לפי המסגרת: גוף שלם ומרווח לתנועה. בעמידה אפשר לכוון מעט למעלה; לתרגילי רצפה משתמשים במצלמה נמוכה ובמבט צד.
3. עומדים מול המצלמה לבדיקת ההצבה. גוף קטן מדי מקבל „קרבו את המכשיר”. שיפוע עקבי של כתפיים, אגן וקרסוליים במשך 800 מ״ש מקבל „ישרו את המכשיר ועמדו זקוף לבדיקה”. זה אומדן חזותי של הטיה לצד; אינו מד זווית של המכשיר ואינו מזהה באופן אמין נטייה קדימה/אחורה. אין בקשת הרשאה לחיישנים.
4. בתרגילי רצפה: לאחר 1.2 שניות בעמידה ברורה עוברים לעמדת ההתחלה במבט צד. בשניים חייבים קודם להשלים זיהוי בעמידה. בשכיבות סמיכה מתחילים בזרועות ישרות; בגשר מתחילים באגן למטה.
5. מחכים 1.2 שניות בעמדת ההתחלה עד שהכפתור זמין. לוחצים „מתחילים לספור”, מבצעים בנחת ומסיימים ב„סיום ותוצאה”. המוכנות נשמרת בלחיצה כפי שתוקן בסבב 1.
6. סיום, עצירה, מעבר לרקע ויציאה משחררים מצלמה ו־worker. התוצאות והקלטת השלד הפעילה נשארות בזיכרון הדף בלבד. „תרגיל נוסף” מכבה שוב את בחירת ההקלטה; תחילת ניסיון חדש מחליפה את ההקלטה הקודמת, ולכן מורידים אותה קודם.

## אבא ואני

ה־worker מקבל `numPoses: 2` ומחזיר את כל השלדים. לכל אדם `RepCounter`, מוכנות, ספירה, פסילות ואבחון משלו. הילד בירוק ואבא בכחול; מופיעים שני מונים ותווית עצירה לכל משתתף.

הזיהוי הראשוני דורש שני אנשים עומדים 1.2 שניות באותו מרחק, הפרש גובה וגם אורך גו+רגל של לפחות 18%, הפרש קרסול אנכי ≤8% תמונה ומרכזי גוף נפרדים. הנמוך הוא הילד. זו השוואת גובה בתמונה, ולכן אנשים בעומקים שונים אינם בסיס אמין לזיהוי; גם הפרש קרסול דומה אינו מוכיח אותו עומק.

לאחר הכיול התוויות קבועות. ההתאמה משתמשת במרכז אגן ובסכום אורכי עצמות צד שלם בתמונה (עם תיקון יחס ממדים), ללא תלות בסדר תשובת המודל או בגובה הנוכחי בכריעה. שינוי אורך מותר עד 22%; תנועה עד 0.30 בגובה התמונה לפריים; ההתאמה לגודל חייבת להיות טובה מהתאמה לאדם השני ב־0.04 לפחות. מרכזים במרחק <0.18 או פער עלות התאמות <0.15 גורמים להמתנה. מצב חסר נשמר לכל הניסיון ולא מוחלף באדם שנותר.

כשאדם חסר, נחתך או זיהויו אינו ברור: המחזור הפעיל שלו מתבטל **מיד**, בלי סובלנות 300 מ״ש של היחיד; המונה שלו נשמר ונדרשת עמדת התחלה מחדש. האדם השני ממשיך אם זיהויו ברור. בחפיפה/זהות לא ברורה שני המונים מחכים. החזרה היא למקום הקודם; חזרה רחוקה ממנו יכולה לדרוש ניסיון חדש. אין כאן זיהוי פנים או הבטחה לזהות ביומטרית — מעבר עומק גדול, גוף דומה או אדם חדש בגודל דומה עדיין דורשים בדיקה אמיתית.

## הקלטת שלד ובדיקות תנועה אמיתית

הקלטה כבויה כברירת מחדל. מסמנים לפני המצלמה, או לוחצים „התחלת הקלטת שלד” לפני הספירה. הפעלה ידנית מחזירה לכיול כדי שהקובץ יכלול גם את זיהוי שני האנשים. אפשר לעצור הקלטה ולהוריד אותה במהלך הניסיון או בתוצאה. ב־6000 פריימים נעצרת ההקלטה ומופיעה הודעה; אין קיטוע שקט או גלגול פריימים.

הפורמט `cam-lab-skeleton`, גרסה 1, כולל: תרגיל, מצב, יחס ממדים, ספים, `countStartMs`, ולכל פריים זמן יחסי ורשימת שלדים. לכל שלד עד 33 נקודות תמונה ועד 33 נקודות עולם; בכל נקודה רק `x/y/z/visibility/presence` מספריים. אין שמות, גיל/גובה גולמיים, פיקסלים, קול, תמונה או וידאו. הספים משמרים את תנאי הניסוי; הם נגזרים מהגיל/גובה, ולכן זה אינו הבטחה לאנונימיות. המידע נשאר בזיכרון והורדת JSON היא הפעולה ששומרת קובץ במכשיר.

`replayRecording` ב־`recording.mjs` מפעיל מחדש את ההתאמה והספירה. הציפיות אינן נלקחות מהמונה בקובץ, אלא מהספירה הידנית של הצופה. שומרים הקלטות אמיתיות **מחוץ למאגר הציבורי**, בתיקייה מקומית, יחד עם `manifest.json`:

```json
[
  { "file": "squats-pair.json", "counted": [5, 4] },
  { "file": "push-ups.json", "counted": [3], "rejected": [1] }
]
```

בשניים סדר הציפיות הוא תמיד ילד ואז אבא. להרצה עם הקבצים המקומיים:

```sh
CAM_LAB_RECORDINGS_DIR=/absolute/path/to/private-recordings node --test tests/*.mjs
```

בלי המשתנה אין קורפוס אמיתי והבדיקות המדומות בלבד רצות. לא סופקו הקלטות אמיתיות בסבב הזה; לא נטען שנבדקו תנועות אמיתיות.

## פרטיות, נכסים וביצועים

- אין `MediaRecorder`, צילום סטילס, העלאת קבצים, analytics, `localStorage` או `IndexedDB`. אין ייבוא מהאפליקציה החיה. הקלטת נקודות היא opt-in מפורש בלבד.
- אין CDN. CSP מגביל טעינות וחיבורים לאותו origin. מודל lite float16 v1 וחבילת MediaPipe 0.10.32 נשארו ללא שינוי, CPU, `VIDEO`, ללא segmentation.
- `ImageBitmap` בודד מועבר ל־worker ונסגר ב־finally; אין תור תמונות. עד 640×480 ו־24 FPS במצלמה, עיבוד רק לפריים חדש. בשניים צפוי יותר עומס; אין הבטחת FPS בטלפון.
- קול רק `he` עם `localService: true`, בקצב 0.85 ובהפרש 6 שניות. משוב שגיאה ממתין לחלון הקול ואינו נדחק על ידי הודעת „מוכן”. בלי קול מקומי ההדרכה בכתב.
- לוג הביצועים נפרד מהקלטת השלד: עד 900 פריימי ביצועים, ללא נקודות. ביחיד גרסה 2; בשניים גרסה 3 עם אבחון וספירה נוספים לאבא. יש אבחון גם ל־0 ספירות.

## הרצה ובדיקות

אין build ואין צורך ב־npm install. משורש המאגר:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

```text
http://localhost:8765/workout/cam-lab/
```

```sh
node --test tests/*.mjs
```

בדיקות המעבדה בשורש מריצות גם את הרגרסיות הישנות ב־`workout/tests/`, ללא שינוי בהן. בדיקת שלמות הנכסים, מתוך `workout/cam-lab/`:

```sh
sha256sum -c assets.sha256
```

## מה נבדק ומה לא

נבדקו רצפי נקודות מדומים לכל ארבעת התרגילים: מחזור מלא, שהייה ממושכת, חלקי, טעות צורה, פריים יעד בודד, היעדר מנוחה, היעדר נקודות עולם, אובדן זיהוי, רעד ו־5 FPS. במכרעים נבדקים החלפת צד, שתי ברכיים כפופות יחד ועומק לא ברור. בזוג נבדקים החלפת סדר המודל, ספירה נפרדת, יציאה וחזרה, חפיפה, גובה דומה, מעבר הדרגתי לרצפה ואדם שנותר ועובר למקום האחר. גם שחזור JSON, סינון שדות, מגבלת ההקלטה, הנחיות הצבה, תורי קול וזרימת UI עם DOM/worker מדומים נבדקו.

בדיקת Chromium headless עם מצלמה מדומה ללא אנשים בודקת טעינת worker/מודל/WASM מקומיים גם עם `numPoses: 2`, הורדת שלד של ההצבה, תוצאה, שחרור מצלמה ורוחב 390px. טיפול הסיום מופעל ישירות בבדיקה זו, משום שאין אדם במצלמה המדומה והמוכנות אינה מושגת; היא אינה בדיקת ספירה או זיהוי על אדם. בדיקת DOM נפרדת בודקת מוכנות וספירה עם נקודות מדומות.

לא נבדקו: ילד/אבא אמיתיים, דיוק זוויות/עומק/זהות של MediaPipe, קורפוס תנועה אמיתית, הסתרות ועומקים משתנים בבית, נטיית מצלמה קדימה/אחורה, Safari/iOS/Android, קול עברי בפועל, סוללה/חום וביצועי טלפון חלש. ספי הצורה והגובה אינם אבחנה רפואית או זיהוי גיל. צריך להשוות את הניסיון בטלפון לספירה ידנית לפני הסתמכות על המונה.
