## סיבת העצירה ומה חסר

בהתאם להנחיה לעצור אם אי אפשר להפיק עברית אנושית באיכות המבוקשת,
לא הופק שמע ולא נוספו קובצי WAV חלופיים או קובצי דמה.

נבדקו תיאורי כלי יצירת הדיבור הזמינים בסשן. קיימים כלי TTS,
אך בבדיקה זו לא אומתו קול עברי טבעי המתאים לטון ולקצב המבוקשים,
מקור קול שאינו מבוסס על אדם אמיתי, וזכויות מתועדות המתאימות
לדרישת מקוריות או CC0 לכל קובץ. לא נשלחה בקשת הפקה, לא נבדקה
דוגמת שמע בהאזנה, ואין כאן קביעה שכלי TTS כלשהו אינו תומך בעברית.
אין בסיס להצהיר שהפקה באמצעות הכלים שנמצאו תעמוד בכל הדרישות.

להמשך חסרים מקור קול מתועד העומד בתנאים האלה, דוגמה שעברה
בדיקת האזנה בעברית מבחינת הגייה, ניקוד, חום, הפסקות וקצב,
ואז הפקה ובדיקת כל 44 המשפטים. מדידות פורמט ועוצמה לבדן אינן
מוכיחות שהקול טבעי ונעים.

הכלי הקיים הורץ משורש המאגר:

```sh
node workout/tools/voice-missing.mjs
```

הפלט הראשון בפועל:

```text
0/44 מוקלטים, חסרים 44
```

הכלי הזה מסתיים בקוד 0 גם כשיש חסרים; אין לפרש זאת כהצלחה.
בנוסף הורצה בדיקת Python עם `wave.open` על כל 44 השמות
שברשימה, בלי עצירה בכשל הראשון: 44 חסרים, 0 נטענו.
הבדיקה מסתיימת בקוד 1. אפשר לשחזר משורש המאגר:

```sh
python3 - <<'PY'
import re
import wave
from pathlib import Path

root = Path('workout/snd/voice')
rows = re.findall(r'^\| `(copy-[^`]+)` \|[^\n]*\| `([^`]+)` \|$',
                  (root / 'LINES.md').read_text(), re.M)
assert len(rows) == 44
loaded = missing = invalid = 0
for ident, filename in rows:
    assert filename == ident + '.wav'
    try:
        with wave.open(str(root / filename), 'rb') as audio:
            assert audio.getnchannels() == 1
            assert audio.getframerate() == 44100
            assert audio.getsampwidth() == 2
            assert audio.getcomptype() == 'NONE'
            assert 0.8 <= audio.getnframes() / audio.getframerate() <= 6
            data = audio.readframes(audio.getnframes())
            assert len(data) == audio.getnframes() * 2
        loaded += 1
    except FileNotFoundError:
        missing += 1
        print('MISSING', filename)
    except (wave.Error, EOFError, AssertionError) as error:
        invalid += 1
        print('INVALID', filename, str(error))
print(f'expected={len(rows)} loaded={loaded} missing={missing} invalid={invalid}')
raise SystemExit(0 if loaded == 44 and not missing and not invalid else 1)
PY
```

בדיקה זו מאמתת פתיחה, פורמט, משך וקריאת הנתונים בלבד; היא אינה
בודקת LUFS, true peak, קליפינג, שקט או טבעיות. בדיקות אלה נשארו חסומות.
