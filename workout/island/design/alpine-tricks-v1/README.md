# תנועות סקי · alpine-tricks-v1

[תצוגה מקדימה](preview.html) בגודל 844×390, [קטלוג](catalog.json), [GLB](alpine-tricks.glb), [דוח המסירה](REPORT.md) ו־[תנאי שימוש](LICENSES.md).

ה־GLB מכיל 12 תנועות ו־42 גשרי כניסה ויציאה מול `ski_ready` ו־`glide`. כל העקומות המשתנות שומרות את מלוא דגימות ה־30Hz; תנוחות קבועות מקודדות בשני מפתחות קצה זהים. הערוצים מיוצאים כ־glTF 2.0 `CUBICSPLINE`, עם נגזרות משותפות בכל מפתח. השלד שומר על שמות, סדר והורות 18 העצמות של `Motion2Canonical18`; המקלות הם אביזרים ולא עצמות נוספות. יחידות: מטרים, ‎+Y למעלה, ‎+Z קדימה.

| מזהה | תנועה | משך בשניות |
|---|---|---:|
| `ski_ready` | מוכנים לזינוק | 2.4 |
| `glide` | גלישה ישרה | 2.4 |
| `turn_left` | פנייה שמאלה | 3.2 |
| `turn_right` | פנייה ימינה | 3.2 |
| `brake` | בלימת מחרשה | 3.6 |
| `jump` | קפיצה, שיא ונחיתה | 3.6 |
| `air_180` | סיבוב 180 באוויר | 4.0 |
| `air_360` | סיבוב 360 באוויר | 4.8 |
| `perfect_landing` | ספיגת נחיתה והתייצבות | 2.8 |
| `soft_fall_recover` | נפילה רכה, החלקה וקימה | 7.2 |
| `victory` | הרמת ידיים לניצחון | 4.0 |
| `gate_exit` | עמידה ביציאה מהשער | 2.8 |

כל גשר נמשך 1.2 שניות ונקרא `bridge__<from>__<to>`. ב־`catalog.json` מופיעים מזהי הקליפים, חלונות מגע, אירועים, גשרי החיבור וקישור לגיליון של שמונה פריימים לכל תנועה וגשר. נקודות המגע הן קשירה, חרטום ועקב במשטח הריצה של כל מגלש.

## צפייה

1. מפעילים שרת משורש הריפו:

   ```sh
   python3 -m http.server 8765
   ```

2. פותחים את [התצוגה המקומית](http://localhost:8765/workout/island/design/alpine-tricks-v1/preview.html), בוחרים תנועה או גשר, ומפעילים ניגון. אפשר לגרור את פס הזמן, להאט ולבחור מבט צד.
3. לביקורת פריים מסוים אפשר להשתמש בפרמטרים `?clip=air_360&time=2.4&view=side`. הקישור לגיליון מציג שמונה פריימים מן ה־GLB הסופי. ספריות התצוגה הן העותקים המקומיים הקיימים ב־`../../vendor/`; אין תלות ב־CDN.

## חיבור עתידי למשחק

החבילה מוסיפה נכסים בלבד. מנוע המשחק מספק את התקדמות הגולש במורד ואת התאמתו לרמפה ולקרקע. הפניות הן פוזות של עומס והטיית מגלשיים; שינוי כיוון הנסיעה שייך למנוע המשחק.

מפעילים את התנועה, אחריה גשר מתאים, ואז את קליפ היעד מזמן אפס. כאשר גשר מכיל היסט שורש, צריך להעביר אותו ל־actor המארח בסיום הגשר ולבצע איפוס מקומי באותו עדכון, תוך שמירת תנוחת העולם:

| גשר יוצא | סיבוב המועבר למארח | הזזה המועברת למארח |
|---|---:|---|
| מ־`air_180` | ‎π סביב Y | `[0, 0, 0.026]` מטר |
| מ־`air_360` | ‎2π, שקול לכיוון המקורי | `[0, 0, 0]` |
| מ־`soft_fall_recover` | 0 | `[0, 0, 0.45]` מטר |
| יתר הגשרים | 0 | `[0, 0, 0]` |

ההזזה נתונה במערכת הצירים של ה־actor בכניסה לקליפ; מסובבים אותה לפי כיוון המארח לפני שמוסיפים למיקום העולם. משתמשים בערכים של `headingOffsetRadians` ו־`translationOffsetMeters` בקטלוג. לאחר 180 הנחיתה היא בגלישה לאחור; אין להחזיר את הסיבוב בכוח כשהמגלשיים על השלג. ההחלקה בנפילה היא תנועה מכוונת של 45 ס״מ שנשמרת בנכס.

## שחזור ובדיקות

הפקודות הבאות מורצות משורש הריפו. תלויות המחבר מותקנות מחוץ לריפו:

```sh
npm install --prefix /tmp/alpine-tricks-tools --cache /tmp/alpine-tricks-npm-cache --no-audit --no-fund @gltf-transform/core@4.2.1 @gltf-transform/extensions@4.2.1 draco3dgltf@1.5.7 gltf-validator@2.0.0-dev.3.10 sharp@0.34.5
```

```sh
node workout/island/design/alpine-tricks-v1/tools/build.mjs
```

```sh
node workout/island/design/alpine-tricks-v1/tools/qa.mjs
```

```sh
node workout/island/design/alpine-tricks-v1/tools/measure.mjs
```

```sh
node workout/island/design/alpine-tricks-v1/tools/render-preview.mjs --chromium /usr/bin/chromium
```

כלי הצילום משתמש ב־Playwright המותקן בסביבה ב־`/opt/codex/runtimes/cua/lib/node_modules/playwright/`. בדיקות התנועה מפענחות את ה־GLB הסופי ב־120Hz, כולל בין מפתחות, ובודקות מגעי סקי, מבנה, לולאות וקצות גשרים; בדיקת הגאומטריה המשוקללת מתבצעת גם ב־30Hz. פלטן ב־[verification/qa.json](verification/qa.json). סטייה במגע נמדדת מול מסלול הציוד המכוון, בנפרד מהתקדמות או מסיבוב מחרשה מכוון.

`measure.mjs` שולף ל־`/tmp` את `motion-qa-v1` בקומיט המוצמד `5eb4f093bc22523ee417a7f2345c3b813bffba24`, ומשתמש בקורא ה־GLB ובנוסחאות המקוריים ללא שינוי. מתאם הקלט מתעד את פוזות הייחוס ואת מדידת הכיוון ההפוך אחרי 180. התוצאות נמצאות ב־[דוח הכלי](verification/motion-qa/report.html), [JSON](verification/motion-qa/report.json) ובדוח המסירה. ציוני הכלי הם מדידה הנדסית ואינם מחליפים ביקורת על הפריימים או בדיקת טלפון.
