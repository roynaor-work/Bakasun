## אימות

בעותק נקי עברו **107 בדיקות**. 12 בדיקות חדשות ו־95 בדיקות קיימות. הסקריפט סירב להחיל את הטלאים על עותק עם שינויים.

- **מילון**. 1,972 מפתחות מהבסיס נשמרו, 3 נוספו, וסך הכול 1,975. הבדיקה דוחה כפילויות, ערכים חסרים ושינויים במשתני התבנית. היא בודקת גם את מבנה שלושת קובצי השליטה ואת תקינות רשימת הקבצים הלא מקוונת.
- **טקסט מערכת**. נסרקו 509 מודולי JavaScript ו־79 קובצי JSON, HTML ו־CSS. בטווח הזה לא נמצאו כתב ערבי או סימני קריאה בטקסטי המערכת, ולא נמצאו הפניות מילוליות חסרות למילון בקריאות התרגום שנבדקו.
- **הקראה**. נבדקו 3,360 שאלות ב־4 תחנות וב־7 רמות, כולל 30 תבניות, רמזים, תשובות ומשובים. הבדיקה בודקת ניקוד ברמת המילה, שוללת ספרות גולמיות, ומשווה גם את מזהי השאלות ואת הפתרונות לבסיס. נבדקו מספרים מ־0 עד 100 והתאמת כמויות בסיום סבב.
- **ציוד והורדה**. כפתור שדרוג עם מחיר בן שש ספרות נשאר בשורה אחת ב־Chromium ב־360×800 וב־844×390, ושם הפריט הארוך נכנס לכרטיס. הוזרקה שגיאת הורדה לשתי החלוניות ונבדקו הודעת הילד והדוח להורים.
- **סביבת בדיקה**. בדיקות Node רצות עם `--jitless`. בדיקת Chromium אימתה ש־`WebAssembly` אינו חשוף. הטלאים מכילים קובצי טקסט בלבד.

בדיקת הניקוד האוטומטית מכסה את הדגימה ואת תבניות ההרכבה. ההיגוי במנוע הקול של מכשיר אמיתי טרם נבדק. סריקת טקסטי המערכת מכסה מחרוזות שמסופקות עם האפליקציה. שמות שמשתמשים מזינים, אבחון טכני חיצוני וטקסט שמוטבע בנכס אינם חלק מהסריקה. ב־`data/config.json` של הבסיס קיימת כפילות קודמת של `wingWidth`. בדיקת הכפילויות חלה על המילון ועל קובצי JSON שהטלאים משנים.

   ```bash
   workout/island/design/strings-patches-v1/apply.sh --check
   ```

2. כדי להכין עותק לבדיקה ידנית, יוצרים עותק עבודה נקי ומפעילים עליו את החבילה. הסקריפט מאמת את הטלאים בעותק זמני לפני שהוא מחיל ומוסיף אותם ל־staging בעותק שבחרתם.

   ```bash
   git worktree add --detach ../bakasun-strings-review 9e95482fbe1887856cbca69fd43c1c77ba62cff4
   workout/island/design/strings-patches-v1/apply.sh --apply ../bakasun-strings-review
   ```
