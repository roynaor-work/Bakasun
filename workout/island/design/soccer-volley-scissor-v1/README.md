# soccer-volley-scissor-v1

שישה קליפים על השלד הקנוני בן 18 העצמות, 30 פריימים בשנייה, במטרים: עף ימין ושמאל, מספרת לאחור, נחיתה על הגב וקימה, הכנה לנגיחה ונגיחה ניטרלית בקפיצה. זו חבילת נכסים לסקירה ולחיבור; קוד המשחק הקיים לא השתנה.

1. פותחים את [preview.html](preview.html) דרך שרת HTTP, למשל שרת הפיתוח של הריפו.
2. בוחרים קליפ, זווית ומהירות; כפתור המגע קופץ לפריים המסומן. ברצף מספרת צופים בבעיטה ובנחיתה יחד.
3. בודקים את [ששת גיליונות הפריימים](sheets/manifest.json), [הקטלוג](catalog.json) ואת [הדוח](REPORT.md).

## חוזה נתונים וחיבור

`catalog.json` נמצא בשורש החבילה; `asset` יחסי אליו. כל GLB עצמאי וכולל גאומטריה, skin, חומרים ואנימציה יחידה. `motions.json` מכיל את הפוזות לבנייה ולשחזור. הערוצים הם סיבובי `xyzw` מקומיים להורה ותרגום Hips; Root קבוע, בלי תרגום שחקן אוטומטי. צירים: ‎+Y למעלה, ‎+Z קדימה, ‎+X שמאל אנטומי.

גובה הכדור מתייחס למרכזו מעל המגרש **בזמן המגע החזוי**: עף 0.5–1.2 מ׳, נגיחה 1.5–2.2 מ׳, מספרת 1.8–2.4 מ׳. בכדור יורד אפשר לתזמן נגיחה מוקדמת או להמתין לעף נמוך; אלה חלונות התאמה לתנועה. אין שינוי גודל של השלד כדי לכסות את כל הטווח. הצרכן בוחר וממקם את השחקן לפי מסלול הכדור. `contactGeometry` מפריד בין נקודת המשטח, מרכז הכדור והמיקום ביחס לאגן; אירועי המגע נמצאים בדיוק ברשת 30Hz. בקליפ הכנה ובקליפ נחיתה אין מגע בכדור.

`player.mjs` משתמש באותה מערכת הגשרים של soccer-kicks-v2: ‏`sampleMotion`, ‏`poseVelocity`, ‏`makeBridge`. מעבירים את הפוזה והמהירות המוצגות כרגע, מקבעים את שלב היעד למשך הגשר, וממשיכים ממנו לפי `resumeTargetTime`. ה־API מקבל פוזות קנוניות; טעינת GLB, החלתן על שלד, אירועי המשחק ותנועת השחקן הם באחריות הצרכן. התצוגה מנגנת ישירות את ערוצי ה־GLB באמצעות AnimationMixer.

סוף המספרת מתחבר ישירות לתחילת הנחיתה. אין לעבור מן האוויר לעמידה. לאחר קליפ הנחיתה אפשר לגשר לעמידה או לריצה. גם הכנה לנגיחה מתחברת לנגיחה ברצף המוגדר בקטלוג. בדיקות הגשרים כוללות את ייחוסי העמידה והריצה המקוריים של kicks ושל locomotion-v2.

## שחזור

מתוך שורש הריפו, מריצים לפי הסדר את הקבצים הבאים באמצעות Node:

```sh
node workout/island/design/soccer-volley-scissor-v1/source/author.mjs
node workout/island/design/soccer-volley-scissor-v1/source/bake.mjs
node workout/island/design/soccer-volley-scissor-v1/source/verify.mjs
node workout/island/design/soccer-volley-scissor-v1/source/verify-transitions.mjs
```

בדיקת הסכמה משתמשת ב־`gltf-validator@2.0.0-dev.3.10` המותקן מחוץ לריפו: מגדירים `GLTF_VALIDATOR_MODULE` לנתיב המודול ומריצים `source/validate-assets.mjs`. כלי הצילום `source/capture.mjs` משתמש ב־Playwright/Chromium וב־Pillow. הדוח מתעד את ההרצות שנעשו בפועל ואת מגבלות המדידה.
