## שפה חזותית וטקסט

הפלטה מבוססת על `../ui-kit-v2/tokens.json`: דיו כהה `#173E40`, טורקיז `#24786D`, מנטה `#B9DDC8`, חול `#F8EED9`, קורל `#EB947F`, זהב `#E9BA57` ונייר `#FFFCF4`. נוספו אדום וירוק פעילים לקריאות של אות הזינוק. קו חיצוני בסיסי: 8 פיקסלים במערכת 512, קצוות מעוגלים, צל מדורג ושלג בהיר.

**אין מילים, אותיות, ספרות או יחידות מהירות צרובות בתמונות הנכסים.** גם הספרות בשעון, מקומות הדירוג וספירת הזינוק הן טקסט חי. דף התצוגה משתמש בעברית ובכיווניות RTL; מספרים וזמנים מבודדים בכיווניות LTR. מיקום הגרפיקה נשאר בקואורדינטות שמאל/מעלה גם כשהטקסט עברי. אין להפוך את התמונות אוטומטית עם כיוון המסמך.

## חוזה הרכבה

- כל תמונה היא ריבוע מלא. **אין לחתוך שוליים שקופים בפריימים**, כדי לשמור על עיגון יציב.
- קואורדינטות ואזורי טקסט במניפסט הם במערכת 512, ממקור שמאל עליון. ב־1024 מכפילים קואורדינטות פי שניים. העיגון עצמו מנורמל לטווח 0–1.
- הצבה על קנבס: `drawX = worldX - anchorX * drawWidth`; באופן זהה לציר Y. שכבות מד המהירות וההתקדמות חולקות את אותו מלבן ציור; הצירים הנוספים הם במערכת המקומית של המלבן.
- האורות מצטברים בשלושת השלבים האדומים, שנייה לכל שלב. בירוק שלושת האדומים כבים. ירוק נמשך 500 מ״ש בהדגמה, ולאחר מכן נשאר דולק בריצה.
- פתיחת המוט מתחילה עם הירוק, אורכת 460 מ״ש ומסתיימת בהחזקת הפריים הפתוח. ציר המוט `[100,390]` זהה בכל הפריימים.
- לולאת דגל: 6 פריימים × 120 מ״ש, סך הכול 720 מ״ש. משתמשים בעיגון תורן קבוע.
- מחוג: סיבוב סביב `[256,300]`, מזווית ‎−120° עד ‎120°. הנוסחה המלאה במניפסט. הערך המספרי והיחידה מוצגים באזורים שהוגדרו בבסיס.
- התקדמות: מילוי נחתך מלמטה כלפי מעלה. הסמן נע על ציר Y מ־423 ל־121; תחילת מסלול בתחתית וסיום למעלה. המסילה יכולה לשבת בכל צד של המסך בלי להפוך אותה.
- תנועה מופחתת: האורות והספירה שומרים על תזמון; השער עובר ישירות לפתוח בירוק, והדגל נשאר בפריים הראשון.

## צפייה ושחזור

1. פותחים את [דף התצוגה](preview.html) דרך שרת קבצים מקומי. אפשר להריץ משורש המאגר:

   ```sh
   python3 -m http.server 8765 --bind 127.0.0.1
   ```

2. עוברים לכתובת המקומית:

   ```text
   http://127.0.0.1:8765/workout/island/design/alpine-start-lights-v1/preview.html
   ```

3. מפעילים את ההדגמה. התוצאה הצפויה: שלושה שלבים אדומים עם ספירה, ירוק ופתיחת מוט, התקדמות ומהירות, דגל ותוצאות. אפשר גם לבחור מצב, רזולוציה ורקע ולבדוק ידנית את הסמנים.

אין תלויות חיצוניות בזמן צפייה ואין פניות לשירותים או שימוש באחסון. `source/catalog.js` נוצר מהמניפסט כדי להימנע מקריאת JSON בזמן התצוגה.

כלי הבנייה דורש Node.js ו־sharp; כלי בדיקת הדפדפן דורש גם Playwright ו־Chromium. מתקינים את התלויות מחוץ לחבילת המסירה או משתמשים בסביבה שבה הן קיימות. אין צורך בהן במשחק:

```sh
node source/build.mjs
node source/verify-assets.mjs
node source/verify-browser.mjs
```

הפקודות מורצות מתוך תיקיית הערכה. אפשר להפנות להתקנות חיצוניות באמצעות `SHARP_MODULE`, `PLAYWRIGHT_MODULE` ו־`CHROMIUM_PATH`. הבנייה מפיקה גם את המניפסט ואת קטלוג התצוגה. הסמל המקורי נשמר לשחזור; הייצוא שלו כולל שול שקוף של 16/32 פיקסלים.

פירוט הרגרסיה: [verification/repository-tests.json](verification/repository-tests.json). בדיקת האימון `tests/workout-royiki.test.mjs:91` דורשת את Chromium headless של Playwright, גרסה 1234, שאינו מותקן בנתיב שהיא משתמשת בו. היא פותחת שרת לפני ניסיון פתיחת הדפדפן ומשאירה אותו פתוח כשהפתיחה נכשלת. לאחר ששאר קובצי הבדיקה סיימו, תהליך הבדיקה התקוע הופסק כדי לאפשר לסיכום הריצה לצאת. הכשל שוחזר בנפרד באותו קובץ בדיקה קיים, עם גבול 20 שניות; [פלט השחזור](verification/repository-test-failure.txt) נשמר. בדיקות החבילה משתמשות ב־Chromium המותקן בסביבה ועברו. אין שינוי בתשתית הבדיקות הקיימת במסגרת מסירה זו.

התצוגה נבדקה דרך HTTP מקומי. פתיחת `file://` ישירה לא אומתה, מפני שמדיניות הדפדפן המנוהל חוסמת ניווט כזה. לא בוצעה בדיקה בטלפון פיזי ולא בוצע חיבור של הערכה למנוע המשחק. תוצאות ההדגמה הן סינתטיות ואינן נתוני משתמש.
