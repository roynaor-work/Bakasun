כל צליל מסופק כ־OGG Vorbis וכ־MP3, במונו וב־44,100 הרץ. עוצמת יעד משולבת: ‎-16 LUFS לפי EBU R128, סטייה מותרת עד 0.15 LU לאחר פענוח כל פורמט; שיא אמיתי עד ‎-1 dBTP. אין נרמול בעוצמת הנגן. בדיקת המונו משתמשת ב־`dual_mono=false`; מדידת מונו מושמע בשני ערוצים יכולה להציג ערך אחר.

כל המקורות הם אוסצילטורים ורעש פסאודו־אקראי עם seed קבוע; לא נעשה שימוש בהקלטות, דגימות חיצוניות או שירות ליצירת אודיו. כל התוצרים המקוריים בתיקייה זו מוקדשים לנחלת הכלל תחת CC0-1.0; ראו [LICENSES.md](LICENSES.md).

## האזנה

1. פותחים את [preview.html](preview.html) בדפדפן דרך שרת HTTP מקומי.
2. בוחרים פורמט ומפעילים כל צליל. במסוק ניתן להפעיל לולאה מדויקת באמצעות Web Audio; שינוי פורמט עוצר את ההשמעה.
3. המניפסט ודוחות הבדיקה זמינים באותו דף. לולאת Web Audio היא הדרך המומלצת לחיבור למשחק: לפענח את הקובץ פעם אחת ולהפעיל `AudioBufferSourceNode.loop=true` על הטווח 0–4 שניות. נגני HTML מסוימים עשויים להוסיף השהיה בתכונת `loop`.

האזנה ישירות מהדיסק תלויה במדיניות הדפדפן; בסביבת הבדיקה ניווט `file://` חסום ולכן לא אומת. לולאת Web Audio דורשת שרת HTTP מקומי בשל הגבלות `fetch` בדפדפן. מטא־נתוני MP3 כוללים Xing/LAME להסרת השהיית המקודד והריפוד; משך המכל עשוי להיות ארוך מהאודיו המפוענח. בדיקת המשך מתבססת על מספר הדגימות המפוענחות: מעבר המטוס הוא בדיוק 66,150 דגימות.

חריג משך קטן בפגיעת המתכת בלבד: קובץ OGG בן דף אחד מפוענח ב־FFmpeg וב־Chromium ל־24,127 דגימות (0.5471 שניות), לעומת 24,255 דגימות (0.55 שניות) ב־MP3. ההפרש הוא 128 דגימות של טיפול ה־Vorbis בקצה הקובץ. המדידות מבוצעות לאחר הפענוח, ומספר הדגימות בפועל מופיע לכל קובץ במניפסט. מעבר המטוס, הנפילה לים ולולאת המסוק מדויקים בשני הפורמטים.

## שחזור ואימות

כלים דרושים: Python 3, NumPy, SciPy, FFmpeg/ffprobe עם libvorbis ו־libmp3lame; לא נדרשת רשת בעת הייצור. מריצים משורש המאגר:

```sh
python workout/island/design/naval-air-audio-v1/tools/build_audio.py build
python workout/island/design/naval-air-audio-v1/tools/build_audio.py verify
```

`build` יוצר את שמונת קובצי האודיו, המניפסט ודוח האימות; `verify` מודד מחדש ובודק את חותמות SHA-256 בלי לשנות קבצים. שינוי גרסת מקודד עשוי לשנות את הבתים והחותמות; מתכוני הסינתזה וה־seed נשמרים. אין קובצי ביניים בחבילה.

בדיקת דפדפן אוטומטית דורשת Node.js ו־Playwright. היא מפעילה שרת מקומי זמני, בודקת ניגון ופענוח של שמונת הקבצים, שלוש חזרות מדויקות של לולאת הרוטור בשני הפורמטים, כפתורי הפעלה/עצירה והחלפת פורמט, תצוגת טלפון ומחשב וקישורי הורדה. היא כותבת את `browser-validation.json`:

```sh
node workout/island/design/naval-air-audio-v1/tools/verify-browser.cjs /usr/bin/chromium
```

אפשר להשמיט את נתיב Chromium כדי להשתמש בדפדפן המותקן של Playwright.

היקף המסירה: נכסים ודף סקירה בתיקייה חדשה בלבד. בהתאם לבקשה לקבצים חדשים בלבד, רישום המשימה וקריטריון הסיום כאן, בלי לערוך את `ops/CONTROL.md`. החבילה מיועדת למסירה וחיבור נפרד למשחק.

מצב המסירה: בדיקות החבילה הושלמו בהצלחה. תוצאות, היקף ומגבלות בדיקות המאגר ב־[REPORT.md](REPORT.md).
