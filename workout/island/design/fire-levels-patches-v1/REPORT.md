## מדידה

הבוט מפעיל את מודל הרחוב, מסלול הכניסה, מודל הקומות וחישוב התוצאה של המשחק. שחקן סבלני מנווט בפקודות בחירת יעד, מחכה ללחץ ולמילוי, מכוון ובוחר כלי לפי סוג האש, ולוחץ על כפתורי החילוץ לפי הסדר. בכל פרופיל התחלתי יש אפס ציוד ומטבעות. השדרוגים נקנים מהתוצאות הקודמות לפי מחיר וסף כוכבים של המשחק. שלושה זרעים קבועים נבדקו בכל אחד מ־30 השלבים.

| --- | --- |

ב־Chromium עם רינדור SwiftShader, עיכוב יזום של הכבאית והידרנט השאיר את שעון המשחק על 0. שחרור בקשת הכבאית לבדה הציג את דגם Meshy בפריים הראשון. הדגם נשאר לאחר שחרור נכסי העיר ונרשמה בקשה אחת לקובץ הכבאית. נבדקו גם בחירה מפורשת בדגם v7, כשל בקשת הדגם ודגל החזרה. במבחן הטווח, מטרה במרחק 230 התקררה ב־v24 ונשארה מחוץ להישג הפאטץ׳. [בדיקת הכבאית](tests/truck-browser.mjs) · [בדיקת הטווח](tests/truck.test.mjs)

במסך מגע מדומה של 844×390, הבדיקה שיחקה בשלב 3 דרך ממשק האי. נגיעה ניתבה לבניין, שעון הרחוב קפא בכניסה, שתי לחיצות ממושכות כיבו את שני המוקדים, ונגיעה בכלב הותירה אותו במצב המתנה. לחיצה על כפתור פינוי הדרך חילצה אותו והמשחק עלה לקומה השנייה. תרחיש בטל הציג כוכב אחד, ודגל החזרה הציג אפס. בבדיקה נפרדת עם קובץ הקומות הארוז אומתו שתי הקומות הראשונות, גם לאחר כשל יזום באתחול WebGL. [בדיקת המגע](tests/fire-levels-browser.mjs) · [בדיקת נכסי הקומות](tests/interior-assets.test.mjs)

213 בדיקות Node עברו, כולל בדיקות הכיבוי הקיימות, הקומות, החילוץ, תוצאת המשחק, והאופליין. חבילת הכיבוי באופליין היא 8.1 MiB וסך חבילות הנכסים 89.8 MiB, בתוך התקציב הקיים של 90 MiB.

## הפעלה ובדיקות

החבילה מכילה קבצים חדשים בלבד. את הפקודות מריצים משורש עותק הבדיקה של הריפו.

1. בדיקת התאמה והחלת החבילה.

   ```bash
   workout/island/design/fire-levels-patches-v1/apply.sh --check
   workout/island/design/fire-levels-patches-v1/apply.sh
   ```

2. פתיחת משחק כיבוי האש בשרת המקומי. מוסיפים `?fireLevels=0` לכתובת האי ומתחילים סיבוב חדש כדי להשוות ל־v24. הדגל `?fireFlow=v23` מעביר את הכניסה לבניין למסלול v23.

   ```bash
   node --test workout/island/design/fire-levels-patches-v1/tests/*.test.mjs
   node workout/island/design/fire-levels-patches-v1/sim/fire-levels-bot.mjs
   node workout/island/design/fire-levels-patches-v1/sim/fire-levels-bot.mjs --no-upgrades
   ```

   לבדיקות הדפדפן משתמשים ב־Chromium וב־Playwright. אפשר לציין את הנתיבים שלהם באמצעות `CHROMIUM_PATH` ו־`ISLAND_PLAYWRIGHT`.

   ```bash
   node workout/island/design/fire-levels-patches-v1/tests/truck-browser.mjs
   node workout/island/design/fire-levels-patches-v1/tests/fire-levels-browser.mjs
   ```

3. להסרה מקומית של הפאטצ׳ים והנכסים שהותקנו.

   ```bash
   workout/island/design/fire-levels-patches-v1/apply.sh --reverse
   ```
