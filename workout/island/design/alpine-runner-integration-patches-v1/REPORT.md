# Alpine Rush · גלישה אינסופית בשלושה נתיבים

החבילה נבנתה על `main` בקומיט `9e95482fbe1887856cbca69fd43c1c77ba62cff4`. החלת ה־patches מפעילה את הראנר בשלושת שלבי הסקי הרגילים. ליגת הסקי נפתחת דרך הכפתור הקיים. בדף האי, `?alpineRunner=0` מחזיר גם את שלושת השלבים הרגילים למרוץ המקורי, כולל השליטה, התוצאות והשיאים של המרוץ.

## החלה והרצה

1. פתחו עותק עבודה של Bakasun שעליו רוצים לבדוק את ה־patches. הריצו משורש עותק החבילה.

   ```bash
   bundle=workout/island/design/alpine-runner-integration-patches-v1
   "$bundle/apply.sh" --check
   "$bundle/apply.sh"
   ```

   אפשר להעביר נתיב לעותק Git אחר, למשל `"$bundle/apply.sh" --check /path/to/Bakasun`. הסקריפט בודק את שלושת ה־patches יחד לפני החלה ומזהה החלה מלאה קודמת. שילוב בפרסום מצריך את עדכון הגרסה המרכזי של האי, כדי שהתקנות קיימות יקבלו את הקוד המעודכן דרך המטמון.

2. הריצו שרת מקומי משורש העותק שאליו הוחלה החבילה.

   ```bash
   python3 -m http.server 8765
   ```

   פתחו את [האי](http://localhost:8765/workout/island/), בחרו **משחקים → סקי → שלב 1** והתחילו גלישה. אפשר לבחור סביבה במסך הפתיחה. לבדיקת המרוץ המקורי, פתחו את [האי עם דגל החזרה](http://localhost:8765/workout/island/?alpineRunner=0). אפשר להוסיף `alpineRunnerSeed=7` לשחזור מסלול בדפדפן ו־`quality=low` לבדיקת האיכות הנמוכה.

3. הריצו את הבדיקות ואת הסימולציה. בדיקות הדפדפן משתמשות בעזרי Playwright ו־Chromium של הריפו.

   ```bash
   node --test "$bundle/tests/"*.test.mjs
   node "$bundle/tests/browser.mjs"
   node "$bundle/tests/performance-browser.mjs"
   node "$bundle/sim/simulate.mjs" --difficulty 2 --seeds 24 --seconds 120
   ```

   כשמריצים בדיקות מחבילה שבעותק נפרד, `ALPINE_TEST_ROOT` מצביע לעותק שעליו הוחלו ה־patches. `ALPINE_LEGACY_ROOT` מוסיף עותק בסיס להשוואת המרוץ והליגה. ל־`sim/simulate.mjs` יש `--repo` למטרה זהה. המחולל מבחין בין זרע טקסטואלי מהכתובת לזרעים המספריים של סימולציית שורת הפקודה.

## כללי המשחק והחיבור לאי

- הגולש מתקדם אוטומטית. החלקה אופקית עוברת לנתיב סמוך, החלקה למעלה קופצת מעל גדר נמוכה והחלקה למטה מתכופפת מתחת לקורה. סלע מחייב הסטה או מגן. גם מקשי החצים וכפתורי המסך מפעילים את ארבע הפעולות.
- המחולל המקורי מייצר מקטעים של 30 מ׳ לפי זרע. טעינה קדימה ומחיקת עצמים שחלפנו על פניהם שומרות על חלון משחק מוגבל. מהירות מוגבלת ל־31 מ׳ לשנייה ומעבר נתיב אורך 0.36 שניות, לפי הפרופיל שאומת במחולל. סימולציית התנגשויות רצה בתזמון קבוע של 120 צעדים בשנייה.
- מגן סופג פגיעה אחת, מגנט מושך מטבעות גם מנתיבים סמוכים במשך 7 שניות, והבונוס הכפול מכפיל איסוף במשך 8 שניות. הניקוד הוא מטרים שלמים ועוד 5 נקודות לכל מטבע שנאסף.
- הריצה מסתיימת בפגיעה ללא מגן. יעדי הכוכב הראשון בשלבים 1–3 הם 150, 225 ו־300 מ׳. הגעה ליעד פותחת את השלב הבא דרך מנגנון ההתקדמות הקיים. הפרס של האי כולל עד 30 מטבעות מהאיסוף ואת פרס הניצחון של השלב, אם הושג היעד.
- השיא נשמר מקומית תחת `island.alpine.runner.best.v1`. פתיחת משחק נוסף קוראת את השיא. חבילת המדיה של הראנר זמינה להורדה לשימוש לא מקוון דרך מנהל האחסון של האי.

## בדיקות וביצועים

- החבילה הוחלה על עותק נקי של קומיט הבסיס. בדיקת ההחלה, ההחלה עצמה והזיהוי של החלה קודמת עברו. גיבובי הנכסים נבדקו שוב בעותק המוחל.
- 11 בדיקות החבילה עברו, כולל הזרמת מקטעים, תזמון קפיצה והתכופפות, בונוסים, תוצאה, שלוש רמות בוט והשוואת המרוץ המקורי לאורך 400 צעדים. גם 23 בדיקות האופליין ו־14 בדיקות Alpine v24.1 עברו.
- בדיקת Chromium בשני כיווני המסך אימתה מחוות מגע, ביטול מחווה, עצירה והמשך, החלפת סביבה ושחרור הקנבס ביציאה. תרחיש סיום מונחה אימת צבירת שלושה כוכבים, שמירת שיא וטעינתו מחדש. הליגה נפתחה כמרוץ בשני המצבים. עם דגל החזרה, פתיחת הליגה והמרוץ הרגיל תאמה לעותק הבסיס והנכסים שנדרשו היו של המרוץ.
- בריצת הרגרסיה של הריפו בעותק המוחל עברו 4,371 בדיקות ו־86 דולגו. בדיקת דפדפן אחת במסך האימון נכשלה בהפעלה כי קובץ ההפעלה של Chromium לא היה בנתיב ברירת המחדל של Playwright. בהרצה חוזרת של קובץ הבדיקות עם Chromium המקומי עברו כל חמש הבדיקות בו, כולל בדיקת הדפדפן.

מדידה מתוך המשחק הפעיל ב־Chromium 151 עם SwiftShader. שלב 1, יער אורנים, זרע 7, שלוש שניות חימום ו־15 שניות דגימה בכל תצוגה. נמדדו פריימים שנשלחו ל־WebGL בפועל, ומשולשים נספרו מפקודות הציור כולל מעברי צל במרוץ המקורי. שתי התצוגות מדמות DPR 2. באיכות נמוכה, קנבס הראנר השתמש ב־DPR 0.8 וקנבס המרוץ ב־DPR 1.

|---|---|---:|---:|---:|

תקציב הראנר הוא 60,000 משולשים לפריים באיכות נמוכה ו־100,000 באיכות גבוהה. מגבלות של שישה אריחים ו־144 מופעי עצמים, יחד עם גאומטריית הגולש והאפקטים, נותנות חסם מחושב של פחות מ־54,000 משולשים. בשתי המדידות של הראנר נשלחו לכל היותר 27 פקודות ציור לפריים, וכל המרקמים נטענו. ביצועי GPU ומגע על טלפון פיזי עדיין דורשים מדידה.

הסקריפט תומך ב־`PERF_VARIANT=legacy` למדידת המרוץ, `PERF_QUALITY=high`, `PERF_STAGE=3`, `PERF_THEME=village`, `PERF_SOFTWARE=0` להרצה עם GPU זמין, ו־`PERF_OUTPUT=/tmp/alpine-perf.json` לשמירת התוצאות.
