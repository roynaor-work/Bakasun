# Alpine Content v1 — תוכן נוסף למסלול הסקי

נמסרו **12 מכשולים, 8 בונוסים, 4 מפריעים, שלוש עוצמות של שלג מתעופף ושובל גולש**. לכל אחד מ־28 הפריטים קובץ GLB עצמאי ו־PNG שקוף בגודל 320×320. כל הדגמים בטווח **104–536 משולשים**; 12 המכשולים בטווח **120–536**. כל 28 קובצי ה־GLB עברו Khronos עם **0 שגיאות ו־0 אזהרות**.

ענף: `codex/alpine-content-v1`. בסיס: `origin/main` בקומיט `43b27dc235387e3cb737aee9558cdf9d5fd5a262`. כל שינויי המשימה הם קבצים חדשים בתוך `workout/island/design/alpine-content-v1/` בלבד. החבילה מוכנה לסקירה ולחיבור; לא שונתה לוגיקת המשחק, לא עודכנה גרסת האפליקציה ולא שונה קובץ קיים, כולל חדר הבקרה, בהתאם להוראה המפורשת למשימה.

שלושת אפקטי השלג כוללים קליפ `spray` רגיל של glTF באורך 0.9 שניות: פליטה, התרחבות, נפילה וכיווץ לאפס. אפשר לנגן ב־AnimationMixer ללא שיידר מותאם. `maxConcurrent` מציע עד 4/3/2 פליטות במקביל; זו המלצת תקציב, לא מדידת FPS.

בנוסף נמסר [`effects/runtime.mjs`](effects/runtime.mjs): חלופה לחלקיקים רציפים ושובל המתעד את מיקום שני המגלשיים בזמן אמת. שלוש העוצמות פולטות 18/42/78 חלקיקים לשנייה, עם תקרות 24/48/96; לכל מגלש יש עד 28 מקטעי שובל ומשך חיים 1.15 ש׳. המודול מגביל `dt`, מפנה אפקטים שפגו, מאפס שובל אחרי קפיצה במיקום ומספק `reset` ו־`dispose`. תמונות החלקיקים הן RGBA: `powder-particle.png` בגודל 64×64 ו־`trail-strip.png` בגודל 32×128. אין צורך להפעיל גם את חלופת GLB וגם את חלופת החלקיקים הרציפים לאותה פליטה.

## סגנון, מידות וחיבור

הרפרנס הוא `alpine-themes-v1`, קומיט `c918a88f9c6b1d2b66f6cd97cbac9b741e7e6ef9`: low poly חם, פאות שטוחות, חומר מט, שלג `#f4f1df`, אלמוג `#df8963`, טורקיז `#579f9c` וענבר `#edbd79`. שש פלטות הסביבה שמורות במניפסט; בדף התצוגה הן מחליפות תאורת סביבה, קרקע והרים. צבעי הפריטים נשארים עקביים לזיהוי גם כשמחליפים עולם.

- יחידות: מטרים; `+Y` למעלה; גלישה ב־`-Z`; מצלמה מאחור ב־`+Z`. הרמפות עולות מ־`+Z` ל־`-Z`.
- GLB לא דחוס, ללא הרחבות, ללא קבצי צד וללא טקסטורות חיצוניות. צבעי PBR נשמרים במרחב ליניארי, `metallic=0`, חספוס 0.9; הגולש המשומש מחדש שומר על החומרים המקוריים.
- המניפסט כולל נתיבים, משולשים, מספר בתים, SHA-256, גבולות במנוחת המודל, עוגנים, קליפים והצעות ל־collision. גבולות האנימציה עשויים להיות רחבים מהגבולות במנוחה; לעץ נוספה מעטפת `animationBounds` שנבדקה לאורך הקליפ ומשמשת גם למסגור המצלמה.
- **החור דורש חיתוך אמיתי בקרקע המארחת ברדיוס 1.08 מטר**. אחרת הקרקע תסתיר את עומק הבור. דף התצוגה כולל חיתוך כזה. המודל לבדו אינו חותך mesh של משחק אחר.
- **לעץ נופל יש תחום תנועה ברדיוס 4.5 מטר**. קליפ `fall` מתחיל זקוף ומסתיים בגזע שנפל. דגם המנוחה כבר שוכב; יש לסנכרן collider עם שלב הנפילה בעת החיבור.
- מעבר צר: להשתמש בשני אזורי ההתנגשות שבמניפסט; תיבה אחת סביב כל המודל תחסום את הפתח. הגשר מספק עוגני כניסה/יציאה וגובה משטח.
- קליפים חד פעמיים: `LoopOnce` ו־`clampWhenFinished=true`; לאתחל פעולה בכל הפעלה. לכל מופע שמנוגן באופן עצמאי דרוש mixer משלו. קליפי המפריעים אינם מחליפים את תנועת השורש במסלול.
- תמונות ה־PNG הן רינדורים שקופים מנורמלים למסגור, והן אינן משמרות קנה מידה בין פריטים. קנה המידה למשחק נלקח מ־GLB ומגבולות המניפסט.
- לשובל חי: להעביר ל־`createAlpineEffects(THREE, options)` את `scene`, שתי הטקסטורות ואת מופע Three.js של המארח; בכל פריים לקרוא `update(dt, {position, heading, moving, leftSki, rightSki})`. מיקומי המגלשיים הם בקואורדינטות העולם ועל פני השלג. המודול אינו מפנה את הטקסטורות שהמארח סיפק.

## תצוגה ובדיקה

1. משורש המאגר להפעיל:

   ```sh
   python3 -m http.server 8765
   ```

2. לפתוח [את התצוגה המקומית](http://localhost:8765/workout/island/design/alpine-content-v1/preview.html).
3. לבחור **במסלול** לתצוגה הכוללת, או **מקרוב** ופריט מתוך ארבע הקבוצות. ניתן להחליף סביבה וזווית, להפעיל/לעצור תנועה ולהוריד GLB או PNG. התוצאה הרצויה: כל הפריטים נטענים, המפריעים נעים, והשלג והשובל מופיעים רק כשהתנועה מופעלת. ברירת המחדל שקטה, כולל `prefers-reduced-motion`.

הדף נבדק ב־**844×390**, ב־390×844 וב־1440×900. כל התלויות נטענות מהמאגר המקומי; אין CDN או פונטים חיצוניים. יש להגיש את המאגר כולו דרך HTTP כדי לשמור על הייבוא היחסי של Three.js. הקבצים אינם מחוברים לפרסום המשחק.

| בדיקה עצמאית של GLB סופי | מספר משולשים, גודל, SHA-256, גבולות, נורמלים יחידתיים, כיוון פאות, היעדר משולשים מנוונים ונתונים סופיים — עברו |

| אנימציות | זמנים עולים, אורכי ערוצים תקינים וקווטרניונים מנורמלים; כל 28 הדגמים נטענו ונבדקו בשלושה זמני דגימה |

בדיקת הדפדפן הקיימת חיפשה `chromium_headless_shell-1234` שאינו מותקן. `launch()` נכשל לפני בלוק הניקוי והשאיר את שרת הבדיקה פתוח; תהליך הבדיקה התקוע הסתיים לאחר יתר הבדיקות. הבדיקה הורצה שוב דרך `ISLAND_PLAYWRIGHT` ומתאם זמני מחוץ למאגר, שהפנה ל־`/usr/bin/chromium`. כל חמש הבדיקות בקובץ עברו. הריצה המקורית לא מוצגת כריצה מלאה ירוקה; שני הפלטים המסוכמים וקוד המתאם נרשמים ב־[repository-tests.json](verification/repository-tests.json).

נבדקו חזותית דף המגע, תמונות כל המודלים ותצוגות המסלול בשתי מידות הנייד. אין טענה למדידת FPS בטלפון פיזי או לבדיקת collision במשחק המחובר; אלה בדיקות של שלב השילוב.

## תקציב ושחזור

מגבלת **3,000,000 בתים** פורשה כתקרה לכל התיקייה, כולל מקור, תיעוד וצילומי אימות. החבילה כ־**1.9MB**. כל ה־GLB יחד: **769,308 בתים**; כל 28 רינדורי ה־PNG יחד: **296,969 בתים**; הקובץ הגדול ביותר הוא שלג חזק: **111,916 בתים**. `source/catalogue.py` מחשב מחדש את כל גדלי הקבצים ובודק את התקרה אחרי בניית המלאי.

כלי ההפקה המדויקים מפורטים ב־`source/requirements.txt` וב־`source/tooling.json`. להתקין את חבילות Node מחוץ לתיקיית המסירה. הבנייה משתמשת בזרעים קבועים; רינדורי PNG עשויים להשתנות מעט בין מעבדים גרפיים. המלאי מתעד את הבתים שנמסרו בפועל.

```sh
python3 workout/island/design/alpine-content-v1/source/build_assets.py
```

לאחר הפעלת שרת HTTP משורש המאגר, ועם Playwright ו־Khronos Validator זמינים:

```sh
node workout/island/design/alpine-content-v1/source/verify.mjs --capture
```

אפשר להגדיר `ALPINE_VALIDATOR` לנתיב מודול המאמת, `ISLAND_PLAYWRIGHT` למודול הדפדפן ו־`ALPINE_CHROMIUM` לקובץ Chromium. ברירת המחדל של המאמת היא התקנה חיצונית ב־`/tmp/alpine-content-tools/node_modules/gltf-validator`; הדפדפן הוא `/usr/bin/chromium`.

לאחר התיעוד והבדיקות, לרענן תמונת מגע, מידות PNG וחתימות:

```sh
python3 workout/island/design/alpine-content-v1/source/catalogue.py
```

האימות אינו דורש Blender, מפענחי Draco, שירותי יצירת מדיה או חיבור לרשת בזמן התצוגה. הבנייה כותבת רק בתיקיית החבילה.
