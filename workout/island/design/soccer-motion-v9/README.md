# ספריית כדורגל v9 — טבעיות

48 קליפים מקוריים משלימים, ללא העתקת 25 קליפי v8. כל קליפ הוא GLB עצמאי עם רשת Draco, טקסטורות מקומיות ושלד motion2 בן 18 עצמות. ההנפשות נאפות ב־30Hz; ההפקה והאימות אינם דורשים הורדת חבילות.

[פתיחת התצוגה](preview.html) · [דוח ומדידות](REPORT.md) · [מקורות ורישיונות](LICENSES.md) · [שיטת המדידה](verification/METHOD.md)

## צפייה מקומית

מתיקיית המאגר מריצים:

```bash
python3 -m http.server 8765
```

פותחים:

```text
http://localhost:8765/workout/island/design/soccer-motion-v9/preview.html
```

בוחרים קליפ שמתנגן בלולאה, או מפעילים מעבר אוטומטי בין כל הקליפים. אפשר לשנות מהירות או זמן. אפשר להציג סמני מגע, עוגני תמיכה ומסלול תנועה חיצוני. בגיליונות הצילומים יש ארבעה רגעים לכל קליפ, כולל רגעי הפעולה; כל גיליון בגודל 844×390.

## מבנה ותאימות

- `runtime/catalog.mjs` — עצמות, קליפים, אירועים, תמיכות, מסלולי תנועה וכדור ומעברים.
- `runtime/library.mjs` — טעינת GLB אמיתי דרך GLTFLoader ו־Draco, הפעלה ושחרור משאבים.
- `runtime/state-machine.mjs` — מפת מעברים ובקר תזמון. מעבר ריצה לבלימה מחכה למגע רגל שמאל בפאזה 0.
- `runtime/clips/*.glb` — 48 קבצים; בכל קובץ אנימציה חדשה אחת בלבד.
- `source/` — כוריאוגרפיה פרוצדורלית מקורית, IK אנטומי, אריזה וכיול מגע על משטחי המודל.
- `verification/` — בדיקות קבלה חדשות, מדידות GLB, ראיות דפדפן וצילומים.

הצירים הם ‎+Y למעלה, ‎+Z קדימה ו־‎+X שמאל אנטומי; היחידות מטרים ושניות. שמות העצמות, ההיררכיה, אורכי המנוחה וה־inverse binds נשמרו. אירועי המגע והשחרור משתמשים במבנה v8: `time`, `type`, `bone`, `local`, `position`.

כמו ב־v8, מסלול השחקן נמצא בקטלוג בנפרד מההנפשה המקומית. לולאות ההנפשה מתחילות ומסתיימות בפוזה זהה; בעולם מחברים כל מחזור למסלול המחזור הקודם. מדידות הנטיעה כוללות את המסלול החיצוני. אין להוסיף במקביל תנועת Root שנייה. הסמנים מיועדים להצגה בלבד; קוד המשחק ממשיך להחליט על בעלות בכדור, תוצאה וחוקי המשחק.

## בנייה ובדיקות

מתיקיית הספרייה:

```bash
node source/build.mjs
node verification/render-sheets.mjs
node --test verification/*.test.mjs
```

הבנייה קוראת בלבד את רשתות v8 הסמוכות. כל הפלט נכתב ב־v9. כלי הצילום משתמשים ב־Playwright ו־Sharp מסביבת הכלים; נתיבי החלפה מפורטים בקובץ כלי הצילום. זמן הריצה בדפדפן משתמש בקבצים מקומיים בלבד.

הנכסים מיועדים לסקירה ולחיבור נפרד. לא נערכו קוד המשחק, קובצי גרסה, בדיקות קיימות או ops. בדיקת הדפדפן היא ב־Chromium; התאמה למכשיר טלפון פיזי דורשת בדיקת המכשיר בשלב החיבור.
