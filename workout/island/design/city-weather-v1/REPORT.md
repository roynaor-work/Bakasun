## סגנון ומבנה

הצבעים נלקחו מה־palette ב־`view/environment.mjs`: ים וטורקיז, חול,
שמנת וקורל. האפקטים משתמשים בצורות רכות ובהצללות מתונות, והזיקוקים
בזהב, קורל וטורקיז. נבדקו קודם נכסי העננים והציפורים הקיימים; לא נמצא
רצף דו־ממדי של ציפורי חוף/פרפרים שמתאים לחבילה. נוצרו צלליות אווירה
קטנות ומקוריות. אין תמונות חיצוניות או נתונים אישיים.

- `manifest.json`: מזהים, קובצי אטלס, חיתוכים, גדלים, pivot, קצב ניגון,
  סדר שכבות, blend, צבעים, SHA-256 והנחיות חיבור.
- `atlases/*.json`: גם מטא־דאטה במבנה TexturePacker, ללא סיבוב או קיצוץ.
- `sprites/<effect>/<frame>.png`: כל פריים בנפרד, זהה לחיתוך מהאטלס.
- שוליים של 2 פיקסלים עם שכפול פיקסלי הקצה מונעים זליגה בין תאים.
- `source/build.py`: מחולל דטרמיניסטי; המקור ניתן לשינוי ולייצור חוזר.
- `LICENSE.txt`: אמנות האפקטים CC0, קוד MIT. צילום העיר משמש רפרנס בלבד
  ונשאר כפוף לזכויות הנכסים הקיימים.

## תצוגה ובדיקה

פתיחת [preview.html](preview.html) מציגה במה של **844×390**. הדף משתמש
בסקריפטים וקבצים מקומיים ללא fetch. בסביבה המנוהלת ניווט `file://` חסום
במדיניות הדפדפן, ולכן האימות בוצע דרך שרת מקומי. פתיחה ישירה לא אומתה.
הבמה מתכווצת באופן יחסי במסך קטן.
יש שבע סצנות, עוצמת גשם, בחירה בין חמשת הזיקוקים, שלושת צבעי החגיגה,
הפעלת עננים/ציפורים/פרפרים/בלונים/קונפטי, והשהיה. הדף אינו תלוי בשירות
חיצוני, אינו כותב לשמירות ואינו טוען את המשחק לצורך הצפייה.

```bash
python3 -m http.server 8765
```

```text
http://localhost:8765/workout/island/design/city-weather-v1/preview.html
```

יצירת הנכסים ואימותם משורש המאגר, עם Python 3, Pillow ו־NumPy:

```bash
python3 workout/island/design/city-weather-v1/source/build.py
python3 workout/island/design/city-weather-v1/source/check_assets.py --rebuild
```

בדיקת הדפדפן נעשית עם Python Playwright ו־Chromium המותקן בסביבה:

```bash
python3 workout/island/design/city-weather-v1/source/check_preview.py
```

## חיבור בהמשך

סדר השכבות מפורט ב־manifest: שמים וכוכבים, עננים, העיר, חיים,
זיקוקים, ערפל, משקעים, חגיגה ולבסוף ממשק. כל הטקסטורות משתמשות
ב־sRGB ו־straight alpha, עם source-over רגיל. מומלץ linear filtering,
ללא mipmaps לאטלס, ו־depthWrite=false לשכבות שקופות.

לגשם/שלג/ערפל יש לחזור על **הפריים החתוך** בלבד. הכוכבים מופרדים
מהגרדיאנט, כך שאפשר לשלוט בנצנוץ. אפשר להזין את gradientStops לשיידר
השמים הקיים. ערפל זקוק למסכת עומק/אופק, וציפורים ופרפרים בתוך העיר
זקוקים להסתרה על ידי בניינים. אלו בחירות חיבור; התצוגה מדגימה שכבות דו־ממד.

מומלץ לטעון אטלסים לפי הצורך: כל אטלס RGBA8 הוא **4 MiB מפוענח**,
גם כשה־PNG קטן. כל השמונה יחד הם 32 MiB לפני מטמוני הדפדפן. אין צורך
לטעון מראש את כל חמשת הזיקוקים. ל־prefers-reduced-motion התצוגה מתחילה
במצב סטטי ומשמיטה זיקוקים, קונפטי ותנועת בלונים. בלשונית מוסתרת אין RAF פעיל.

לא בוצעו חיבור למשחק, בדיקת טלפון פיזי או פרסום ל־main. ההנחיה המפורשת
של המשימה — תיקייה חדשה בלבד — נשמרה גם ביחס ל־`ops/CONTROL.md`,
לקובצי הגרסה ולשירות העובד. קריטריון המסירה הוא נכסים מלאים, תצוגה,
אימות, דוח ו־push לענף החדש.
