# שישה נושאי סקי ל־30 שלבי ליגה

חבילת נכסים מקורית בסגנון low poly חם לילדים בני שבע, עם תצוגה מאחורי הגולש. שלבי הליגה מחולקים לשש חמישיות רצופות. כל התוצרים בתיקייה `workout/island/design/alpine-themes-v1/`.

ענף: `codex/alpine-themes-v1`, נוצר מ־`main` בקומיט `d759582c171600dd7c7df7906c2fb38ae7f8b88a`. זו חבילת עיצוב מוכנה לסקירה ולחיבור עתידי למשחק. כל שינויי המשימה הם קבצים חדשים בתיקייה זו בלבד.

## מה נכלל

| שלבים | נושא | שלושת סוגי העצים או הסלעים | משולשים לכל סוג |
|---|---|---|---|
| 1–5 | יער אורנים ושלג רך | `pine-tall`, `pine-round`, `pine-young` | 108 / 108 / 108 |
| 6–10 | מערת קרח כחולה עם נצנצים | `ice-cluster`, `ice-arch`, `ice-spire` | 128 / 216 / 96 |
| 11–15 | הר געש, סלעים כהים ושלג מפויח | `basalt-stack`, `soot-boulder`, `glow-stones` | 76 / 76 / 76 |
| 16–20 | לילה, כוכבים ואורורה | `night-pine`, `frost-boulder`, `moon-crystal` | 108 / 52 / 96 |
| 21–25 | כפר אלפיני, בקתות וחבלים | `village-pine`, `garden-boulder`, `snow-fir` | 108 / 52 / 108 |
| 26–30 | פסגה ענקית מעל העננים | `granite-slab`, `snow-spire`, `cloud-boulder` | 52 / 52 / 52 |

לכל נושא:

- שלוש טקסטורות RGB בגודל **1024×1024**: `snow.png`, `ground-a.png`, `ground-b.png`. קצוות נגדיים זהים ברמת הפיקסל לשימוש מחזורי.
- רקע שמיים RGB בגודל **2048×1024**, עם צלליות הרים ותוכן ייחודי לנושא. השמיים מיועדים כרקע דו־ממדי למצלמה מאחור, ולא כמפת סביבה כדורית 360°.
- שלושה מודלי סביבה, שני שערי סלאלום, רמפה, שלט חץ ואריח קרקע, כולם GLB תקני ולא דחוס.
- `gate-coral.glb` ו־`gate-teal.glb`: **כל קובץ הוא זוג דגלים שלם** באותו צבע. הצבעים קבועים בכל העולמות. בכל דגל יהלום פשוט ופס בהיר, בלי מילים, מספרים או מותגים.
- `ramp.glb`: משטח שלג עם שולי צבע עדינים; `arrow-sign.glb`: צללית חץ בלבד; `terrain-tile.glb`: אריח שטוח של 8×8 מטר עם UV מחזורי.
- ארבעה ספרייטים שקופים **256×256** — פתית שלג, נצנוץ, אבקת שלג והילה — ואטלס **1024×256**. `effects.json` מפרט צבעים, אזורי UV ותקציבי חלקיקים.

תוספות: בכפר `chalet.glb` (260 משולשים) ו־`rope-fence.glb` (400). גולש קנה מידה מקורי, ללא סימנים או טקסט, נמצא ב־`shared/reference-skier.glb` (392 משולשים) וממחיש את המצלמה; הוא דגם סטטי לתצוגה. הר הגעש משתמש בחריטות קריסטל ענבריות ובשפת קלדרה עדינה. אין לבה, אש, פיצוצים או הבהובים.

בסך הכול: **129 קבצים חדשים**, ובהם **51 GLB**, **54 PNG של טקסטורות ורקעים**, **6 תמונות תצוגה**, מניפסט, 30 פריסות מסלול, 6 מפרטי אפקטים, קוד מקור, רשימת מקורות ורישיונות ומלאי עם SHA-256. היקף החבילה כ־**4.36 MB**. כל מודלי הסביבה כוללים **52–216 משולשים**; המודל הכבד ביותר בחבילה כולה הוא גדר החבל: **400 משולשים**, מתחת לתקרת 800.

## עקביות וקריאות

אותה גאומטריה שטוחה, גימור מט, צבעי שלג רכים, אור מילוי חם ודגלי אלמוג וטורקיז חוזרים בכל הנושאים. התאורה בלילה בהירה מספיק לזיהוי דגלים וסלעים. העצמים הגדולים מוצבים בצדי המסלול, והמצלמה נשארת מאחורי הגולש. כל חלון של חמישה שלבים משנה את פיזור הסביבה, פניות השערים, אורך המסלול ומספר הרמפות; הנושא החזותי נשאר קבוע בחמישייה.

הנכסים הוויזואליים נקיים מכיתוב. תוויות העולם, מספרי השלבים ומוני המשולשים הם רכיבי HTML בתצוגה בלבד. `previews/` מכילה ייצוא ישיר של הקנבס ללא שכבות הממשק.

## פתיחת התצוגה

1. משורש המאגר להריץ:

   ```sh
   python -m http.server 8765
   ```

2. לפתוח [preview.html](http://localhost:8765/workout/island/design/alpine-themes-v1/preview.html).
3. לבחור עולם ואחד מחמשת מספרי השלבים. ששת הכרטיסים בהמשך מציגים את כל הנושאים יחד. במצב **בדיקת מודל** ניתן לבחור כל מודל, לראות ספירת משולשים והיקף קובץ ולהוריד GLB. כפתור התנועה מפעיל חלקיקים או סיבוב מודל; ברירת המחדל שקטה וסטטית.

התצוגה עובדת עם נכסים מקומיים וספריית Three.js r160 שכבר קיימת ב־`workout/3d/lib/three.module.min.js`. יש להגיש את המאגר כולו דרך HTTP, כך שהייבוא היחסי יישאר תקין. אין CDN, טעינת פונטים או קריאות מדיה חיצוניות. קובצי ה־GLB עצמאיים ונטענים גם עם GLTFLoader תקני ללא מפענחים נוספים.

מונה הסצנה סוכם את כל המשולשים של הגאומטריה המחוברת לסצנה, כולל שני משולשים לכל ספרייט. הוא מציג תקציב לפני סינון המצלמה ואינו מוסיף שוב את מעברי הצללים. המונה למודל מתייחס ל־GLB השלם, לרבות כל קבוצות החומרים ושני הדגלים בשער. תקרת המודל מוצגת גם במניפסט ונבדקת במחולל.

## שימוש בחבילה

- `manifest.json`: נתיבי כל הנכסים, גדלים, משולשים, תחומי שלבים, צבעים ומידות תחום לכל GLB.
- `levels.json`: שלושים פריסות שונות עם מיקומים, זוויות, קני מידה, מצלמה ומזהי נכסים. שדה `designOnly` מסמן שמדובר במפרט עיצוב. אורך המסלול 240–384 מטר, רוחב תכנוני 14 מטר; הרמפות מרוחקות לפחות 10 מטרים מהשער הקרוב לאורך המסלול.
- קנה המידה הוא **מטרים**, **Y למעלה**, גלישה אל **‎-Z**, והמצלמה ב־**‎+Z**. מקור רוב העצמים בבסיס בגובה 0. מקור אריח הקרקע במרכזו. הרמפה עולה כשגולשים מ־+Z ל־-Z. החץ מצביע ל־+X; לסימון שמאלה מסובבים סביב Y בחצי סיבוב.
- צבעי PBR ופליטה ב־GLB נשמרים במרחב ליניארי לפי glTF. טקסטורות הצבע הן sRGB; טקסטורות חלקיקים משתמשות באלפא רגילה, לא מוכפלת מראש. האריחים מכילים UV; בעת החלת טקסטורת שלג על החומר רצוי לאפס את גוון הבסיס ללבן ולבחור RepeatWrapping.
- שערי הסלאלום כוללים עמודים במרחק 6.4 מטר זה מזה; המרווח החופשי בין הדגלים הוא 4.44 מטר. אפשר להחליף בין שני קובצי הצבע או להחליף את חומר הדגל, בלי לשנות מידות.
- באטלס, ארבעה תאים משמאל לימין: `snowflake`, `sparkle`, `powder`, `glow`. `uvRect` ב־`effects.json` משתמש במקור בפינה השמאלית העליונה ובמבנה `[x,y,width,height]`; הספרייטים ממורכזים בתאים. באטלס זה יש שורה אחת, לכן היפוך Y אינו משנה את בחירת התא.
- לטעון נושא אחד בכל פעם. התצוגה שומרת מטמון לצורך סקירה מהירה; מנוע המשחק יכול לפנות נושא ביציאה ממנו. תקציבי האפקטים הם המלצות נפרדות לכל מערכת ואינם מדידת FPS.

## שחזור ומקורות

מתוך תיקיית חבילה זו, עם Python 3 והגרסאות המפורטות ב־`source/requirements.txt`:

```sh
python source/build_assets.py
```

לייצוא שש התמונות, נדרש שרת HTTP משורש המאגר ו־Python Playwright עם Chromium. בעת ההכנה השתמשנו ב־Playwright 1.62.0 וב־`/usr/bin/chromium`:

```sh
python source/capture_previews.py --origin http://127.0.0.1:8765 --chromium /usr/bin/chromium
```

לבסוף לרענן את רישום המקורות והמלאי:

```sh
python source/catalogue.py
```

הקוד משתמש בזרעים קבועים, בצורות מקוריות ובנוסחאות מחזוריות; אין הורדת נכסי מדיה. PNG של הקנבס עשוי להשתנות מעט בין מעבדים גרפיים, ו־`asset-inventory.json` מתעד את הבתים שנמסרו בפועל. [LICENSES.md](LICENSES.md) מפרט מקור ורישיון **לכל קובץ חדש**. כל היצירות המקוריות בחבילה מוקדשות ל־**CC0-1.0**; התלות הקיימת של Three.js נשארת ברישיון MIT מחוץ לחבילה.
