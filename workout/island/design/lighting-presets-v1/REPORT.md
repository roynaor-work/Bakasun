# ערכות תאורה ושמיים v1 · דוח מסירה

17.11.2026 · ענף `codex/lighting-presets-v1` · בסיס `f5f2b408`

עשר ערכות תאורה ושמיים תחת חוזה JSON אחד, שלוש טקסטורות מקוריות קטנות ומתאם Three.js שאפשר לשתף בין משחקי האי. [התצוגה](preview.html) מציגה שלוש סצנות תלת־ממד חיות: חוף עם מתקני אימון, מגרש כדורגל עם יציעים, ומסלול הררי מושלג. כל הערכות חלות על שלושתן יחד, באותו מיפוי צבע ועוצמה.

כל הקבצים חדשים ונמצאים תחת `workout/island/design/lighting-presets-v1/`. זו חבילת מסירה עצמאית; חיבור למשחקים הקיימים הוא שלב נפרד. בהתאם להוראה המפורשת לא נערכו קבצים קיימים, לרבות `ops/CONTROL.md` שנקרא, קובצי המשחק, release, מטמון או manifest האופליין של האפליקציה.

## הורדה וצפייה באופליין

1. מורידים את [חבילת ה־ZIP מהענף](https://raw.githubusercontent.com/roynaor-work/Bakasun/refs/heads/codex/lighting-presets-v1/workout/island/design/lighting-presets-v1/lighting-presets-v1.zip) או את [הקובץ המקומי](lighting-presets-v1.zip), ומחלצים את כל התיקייה.
2. פותחים `lighting-presets-v1/preview.html` בדפדפן. אין build, התקנה או חיבור לרשת. לשחזור תצוגת היעד קובעים חלון של **844×390 CSS px**.
3. אם הדפדפן חוסם פתיחה מהדיסק, מריצים מהתיקייה שמכילה את התיקייה המחולצת:

   ```sh
   python3 lighting-presets-v1/tools/serve.py
   ```

   המפעיל פותח כתובת ב־`127.0.0.1` בלבד, על פורט פנוי. הוא משתמש ב־Python 3 ובספרייה התקנית; אפשר לנתק את האינטרנט. `Ctrl+C` סוגר אותו. באפשרות זו המחשב מגיש את הקבצים לעצמו.
4. בוחרים ערכה; שלוש הזירות מתעדכנות יחד. גוררים כל זירה בנפרד או משתמשים בחצים לאחר מיקוד; `Home` מאפס זווית. ״תנועה״ מפעיל ועוצר עננים ומשקעים. ״העתק ערכה״ מעתיק את אובייקט ה־JSON הנבחר; ״כל הערכות״ מוריד את הקובץ הקנוני.

התוצאה הצפויה: שלוש זירות שונות עם תאורה אחידה, מעבר מיידי בין עשר ערכות, בלי בקשות חיצוניות. במידת היעד הכול נכנס ללא גלילה. בטלפון צר הזירות נערמות וניתן לגלול אנכית.

## חוזה ושילוב

- מערכת צירים ימנית, `+Y` למעלה. כל המרחקים במטרים. `sun.direction` מצביע **מהראשית אל מקור האור**; קרני האור נעות בכיוון ההפוך. בלילה אותו אור כיווני משמש כירח.
- צבעים ב־sRGB ‏`#RRGGBB`; `THREE.Color` ממיר למרחב העבודה הליניארי. `ambient.color` ו־`groundColor` משמשים ב־HemisphereLight. הפוג ליניארי לפי עומק המבט, כמו `THREE.Fog`.
- גרדיאנט שמיים: צבע הקרקע מתחת לגובה כיווני ‎−0.15, אופק ב־0, צבע עליון ב־0.35 ושיא ב־1. אריח השמיים חוזר 8×4 ומוסיף שונות עדינה בלבד. הכוכבים מפוזרים עם seed קבוע; העננים הם billboards שקופים.
- התצוגה משתמשת ב־ACES Filmic, חשיפה 1 ו־sRGB output לכל הערכות. נשמרת אותה חשיפה בהשוואה. DPR מוגבל ל־1.5; צל שמש אחד של 1024² לכל זירה. הזרקורים מאירים באמת, עם דעיכה ריבועית וללא מפות צל נוספות. ההילות הן sprites במיזוג additive.
- במנוע עם קנה מידה אחר מגדירים `worldUnitsPerMeter`. לדוגמה, 94 יחידות למטר מכפילות את מרחקי הערפל והזרקורים פי 94 ואת עוצמת הזרקורים פי 94², לשימור ההארה. יש להשאיר `camera.far` מעל `340 * worldUnitsPerMeter` כדי להכיל את כיפת השמיים והכוכבים. מרכז סביבת הדוגמה הוא ראשית העולם.
- המתאם מקבל את מופע `THREE` של המשחק ואינו יוצר renderer או לולאת משחק. קוראים ל־`update(seconds, camera)` מתוך הלולאה הקיימת. יש להחליף את מקור התאורה הקודם בנקודת החיבור כדי לקבל את העוצמות המתוכננות.

דוגמה בתוך מודול של משחק, עם נתיבים יחסיים מקומיים מותאמים למקום החיבור:

```js
import './design/lighting-presets-v1/preset-data.js';
import './design/lighting-presets-v1/lighting.js';

const pack = globalThis.LIGHTING_PACK;
const maps = await IslandLighting.loadTextures(THREE, pack, globalThis.LIGHTING_TEXTURES);
const lighting = IslandLighting.create(THREE, scene, maps, { worldUnitsPerMeter: 1 });
renderer.outputColorSpace = THREE.SRGBColorSpace;
renderer.toneMapping = THREE.ACESFilmicToneMapping;
renderer.toneMappingExposure = pack.renderer.exposure;
lighting.apply(pack.presets.find(p => p.id === 'morning'));
// In the existing frame loop:
lighting.update(seconds, camera);
// On teardown: lighting.dispose(); caller disposes maps after the last user.
```

אפשר לטעון רק `presets.json` עם מנגנון הנכסים המקומי של המשחק במקום העותק המוטמע. בעת שינוי ערכה עורכים את ה־JSON ומריצים את הבנייה לעדכון snapshot, טקסטורות, ZIP ו־manifest; לא עורכים את `preset-data.js` ידנית.

## בדיקות ותוצאות

תוצאות הנכסים ב־[asset-report.json](verification/asset-report.json), ותוצאות הדפדפן ב־[browser-report.json](verification/browser-report.json). [גיליון השוואה של כל הערכות](verification/all-presets-contact-sheet.webp).

- Chromium 151.0.7922.173, ‏ANGLE/SwiftShader: עשר ערכות × שלוש זירות = **30 שילובי רינדור** ב־844×390. ערכי התאורה, העננים, הכוכבים, הערפל והמשקעים נבדקו בכל זירה. לכל זירה התקבלו עשרה צילומים שונים; נבדק שהאזורים התלת־ממדיים מכילים פרטים.
- בדיקה חזותית של כל עשר הערכות ושל הפריסות. זוויות המצלמה משאירות אזור שמיים; נבדקו בנפרד פיקסלים של כוכבים, עננים והארת משטח באמצעות זרקורים. ההשוואה נעשית עם האפקט מופעל וכבוי, על GPU תוכנה.
- פריסות: 844×390, ‏1280×720, ‏390×844 ו־320×740; אין גלילה אופקית. במידת היעד אין גם גלילה אנכית. כפתורים וקישור ההורדה הם לפחות 44×44 CSS px.
- בחירת ערכה דרך מקלדת, גרירה וחצים לסיבוב מצלמה, איפוס Home, העתקת JSON, הורדת JSON זהה לקנוני, תנועת חלקיקי גשם בפיקסלים, השהיה והעדפת תנועה מופחתת. התצוגה מתחילה ללא הנפשה כדי לאפשר השוואה יציבה; הלולאה נעצרת כשהדף מוסתר.
- מתאם בקנה מידה 94: מרחקים ועוצמת זרקורים חושבו נכון; מעבר מאצטדיון לצהריים הסיר את כל הזרקורים; `dispose()` חוזר בטוח ומשחזר את הערפל שהיה בסצנה. גם פינוי התצוגה נבדק.
- **0 בקשות חיצוניות, 0 שגיאות JavaScript/WebGL ו־0 שגיאות HTTP** בהרצות התקינות.
- ה־ZIP חולץ לתיקייה זמנית שאינה בתוך המאגר. כל עשר הערכות ושלוש הסצנות נטענו ב־browser context חדש עם `offline=True`, בלי cache, תוך אספקת ששת קובצי הדף הישר מהדיסק דרך תשתית הבדיקה. אין גישה לאינטרנט, לשרת HTTP או לקבצים שכנים של המאגר במסלול הזה.
- פתיחה ישירה ב־`file://` **לא אומתה**: Chromium המנוהל בסביבה חוסם אותה עם `ERR_BLOCKED_BY_ADMINISTRATOR`. לא שונתה מדיניות הדפדפן. לכן מצורף מפעיל loopback מקומי; קובצי התצוגה עצמם הם סקריפטים רגילים עם נתונים ותמונות מוטמעים, ללא fetch או imports.
- ללא JavaScript קישור הורדת הנתונים נשאר זמין; בהיעדר WebGL מוצגת הודעה וקישור ההורדה זמין. אין תצוגת תלת־ממד במצבים אלה.
- תקינות JSON, מזהים ייחודיים, וקטורים מנורמלים, גבולות מספריים, טווחי ערפל, PNG אמיתיים, אלפא, התאמה מדויקת של תפרי השמיים בשני הצירים, התאמת snapshot, SHA-256, תוכן ו־CRC של ה־ZIP ותקציב **כל התיקייה** נבדקים בכל הרצה של validator.
- `npm test` של המאגר עבר: **3,278 עברו, 0 נכשלו, 56 דולגו מתוך 3,334**, כ־191 שניות. סיכום ב־[repo-tests.json](verification/repo-tests.json). ההרצה השתמשה ב־Chromium 151 המותקן דרך `PLAYWRIGHT_BROWSERS_PATH` זמני תחת `/tmp`, עם קישורים ל־`/usr/bin/chromium`. ניסיון קודם ללא ההגדרה נכשל בבדיקת Royiki קיימת בגלל executable חסר של Playwright והותיר שרת בדיקה פתוח; לאחר התאמת סביבת ההרצה הורצה כל החבילה מחדש בהצלחה. לא נערך קוד הבדיקה הקיים.

מקור ו־SHA-256 של עותק Three.js ב־[source-provenance.json](verification/source-provenance.json). רשימת השינויים והוכחת ההגבלה לקבצים חדשים ב־[scope-report.json](verification/scope-report.json).

### הרצה חוזרת

משורש המאגר; כלי היצירה והבדיקה דורשים Python 3 ו־Pillow. בדיקת הדפדפן דורשת גם Playwright ו־Chromium. אלה כלי פיתוח בלבד; אינם דרושים לצפייה.

```sh
python3 workout/island/design/lighting-presets-v1/tools/build.py
python3 workout/island/design/lighting-presets-v1/tools/validate.py
python3 workout/island/design/lighting-presets-v1/tools/check_browser.py
```

`build.py` דטרמיניסטי: אין הורדות, השעה בקובצי ה־ZIP קבועה, והוא כותב רק בתוך החבילה. `presets.json` הוא המקור לערכים; ה־PNG נבנים מנוסחאות מקוריות. הפרש מעטפת Three.js מתועד ברישיון; המקור המקומי במאגר הבסיס לא נערך.

## מגבלות והמשך חיבור

אין כאן שינוי בתאורת המשחקים הפעילים או פרסום לאתר. הסצנות הן זירות דוגמה מקוריות; הן אינן צילום מהמשחקים. הגשם אינו מוסיף רטיבות והשלג אינו מוסיף כיסוי קרקע דינמי. יש לשלב את החוזה דרך התאורה והחומרים של כל משחק, כולל התאמת קנה מידה ומצלמה. תנועה רצה רק לפי בחירה; לא נמדדו FPS או צריכת סוללה בטלפון פיזי. נדרש לבדוק קריאות, איכות וביצועים במכשיר לאחר החיבור למשחק.
