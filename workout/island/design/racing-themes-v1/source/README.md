# כלי המחבר והאימות

התצוגה אינה דורשת התקנה או בנייה. כלי המקור נועדו לשחזור השכבות והאריחים ולבדיקת הנכסים. הם כותבים רק בתיקיית החבילה ובתיקיות זמניות; אין לשנות קבצי משחק, גרסה או שירות־עובד לצורך מסירת נכסים זו.

סביבה שנבדקה: Blender 4.3.2 במעבד, Node.js 24, ImageMagick 7, Python 3 עם Pillow, Playwright עם Chromium המותקן. תלויות האימות אינן נטענות בתצוגה.

משורש הריפו, יצירת 12 שכבות ו־4 מעקות בתיקייה זמנית:

```sh
blender -b --factory-startup --python workout/island/design/racing-themes-v1/source/render-layers.py -- /tmp/racing-themes-renders
```

אריזה מחדש של שכבות ואריחים, תוך שימוש באטלסי האביזרים המוכנים שכבר בחבילה:

```sh
node workout/island/design/racing-themes-v1/source/build-assets.mjs /tmp/racing-themes-renders --reuse-props
```

ששת תאי כל אטלס הם קובצי המקור המוכנים לשילוב. יצירה מחדש של תוכן האביזרים בבינה מלאכותית אינה דטרמיניסטית. החלפתם דורשת יצירת גיליון שקוף חדש, בדיקה חזותית והתאמת מלבני החיתוך במחולל. אפשר למסור למחולל נתיב לתמונת המקור במקום הדגל לשימוש חוזר; תמונת המחבר הגדולה אינה חלק מחבילת הריצה, וחתימתה נשמרת בקובץ המקורות. שאר המחולל משתמש בזרעים קבועים ואינו מוריד דבר מהרשת.

אימות פורמט, משקל, שקיפות, מסגרות אביזרים, שפות אריחים, חתימות ותיקיית השינוי:

```sh
python3 workout/island/design/racing-themes-v1/source/verify-assets.py
```

לבדיקות הדפדפן בלבד, להפעיל שרת מקומי משורש הריפו:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

ובמסוף נוסף:

```sh
node workout/island/design/racing-themes-v1/source/verify-browser.mjs
```

בדיקת הדפדפן שומרת צילומי מסלול ונכסים במידה המקורית, בודקת כל שכבת רקע בנפרד, מעברים מהירים בין ערכות, ניגון והשהיה, העדפת תנועה מופחתת ומצב ללא רשת. אם מדיניות הדפדפן המנוהל חוסמת פתיחה ישירה של קבצים, הבדיקה מתעדת זאת וטוענת את אותם קבצים מהדיסק באמצעות מיפוי בקשות מקומי, כשהרשת כבויה. היא אינה משנה את מדיניות הדפדפן.
