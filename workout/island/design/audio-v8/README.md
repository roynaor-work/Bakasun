# צלילי ספורט v8

36 אפקטים מסונתזים במודול WebAudio עצמאי אחד: שופט, כדורסל, כדורגל, קהל, צעדים ודשא, טניס, סקי ומירוצים. כל מקור מוגבל בזמן ונעצר מפורשות; אין קהל או שריקה בלולאה, קובצי שמע או הורדות בזמן משחק.

1. [הקשבה](index.html) — הפעילו דרך שרת HTTP, לחצו “הפעלת שמע” ובחרו אפקט.
2. [חיבור ודוגמה מלאה](INTEGRATION.md) — המודול היחיד לייבוא: `runtime/sports-audio.mjs`.
3. [מדידות, סבבים וציונים](REPORT.md) — הבדיקות האחרונות ב־`iterations/05` ו־`iterations/06`.

בדיקה עצמאית מתוך תיקייה זו, ללא התקנות:

```sh
node --test
```

קובצי המשחק הקיימים אינם משתנים. קטלוג הפונקציות, אורכי ברירת המחדל, התקרות ושיאי ה־PCM מוגדרים ב־`SOUND_CATALOG`. בקריאה ל־prepare מכינים את אירועי המשחק במסך הכניסה, לפני לולאת הציור.

רק `runtime/sports-audio.mjs` מיועד לייבוא במשחק. עותקי הקוד ב־iterations הם ראיה לשני הסבבים האחרונים והשוואת מעטפות, והעותק האחרון נבדק מול מודול הריצה. דוחות המדידה הם Markdown קריא; אין קובצי JSON או אודיו בחבילה.
