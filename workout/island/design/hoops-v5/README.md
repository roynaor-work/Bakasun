# כדורסל v5 — אולם וקהל

חבילת נכסים ותצוגה עצמאית, 04/11/2026. אולם במידות מגרש מקצועני אמריקאי, ללא שמות ליגה, מועדונים, מותגי ציוד או שחקנים אמיתיים.

נוצרו פרקט מייפל עם חומר לכה והשתקפות חיה, יציע בן שתי קומות עם 2,762 צופים, גופי תאורה וקורות תקרה, לוח תוצאות תלוי בעל ארבע פאות, מסכי קצה, ספסלי שתי קבוצות ושולחן מזכירות. שני הסלים כוללים זכוכית, טבעת, רשת יהלומים, ריפוד ושעון זריקה. שתי גופיות מקוריות בצבעי טורקיז ושנהב נושאות את המספרים 07 ו־23; לכדור מפת עור מחוספס ונורמל.

החבילה נמצאת כולה בתיקייה זו. לא שונו קוד המשחק, שמירות, איזון, נכסים קיימים או גרסת ההפצה. העדכון היחיד מחוץ לתיקייה הוא רישום המסירה ב־`ops/CONTROL.md`.

## צפייה ובדיקה בטלפון

1. משורש המאגר מפעילים שרת תצוגה מצומצם:

   ```sh
   python3 workout/island/design/hoops-v5/source/serve.py
   ```

2. פותחים [את התצוגה המקומית](http://127.0.0.1:8765/workout/island/design/hoops-v5/preview.html). השרת מאזין ל־loopback בלבד ומגיש רק את החבילה והתלויות הגרפיות המותרות. לצפייה במכשיר פיזי נדרש שרת פיתוח נגיש למכשיר או חיבור החבילה לאתר במסגרת משימת האינטגרציה.
3. עוברים בין אולם, פרקט, יציע וחומרים. גוררים לסיבוב, צובטים לזום, ובודקים עצירת תנועה וחיסכון. במקלדת: חצים, פלוס/מינוס ו־Home לאיפוס. כל ששת יעדי המגע הם לפחות 44×44 פיקסלים.
4. התוצאה הצפויה: ארבעה מבטים תקינים לאורך ולרוחב, טקסטורות מלאות, תנועת קהל, והשתקפות שנעלמת במצב חיסכון. חסרון של נכס מציג הודעת כשל וניסיון נוסף.

אין טעינת CDN, גופנים מרוחקים או גישה לרשת חיצונית. `script-src 'self'` נשמר; Draco משתמש ב־worker סטטי מקומי. `blob:` מותר לתמונות ולקריאת טקסטורות מוטבעות ב־GLB בלבד.

## קובצי המסירה

הגדלים המדויקים, SHA־256, מרקמים וספירות לאחר פענוח נמצאים ב־[verification/assets.json](verification/assets.json). כל GLB דורש Draco; כל primitive דחוס ונבדק גם לאחר פענוח עצמאי.

המגבלה היא **1,500,000 bytes לכל קובץ**, ולא לחבילה כולה. הגדול ביותר הוא כ־1.03MB. כל 11 קובצי הטקסטורה וכל התמונות המוטבעות עד 1024 בכל ציר ועד 1.5MB; הטקסטורה הגדולה היא אטלס הקהל, 683,028 bytes. פירוט ב־[מלאי הטקסטורות](verification/texture-inventory.json).

הטקסטורות החיצוניות הן עותקי מסירה/עריכה של המפות המוטבעות. התצוגה טוענת את ה־GLB בלבד, ללא טעינה כפולה שלהן.

## שחזור

Blender 4.3.2; Node 24.19; Python עם numpy 2.3.5, Pillow 12.3.0 ו־Playwright 1.62.0; Chromium מותקן ב־`/usr/bin/chromium`. תלויות Node מוצמדות ב־[source/package.json](source/package.json). מתקינים אותן בתיקיית כלים מחוץ למאגר, עם cache במיקום בר־כתיבה.

```sh
python3 workout/island/design/hoops-v5/source/textures.py
blender -b -t 4 --python workout/island/design/hoops-v5/source/build.py
node workout/island/design/hoops-v5/source/pack.mjs --modules /absolute/tooling
python3 workout/island/design/hoops-v5/source/browser-check.py
npm test
```

`build.py` יוצר קובצי ביניים לא דחוסים. **חובה להריץ `pack.mjs` אחריו**, לפני שימוש או מסירה. גוונים ופריסת קהל דטרמיניסטיים ב־seed 504. יש לבדוק חזותית את הצילומים המחודשים לאחר שינוי גאומטריה או מצלמה.

מקורות וזכויות ב־[LICENSES.md](LICENSES.md).
