## צפייה

1. משורש המאגר הפעילו שרת סטטי:

   ```sh
   python3 -m http.server 8765 --bind 127.0.0.1
   ```

2. פתחו את [תצוגת הסביבות](http://127.0.0.1:8765/workout/island/design/alpine-v5/preview.html), החליפו בין שלוש הסביבות ולחצו על ״הדגמת נחיתה״ ו״רסס אבקה״. מתחת לזירה יש רקעים בשני הכיוונים, נגן פריימים ואטלס סימונים.
3. התוצאה הרצויה: הרים ללא מתיחה, גדרות וסמנים קריאים, אור על השלג בלילה, אבקה עם שוליים שקופים שנעלמת בסיום. בדקו ב־844×390 וב־390×844. צילומי מסירה נמצאים ב־[previews](previews/).

התצוגה משתמשת בקובצי המסירה הסופיים וב־Three.js ו־GLTFLoader הקיימים ב־`../../vendor/`. לכן יש לפתוח אותה מתוך המאגר באמצעות HTTP; אין צורך בהתקנה או ב־CDN. היא מדגימה הרכבה של הנכסים, ואינה מסלול משחק או מדידת ביצועים בטלפון.

## חוזה שילוב

קראו את `manifest.json`, בחרו `environments/<id>.json` וטענו את הנכסים שברשימת `assets`. הנתיבים ב־manifest יחסיים לתיקייה זו; `image` בקובץ אטלס יחסי לתיקיית קובץ האטלס. המדידות וחותמות SHA-256 חושבו מהקבצים הסופיים. יש לטעון סביבה אחת בכל פעם ולהשתמש במזהים המשותפים כמפתח למטמון.

**רקעים:** לרוחב 1536×864, לאורך 720×1280. sRGB, ללא alpha, ללא חזרה, `cover` תוך שמירת יחס התמונה. אלה לוחות רקע עם תאורת הרים מרוחקים אפויה, ולא HDR, cubemap או תאורת PBR. גרסאות האורך הן חיתוך מכוון מתוך הלוח הרחב; זרקורי הרקע שבקצוות יכולים לצאת מהחיתוך. הזרקורים בתלת־ממד מספקים את התאורה הקרובה בכל כיוון. יש לשחרר את מרקם הכיוון הקודם בעת סיבוב המסך.

**שלג:** `textures/snow-albedo.webp` הוא צבע בסיס ניטרלי 512×512; normal ו־roughness בגודל 256×256. Albedo ב־sRGB, נתוני normal/roughness במרחב לינארי, normal מסוג OpenGL ‎+Y. מפה אפורה יכולה להידגם בערוץ R; ב־Three.js גם G מכיל את אותו ערך. `RepeatWrapping`, חזרה אחת לכל 4×4 מטרים, mipmaps ו־anisotropy עד 4. הגוון והתאורה נגזרים מהגדרת הסביבה; אין לצבוע מחדש את קובצי המקור. שוליים נגדיים זהים בדיוק אחרי פענוח.

**אטלסים:** אבקה וענן נחיתה הם PNG בגודל 512×512 עם 4×4 תאים, 128×128 לתא, padding שקוף של 12px. אבקה: 20fps, ‏0.8 שניות; נחיתה: 16fps, שנייה אחת. סדר משמאל לימין, שורה עליונה תחילה. `rect` משתמש בראשית שמאל־למעלה; `uv` הוא `[u0,v0,u1,v1]` בראשית שמאל־למטה, כבר עם חצי פיקסל פנימה. אל תהפכו את השורה פעמיים. טענו תמונת אטלס רגילה עם ברירת המחדל `flipY=true` של TextureLoader; בקישור ל־glTF או למנוע עם `flipY=false`, התאימו את v פעם אחת לפי חוזה הטעינה.

```js
// רק אחרי אירוע מגע אמיתי שמגיע מהסימולציה:
const age = nowSeconds - contactSeconds;
if (age >= atlas.durationSeconds) hideEffect();
else useFrame(atlas.frames[Math.floor(age * atlas.fps)]);
```

Alpha הוא straight/unassociated; RGB נשמר גם בפיקסלים שקופים לצמצום הילות כהות. דגימה לינארית, clamp-to-edge, ללא mipmaps, ‏`depthWrite=false`, ‏`depthTest=true`, blending רגיל `SRC_ALPHA / ONE_MINUS_SRC_ALPHA`. עקומת ההופעה וההתפוגגות אפויה; לא להכפיל מעטפת opacity נוספת. הפריים הראשון והאחרון ריקים בכוונה. `pivot` נמדד מראשית התמונה העליונה: `[0.5,0.8]` תואם `Sprite.center=(0.5,0.2)`. להגביל לשני ענני נחיתה ושלושה רססי אבקה; תקציב כיסוי שקוף כולל עד 12% מסך הוא יעד שילוב, לא תוצאת מדידה.

`snow-flecks` מכיל 16 **וריאציות סטטיות** של גרגרי שלג, ולא רצף אנימציה. בחרו תא אקראי לכל חלקיק, עד 48 חלקיקים בגודל 0.8–3.5 ס״מ. לא להפוך אותם לפתיתי כוכב גדולים. במצב תנועה מופחתת מכבים שלג אווירה ותנועת ערפל; מגע יכול להציג פריים סטטי 5 למשך 150ms וב־opacity ‏0.35.

**סימונים ו־decals:** אטלס `decals/route-and-snow.png` מספק 16 סמלים: חץ ירידה, chevrons, פניות שמאלה/ימינה, אזהרה, קו גבול, אזור נחיתה, משבצות סיום, זוג חריצי סקי, חריצי פנייה, סימן נחיתה, אדוות שלג, סדק קרח, נקודות מקל וסמן מסלול. השמות, UV והמידות נמצאים בקובץ JSON הצמוד. ראש הסמל לכיוון `+Z` במישור השלג. יש להקרין על פני השטח המקומיים, להשתמש ב־polygon offset ולכבות depthWrite; מלבן אופקי יחיד על מדרון יכול לצוף או להיבלע. אין להשתמש בסמל כ־collider או כסמכות לניקוד.

**מודלים:** מטרים, מעלה `+Y`, התקדמות במסלול `+Z`, שורש בראשית, סיבוב אפס ו־scale ‏1. גדר ברוחב 6 מ׳ כוללת שני עמודי קצה, עוגני `anchor_snap_left/right` ושקיעה של 12 ס״מ בשלג. יישור העוגנים של שני מקטעים גורם לחפיפה מכוונת של עמודי הקצה; אין להוסיף עמוד נוסף שם. רשת הגדר היא גאומטריה פתוחה עם 592 משולשים, ללא מישור alpha מלא. סמן המסלול פונה ל־`-Z`, החץ על הלוח לכיוון `+Y`; בתצוגה מסובבים אותו אל הגולש. דגמי הגדר והסמן נפרדים לכל סביבה, עם אותם מידות ועוגנים.

עמוד הזרקורים מכיל עדשות emissive ועוגני `anchor_lamp_0..2`. Emissive לבדו אינו מאיר שלג: יש להציב תאורת זמן־אמת או בריכות אור ליד העוגנים. הגדרת הלילה כוללת שתי הצבות, יעדים, צבע ועוצמה בקנדלה. התקציב: עד שני SpotLight ללא צל; בטלפון חלש משתמשים בעדשות ובבריכות אור בלבד. חרוט האור הוא billboard שקוף עדין; אין צורך ב־volumetrics או postprocessing. ערפל המרחק מוגדר כ־linear; אפשר להתאים בעת החיבור את טווחי הערפל למרחק הראייה של המשחק.

## שחזור ובדיקות

הכלים דורשים Python עם NumPy ו־Pillow. אפשר לשחזר את הגאומטריה, המרקמים והאפקטים תוך שמירת לוחות הרקע שכבר נמסרו:

```sh
python3 workout/island/design/alpine-v5/tools/build-assets.py --reuse-backgrounds
python3 workout/island/design/alpine-v5/tools/finalize.py
python3 workout/island/design/alpine-v5/tools/validate.py
```

לייצוא רקעים מחדש נדרשים שלושת קובצי PNG המקוריים, שחותמותיהם ב־`sources.json`; הם נשמרו מחוץ לחבילה. `build-assets.py --sunset <png> --fog <png> --night <png>` מבצע חיתוך, שינוי גודל וייצוא בלבד. יצירת המאסטרים עצמה מתועדת ב־[PROMPTS.md](PROMPTS.md).

כלי הבדיקה החיצוניים אינם חלק מחבילת המשחק. לדוגמה:

```sh
npm install --prefix /tmp/alpine-v5-checks --cache /tmp/alpine-v5-npm-cache --ignore-scripts --no-audit --no-fund gltf-validator@2.0.0-dev.3.10 playwright-core@1.64.1
node workout/island/design/alpine-v5/tools/check-gltf.mjs /tmp/alpine-v5-checks/node_modules/gltf-validator/index.js
node workout/island/design/alpine-v5/tools/check-preview.mjs /tmp/alpine-v5-checks/node_modules/playwright-core/index.mjs
python3 workout/island/design/alpine-v5/tools/export-previews.py
```

בדיקת הדפדפן מצפה ל־Chromium ב־`/usr/bin/chromium`; ניתן לבחור נתיב עם `CHROMIUM_PATH`. היא מפעילה שרת loopback זמני, אוכפת CSP מקומי, בודקת את שתי המידות, החלפות מהירות, סיבוב מסך ו־reduced motion, ושומרת PNG זמניים ב־`/tmp` לצורך ייצוא צילומים. דוח הבדיקה אינו טוען לבדיקת טלפון פיזי. הגרסה והמשחק הקיימים אינם חלק ממסירת הנכסים.
