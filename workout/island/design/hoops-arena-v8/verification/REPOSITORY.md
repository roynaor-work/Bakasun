# אימות מול הריפו

`npm test` הורץ על הריפו ללא שינוי קוד קיים או בדיקות קיימות. תוצאה: **3,277 עברו, 55 דולגו, 0 נכשלו**; 3,332 בדיקות בסך הכול. משך הריצה המדווח: 341.03 שניות.

סביבת ההרצה: Node 24.19.0, גישה מקומית לרשת עבור שרתי בדיקות, Chromium המותקן ב־`/usr/bin/chromium`, Playwright 1.56.1. בורר `ISLAND_PLAYWRIGHT` של הבדיקות הופנה למתאם זמני מחוץ לריפו, שבוחר את Chromium המערכתי ואת דגל sandbox של סביבת הענן. המתאם אינו משנה assertions או התנהגות בדיקות.

בריצה הראשונה במעטפת המוגבלת נכשלו ארבעה קובצי בדיקה בשל `spawnSync/listen EPERM`; בהרצה עם רשת נמצא גם שדפדפן ה־bundle של Playwright אינו מותקן. בחירת דפדפן המערכת והרשאות הריצה המתאימות פתרו את הכשלים. לא שונה שום קובץ קיים כדי להשיג מעבר.

הבדיקה הנדרשת לחבילה היא נפרדת, וללא תלות בכלים האלו:

```sh
cd workout/island/design/hoops-arena-v8
node --test
```

13 בדיקות החבילה עוברות: משולשים לכל חלק לאחר פענוח, שכפול nodes, קהל/מושבים/מסכים/כדור בפועל, שלושה LOD, שתי הגשות בריפליי, UV לפרקט, עוגני שילוב, גדלים, מרקמים, שמירת שני סבבים, מידות PNG, חתימת הצילומים, חלון ריפליי חסום, אינטרפולציה ושחזור מצב.
