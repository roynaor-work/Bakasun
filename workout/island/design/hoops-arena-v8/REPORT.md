# אולם 08 — מסירת אולם ושידור לכדורסל

אולם מקורי ללא סמלים: פרקט מייפל עם חומר לכה והחזר תאורה, שני סלים עם לוחות שקופים ורשתות פתוחות, שתי קומות יציע, קהל ומושבים ב־instancing, תאורת זרקורים, קוביית תוצאות, שעוני 24 ו־HUD בעברית עם עבירות ותצוגת ריפליי. אין שחקנים בחבילה.

`runtime/` היא תיקיית הריצה. [INTEGRATION.md](INTEGRATION.md) כולל דוגמת טעינה קצרה וחוזה שילוב. [RUNTIME.md](RUNTIME.md) מכיל את רשימת הקבצים המדויקת, הגדלים ו־SHA-256. three.js r160 ו־Draco מקומיים; ללא build וללא CDN.

התקציב כולל את כל האולם, מספר מופעי nodes, כל מופעי הקהל והמושבים, שמונת מסכי התוצאה/24 וכדור הדוגמה. ספירת הריפליי כוללת שתי סצנות מלאות ללא הנחת culling. כל primitive מפוענח ב־Draco, וספירת הגאומטריה הדינמית משתמשת ב־factories של ה־runtime. [הפירוט לכל חלק](verification/BUDGET.md).

## הסבבים והבדיקות

בוצעו **9 סבבי בנה → רינדור → בדיקה → ביקורת → תיקון**. רק סבבים [08](iterations/08/REVIEW.md) ו־[09](iterations/09/REVIEW.md) נשמרים בתמונות; שבעת הקודמים נמצאים כשורה אחת כל אחד ב־[HISTORY.md](iterations/HISTORY.md). בכל סבב נשמרו שישה מצבים: רחב וקרוב בשני כיווני מסך, וריפליי בשניהם. חתימת runtime של הצילום האחרון נבדקת אוטומטית.

- `node --test`: **13 עברו, 0 נכשלו**, ללא npm install.
- [בדיקות דפדפן](verification/BROWSER.md): מצלמות, איכות, ריפליי, 24/עבירות, DPR1/2, סיבוב מסך, גבולות טקסטורות, חיתוך, כשלי GLB/worker/WASM, אובדן context, CSP האי ו־5 מחזורי טעינה/ניקוי על אותו renderer.
- [בדיקות הריפו](verification/REPOSITORY.md): **3,277 עברו, 55 דולגו, 0 נכשלו**, בלי שינוי קבצים קיימים.
- [מדידת תוכנה](verification/PERFORMANCE.md): עלות update/render/gl.finish ב־Chromium/SwiftShader, עם מגבלות סביבת הענן מפורטות. אין טענה למדידת GPU בטלפון פיזי.
- [מבחן רינדור רציף](verification/SOAK.md): **145.00 דקות, 142 מחזורים, 37,267 פריימים; עבר**. [כל הדגימות](verification/soak.csv) אומתו עצמאית: עבודה חיובית, עד 28,800 משולשים נצפים, 137 גאומטריות GPU, 8 טקסטורות, ועד 46,272 בתים לבאפרי הריפליי. הגרסה הסופית נבדקה במשך 115 דקות ללא שינוי runtime. אין שגיאות דף/קונסול/בקשות חיצוניות.

ביקורת עצמית קצרה: הבעיות שנמצאו ותוקנו כללו UV שהוסר בייצוא, פינות וקיר שהסתירו את המגרש, ריפליי חתוך באנכי, מעקה שחצה צופים, מידות לוח וטבעת, משאב PMREM שנותר, וחוסר התאמה של worker למדיניות האי. החבילה הנוכחית שומרת על תקציב גם בריפליי ומתאימה לחיבור למנוע; בדיקת מכשיר פיזי היא שלב האינטגרציה שנותר.
