# Internal authoring contract
All new files only in this package. Source groups import pure helpers from `./authoring.mjs` and descriptors from runtime/catalog.mjs. These descriptors (83 actions) are the agreed action list; do not edit catalog without coordinating.

Group modules export `pose(meta,t)` and optional `definitions(meta)` where t in [0,1]. pose returns same V8 target structure `basePose()`: hips additive vector, yaw, lean (positive is +Z tilt), twist (Chest relative to Hips), roll, headPitch/headYaw, feet.{LeftFoot,RightFoot}.{sole:[x,y,z],yaw,pitch}, hands.{LeftHand,RightHand}.{position,orientation,contact}, ball:[x,y,z], phase string, reference:[x,y,z]. `basePose()` is v8 held-ready; override hands for empty clips, no outstretched T idle. Ball invisible for meta.ball=false via export scale (ball still defined). In-place: local feet subtract reference motion; reference is separate host-owned path. Root identity. Final local pose must exactly equal first for loop clips; build enforces it.

Use analytic IK `bakePose(p,t)` root pipeline. IMPORTANT canonical arms .27+.24m; legs .41+.37m (read runtime/skeleton.mjs). Legs and hands must reach their targets without clamping. Common helpers: control(time,[[t,value]...]), ramp,smooth,pulse,mix,add/sub/mul,norm,axis,euler,rotate,contactHand(center,normal,fingers),freeHand(position,normal,fingers),twoHands(center,back,tilt),basePose(). Hand contact [0,-.08,.025], foot sole [0,-.08,0], ball radius .12. Be mindful ballReady p.ball defaults y1.115 z.34, canonical rest hip? Read skeleton.

Definitions returns {events:[{time,name,domain:'presentation'}], supportWindows:[{effector,startTime,endTime,kind:'plant'|'pivot',localPointMeters:[0,-.08,0]}], ballContactWindows:[{effector,startTime,endTime,localPointMeters:[0,-.08,.025]}], phases:[{startTime,endTime,name}]}. Pipeline fills atSeconds/support seconds/anchorMeters. If definitions omitted build derives support/contact windows from per-frame pose using continuous intervals. Set p.phase to 'held'|'gather'|'carry'|'release'|'flight'|'dribble-contact'|'dribble-flight'|'empty'; separate real release from dribble releases. You may return p.events? Prefer definitions for exact timings on 30Hz (times aligned to frame/duration).

30Hz exact: duration*30 is integral; t=i/(duration*30). Pose samples only this grid, interpolated 120Hz acceptance. Do not add off-grid time keys. Events may be continuous but pipeline windows quantized. For anticipation use crouch before jump, landing flexion after; dunk palm >=3.30m, shoulder + arm reach constraints; canonical athlete ~1.65m tall requires ~1.5m hips lift to clear rim. Hold/gather below sternum until shot/dunk action lift, annotate phase 'shooting'|'dunk' when intentionally above chest. Shots ball stays in hand surface contact up to release. Euro long then short grounded strides then jump; both hands during gather, guide leaves late, main hand only releases at launch.

Optional rigid body orientation: p.hipsPitch/p.hipsRoll rotates Hips before spine/chest lean, Root identity unchanged. p.legPoles?.Left/Right and p.armPoles?.Left/Right absolute root-local points override default body-relative poles. Defaults now rotate leg and arm poles by full Hips orientation to support prone/supine getup.
