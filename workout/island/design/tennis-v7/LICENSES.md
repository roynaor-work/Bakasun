# מקורות ורישיונות

הדמויות, התלבושות, המחבטים, המגרשים, הרשת, הכדור, הצוות, היציעים, פריסת הקהל והאנימציות הם נכסים מקוריים ובדויים. לא נעשה שימוש בפנים מצולמות, סריקה של אדם, שם או מראה של שחקן אמיתי, סימן מסחרי או סמל מועדון.

| רכיב | מקור | רישיון |
|---|---|---|
| אנטומיה בסיסית, משטחי פנים, בגד ונעל | פונקציות מקור קיימות ב־`../characters2/source/{mesh,body,head_hands,gear}.py`; שימוש בקריאה בלבד | CC0-1.0 לפי חבילת המקור |
| שלד / טופולוגיה | שמות, סדר והורים מ־`../motion2/soccer.json`; כיול תנוחת T ו־inverse binds חדשים ב־`rig.json` | CC0-1.0 |
| ארבעת מראות הטניס, אטלסים, אחיזה סגורה וחצאיות | `source/characters.py` | CC0-1.0 |
| תנועות הטניס | keyframing מקורי ו־IK בזמן ייצוא ב־`source/motions.mjs`; אין motion capture או קליפים מסחריים | CC0-1.0 |
| זירה, צוות, רשת, כדור, פריסת קהל ומרקמי קרקע | מחוללים מקוריים בתוך `source/` | CC0-1.0 |
| Three.js r160, GLTFLoader, DRACOLoader | npm `three@0.160.0`; מאוגד מקומית ב־`vendor/three-r160-loaders.js` | MIT, נוסח מלא ב־`vendor/LICENSE.three` |
| מפענח Draco JS | עותק הספרייה שמופץ עם Three r160; תוכן ללא שינוי עטוף במחרוזת preload | Apache-2.0, נוסח מלא ב־`vendor/LICENSE.draco` |
| כלי כתיבה בלבד | glTF Transform 4.5.1 (MIT), meshoptimizer 0.24.0 (MIT), gltf-validator 2.0.0-dev.3.10 (Apache-2.0), esbuild 0.25.12 (MIT) | אינם נדרשים לפתיחת התצוגה |
| טיפוגרפיה | גופני מערכת מותקנים; אין הורדת גופן | אינו מופץ גופן בחבילה |

תוצרי העיצוב המקוריים נמסרים תחת [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/). רישיונות הספריות נשארים שלהם. ה־hash של כל מקור שנקרא וכל GLB שנמסר נמצא ב־manifest.json. אין שינוי לנכסי המקור.
