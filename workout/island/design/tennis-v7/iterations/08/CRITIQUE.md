# סבב 08 — עיגון הצוות, גלישה ובדיקת אופליין

נשמרו 12 צילומי Chromium. נוספו שרפרפים לצלמים, ידיהם הורמו אל המצלמה, והדום שופט הכסא והקהל הותאמו למפלסי המושב/המדרגות. החלקה מציגה כעת גלישה של עד 0.85 מ׳ לצד והתאוששות; המסלול חיצוני וה־GLB נשאר in-place. ניגוד תוויות הבקרה התחזק.

בדיקת הדפדפן רצה עם `offline=True`: קובצי התצוגה נקראו מהדיסק ישירות דרך harness, בלי חיבור לשרת ובלי בקשה חיצונית. כל בדיקות הבחירה, הניגון, ההשהיה, הסרגל, גרירה, צביטה, החלפת כיוון, מצב חסכון, reduced motion ושחזור הקשר WebGL עברו. עצירה אינה ממשיכה לרנדר פריימים מיותרים.

**לא מסיימים עדיין:** ברוחב 844 שלושת לחצני המשטחים הם כ־41.7px, פחות מ־44. יש להרחיב מעט את הפאנל. בבדיקה התגלה גם selector כללי שתפס את `body[data-view]` כאילו היה כפתור; הוא הוגבל לכפתורים ונוקה. החבילה המקומית מרובת קבצים תקינה, אבל כדאי למסור גם HTML יחיד הכולל הכול לפתיחה פשוטה בטלפון.

| סעיפים | מצב |
|---|---|
| C01–C15 | עוברים חזותית ובמבנה; פירוט צוות, גלישה, שתי ידיים וצל נבדקו |
| C16 | כל האינטראקציות עברו באופליין |
| C17 | לא עובר עדיין: שלושה לחצנים ברוחב 41.7 במקום 44 |
| C18 | כל 12 GLB תקינים, 0 שגיאות/אזהרות; הגדול כ־0.342 MB |
| C19 | מפת צל במטמון, LOD, Lambert חסכוני ו־DPR אדפטיבי קיימים; ההרצה הממושכת ממשיכה, מדידת תוכנה נפרדת תישמר |
| C20 | לא מסיימים עד צילום נוסף, בדיקת HTML יחיד וסיכום המדידות |

התיקון הבא מצומצם: פאנל רוחב 280px, יצוא HTML עצמאי, בדיקת אופליין חוזרת וצילום 09. אין שינוי בנכסי הדמויות ובקליפים שנבדקים ברצף.
