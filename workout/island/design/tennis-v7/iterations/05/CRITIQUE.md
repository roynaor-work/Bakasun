# סבב 05 — נכסים תקניים ותנועת שתי ידיים

נשמרה מטריצת עשרת הצילומים. נוספו מצחייה וסרטי בד מקוריים ללא סמל, והיד החופשית יורדת מתנוחת המרפק המוגבהת. בבקהנד היד השנייה מחושבת ביחס לידית ולא לפי נקודה מנותקת. מכווני Tangent קיימים במגרשים, ערכי הצבע בדשא תקינים, וכל 12 הקבצים עוברים glTF Validator בדחיסה ואחרי פענוח: **0 שגיאות, 0 אזהרות**.

**לא מסיימים עדיין.** יש צורך בתקריב אחיזה ופנים נגיש דרך הממשק, ובבדיקת מצב החסכון. בדיקת הרצף חשפה מגבלת צעד זמן 0.12 שמאטה תנועה במחשב המרנדר לאט מאוד; לא נשתמש במשך חלון המדידה כהוכחה למספר מחזורים. בהרצה הבאה יימדד זמן האנימציה בפועל.

| סעיפים | מצב |
|---|---|
| C01–C10 | עוברים חזותית ומבנית; שיער/כובע וארבעה בגדים מובחנים, ללא חורי ירך או גרב ארוכה |
| C11–C14 | מסלולים קיימים ותקינים בדגימות; שעון בזמן אמת דורש תיקון |
| C15 | מגע מחבט מסונכרן לדגימת FK; לבדוק אחיזה מוגדלת |
| C16–C17 | יעדי המגע גדלו; חסרים מיקודי פנים/ידית ובדיקת החלפת כיוון בזמן ניגון |
| C18 | עובר ללא אזהרות Validator; הגדול ביותר בדמויות כ־0.315 MB |
| C19 | נדרש מצב חסכון זול יותר וספירת פריימים המוצגים בפועל |
| C20 | מטריצת צילומים מלאה, ללא בקשות חיצוניות; ביקורת רצף זו אבחונית ואינה אישור ביצועי טלפון |

הערת תיעוד: בגרסה הישנה של capture.py חושבו hashes בסוף ההרצה. תסריט התצוגה התקדם בזמן שצילום 05 היה פתוח, ולכן ה־hash של preview.js ברשומה הזו אינו הוכחת הגרסה שנטענה לתמונות. התמונות עצמן הן צילומי Chromium מקוריים; מסבב 06 נשמר snapshot של המקור בתחילת הצילום.
