# סבב 03 — רציפות הגוף וביקורת תנועה מתמשכת

עשרת הצילומים נשמרו. נוספה ביקורת רצף ממושכת: כל אחד מתשעת הקליפים מנוגן במחזורים מלאים, בשני הכיוונים וביום/ערב; הדגימות והזמנים נשמרים ב־motion-review.json. גיליונות הפוזות משתמשים בפריימים אמיתיים מהדפדפן. בתחילת הסבב נבדק בעין גיליון שחקן א׳ על כל תשעת הקליפים.

גובה הסוליה המתועד הוא כ־0.020–0.021 מ׳, מול משטח/קו בגובה 0.009–0.025 מ׳. פתרון IK המתוקן מגיע ליעד המוגבל בדיוק נומרי, ללא מתיחת עצמות. פורהנד, בקהנד, וולה, שמאש והחלקה נבדלים בבירור במסלול. השירות כולל זריקה, תנוחת העמסה, פגיעה עילית ומעקב. הריצה נסגרת ללולאה, והחגיגה כוללת שתי הרמות.

**עדיין לא עובר.** פאות החצאית הפוכות, ולכן השכבה החיצונית נסתרת ומכנסי הבסיס נראים. נותרו שני פסי מכפלת ישנים בירך. בקצה השירות ראש המחבט נחתך בתקריב. הרשת נעלמת במרחק מפני סינון מפת alpha. בבדיקת התוכנה התגלו 1–5 FPS עם הקהל הישן; זו אינה מדידת טלפון, אך זו עלות שיש לצמצם. הערב עדיין בהיר מדי. גודל לחצנים צריך לגדול.

| סעיפים | מצב |
|---|---|
| C01–C03 | נוספו נורמלים עדינים; התקציב נשמר אך מפת נורמל 1K כבדה מדי ביחס לתועלת |
| C04 | לא עובר: רשת alpha נעלמת בריחוק; להחליף למיתרים ממשיים ולשמור צל רך מכוון |
| C05 | שופט כסא, ארבעה שופטי קו ושני צלמים קיימים ונבדקו במבט רשת |
| C06, C19 | לא עובר ביצועי תוכנה; נדרשים LOD זול באמת ואיחוד חומרי הזירה |
| C07 | עוד תיקון ערב נדרש |
| C08–C09 | לא עובר: כיוון פאות החצאית ומכפלת הירך |
| C10–C14 | התנועה והגובה השתפרו; שירות ושמאש צריכים מסגור רחב יותר מעל הראש |
| C15 | מיקום הסימון עובר; כדור קטן וכהה מדי בריחוק |
| C16–C17 | האינטראקציות תקינות; נדרשים לחצני 44px ומניעת חיתוך בשירות |
| C18 | כל GLB מתחת 1.5MB; יש להקטין נורמלים ל־512 בלי לפגוע במראה |
| C20 | צילומים, hashes, ביקורת ופוזות נשמרים; לא מסיימים בסבב הזה |

התיקונים הבאים: פאות חצאית, ניקוי גאומטריה ישנה, מרווח למחבט, LOD קהל של 32 משולשים בשורות הרחוקות, שני חומרים לזירה, מיתרי רשת ממשיים וצל רך מתמטי תואם אור, נורמלים 512 ותאורת ערב מזוהה.

הערת מדידה שהתגלתה בהמשך: בגרסה הזו צעד הזמן מוגבל ל־0.12 שנ׳. כאשר SwiftShader איטי מאוד, האנימציה מאטה ביחס לזמן הקיר; לכן `cyclesPerCase:3` הוא מספר המחזורים המתוכנן, ואינו אישור ששלושה מחזורים שלמים הוצגו. הדגימות העצורות וגובה הרצפה תקפים. בסבב 06 ואילך השעון מתוקן ונמדד גם מספר המחזורים בפועל.
