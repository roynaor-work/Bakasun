# סבב 06 — פנים, אחיזה, שעון וחסכון

נשמרו 12 צילומים, בהם תקריב פנים לאורך ואחיזת שתי ידיים לרוחב. יש כעת בחירת גוף/פנים/אחיזה; האצבעות נראות סביב הידית, הרשת והמיתרים ממשיים, והכדור נמצא ליד מרכז ראש המחבט בזמן הסמן. שירות לרוחב אינו חותך עוד את ראש המחבט.

**נדרש עוד סבב.** תקריב הפנים הראה שההפחתה אגרסיבית מדי למראה הקרוב: לסת ארוכה, עיניים צרות ומעברי פנים זוויתיים. יישמר יותר פירוט ב־LOD הקרוב, עם פנים מקוריות רכות יותר. תקריב דמות אינו מצדיק רינדור של כל הקהל. מצב החסכון הוסיף Lambert, אבל עוד לא נמדד בנפרד. בדיקה בקוד three.js הוכיחה שהמדידה הישנה אינה כוללת צללים.

| סעיפים | מצב |
|---|---|
| C01–C07 | עוברים בתמונות; תאורת יום/ערב מובחנת, צוות ויציע נוכחים |
| C08 | דורש שיפור בפנים בתקריב; המגדרים, התסרוקות והבגדים מובחנים |
| C09–C15 | אחיזה, שתי ידיים, ציוד, רצפה וסמני מגע נבדקו; השעון מתוקן לזמן קיר ונוסף מונה מחזורים בפועל |
| C16–C17 | גוף/פנים/אחיזה פועלים; עוד תיקון ליעד מגע 44px של הסרגל והסגל לרוחב |
| C18 | 12 GLB תקינים, 0 שגיאות/אזהרות בדחיסה ובפענוח |
| C19 | לא מסיימים לפני ביקורת החסכון, הסתרת עבודה שאינה נראית ומדידת main/shadow נפרדת |
| C20 | snapshot המקור נשמר לפני הצילום; הרצת רצף אחרונה תשתמש בשעון החדש |

השיפורים הבאים: פנים קומפקטיות יותר, עיניים פתוחות ורכות, LOD קרוב עם סבילות קטנה יותר, LOD לסגל, צל סטטי לזירה, צל מגע לשחקנים בריחוק והסרת קהל ממבטי פנים/אחיזה/קו. לאחריהם נשמר עוד סבב ונבדקות כל האינטראקציות בלי רשת.
