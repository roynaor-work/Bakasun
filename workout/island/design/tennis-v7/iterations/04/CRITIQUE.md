# סבב 04 — הקלה אמיתית, רשת וחצאית

נבדקו עשרת הצילומים ובפרט תקריב שחקנית, יום לאורך וערב לרוחב. החצאית כעת פונה החוצה, הירך רציפה והפסים הישנים הוסרו. המיתרים הם גאומטריה ממשית, והרשת נשארת קריאה גם כשהטקסטורה הייתה נעלמת קודם. צל הרשת הרך מוקרן לפי כיוון האור. ערב מציג קרקע כהה וגופי תאורה מאירים.

עלות מבט שידור: **84,791 משולשים, 33 קריאות ציור**, כולל צללים; קודם 143,803 ו־61. מעטפת הזירה ירדה ל־20,012 bytes ושני חומרים. הקהל הרחוק ירד ל־32 משולשים לאבטיפוס, נשאר instancing בכל השורות. הלחצנים העיקריים כעת 44–50px.

**עדיין לא מסיימים.** בדיקת GLB אחרי פענוח מצאה ערכי COLOR_0 מעל 1 בדשא ו־tangent חסר במפות הנורמל. אלה תוקנו לבנייה הבאה, יחד עם דיוק אחיזת שתי הידיים בבקהנד ותנוחת היד החופשית. חסרים מבטי פנים/אחיזה נגישים, ביקורת מדידה של מצב החסכון והחלפת כיוון בזמן ניגון. תקריב שירות צריך עוד צילום בפגיעה עצמה.

| סעיפים | מצב |
|---|---|
| C01–C03 | עוברים חזותית; תיקון glTF של הדשא ו־tangent נדרש |
| C04–C09 | עוברים בצילום; נוסף כובע מצחייה/סרט בד כדי להבחין בתסרוקות מלפנים בסבב הבא |
| C10–C14 | שלד וגובה עוברים; לדייק בקהנד בשתי ידיים ולבדוק שוב את כל הקליפים |
| C15 | כדור וסימון קיימים; עדיין נדרשת ביקורת אחיזה ומגע בתקריב אמיתי |
| C16–C17 | יעדי מגע עיקריים 44px; להוסיף מיקוד פנים/מחבט ולבדוק החלפת כיוון/מקלדת |
| C18 | 12 GLB בתחום; כל אטלס דמות 512, מפות קרקע 1024/512 |
| C19 | תקציב השתפר 68% מול 01; נדרשת מדידה נפרדת אחרי סיום ההקלות |
| C20 | כל צילומי המטריצה נשמרו, ללא גלילה או שגיאות קונסול |

הסבב הבא סוגר תקינות GLB, תנוחת שתי ידיים וביקורת שירות/שמאש. לאחריו — עוד סבב תקריבי פנים, אחיזה ואינטראקציה.

תיקון לתיאור המדידה: קריאת קוד Three r160 בהמשך הראתה ש־renderer.info באיפוס ברירת המחדל מונה את המעבר הראשי בלבד. המספרים לעיל הם של המעבר הראשי, ולא כוללים את מעבר הצללים. מסבב 07 איפוס ידני ומונה נפרד שומרים גם main וגם shadow; הדוח הסופי משתמש בהבחנה הזו.
