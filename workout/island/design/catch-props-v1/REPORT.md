# אביזרי מרדף — catch-props-v1

19 מודלי GLB מקוריים בסגנון low poly חם למשחק ״תפוס את הפושע״. מוכנים לסקירת נכסים: כביש רחב במבט מאחור, קטלוג עם תקריב לכל נכס, מונה משולשים, שני מצבי מצלמה, סיבוב ורשת משולשים. אין מילים, ספרות, לוחיות רישוי או מותגים על המודלים והאטלס. הברק, מפתח התיקון, המגן הבדיוני והסימון בשלט הם צורות גאומטריות מקוריות.

- נקודת הכניסה: [preview.html](preview.html).
- [גיליון כל הנכסים](previews/asset-sheet.png), [מבט מאחור](previews/road-rear.png), [כל הכביש](previews/road-overview.png), [מובייל](previews/mobile.png).
- [המניפסט](manifest.json) מכיל ספירות, מידות, מיקומים לתצוגה ו־SHA-256 לכל GLB.
- [מקורות ורישיונות לכל הקבצים](LICENSES.md); כל הקבצים החדשים CC0-1.0.

## פתיחת התצוגה

1. משורש המאגר הפעילו את השרת המקומי:

   ```sh
   python3 -m http.server 8765
   ```

2. פתחו [את תצוגת הנכסים המקומית](http://localhost:8765/workout/island/design/catch-props-v1/preview.html).
3. בחרו נכס בקטלוג לתקריב. כפתור ״מבט מאחור״ מחזיר לכביש, ״כל הכביש״ מציג מבט כולל. גרירה מסובבת את המצלמה וגלילה מקרבת. במקלדת: חצים לסיבוב, `+` ו־`-` לקירוב, `Home` לחזרה לכביש.
4. התוצאה הצפויה: 19 נכסים, 6,414 משולשים בערכה, כל נכס לכל היותר 836. ״הצגת משולשים״ חושפת את הרשת. ״רוטור מסתובב״ מניע רק את הצומת `rotor`.

התצוגה משתמשת בספריות הקיימות `../../vendor/three.module.js`, `../../vendor/GLTFLoader.js` ובתלות הקיימת שלהן `../../vendor/BufferGeometryUtils.js`. אין טעינת CDN, תהליך build, חיבור לחשבון או בקשות רשת חיצוניות. יש לשרת את המאגר באמצעות HTTP; פתיחה ישירה באמצעות `file:` מציגה הוראות.

## חוזה הנכסים

| מאפיין | ערך |
|---|---|
| פורמט | glTF 2.0 בינארי; קבצי GLB עצמאיים עם מאגר בינארי ותמונה מוטמעים |
| כיוונים ויחידות | חרטום / התקדמות ב־+Z, למעלה +Y, יחידה אחת = מטר |
| ראשית | שורש ללא סיבוב או קנה מידה; Y=0 בתחתית, X/Z במרכז תיבת התחימה |
| תקציב | עד 1,500 משולשים לכל נכס, כולל כל הילדים; המקסימום בפועל 836 |
| חומרים | חומר אחד, מרקם צבע אחד; roughness=1, metallic=0; נורמלים שטוחים |
| אטלס | [atlas-1024.png](atlas-1024.png), ‏1024×1024 RGBA, ‏11,270 בתים; 32 דגימות צבע במרכזי אריחים |
| אריזת האטלס | אותו PNG זהה בבייטים מוטמע בכל GLB. זהו אטלס משותף אחד; אין טקסטורות עזר או מפות normal |
| זיכרון מרקם | בתצוגה מוחלף העותק המוטמע במרקם משותף אחד, כ־4 MiB ללא mipmaps |
| דחיסה | גאומטריה ללא דחיסה; אין Draco, Meshopt או הרחבות glTF |
| מקור | גאומטריה ואטלס מקוריים ב־[source/build.py](source/build.py), ללא מודלים שהורדו |

הגבולות המדויקים לכל נכס נמצאים ב־`bounds` במניפסט. גלגלי הרכבים וסקידי המסוק נוגעים ב־Y=0; המסוק מוצג בגובה 4.1 מ׳ באמצעות מיקום מופע בלבד. צבעי הפנסים והחלונות אפויים באטלס; אין אורות, מצלמות, סביבה, שלד או אנימציות אפויות בקובצי ה־GLB.

### רוטור

במסוק השורש `police-helicopter` מכיל אחים `body` ו־`rotor`. ציר הרוטור מקומי +Y; מרכז הציר ביחס לשורש הוא `[0, 2.2, 0.44]` מטר. סיבוב `rotor.rotation.y` מניע את הלהבים והטבור בלבד. הרוטור הנפרד נכלל בספירת 590 המשולשים. רוטור הזנב הוא גאומטריה סטטית בתוך הגוף.

### דקלים, קפיצות ומעקה

ארבעת כתמי הכביש הם משטחים שטוחים לחלוטין ב־Y=0, ללא עובי. יש שני קווי מתאר שונים לכל סוג. alphaMode הוא `BLEND` והמשטחים דו־צדדיים; התצוגה מכבה `depthWrite` ומפעילה `polygonOffset` כדי למנוע ריצוד על הכביש. בעת חיבור למנוע המשחק יש להחיל הגדרות דקל דומות או להרים את המופע בכמה מילימטרים מעל פני הדרך.

הרמפה עולה לכיוון +Z מגובה 0.02 עד 0.9 מ׳ לאורך 3.6 מ׳. לגשר שתי רמפות עם רווח פתוח של 1.5 מ׳ בין Z=−0.75 ל־Z=+0.75; אין משטח מוסתר שחוצה את הרווח. המעקה הוא מקטע של 5 מ׳ לאורך Z. אלה נכסים חזותיים; נפחי התנגשות, הפעלת בונוסים ופיזיקת קפיצה יוגדרו בחיבור למשחק.

## אימות שבוצע

תאריך: 13/11/2026. ראיות מפורטות ב־[validation.json](validation.json).

- **Khronos glTF Validator 2.0.0-dev.3.10:** כל 19 הקבצים עברו עם 0 שגיאות, 0 אזהרות ו־0 הודעות מידע.
- **קריאת GLB עצמאית:** אומתו אורכי המקטעים, אינדקסים, נורמלים מנורמלים, כיוון הליפוף של כל משולש, היעדר משולשים מנוונים, מספרי משולשים ו־SHA-256.
- **חוזה גאומטריה:** כל השורשים ללא סיבוב/scale, התחתית ב־Y=0, מרכז X/Z בראשית, כל ארבעת הדקלים מישוריים. בכל קובץ חומר ותמונה יחידים, והתמונה זהה לאטלס שבחבילה. אין URIs חיצוניים או הרחבות דחיסה.
- **Chromium / Playwright עם SwiftShader:** תצוגות 1440×1050 ו־390×844. נבחרו כל 19 הנכסים בכל גודל; כל 19 חותכים את תחום הראייה בשני המבטים הכוללים. אומתו רשת משולשים, פקדי מקלדת, סיבוב נכס והנעת הרוטור ללא תזוזת גוף המסוק.
- **נגישות תנועה:** בהעדפת `prefers-reduced-motion` הרוטור מתחיל כבוי; אפשר להפעילו ידנית. לכפתורי בחירה יש מצב `aria-pressed`, ופוקוס מקלדת נראה.
- **טעינה:** 0 שגיאות דף/קונסול, 0 תגובות HTTP כושלות ו־0 בקשות חיצוניות בשני גדלי המסך.
- **סקירה חזותית:** נבדקו גיליון כל 19 הנכסים, כביש מאחור ומלמעלה ותקריבים. חלונות הרכבים מוצגים במלואם; מפתח הגלגל וסמל השלט קריאים משני הצדדים.
- **שחזור:** המחולל הורץ שוב והפיק GLB ואטלס זהים בבייטים. הוא דורש Python 3 ואת הספרייה הסטנדרטית בלבד.

בדיקת מובייל כאן היא הדמיית viewport בדפדפן שולחני. לא נמדדו FPS או צריכת זיכרון בטלפון פיזי. לא נוספו או נערכו קובצי בדיקות במאגר.
