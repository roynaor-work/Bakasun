# חוזה הרצף — API 1.0.0

`src/pit-sequence.mjs` הוא מודול JavaScript טהור לדפדפן ול־Node. אין תלות
ב־Three.js, ברשת, ב־WASM או בשעון מערכת. כל הזמנים בשניות של שעון המשחק;
הרצף התקין כולל כניסה ויציאה ונמשך **2.88 שניות ב־1×**. קובץ `sequence.json`
הוא מקור לוח הזמנים, שיוך הדמויות וחיבורי האביזרים. קוד המשחק הקיים לא חובר.

```js
import {createPitSequence} from './src/pit-sequence.mjs';
const config = await fetch('./sequence.json').then(response => response.json());
const pit = createPitSequence(config); // אישורים אוטומטיים לסימולציה המקומית
pit.start();
const snapshot = pit.update(1 / 60); // delta בשניות, מתוך לולאת המשחק
```

| יצוא או פעולה | חוזה |
|---|---|
| `API_VERSION` | המחרוזת `1.0.0` |
| `validateSequence(config)` | מחזיר `{valid, errors}` קפוא; בודק סדר ותלויות, ארבע תחנות, שמונה זהויות גלגל, שישה שחקנים, מסלולים, הורות אביזרים ואירועים |
| `samplePitSequence(config, time, options)` | דגימה טהורה ללא אירועים נשלחים; מוגבלת לטווח `0..duration` ולשערי האישור |
| `createPitSequence(config, options)` | יוצר בקר חדש ומצלם עותק קפוא של ההגדרות |
| `start()` / `pause()` | מפעיל או משהה; אינו מאפס את הזמן |
| `update(deltaSeconds)` | מתקדם רק בזמן ניגון; מקטעי זמן חסומים אינם נצברים כחוב להמשך |
| `seek(time)` | דוגם מחדש, משהה ואינו שולח אירועים; נסיגה לפני ההידוק מבטלת אישורים ידניים מהעתיד |
| `reset()` | חוזר לאפס, משהה ומנקה אישורים ידניים; הגדרת הנתיב הפנוי נשמרת |
| `getSnapshot()` | מחזיר מצב קפוא, כולל אובייקטים ומערכים פנימיים |
| `setLaneClear(boolean)` | מעדכן זמינות נתיב; חסימה בזמן יציאה מקפיאה את הפוזה הנוכחית ללא חזרה לאחור |
| `setConfirmation(wheelId, boolean = true)` | מאשר אום מסוים לאחר השלמת ההידוק; מזהה לא מוכר או אישור מוקדם גורמים לשגיאה |
| `subscribe(listener)` | המאזין מקבל `(event, snapshot)`; מוחזרת פעולת ביטול מנוי שניתן לקרוא שוב |

כל פעולות הבקר מלבד `subscribe` מחזירות snapshot. ערכים מספריים חייבים
להיות סופיים; `update` דוחה delta שלילי. `seek` ודגימה טהורה מצמידים זמן
מחוץ לטווח לקצה הקרוב. הבקר אינו מחזיק טיימר ואינו טוען נכסים בעצמו.

## מצב מוחזר

`time`, `duration`, `progress` ו־`stageProgress` מתארים את הזמן האפקטיבי.
`requestedTime` מציג את הזמן שהתבקש לפני חסימה. `stage` הוא מזהה השלב;
`state` יכול להיות גם `hold_fasteners` או `hold_exit`. `playing` קיים בבקר,
ו־`complete` נכון רק בסיום יציאה מורשית. `held` ו־`blockedBy` מסבירים עצירה.

`car` מכיל `position`, `liftMeters`, `stopped`; `jacks.front/rear` מכילים
`liftMeters`, `clear`, מיקום בסיס, `yaw` ונקודת מגע עם השלדה `chassisContact`.
`wheels` ממופה לפי `front_left`, `front_right`,
`rear_left`, `rear_right`, עם זהויות `oldId/newId`, מצבי הבעלות
`oldState/newState`, מצב האום `fastener`, אישור `confirmed`, והחלפה `replaced`.
ישן עובר `hub → held → released → rack`; חדש עובר `rack → held → hub`.

`actors` ממופה לפי מזהה דמות ומחזיר `clip`, `clipFile`, `clipTime`,
`clipDuration`, מיקום בסיס ו־`yaw`. `rootMotionBaked` מציין שתנועת `Root`
כבר קיימת ב־GLB; `rootOffset` הוא נתון עזר בלבד. **אין להוסיף אותו שוב
למיקום הדמות.** שדות מיקום, מרחק ואביזרים במטרים; זוויות בראדיאנים.

ארבעת מכונאי הגלגלים מוצבים ב־`x=±1.40` כדי שהברכיים ומגני הברכיים
יישארו מחוץ לצמיגים. `actors[].poseAdjustment` מגדיר תיקון קבוע לתנוחת
העבודה: תוספת סיבוב מקומי בציר X של `Spine: .258`, `Chest: .172`,
`Neck: -.129` ראדיאנים. יחד עם תנועת המקור מתקבלת רכינת גוף של 0.75
ראדיאנים. סדר היישום הוא דגימת כל ערוצי ה־GLB, כפל התיקון בקוואטרניונים
המקומיים, הצבת הדמות לפי מיקום הבסיס, ורק אז IK של הידיים וחיבור האביזרים.
אין שינוי באורכי העצמות, בתזמון או בקובץ ה־GLB. התיקון הקבוע מיושם גם
בהמתנה ובפינוי כדי לשמור על רציפות; מפעילי הג׳קים אינם מקבלים אותו.

הצעד האפוי של המכונאי מגיע ל־`Root[-.35,0,-.28]` בעת איסוף החדש וחוזר
לאפס עד הושבתו. יד ימין עוזבת את הגלגל ב־1.50 כדי להגיע לנרתיק; יד שמאל
מסיימת את ההושבה ב־1.60. זמני האחיזה, המגע באקדח והגלגול נמצאים ב־JSON.
מפעילי הג׳קים עומדים בצדי המכונית. הג׳ק האחורי ממתין בצד בעת הכניסה
ומתגלגל פנימה ב־0.30–0.46. ההורדה מסתיימת ב־2.04, ורק לאחריה שני
הג׳קים מתגלגלים החוצה עד 2.10. עקומת הגבהת המכונית נקבעת לפי `loweredAt`
של הג׳קים, בתוך שלב `jack_down`; משך קליפ המפעיל נשאר 0.14 שניות.
ב־2.00 המפעילים מפעילים את שסתום ההורדה ומשחררים אחיזה. הידיים חוזרות
לתנועת הקליפ עד 2.10; ההורדה ההידראולית ממשיכה עד 2.04 עם הידית נעולה.
נקודות המגע נמדדו במשולשי המכונית: `FrontWing` בקדמת `z=2.29`,
ו־`Diffuser` באחורי `x=.08,z=-1.97`. מרכז משטח הג׳ק נמצא 25 מ״מ מתחת
לתחתית שנמדדה. הג׳ק האחורי משתמש במשטח צר כדי לעקוף את הסנפיר המרכזי;
פינוי רוחבי של 1.40 מטר משאיר גם את בסיסי הג׳קים מחוץ למעטפת המכונית.

## אישורים ושערי יציאה

ברירת המחדל `autoConfirm: true` מיועדת לתצוגת הסימולציה. חיבור עתידי למנוע
משחק צריך ליצור בקר עם `{autoConfirm: false}` ולאשר כל תחנה באמצעות
`setConfirmation(wheelId, true)` רק לאחר אישור ההידוק שלה. אישורים אוטומטיים
אינם מדידה של ביצוע בעולם או במנוע אחר.

במצב ידני הזמן נעצר ב־1.88, המכונית מוגבהת והרמזור אדום עד שכל ארבעת
האומים מאושרים. ארבעת אירועי `torqued` נשלחים **לפני** שער
`service_complete`, כך שמאזין חיצוני יכול לבקש אישור. כשארבעת האישורים
מגיעים, `start`/`update` ממשיכים מהנקודה הנוכחית.

הירוק ב־1.88 מציין שהטיפול הושלם. `canExit` נשאר שקר עד שהג׳קים הונמכו
ופונו, הידיים פינו את המכונית, אות היד הושלם ונתיב היציאה פנוי. חסימת נתיב
עוצרת ב־2.30. גם דילוג פריים גדול אינו עוקף שער. ביטול אישור אום לאחר
תחילת יציאה נדחה; `reset` או נסיגה באמצעות `seek` מתחילים ביקורת חדשה.

## שיוך דמויות ואירועים

ארבעת `wheel_front_left/right` ו־`wheel_rear_left/right` מקבלים כל אחד את
התחנה והגלגלים שלו. כולם מבצעים במקביל `loosen`, `remove_old`, `mount_new`,
`tighten`; אחריהם `withdraw` משותף לחלונות `green` ו־`jack_down`, ואז
`idle_clear`. `jack_front` ו־`jack_rear` מרימים ומורידים יחד. בזמן הטיפול הם
מחזיקים את קצה `jack_up`; אחרי ההורדה `jack_front` מבצע `signal` ומחזיק
`signal_hold`, ואילו `jack_rear` מחזיק את קצה `jack_down`.

האירועים מגיעים לפי סדר `sequence.json`, עם `time`, `type` ו־`wheel/actor`
כאשר רלוונטי. כל פריים מדלג שולח את כל האירועים שנחצו פעם אחת; עדכון נוסף
על אותה נקודה אינו שולח אותם שוב. `snapshot.events` הוא יומן האירועים
שהגיע זמנם במצב הנוכחי. `seek` מדלג על אירועי העבר ללא שליחה; `reset`
מאפשר ניגון חדש. `snapshot` שנמסר למאזין הוא מצב הבקר בסוף העדכון, ולא
דגימה של זמן האירוע. ניתן לאשר אום מתוך מאזין `torqued`; אין צורך לשנות
את הזמן מתוך המאזין.

```sh
node --test workout/island/design/racing-pit-sequence-v2/tests/pit-sequence.test.mjs
```
