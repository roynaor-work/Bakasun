# בדיקת הקמפיין עם שלושה בוטים

הסקריפט מפעיל את משחק ה־WebGL המקומי ב־Chromium. הוא מריץ את הבוט המובנה מול האויבים, הבוסים והנשקים של המשחק, בתיקיית פרופיל דפדפן זמנית. לכל פרופיל בוט יש שמירה נפרדת.

| פרופיל | שגיאת כוונת מרבית בכל ציר¹ | זמן בין בחינות יעד | החלפת נשק | יכולות |
|---|---:|---:|---|---|
| מתחיל · novice | 0.18 | 0.80 שנ׳ | נשאר בנשק הנוכחי | כבויות |
| רגיל · regular | 0.075 | 0.32 שנ׳ | בעת התחממות או טעינה | פעילות |
| מומחה · expert | 0.015 | 0.12 שנ׳ | בעת התחממות או טעינה | פעילות |

¹ ציר הכוונת נע בין ‎−1 ל־1. לדוגמה, טעות אופקית של 0.18 היא עד 9% מרוחב המסך. הבוט יכול לבחור יעד חדש מוקדם יותר אם היעד הקודם נעלם.

## הרצה

נדרשת Python עם Playwright. בבדיקה שימשו Playwright ‏1.62.0 ו־Chromium ‏151.0.7922.173. הפקודות הבאות מתקינות את Playwright ואת הדפדפן המצורף.

```sh
python -m pip install playwright==1.62.0
python -m playwright install chromium
```

יש להריץ מתוך התיקייה המכילה את הסקריפט. המשתנה `GAME` מצביע לתיקיית המשחק **לאחר החלת הטלאי**.

```sh
GAME="$(git rev-parse --show-toplevel)/workout/island/minigames/boar-island"
python bot-playthrough.py --game-dir "$GAME" --output campaign-results.json
python bot-playthrough.py --game-dir "$GAME" --all --output checkpoint-results.json
```

אפשר להשתמש ב־`--chromium /usr/bin/chromium` עם דפדפן מערכת. `--waves 1 5 10 15 20` בודק שלבים נבחרים, `--profiles regular` מצמצם לפרופיל אחד, ו־`--seed 1701` משחזר את הזרע ששימש בדוח. `--baseline` מפעיל את מתג החזרה למשחק הישן.

## פירוש המדדים

* **קמפיין** מתחיל בשמירה חדשה עם המקלע הבסיסי וכסף התחלתי רגיל. הבוט פותח את מסך השלבים, בוחר בשלב 1 ובסיום כל ניצחון בוחר את ההטבה הראשונה שהמשחק הציע וממשיך בכפתור השלב הבא. בין שלבים הוא קונה לפי סדר העדיפויות שבסקריפט, במחירי המשחק ומתוך היתרה שהרוויח. כל שלב שנוצח נבדק ברשימת ההשלמות. המסלול מסתיים בתבוסה הראשונה או בסוף שלב 20.
* **בדיקה עצמאית לכל שלב** מתחילה בדפדפן נקי עם אותו ציוד לכל שלושת הבוטים. שלבים 1–5 מתחילים עם מקלע ברמה 1. בתחילת כל חמישייה נוספת המקלע עולה בשתי דרגות ושאר שלוש משפחות הנשק עולות בדרגה, וכן שדרוגי ההגנה, הקירור, הטיל וצריחי העזר. דרגת ההקפאה נעצרת ב־2. התחלה ישירה דרך QA מאפשרת למדוד גם בוס שבוט מתקשה להגיע אליו בקמפיין. שדרוגי הנשק המיוחדים והטבות השלב ריקים.
* `seconds` הוא משך הלחימה בשניות משחק, בהתקדמות של 30 צעדים לשנייה. `hits` ו־`shots` הם מוני הדיוק של המשחק. `firstKillSeconds`, `firstDamageSeconds`, `peakEnemies` ורשימת הבוסים נדגמים שלוש פעמים בשנייה. הנזק הראשון מציין ירידה בנקודות ההגנה של השחקן. זמן המחשב וקצב הציור מחוץ למדידה.
* זרע הקרב נקבע מחדש לפי מספר שלב בתחילת כל ניסיון. גודל החלון קבוע על 960×540. המשחק מפעיל את לוגיקת הקרב, הקליעים והאפקטים בצעדים ידניים. לולאת הציור והקול כבויים. תקרת ברירת המחדל היא 180 שניות משחק לכל ניסיון, וחריגה נרשמת כ־`timeout`.

## תוצאות הקמפיין בזרע 1701

| פרופיל | שלבים שהושלמו ברצף | סיום | פגיעות מתוך היריות בכלל המסלול |
|---|---:|---|---:|
| מתחיל | 4 | הפסיד למלך הברזל בשלב 5 לאחר 73.63 שניות | 13.1% |
| רגיל | 14 | הפסיד לצב המבצר בשלב 15 לאחר 68.73 שניות | 17.3% |
| מומחה | 20 | ניצח את לווייתן הפלדה בשלב 20 לאחר 43.30 שניות | 66.8% |

המומחה עבר בכל ששת מצבי מזג האוויר. הרגיל הגיע לשלב 15 עם 175 נקודות הגנה ועם שני שדרוגי מקלע מיוחדים שנרכשו בכסף שהרוויח. באותו שלב נמדדו עד 14 אויבים פעילים בבדיקה שלו, לעומת 6 בבדיקה של המומחה. התוצאות מתעדות זרע אחד ושיטת קנייה אחת.

הפירוט לכל ניסיון, כולל הציוד, מצב מזג האוויר ומספר האויבים שנותרו, מופיע בקבצים [campaign-results.json](campaign-results.json) ו־[checkpoint-results.json](checkpoint-results.json).
