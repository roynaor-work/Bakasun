## החלה ובדיקה

הענף מוסיף קבצים רק בתיקיית החבילה. סקריפט ההחלה מיועד לעותק בדיקה של הריפו.

1. משורש הריפו, בדקו התאמה והחילו את הפאץ׳.

   ```sh
   workout/island/design/boars-levels-patches-v1/apply.sh --check
   workout/island/design/boars-levels-patches-v1/apply.sh
   ```

2. הריצו את בדיקות המשחק. לבדיקת הדפדפן נדרשים Playwright ו־Chromium. אפשר להגדיר `CHROMIUM_PATH` לדפדפן מערכת.

   ```sh
   node --test workout/island/design/boars-levels-patches-v1/tests/levels.test.mjs
   node --test workout/island/design/boars-levels-patches-v1/tests/campaign-browser.mjs
   npm test
   ```

3. פתחו את אי החזירים. לחיצה על **בחירת שלב** פותחת את מפת השלבים. במוסך, **שדרוגי נשק** מציג מחיר ותנאי פתיחה. בדקו שגם כתובת המשחק או האי עם `?boarsLevels=0` מתחילה את הגל הבא ישירות.

הפאץ׳ מעדכן את חיבור המסגרת באי ואת מניפסט האופליין עם ארבעת קובצי הריצה החדשים. ביטול הפאץ׳ בעותק הבדיקה:

```sh
workout/island/design/boars-levels-patches-v1/apply.sh --reverse
```
