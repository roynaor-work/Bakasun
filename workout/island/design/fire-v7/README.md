# Fire v7 · רחוב תחת אש

חבילת נכסים עצמאית: 3 רכבי כיבוי, 3 כבאים בשלד motion2, חמישה סוגי מבנים בארבע רמות נזק, רחוב וחלקיקים. יש 59 קובצי GLB דחוסים ב־Draco, כולל LOD. אין חיבור למשחק הקיים.

## פתיחה מקומית

1. הורידו את התיקייה בשלמותה ופתחו [preview.html](preview.html) בדפדפן עם WebGL 2. כל הסקריפטים, התמונות, הדגמים ומפענח Draco מקומיים. אין התקנה או build.
2. בחרו הרחוב, הרכבים, הצוות, המבנים או האפקטים. קרוב ורחב משנים מצלמה; גרירה מסובבת, צביטה/גלגלת מקרבת. במקלדת: חצים לסיבוב, רווח להשהיה ו־Home לאיפוס מצלמה.
3. ברחוב, הפעילו מים ובחרו יעד. חום המבנה יורד עד לכיבוי. ללא מים, האש מחממת שכנים ומתפשטת. איפוס מחזיר את נקודת ההתחלה.

כל הדגמים, אטלסי החומרים, 15 אטלסי האפקטים, השמיים ומפענח Draco מוטמעים ב־assets-data.js. אין בקשות תמונה, GLB או WASM בזמן ההפעלה. קבצי המקור העצמאיים נשמרו גם בתיקיות שלהם לשימוש במשחק.

תוצאה תקינה: סצנה בתנועה, קריאות ציוד ברכב ובצוות, החלפת רמות נזק, וסילון מים המשפיע על מד החום. כפתור מדדים מציג את קצב הדפדפן הנוכחי, משולשים, קריאות ציור, חלקיקים ו־LOD.

הדפדפן המנוהל בסביבת היצירה חוסם file:// במדיניות. פתיחה ישירה לא נבדקה בו; הבדיקה נעשתה דרך loopback עם כל הכתובות החיצוניות חסומות, ובהמשך כשהדפדפן כולו במצב offline. אם הדפדפן שלכם מגביל קבצים מקומיים, אפשר להפעיל מאותה תיקיית ריפו:

```sh
python3 -m http.server 8777 --bind 127.0.0.1 --directory workout/island/design/fire-v7
```

ואז לפתוח:

```text
http://127.0.0.1:8777/preview.html
```

## איכות וביצועים

נייד מכוון ל־30fps ומוריד בהדרגה עלות ציור כאשר הקצב נמוך. פרטים משאיר את החומרים והרזולוציה הגבוהים; חסכונית משתמשת ב־LOD הרחוק ובתאורה פשוטה. גלריית הנכסים שומרת חדות נפרדת מההפחתה ברחוב. בהעדפת תנועה מופחתת מתחילים בהשהיה, ללא הבהובים או סיבוב אוטומטי.

המדידה בסביבת היצירה משתמשת ב־SwiftShader על CPU. היא אינה מדידה בטלפון בינוני. ראו [REPORT.md](REPORT.md) לנתונים בפועל ולפריטים שעוד דורשים מכשיר פיזי.
