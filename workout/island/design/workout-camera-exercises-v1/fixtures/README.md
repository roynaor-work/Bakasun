# הקלטות התנוחה המדומות

כל הקלטה מורכבת מקואורדינטות שלד שנכתבו ביד ומהזמנים בין תנוחות מפתח. המחולל משלים את המסלול בין התנוחות ודוגם אותו במרווחים קבועים. הקבצים מכילים קואורדינטות סינתטיות בלבד.

| קובץ | תוכן |
| --- | --- |
| `geometry.mjs` | מיפוי נקודות ל־MediaPipe, תנוחות בסיס, דגימה, שינוי זווית מסגרת וגודל, ריצוד, חוסר נקודות ונבדק שני מדומה |
| `jump.mjs` | חימום וקפיצות, כולל דוגמאות של תנועה דומה שבה חסר שלב |
| `hall.mjs` | מעברים בפריים, החלפות כיוון, ניתור בנקודת סיום, תנוחות הושטת יד ויציאה לפי אות |
| `strength.mjs` | תרגילי כוח, רצפה, החזקות ומתיחות, כולל מעבר צד |

בכל הקלטה יש תנוחת כיול, עמדת התחלה, תנועה ותוצאת ייחוס. לתרגילי חזרות תוצאת הייחוס היא מספר המחזורים הגמורים. לתרגילי זמן הטווח משאיר מקום לזמן התייצבות, לקצב הדגימה ולזיהוי רצף פעיל. בתרגילי מסדרון חזרה מייצגת מעבר שנראה בפריים. מגע בקיר, מרחק מסלול ותמיכה בכיסא או במדרגה אינם מסומנים כמאומתים.

`tests/replay.mjs` מעביר את אותן נקודות שלד לשני המונים. המונה החדש מתחיל לקבל פריימים כשהמעקב יציב, כפי שקורה במסך האימון. במונה הישן מעבירים קודם את עמדת המנוחה לצורך חימוש, בלי ספירה לאחור של ממשק המשתמש. התוצאה ב־`tests/benchmark.mjs` מציינת בנפרד את שבעת תרגילי המצלמה הישנים ואת ששת התרגילים שמדד החזרות שלהם ניתן להשוואה.
