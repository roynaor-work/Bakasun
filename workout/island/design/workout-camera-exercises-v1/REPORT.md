# מצלמה, תרגילים וספירה מקומית · v1

החבילה מוסיפה ל״האימון שלי״ מסלול מקומי לבחירת תרגיל או תוכנית אימון, עם ספירה לפי תנוחה או אימון על אמון. היא מבוססת על `main` בקומיט `9e95482f`. בענף המסירה נוספה רק התיקייה הזאת. ההפעלה של v1 דורשת החלה מפורשת של ה־patches ובחירה במסלול.

## ביקורת המצב הקיים

## מה משתנה ב־v1

בדיקת הצורה מוגבלת לנקודות גוף ולמה שנראה בפריים. במסדרון המונה מחפש מעבר נראה ותבנית תנועה, ובריצה בצפצוף הוא דורש אות יציאה שנוצר במכשיר לפני התנועה. מגע בקיר, המרחק האמיתי, גובה קפיצה, מיקום מדרגה, יציבות ציוד ומה שנעשה מחוץ לפריים אינם מדודים. בהסתרה המודל עלול להחזיר תנוחה אחת גם כשיש שני אנשים. לציוד, למגע ולמסלול שחלקו נסתר אפשר לבחור אימון על אמון.

## פרטיות בזמן הריצה

- שרת הקבצים נקשר ל־`127.0.0.1` בלבד. הדפדפן קורא קבצים מותרים מאותה כתובת במכשיר, ב־GET או HEAD. החיבור לאינטרנט יכול להיות כבוי.
- v1 פותח דף עצמאי לפני טעינת האפליקציה הוותיקה. המדיניות בדף ובתגובה ל־worker מתירה סקריפטים וחיבורים רק מאותו מקור, ומאפשרת WASM עבור מנוע MediaPipe הקיים. המודל, המנוע וה־WASM מגיעים מהנכסים שכבר נמצאים ב־`cam-lab/`.
- לחיצה מפורשת מפעילה וידאו עם `audio: false`. הפריים מועבר לעובד מקומי, נסגר אחרי הזיהוי, ודגימת הבהירות מתנקה. המסלול אינו משתמש בהקלטת וידאו, יצוא תמונות או נקודות גוף, שירותי דיבור, אחסון מתמשך, תור העלאות או שירות ענן. מעבר לאמון, עזיבת המסך, הסתרת הלשונית ופתיחת הדגמה משחררים את ערוצי המצלמה.
- יציאה ל־v1 דרך פורט מקומי חדש מבודדת את האימון מתור העלאות קודם. ההפעלה נחסמת אם הדף כבר נשלט בידי Service Worker אחר. אפשרות זו רלוונטית להתקנה ותיקה באותו מקור.

## מדידה לפני ואחרי

## בדיקות

140 בדיקות Node של החבילה ושמונה בדיקות Chromium עברו. בחבילת בדיקות האימון והמעבדה הוותיקה עברו 32 מתוך 35 בדיקות. שלושת הכשלים הופיעו גם ב־`main` לפני החלת ה־patches, במסגור גוף מלא, בספי גיל וגובה ובבדיקת מבט צד וקואורדינטות. [בדיקות המעבדה הוותיקה](../../../tests/cam-lab.test.mjs)

בהרצה הרחבה הראשונה של `npm test` עברו 4,370 בדיקות, 86 דולגו ושתיים נכשלו. בדיקת תגי גרסה מצאה נתיבי ייבוא שדרשו התאמה, ובדיקת רועיקי דרשה את Chromium בנתיב ש־Playwright מצפה לו. אחרי התאמת נתיבי הייבוא ושימוש ב־Chromium המקומי, 14 מתוך 14 בדיקות רועיקי ותאימות שבועית עברו בהרצה חוזרת על ה־patches הסופיים.

## החלה, הרצה וחזרה

1. מתוך checkout נפרד של הענף, בדקו והחילו את שני ה־patches. ברירת המחדל של `apply.sh` היא בדיקת התאמה. הסקריפט בודק את שני הקבצים לפני החלה. קובץ האפליקציה הקיים היחיד שה־patches מחליפים בו שורה הוא `workout/index.html`.

   ```bash
   bash workout/island/design/workout-camera-exercises-v1/apply.sh --check
   bash workout/island/design/workout-camera-exercises-v1/apply.sh --apply
   ```

2. הפעילו את השרת באותו מכשיר שבו משתמשים במצלמה ופתחו בדפדפן את הכתובת שהוא מדפיס. `--port 0` בוחר פורט פנוי ומבודד. כתובת עם `?cameraV1=1&ex=squats` פותחת את תרגיל הסקוואט כברירת המחדל. בחרו מסלול, בדקו שהמונה מגיב או נעצר בזמן שינוי המסגור, וסיימו כדי לראות את מקור הספירה. יש להכין במכשיר Node ואת קבצי הריפו מראש. השרת אינו נגיש מטלפון אחר ברשת המקומית.

   ```bash
   node workout/island/design/workout-camera-exercises-v1/serve.mjs --port 0
   ```

3. הריצו את הבדיקות על ה־checkout שבו ה־patches הוחלו. בדיקת הדפדפן דורשת Chromium ו־Playwright לפייתון שכבר הותקנו.

   ```bash
   node --test workout/island/design/workout-camera-exercises-v1/tests/*.test.mjs
   node workout/island/design/workout-camera-exercises-v1/tests/benchmark.mjs
   node workout/island/design/workout-camera-exercises-v1/tests/tracking-diagnostic.mjs
   python3 workout/island/design/workout-camera-exercises-v1/tests/browser-smoke.py
   ```

4. בשרת הרגיל של האפליקציה, פתיחה בלי הדגל או עם `?cameraV1=0` חוזרת לכניסה הוותיקה. השרת המקומי המצורף מיועד ל־v1. כדי להחזיר פיזית את ה־checkout הניסיוני למצב שקדם להחלה, השתמשו ב־`--reverse`.

   ```bash
   bash workout/island/design/workout-camera-exercises-v1/apply.sh --check-reverse
   bash workout/island/design/workout-camera-exercises-v1/apply.sh --reverse
   ```
