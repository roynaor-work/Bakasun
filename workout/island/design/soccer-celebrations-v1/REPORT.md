## מדידה ושמירת מגע

כלי התנועה המקורי:

`motion-qa-v1`

הופעל בקומיט המקובע:

`5eb4f093bc22523ee417a7f2345c3b813bffba24`

שמונת קובצי המקור שלו נמצאים ב־[source/upstream-qa](source/upstream-qa/provenance.json), כולל חתימות. ה־runner מאמת את החתימות ומפעיל את ה־CLI המקורי מתוך תיקייה זמנית. נוסחאות הציון, הספים, המשקלים וקורא הקבצים נשארו ללא שינוי. הדגימה היא ב־120Hz, בתוספת זמני אירועים וגבולות תמיכה ומגע מדויקים; ערוצי המקור אומתו כ־30Hz.

לצורך בדיקת כל שחקן, המתאם מסיר את קידומת שמות העצמות שלו בעותק בזיכרון בלבד. ערוצי האנימציה, היררכיית ההורות והתזמונים אינם משתנים. ייחוס ההמתנה הוא אנימציית ההמתנה האמיתית המשותפת מהחבילה הקיימת, מסובבת לכיוון ההתחלתי של השחקן. שורות הייחוס אינן נכללות בסף או בממוצע השחקנים. פירוט השיטה ב־[source/QA.md](source/QA.md).

סטיית תמיכת הרגל המרבית: **4.036 מ״מ**, לעומת גבול של 20 מ״מ. פער נקודות המגע המוצהרות המרבי: **6.295 מ״מ**. כל חלון תמיכה ומגע נשמר עם המשתתף, העצם, הנקודה המקומית, הזמנים והתוצאה. בדיקות שליליות של הזזת נקודת תמיכה ונקודת מגע ב־10 ס״מ זוהו בהצלחה.

בהחלקת הברכיים נמדדו שני מרכזי הברכיים בנפרד: תנועה של **1.800 מ׳** בין 1.3 ל־3.3 שניות, בגובה קבוע של **60.989 מ״מ**. זו גלישה מכוונת, ולכן אינה נחשבת לרגל נטועה; התמיכות שלפני ההחלקה ואחרי הקימה נבדקות כנעילות רגילות.

[ביקורת פני הרשת](verification/surfaces.json) דוגמת את כל קודקודי הרשת המשוקללת בפועל ב־60Hz, כולל אירועים וגבולות תמיכה. גובה הקודקוד הנמוך ביותר שנמצא: **4.498 מ״מ** מעל הרצפה. בנוסף כוילו משולשי עור, בד וגביע אמיתיים ונשמרו מזהי הקודקודים והקואורדינטות הבריצנטריות; נקודות המשולש נעקבו לאורך חלונות המגע. פער המשטחים המכוילים המרבי: **15.470 מ״מ**.

הציון הוא מדד אבחוני משוקלל, ולא דירוג תפיסתי. בשני קליפי הריצה מדד הרציפות מול עמידה נשאר אדום: הם מתחילים ומסתיימים בתנועת ריצה, בעוד הייחוס הוא עמידה. ציוניהם **90.8** ו־**89.2** עומדים בסף המבוקש. אין טענה שכל המדדים ירוקים. חיבור למשחק דורש ערבוב כניסה ויציאה מתאים לתנועת השחקן. דגימת פני הרשת אינה אישור רציף להיעדר חדירה בין גופים, לכיוון כפות הידיים או להתנגשות בגדים; סמני היד הם סמני מפרק הנמצאים מעט בתוך משטח היד.

## תצוגה ואופליין

התצוגה משתמשת רק בקבצים מתוך התיקייה. בבדיקת Chromium הושבתה WebAssembly, נטענו 14 הקליפים ונבדקו ניגון, גרירה בציר הזמן ושינוי זווית. לא נדרשו בקשות חיצוניות, קובצי decoder או משאבי WASM. המידה הראשית היא **844×390**, ונבדק גם **390×844**. הראיות וחתימות הקבצים המצולמים נמצאות ב־[browser.json](verification/browser.json), לצד [צילום רוחבי](verification/preview-844x390.png) ו־[צילום אנכי](verification/preview-390x844.png).

[הורדת החבילה לאופליין](soccer-celebrations-v1.zip) — כולל קובצי תצוגה, מקורות וראיות בדיקה.

1. מורידים ומחלצים את הארכיון.
2. מתוך התיקייה שחולצה מריצים את הפקודה הבאה. היא מפעילה שרת מקומי על המחשב, באמצעות הספרייה התקנית של Python, ופותחת את התצוגה בדפדפן.
3. בוחרים חגיגה, מנגנים או גוררים לפריים רצוי. התוצאה הרצויה היא תצוגה מלאה עם השחקנים מסונכרנים ועם קישורים לקובץ ולגיליון שמונה הפריימים, גם כשהמחשב מנותק מהאינטרנט.

```sh
python3 start-preview.py
```

אימות פורמט עצמאי באמצעות Khronos glTF Validator בגרסת JavaScript המקומית: **0 שגיאות**, **120 אזהרות**. [הדוח המלא](verification/gltf-validation.json) כולל חתימות ופרטי האזהרות. אזהרות יצירת מרחב משיקים בזמן ריצה מקורן ברשת הקיימת, וגלויות בדוח; הן אינן שגיאות פורמט.

אין בחבילה WASM, Draco, meshopt או KTX2. טקסטורות מקומיות מוטמעות בקבצים; ספריות התצוגה המקומיות נמצאות ב־vendor ורישיונן מצורף. הארכיון מכיל גם מקורות וראיות בדיקה, ואינו מכיל עותק של עצמו.

## חוזה חיבור ושחזור

הצירים הם ‎+Y למעלה, ‎+Z קדימה ו־‎+X לשמאל אנטומי; היחידות מטרים והסיבובים הם קווטרניונים מקומיים. לכל שחקן אותן 18 עצמות ואותם היסטי מנוחה; קידומות השמות מפרידות בין המשתתפים. הקטלוג מגדיר תפקידים, אירועים, חלונות תמיכה ומגע ושלושת שלבי הגביע.

תנועת העולם אפויה בערוצי Root של כל שחקן. מציבים את קבוצת החגיגה במקור עולם אחד וצורכים את התנועה פעם אחת. אין להוסיף שוב את מסלול הריצה של הסימולציה. כל המשתתפים משתמשים באותו זמן אנימציה; עצירה מקפיאה את כולם. בהפרעה יש לשחרר את המגע ולעבור עם כל המשתתפים יחד. אירועים הם סמני תצוגה, ואינם מפעילים ניקוד או פיזיקת משחק.

מתוך התיקייה, בנייה ובדיקות נתונים פועלות מקומית ללא התקנת חבילות:

```sh
node source/author.mjs
node source/run-qa.mjs
node source/measure-surfaces.mjs
node source/validate-glb.mjs
```

צילום מחדש דורש Playwright ו־Chromium המותקנים בסביבת הבדיקה, ואינו דרישה לניגון או לבדיקת הנתונים:

```sh
node source/capture.mjs
```

לאחר יצירת הראיות, אורזים את החבילה, יוצרים את [מניפסט החתימות](MANIFEST.sha256) ומאמתים את שלמותה:

```sh
python3 source/package.py
node source/verify-package.mjs
```

הארכיון חולץ גם לתיקייה מחוץ למאגר. הבנייה, בדיקת התנועה ואימות החבילה עברו שם ללא תלות בתיקיות שכנות; כל קובצי ה־GLB שנבנו מחדש היו זהים בבתים לקובצי המסירה.

בדיקות המאגר הכלליות: **4,261 עברו ו־64 דולגו**. בדיקת דפדפן קיימת אחת כשלה משום שקובץ Chromium בנתיב ברירת המחדל של Playwright אינו מותקן בסביבה. הקובץ המכיל אותה הורץ שוב באמצעות Chromium המקומי המותקן: **5 מתוך 5 עברו**, ללא כשל. ההרצה החוזרת דרשה הגדרת סביבת בדיקה בלבד; קבצים קיימים לא שונו.
