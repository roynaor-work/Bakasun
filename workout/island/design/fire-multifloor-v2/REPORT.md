## שימוש בתצוגה

1. מריצים משורש המאגר `python3 -m http.server 8765`.
2. פותחים [preview.html בשרת המקומי](http://localhost:8765/workout/island/design/fire-multifloor-v2/preview.html), במידה 844×390.
3. ב״כבאית״ מפעילים נסיעה, אורות ופתיחה/סגירה של הסולם. ב״בניין״ בוחרים קומה ומצב שריפה; ב״ציוד״ בוחרים כלי ולוחצים ״הפעלת הכלי״. גוררים לסיבוב ומשתמשים בגלגלת להגדלה. מקשי חיצים מסובבים ו־Home מאפס מצלמה כשהקנבס ממוקד.

התצוגה טוענת את נכסי ה־GLB עצמם ומנגנת את הקליפים שלהם. היא משתמשת רק בקובצי three.js הקיימים במאגר; יש להגיש את המאגר ב־HTTP. חיבור המשחק יתבצע בנפרד בהתאם להגבלת התיקייה.

## חוזה חיבור

- יחידות מטרים, Y כלפי מעלה ו־Z קדימה. המשאית והציוד מבוססים על נקודת המגע בקרקע.
- מעטפת הבניין במקור. קומה N מוצבת ב־`[0,(N-1)*3.2,0]`; שלושה חדרים בכל קובץ קומה. המניפסט כולל נקודות כניסה וחילוץ, מיקומי דלתות ונתיבי מדרגות.
- ה־GLB נטען במצב שלם. `burnt_*` שמור בסקאלה אפס; להפעלה יש להגדיר סקאלה `[1,1,1]` ולהסתיר את `intact_*`. `runtime.mjs` מספק `setBurnState` ו־`collectBurnables`, תוך שמירת הטרנספורמציות של הריהוט עצמו. עוגן האש אינו מוחלף בין המצבים.
- `cutaway_front_*` ו־`cutaway_ceiling_*` מוסתרים רק בתצוגת הביקורת כדי לחשוף את החדרים. במשחק אפשר להשאירם גלויים. `shell_floor_N` מאפשר לבודד מעטפת של קומה.
- קליפים חד־פעמיים מנוגנים פעם אחת עם clamp בסוף. `drive` ו־`lights` מיועדים ללולאה. הנסיעה מגלגלת את הגלגלים במקום; מנוע המשחק אחראי לתנועת הרכב. הסולם נפתח ונסגר באמצעות קליפים הפוכים, כולל הזזת החוליות.
- עוגני החיבור הם `ladder_tip`, `hose_outlet`, `spray_origin`, `cover_origin` וידיות השמיכה לפי הדגם. ארבעת JSON האפקטים כוללים מלבני פריימים, FPS ו־pivot. שמיכת ה־GLB נפרשת ומכסה בקליפ השימוש; האטלס הוא אפשרות משלימה לאפקט דו־ממדי.
- אפקטי אש, עשן והתזת החומר מנוהלים בצד המנוע, כפי שמודגם ב־`preview.mjs`; הם אינם מערכות חלקיקים מוטבעות ב־GLB. זו חבילת עיצוב וחוזה חיבור, לא שינוי במכניקת המשחק.

## אימות ושחזור

המאמת הרשמי מופעל דרך `source/validate.mjs`. הוא בודק Khronos, משולשים בפועל, ערוצי אנימציה, נקודות קצה הפוכות לסולם, שמות המצבים, שלוש קומות ותשעה חדרים, שקיפות ושמונה פריימים נבדלים באפקטים, וגודל כל התיקייה. התוצאות נמצאות ב־[khronos.json](evidence/khronos.json) וב־[asset-checks.json](evidence/asset-checks.json). צומתי עוגן ריקים עשויים לקבל `NODE_EMPTY` ברמת מידע בלבד.

קוד השחזור כלול ב־`source/`: את הבניין מייצרים עם Python רגיל; את המשאית והציוד עם `blender --background --python`; את האטלסים עם Python ו־Pillow. `source/package.py` מעדכן את המניפסט מתוך התוצרים הסופיים. הוראות התקנת המאמת מחוץ למאגר נמצאות בראש קובץ האימות.
