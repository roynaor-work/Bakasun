## סביבת בדיקות הריפו

ההרצה הראשונה ללא הרשאת sockets מקומיים נכשלה בארבעה קובצי בדיקה קיימים. בדיקה מול worktree נקי בקומיט הבסיס `f5f2b40814fc0e2186daed1ac100a8d806dd3a7d` הוכיחה את אותה בעיית סביבה: שלוש בדיקות נזקקו לשרת HTTP מקומי, והבדיקה הרביעית ניסתה להשתמש ב־Chromium שאינו מותקן במטמון Playwright.

לאחר מתן גישה ל־localhost ושימוש ב־`/usr/bin/chromium`, הבדיקות הממוקדות עברו גם בענף העבודה וגם בקומיט הבסיס. לאחר מכן עברה הרצת `npm test` מלאה. קובצי הבדיקות הקיימים לא נערכו.

הגדרת הדפדפן היא מודול preload חדש, שניתן לקריאה ב־`source/system-browser-preload.mjs`. הוא משנה רק את הנתיב הבינרי של Chromium, שומר את אפשרויות ההרצה המקוריות ואינו משנה assertions, CSP או תוצאות. הוא אינו נטען על ידי המשחק או התצוגה.

הפקודה ששימשה, משורש הריפו בסביבת הענן:

```sh
NODE_OPTIONS="${NODE_OPTIONS:+$NODE_OPTIONS }--import=$PWD/workout/island/design/hoops-motion-v8/source/system-browser-preload.mjs" npm test
```

Node בסביבה זו עשוי להציג סיכום לפי קובצי בדיקה במקום פירוט תתי־בדיקות. בקרת assertion שגוי בקובץ זמני הוכיחה ש־`node --test` הרגיל מחזיר קוד יציאה 1 עבור כשל, גם במצב זה.
