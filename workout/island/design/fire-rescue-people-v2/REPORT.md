## קליפים ומשמעות

**63 קליפים נדרשים**, ועוד 8 קליפי `ready` למדידת כניסה ויציאה של האזרחים; סך הכול 71. כל GLB מכיל אנימציות glTF רגילות: quaternion מקומי לכל 18 העצמות, translation ל־Root ול־Hips, דגימות ב־30Hz ואינטרפולציית LINEAR.

| קבוצה | מזהים | משמעות |
|---|---|---|
| כל שמונת האנשים | `panic_stand`, `cough`, `wave_help` | בהלה, שיעול, נפנוף לעזרה |
| כל שמונת האנשים | `sit_floor`, `carried_shoulder`, `walk_happy` | מעבר לישיבה על הרצפה וחזרה, הרמה לכתף/נשיאה/הורדה, הליכה שמחה בחוץ |
| שלושת הכבאים | `hose`, `extinguisher`, `rescue_carry`, `signal_clear`, `idle` | זרנוק, מטף, חילוץ בנשיאה, סימון פנוי ועמידה |
| שמונת האנשים | `ready` | מנוחת מעבר אמיתית, המשמשת לבדיקת הרציפות |

התינוק מגיב בבהלה, משתעל ומנופף בישיבה נתמכת בעגלה; ב־`walk_happy` העגלה מתקדמת והוא מניע ראש וידיים. ב־`sit_floor` הוא עובר לישיבה על הרצפה לצד העגלה; ב־`carried_shoulder` הוא מורם לכתף ומוחזר לעגלה. זו התאמת אותן פעולות לגיל התינוק.

הנשיאה והישיבה כוללות קטעי תמיכה אמיתיים בתחילת ובסוף הקליפ, עם השהיה לפני תחילת התנועה. קטעי האוויר אינם מסומנים כתמיכת קרקע. הליכה כוללת מסלול Root אמיתי, שלבי הנפת רגל ועצירת שתי הרגליים; רוב הקליפים הם פעולות עם כניסה ויציאה, ולא לולאות. דגל `loop` מפורש ב־manifest וב־extras של האנימציה. `ready`, `idle` ובהלה נסגרים ללולאה.

## שלד, מגע ושילוב

`skeleton.json` זהה לחוזה של `motion2/soccer.json`: שמות, סדר, הורים ותרגומי מנוחה של 18 עצמות. אין עצמות פנים, אצבעות או אביזרים נוספות. מטרים; +Y למעלה, +Z קדימה, +X שמאל אנטומי. קומת הדמות מוגדרת ב־Character wrapper ובקודקודים, עם inverse binds תואמים. קובצי GLB כבר מכילים קנה מידה: **אין להכפיל שוב ב־manifest.scale**.

העור מחולק לקטגוריות `body`, `stroller`, `hose`, `extinguisher` לפי הצורך. הציוד קיים בקובץ; בעת בחירת קליפ יש להציג את קטגוריות `clip.equipment` ולשמור את הגוף והעגלה. התצוגה המצורפת מדגימה זאת. עוגני `waterNozzle`, `hoseInlet`, `extinguisherNozzle`, `carryShoulder` ו־`strollerHandle` מופיעים לפי סוג הדמות; כיוון פייה נקוב ב־extras של העוגן. יצירת מים/אבקה שייכת למנוע המשחק, דרך העוגנים האלה.

לשילוב נשיאה, טוענים מחלץ ואדם באותו מוצא עולם ומסנכרנים `rescue_carry` ו־`carried_shoulder` לאורך 5.6 שניות. האדם מתחיל 0.70 מטר לפני המחלץ, האגן נע לכתף, וחוזר. העגלה נשארת לפני המחלץ בזמן הרמת התינוק. זו כוריאוגרפיה מעוצבת עם אחיזת כתף; אין כאן סימולציית גוף רך או הקלטת mocap.

## שחזור

משורש המאגר, לאחר התקנת Python עם NumPy 2.3.5 ו־Node 20 ומעלה:

```sh
python3 workout/island/design/fire-rescue-people-v2/source/geometry.py
node workout/island/design/fire-rescue-people-v2/source/build.mjs
npm install --prefix /tmp/fire-rescue-people-v2/tools --cache /tmp/fire-rescue-people-v2/npm-cache gltf-validator@2.0.0-dev.3.10 --no-audit --no-fund
node workout/island/design/fire-rescue-people-v2/source/audit.mjs
node --test workout/island/design/fire-rescue-people-v2/source/qa-vendor/test/*.test.mjs
```

לפתיחת התצוגה:

```sh
python3 -m http.server 8769
```

פותחים [את התצוגה המקומית](http://localhost:8769/workout/island/design/fire-rescue-people-v2/preview.html). לשחזור בדיקת הדפדפן נדרשים Playwright ו־Chromium מותקנים; `CHROMIUM_PATH` ו־`FIRE_PREVIEW_URL` מאפשרים לשנות את הנתיבים.

```sh
node workout/island/design/fire-rescue-people-v2/source/browser-qa.mjs
```

בדיקות המאגר הראשונות: 3,277 עברו, 56 דולגו, כשל סביבתי אחד משום ש־Playwright לא מצא את דפדפן Chromium המובנה. נבחר Chromium המותקן במערכת דרך נתיב זמני, וקובץ הבדיקה שנכשל הורץ שוב: **5/5 עברו**. לא שונו קובצי בדיקות או קבצים קיימים. בסך המקרים המקוריים, 3,278 עברו לאחר תיקון הסביבה ו־56 דולגו; אין כשל פתוח. הפקודה המלאה לא הורצה מחדש.
