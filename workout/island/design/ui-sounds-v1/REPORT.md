# דוח צלילי ממשק v1

תאריך: 17.11.2026 · ענף: `codex/ui-sounds-v1`

## מסירה

27 צלילים מקוריים, כל אחד ב־OGG Vorbis וב־MP3 (54 קובצי אודיו). כל השינויים בתיקייה החדשה `workout/island/design/ui-sounds-v1/` בלבד.

סינתזה של גלים סינוסיים והרמוניות חלשות: עץ עגול למגע, פעמונים לתגמולים, בועות לפאנלים ומתנות, וצלילים רכים לתוצאות. אין הקלטות או דגימות חיצוניות. רישיון CC0-1.0.

## שימוש והאזנה

1. פותחים את `listen.html` ישירות מהתיקייה, או באמצעות שרת קבצים מקומי.
2. בוחרים OGG או MP3 ולוחצים על האזנה. אפשר לנגן הכול ברצף, לשנות עוצמה ולהעתיק מזהה.
3. עצירה או Escape מפסיקים את הניגון; מעבר ללשונית אחרת עוצר גם את הטיימר.

הדף עצמאי, רספונסיבי ובעברית; המניפסט מוטמע בדף כדי לאפשר `file://`. אין ספריות דפדפן, בקשות לרשת חיצונית, CDN, גופנים חיצוניים או WASM.

## שחזור ובדיקה

דרישות בנייה בלבד: Python 3, NumPy, FFmpeg עם libvorbis ו־libmp3lame.

```sh
python3 workout/island/design/ui-sounds-v1/synthesize.py
python3 workout/island/design/ui-sounds-v1/synthesize.py --verify
python3 workout/island/design/ui-sounds-v1/synthesize.py --output /tmp/ui-sounds-rebuild
```

היצירה דטרמיניסטית באותה גרסת FFmpeg/NumPy. `--verify` אינו כותב קבצים: בודק כיסוי מזהים, מלאי, גיבובים, מטא־נתונים, עוצמה, שיאים, משכים וקצוות באמצעות פענוח מחדש.

## הנחיות לחיבור בהמשך

- `manifest.json` הוא מקור האמת למזהים ולנתיבים יחסית לתיקייה הזאת; מומלץ לטעון OGG עם MP3 כחלופה לפי תמיכת הדפדפן.
- לחיצות: שלוש וריאציות; מטבעות: נמוך/בינוני/גבוה; כוכבים: 1/2/3 תווים עולים.
- `timer_last_10`: ניגון יחיד של 10 שניות, עשר פעימות כפולות במרווח שנייה. לעצור בהשהיה או יציאה; אינו לולאה.
- `countdown_3/2/1`: תווים נפרדים לתזמון מול שעון המשחק. `countdown_321`: רצף חלופי בן 3 שניות, לתזמון 3/2/1 בזמנים 0/1/2. לבחור באחת משתי האפשרויות.
- `start` מנוגן בשנייה 3 לאחר הרצף. היסט ההתחלה הנשמע הוא כ־50 מ״ש, מתועד במניפסט; לתזמון מדויק יש לפענח מראש ולתזמן באמצעות Web Audio.
- הספירה ללא דיבור, בהתאם לסינתזה המקורית. `passed` הוא אישור הצלחה קצר, `stage_success` חגיגה ארוכה יותר ו־`game_end` סיום חיובי ללא תלות בניצחון.
- טיימר: 22.05kHz מונו, MP3 ב־16kbps כדי לשמור עשר שניות מתחת למגבלה. יתר הקבצים: 44.1kHz מונו, MP3 ב־64kbps; OGG באיכות 0.
- קוד המשחק הקיים לא שונה והחבילה טרם חוברה למשחק.

בדיקת הדפדפן השתמשה בשרת HTTP מקומי על `127.0.0.1` בלבד. ניווט ישיר ל־`file://`
חסום במדיניות הדפדפן המנוהל של סביבת הבדיקה (`ERR_BLOCKED_BY_ADMINISTRATOR`), ולכן
פתיחה ישירה מהדיסק לא אומתה כאן. הדף אינו מבצע `fetch` ומטמיע את המניפסט, כך שאין לו
תלות בשרת לצורך קריאת הרשימה. לא בוצעה בדיקה במכשיר טלפון פיזי או בספארי.

פרק בדיקות המסירה הזה מתעד את ריצת המסירה; הרצת בנייה חדשה מייצרת מחדש את הדוח המדוד.

### בדיקות הריפו

`npm test`: מתוך 4,326 בדיקות, 4,261 עברו ו־64 דולגו. בדיקה אחת, במסך תרגילי האימון
הקיים (`tests/workout-royiki.test.mjs`), נכשלה כי קובץ Chromium Headless Shell ש־Playwright
מצפה לו אינו מותקן בסביבה. הבדיקה פתחה שרת לפני כשל ההפעלה והשאירה את התהליך פתוח;
לאחר אבחון הכשל הופסק התהליך שנותר פתוח כדי לאפשר לריצה להסתיים.

אותו קובץ בדיקה הורץ מחדש מול Chromium המותקן במערכת, באמצעות נתיב דפדפנים זמני
ב־`/tmp` בלבד: **5 עברו, 0 נכשלו**, כולל בדיקת מסך כל 50 התרגילים, הספירה, ההגדרות
ונפילת הגיבוי. לא שונה קוד הבדיקות או אף קובץ קיים בריפו. הריצה הכללית עצמה החזירה
קוד יציאה 1 בגלל סביבת הדפדפן הראשונית; הבדיקה החוזרת החזירה 0.

`git diff --check` עבר, וסקירת השינויים אישרה שכל 59 הקבצים הם תוספות בלבד בתוך
התיקייה שהוגדרה למשימה.
