ההגבלה המפורשת לתיקייה חדשה נשמרה: לא נערכו `ops/CONTROL.md`, קובצי המשחק, מספרי גרסה או קבצים קיימים אחרים. זהו רישום המסירה המקומי של המשימה. חיבור לקוד המשחק יבוצע בנפרד.

כל הגרפיקה יחד: **234,618 בתים**. הייצוא הגדול ביותר: **18,483 בתים**, לעומת תקרה של 400,000 בתים לקובץ. לכל PNG ערוץ אלפא, והגאומטריה והעיגון זהים למקור ה־SVG. `meter-hidden` שקוף לחלוטין בכוונה, כדוגמת מצב בלבד; בממשק אמיתי מסתירים או מסירים את המד.

המקורות נכתבו במיוחד לחבילה. הפלטה משמרת ירוק יער `#173f36`, ירוק עמוק `#102e29`, שמנת `#f5efdc`, פליז `#d4bf82` וחימר `#b76c4c`. אדום, צהוב, ירוק וסגול נוספו לטווחי האיכות. אין נכסים חיצוניים, תמונות מוטבעות, גופנים או טקסט שנשרף בגרפיקה. גם שמות האפקטים והכפתורים הם טקסט HTML נפרד.

## המד ורצף ההגשה

המסילה נראית ברוחב 12px, בתוך שכבה צרה של 32×176px. הרקע שקוף למחצה, בקצה הימני, ואינו קולט לחיצות. הצבעים סימטריים סביב המרכז: אדום בקצוות, צהוב פנימה, ירוק משני צדי סגול צר במרכז. ערך `p=0` הוא למעלה ו־`p=1` למטה; מרכז המצביע הוא `y=14+148*p` בפיקסלים.

| מצב | התנהגות |
|---|---|
| `moving` | מצביע נע במחזור של 1,400ms בין 6% ל־94%. מחוון ידני בתצוגה מאפשר להקפיא כל ערך לבדיקה |
| `locked` | לחיצה מקבעת את הערך שמוצג באותו רגע; הילה מתיישבת במשך 220ms, ללא שינוי הערך שננעל. אין הגשה חוזרת באותה לחיצה |
| `hidden` | אחרי 420ms מתחיל מעבר לראלי והיעלמות של 180ms; המד מוסר לגמרי אחרי 600ms. כפתור ההגשה וסמן הכיוון מוסתרים ב־420ms |

`endServe()` מסתיר מיד גם באמצע נעילה, ומנקה אפקטי מכה. בחזרה להגשה חדשה המד חוזר. אין לולאת ציור אחרי סיום האפקטים, במצב ידני יציב או במנוחה עם תנועה מופחתת.

בתצוגה, הסגול מדגים „הגשה חזקה” והירוק מדגים „ירוק מושלם”. אלה הדגמות של גרפיקה ותזמון; בשילוב, המשחק הוא שקובע את התוצאה והאיכות. אין כאן שינוי ניקוד או חישוב חוקיות הגשה.

## פריסה וקלט

כל יעדי הפעולה הם כפתורי HTML בגודל **56×56 CSS px**, גם במסכים צרים. ה־PNG הוא 128×128 ומוצג ב־56×56. המרווח בין כפתורי השורה התחתונה הוא 12px, והכיתוב נמצא מחוץ לגרפיקה.

| רכיב ב־844×390 | מלבן `[x,y,width,height]`, מהפינה השמאלית העליונה |
|---|---|
| מד | `[796,97,32,176]` |
| חיתוך / דרופ / סמאש / הגשה | `[540,306,56,56]` / `[608,306,56,56]` / `[676,306,56,56]` / `[744,306,56,56]` |
| בחירת מיקום, מרכז־ימין | `[712,166,56,56]` |
| בלימה, שמאל־למטה | `[24,306,56,56]` |
| אזור מרכזי ללא רכיבי HUD | `[198,92,440,198]` |

בחירת מיקום פותחת שלושה כפתורים בעמודה לצד המגרש. שמאל, מרכז וימין הם כיווני מסך פיזיים ואינם מתהפכים בגלל RTL. החצים מוגבלים לקצוות; Escape סוגר ומחזיר פוקוס. בלימה מוחזקת משתמשת בלכידת מצביע, עם שחרור גם מחוץ לכפתור וב־cancel/blur. מצב מושבת משתמש ב־`disabled` אמיתי; לחיצה ובחירה מקבלות גרסת `pressed`.

אפשר להגיש עם רווח, לבחור מיקום עם A וחצים, לבלום בהחזקת B, ולבחור חיתוך S, דרופ D וסמאש X. Tab ו־Enter/Space מפעילים את הכפתורים כרגיל. אחרי שהגשה ממוקדת נעלמת, הפוקוס עובר לסמאש בלי להיחטף מכפתור אחר שהמשתמש כבר בחר.

הפריסה משתמשת ב־`env(safe-area-inset-*)`. מתחת ל־620px היא מתארגנת בגובה 520px ושומרת על גודל המגע; הכפתורים אינם מוקטנים עם כל המסך.

## אפקטים

| אפקט | משך | התנהגות |
|---|---:|---|
| `power-serve` — הגשה חזקה | 460ms | כדור עם שובל שמנת ופליז, התרחבות עדינה ודעיכה |
| `spin` — ספין | 640ms | קשתות סיבוב סביב כדור; סיבוב עדין ודעיכה |
| `perfect-green` — ירוק מושלם | 700ms | טבעת ירוקה, סימן אישור ופרצי פליז קצרים |
| `out` — יצא | 1,500ms | איקס אדום עם הפרדת שמנת; אטום לאורך כל משכו ומוסר בסוף, בהתאם לרפרנס v1 |
| `net` — רשת | 900ms | סמל רשת וכדור נופל; דעיכה בסיום |

כל אפקט חד־פעמי, מוגבל בזמן ומוסר מה־DOM בסיום. אין לולאה, טקסט שאריתי או הבהוב מסך. הודעת האפקט היא אזור `aria-live` נפרד, שמתעדכן פעם באירוע ולא בכל פריים.

השהיה או הסתרת לשונית מקפיאות את שעון המד, הנעילה והאפקטים. חזרה אינה צורכת את הזמן שעבר ברקע. בהעדפת תנועה מופחתת המצביע סטטי במרכז, אין התיישבות, סיבוב או שינוי קנה מידה; הנעילה, ההיעלמות ומשך החיוויים נשמרים.

## פתיחה ובדיקה

1. פותחים את [preview.html](preview.html), בחלון של 844×390. בתצוגה רגילה אפשר לפתוח את הקובץ מקומית; סביבת הבדיקה המנוהלת כאן חוסמת `file://`, ולכן האימות בוצע בשרת מקומי.
2. לוחצים על הגשה. התוצאה הצפויה: המצביע נעצר באותו מקום, ההילה מתיישבת, ואז המד וכפתור ההגשה נעלמים וכפתורי הראלי זמינים.
3. גוללים למטה לבדיקת שלושת מצבי כל כפתור, החלפת SVG/PNG, הפעלת חמשת האפקטים, הגשה חדשה, השהיה ומיקום ידני. שינוי פורמט שומר על מיקום ועיגון.

להרצה מקומית משורש המאגר:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory workout/island/design/tennis-ui-v2
```

כתובת לפתיחה: [תצוגת טניס מקומית](http://127.0.0.1:8765/preview.html).

## חוזה שילוב

[manifest.json](manifest.json) כולל רשימת נכסים, נתיבי SVG ו־PNG, מידות, תפקידים, עוגנים, זמני חיים, פלטה, מצבי כפתורים, פריסה ו־SHA-256 לכל ייצוא. [tennis-config.js](tennis-config.js) נוצר מאותו מידע ומאפשר לתצוגה לעבוד ללא `fetch` או טוען מודולים.

קובצי הממשק לשימוש חוזר: `tennis-config.js`, `tennis-ui.css`, `tennis-ui.js`. אפשר לקחת רק את הנכסים ולממש את חוזה התזמון במשחק הקיים. הדוגמה המלאה לבניית DOM נמצאת ב־`preview.html`.

```js
const hud = TennisUIV2.create(root, {
  config: TENNIS_UI_V2_CONFIG,
  assetBase: './design/tennis-ui-v2',
  onServe: ({position, placement}) => { /* send captured input to game */ },
  onAction: ({id, held, index}) => { /* dispatch requested input */ }
});
// Authoritative simulation events control the display:
hud.startServe();
hud.setPosition(0.4);           // optional authoritative sample; freezes demo oscillator
hud.lockServe();
hud.playEffect('perfect-green', {x: 0.5, y: 0.59});
hud.setPaused(true);
hud.setPaused(false);
hud.endServe();                // immediate cleanup, including in the middle of a lock
hud.destroy();                 // listeners, animation and effects are disposed
```

נקודות `x,y` בדוגמת האפקטים הן קואורדינטות מסך מנורמלות יחסית למארח. בשילוב תלת־ממדי יש להקרין בכל פריים את נקודת העולם המוסמכת של פגיעת הכדור, המגע בקרקע או המגע ברשת; אין להסיק יציאה או רשת לפי הקואורדינטות בתצוגה. העוגן של כל אפקט הוא `[0.5,0.5]`: פינת התמונה היא נקודת האירוע פחות חצי גודל התצוגה. PNG הוא sRGB עם אלפא ישרה; המנוע מטפל בהכפלת האלפא, ולשכבת אפקט שקופה אין לכתוב עומק.

אין כאן בדיקת טלפון פיזי או שילוב במשחק הפעיל. המגרש הוא איור גאומטרי להמחשת פריסה ואינו נכס שמחליף את מגרש המשחק. בדיקת הסתרת לשונית מפעילה את אירועי מחזור החיים בדפדפן באופן מדומה.

ריצת `npm test` המלאה החזירה 4,261 הצלחות, 64 דילוגים וכישלון תשתיתי אחד: בדיקת Royiki הקיימת ניסתה לפתוח Chromium בנתיב המטמון של Playwright, שבו אין דפדפן מותקן. אחרי שזוהה הנתיב החסר נסגר התהליך שנותר עם שרת פתוח, והקובץ `tests/workout-royiki.test.mjs` הורץ מחדש עם Chromium המותקן במערכת: **5 מתוך 5 עברו**, כולל הבדיקה שנכשלה. ארבע ההצלחות הכפולות נספרו פעם אחת בלבד בסיכום. לא בוצעה ריצה מלאה שנייה ולא נערכה בדיקה קיימת. המתאם המקומי [repository-playwright.mjs](tools/repository-playwright.mjs) מחליף את נתיב הדפדפן ושומר על כל ארגומנטי ההפעלה של הבדיקה.

התצוגה אינה דורשת התקנה. לכתיבה ולאימות בלבד: Python, החבילות המוצמדות ב־[tools/requirements.txt](tools/requirements.txt), ו־Chromium. ה־PNG נוצר ישירות מה־SVG באמצעות Canvas של Chromium `151.0.7922.173`; מנוע או גרסה אחרים עשויים לשנות מעט פיקסלים ושוויון בינארי.

משורש המאגר:

```sh
python3 workout/island/design/tennis-ui-v2/tools/build.py
python3 workout/island/design/tennis-ui-v2/tools/verify.py
npm test
```

בסביבה שבה Playwright זמין אך הדפדפן שבמטמון חסר, הרצת הבדיקה הממוקדת שנבדקה כאן:

```sh
ISLAND_PLAYWRIGHT="$PWD/workout/island/design/tennis-ui-v2/tools/repository-playwright.mjs" CHROMIUM_PATH=/usr/bin/chromium node --test tests/workout-royiki.test.mjs
```

אפשר להשתמש באותו מתאם גם בריצה מלאה באמצעות `npm test` במקום הפקודה האחרונה. אם מודול Playwright של Node אינו מותקן בנתיב הסביבה הרגיל, מגדירים `PLAYWRIGHT_NODE_MODULE` לנתיב המלא של `playwright/index.mjs`.

ניתן לבחור דפדפן אחר באמצעות `CHROMIUM_PATH`. כלי האימות מפעיל שרת מקומי זמני וסוגר אותו בסיום. המחולל כותב רק בתיקיית החבילה. אין שינוי בקובצי תלויות או בדיקות קיימים במאגר.
