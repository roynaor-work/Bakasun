## שיטת הסריקה

מקור השמות הוא הקוד, לא רשימה ידנית ולא תיעוד ישן. הסורק סורק קבצים במעקב Git וגם קבצי מקור חדשים שאינם מתעלמים מהם. הוא מוציא מהסריקה את התוצרים שלו ואת ספריות הספקים `vendor`, `lib`, `node_modules` וקובצי `*.min.js`. בקובצי HTML הוא קורא בלוקי script ומדלג על importmap ובלוקי JSON. טקסט, הערות ו־regex אינם נחשבים לקריאות רק מפני שמופיע בהם `.get`.

הוא מזהה `URLSearchParams`, קריאות דרך משתני query, `params` שהועברו לפונקציה, `searchParams`, קבועי מחרוזת, מפות שמות ועוזרי הקריאה הקיימים בפרויקט. קיים מתאם מפורש גם ל־regex של `qa` בחזירים. קריאות ישירות וקריאות דרך עוזר מסומנות בנפרד. ברירות מחדל ופירוש התנהגות אינם מומצאים מתוך שם הדגל: הם נשמרים בקובץ ההערות ונסקרים מול ביטויי המקור ושערי התצורה.

הצלבת שלמות נפרדת בוצעה עם **Acorn 8.15.0**, שהותקן בתיקייה זמנית מחוץ לריפו בלבד: 1,584 בלוקי/קובצי JavaScript מתוך 1,562 קבצים נותחו ללא שגיאות תחביר. נמצאו 428 קריאות query עם שם מילולי; לא נמצאה אף קריאה כזו שחסרה ברישום. 18 אתרי קריאה עם ארגומנט לא מילולי נסקרו בנוסף: שני קבועי שם והעברות `name`/`key` לעוזרים, לרבות ארבעת מכווני היציאה מהמסלול. מתאמי הסורק מכסים אותם, וכן את מפת שמות משימות הבונוס ואת תבנית `qa`.

לראיות הוספה נסרקו **9,902 גרסאות קובץ** מתוך **9,850 אובייקטי טקסט** בהיסטוריית Git הנגישה מבסיס העבודה. עבור דגלי מוצר נבדקה היסטוריית קוד המוצר, כולל קבצים שכבר אינם קיימים; עבור שמות הנקראים רק בערכות/כלים נבדקה היסטוריית הנתיבים הקוראים הנוכחיים. הרשומה מציינת במפורש את שיטת החיפוש ואת הקובץ/שורה/קומיט שבהם זוהתה הקריאה הראשונה. לאחר מכן נמצא הקומיט הראשון לאורך ההורה הראשון של הענף שמכיל אותה, ונקרא ממנו מזהה השחרור. שדה נפרד שומר גרסה שהוזכרה בכותרת קומיט הפיתוח, אם קיימת. זו הבחנה בין הוספת קוד לבין ערך השחרור במועד שילובו; אין כאן טענה שכל תצוגת design פורסמה לאתר.

ראיות הבדיקות כוללות הפניה מפורשת ל־URL, אזכור מילולי או ייבוא של מודול קורא, עם שורה וסימון אם הקובץ נכלל ב־`tests/*.mjs` של CI. כלי מדידה נשמרים בנפרד. עצם אזכור השם, הערה עם URL או ייבוא מודול אינם הוכחה לבדיקה של שני צדי הדגל; הרישום אינו מדידת כיסוי אוטומטית.

## הרצה חוזרת

משורש הריפו, עם Node.js 22 ומעלה:

```bash
node workout/island/design/architecture-map-v1/tools/scan-flags.mjs
node workout/island/design/architecture-map-v1/tools/scan-flags.mjs --check
node workout/island/design/architecture-map-v1/tools/scan-flags.mjs --self-test
```

לשחזור ראיות ההיסטוריה:

```bash
node workout/island/design/architecture-map-v1/tools/scan-flags.mjs --history
```

אין צורך בהתקנת npm להרצת הסורק. `--history` דורש גרף קומיטים מלא; בעותק shallow הוא מסרב להסיק גרסת הוספה ומבקש להשלים היסטוריה. בעותק partial הוא מוריד לפי הצורך אובייקטי טקסט של קוד, ללא נכסי מדיה היסטוריים. הרצה רגילה משתמשת בראיות ההוספה השמורות; שם חדש דורש שחזור היסטוריה אחרי שהקריאה שלו נכנסה ל־Git.

`--check` אינו כותב לקובצי התיעוד. הוא נכשל אם יש קריאה דינמית בלתי פתורה, שם ללא פירוש/היסטוריה, מקור שהשתנה מאז סקירת הפירוש, או תוצר שאינו מתאים לסריקה. בהרצה רגילה נכתבים רק `flags.json` ו־`FLAGS.md` בתיקייה הזו. אפשר להפעיל את הסקריפט גם בנתיב מלא מכל תיקיית עבודה.

## גבולות הסקירה

הסורק אינו מפרש JavaScript כללי ואינו מוכיח שכל ענף נגיש בכל שילוב דגלים. הוספת צורת קריאה חדשה דורשת סקירת המתאם והצלבה מחדש. היסטוריית ההוספה היא הקריאה הראשונה שהניתוח זיהה בטווח המוצהר; היא אינה רישום מוצר חיצוני או תאריך פריסה. חותמת מקור מחייבת סקירה מחדש כשקוד משתנה, אך אינה מוכיחה לבדה שהפירוש האנושי נכון.

לא בוצעה בדיקת משחק ידנית בטלפון או בדיקת תחושת שליטה. לא נמדדו FPS, זמני טעינה או משקלי רשת מחדש לצורך דוח זה. מפת המודולים נשענת על קוד, נתונים וגרף הייבוא, ורישום הבדיקות מפנה לראיות הקיימות; אין ייחוס תוצאות מדידה ישנות לגרסה או למכשיר הנוכחיים.

הענף מיועד לתיעוד ולכלי סריקה בלבד. אין בו שינוי סכמה, חיבור תוסף משחק, העלאת גרסה או מיזוג ל־`main`.
