# התאמת motion2 לשלד הדמויות

לכל דמות יש בדיוק 18 עצמות, באותם שמות ובהיררכיה של `workout/island/design/motion2/hoops.json`. תנוחת הקשירה הגאומטרית נשמרה מהגוף האנושי: הזרועות באלכסון והמרפקים כפופים. לעומת זאת, ב־motion2 הזרועות והרגליים במנוחה פונות מטה. לכן העתקת quaternion לפי שם בלבד אינה התאמה תקינה.

`retarget-map.json` מכיל התאמה נפרדת לכל עמדה ולשופט. לכל עצם נשמרים מיקום המנוחה המקומי והעולמי בפועל, אורך המקטע, מטריצת הקשירה ההפוכה ותיקון מסגרת הסיבוב. לזרועות ולרגליים נמדד גם מישור הכיפוף, כדי להסיר עמימות של סיבוב סביב ציר הגפה. הידיים מכוילות לפי כיוון האצבעות ונורמל הצד הפנימי שנמדדו ברשת; הן אינן משתמשות בנורמל גב כף היד. מסגרת היד הקנונית היא אצבעות לכיוון ‎−Y ופנים כף היד לכיוון ‎+Z, כפי שמשתמע מנקודת המגע `[0, -0.08, 0.025]` ב־motion2. כפות הרגליים נשארות בכיוון קשירה שטוח וקדימה ‎+Z, בלי עצמות אצבעות נוספות.

עבור עצם `i`, התיקון `B_i` מסובב את מסגרת הקשירה של הדמות למסגרת המנוחה הקנונית. מכיוון שסיבובי הקשירה בקבצים שנמסרו הם זהות, הכלל הוא:

```text
sourceWorld[i] = sourceWorld[parent] × sourceLocal[i]
targetWorld[i] = sourceWorld[i] × B_i
targetLocal[i] = inverse(B_parent) × sourceLocal[i] × B_i
```

הכלל משמר את ההזזות המקומיות, אורכי הגפיים, קנה המידה ומטריצות הקשירה של הדמות. הוא אינו מחליף את ההזזות בערכי המנוחה של אדם בגובה אחר. פריים קנוני עם סיבובי זהות מביא את כיווני הגפיים למנוחה הקנונית; `resetBind()` מחזיר את תנוחת הקשירה האנושית המקורית.

## שימוש מקומי ללא build

המתאם הוא מודול עצמאי ב־`source/retarget-motion2.mjs`, המשתמש ב־three.js r160 המקומי. יש להפעיל אותו על שורש של דמות אחת, עם מטא־נתוני `rig.json` שכבר נטענו. יש לבחור בעלים אחד לסיבובי העצמות בכל פריים; המתאם והתנועה הפרוצדורלית של דף התצוגה אינם מופעלים יחד על אותה דמות.

טעינת קובצי ה־GLB הסופיים דורשת שני מפענחים מקומיים: גאומטריה עם Draco ונתוני אנימציה עם Meshopt. המתאם עצמו אינו טוען GLB ואינו צריך מפענח נוסף. יש להגדיר את הטוען של הצרכן כך:

```js
import { GLTFLoader } from './vendor/GLTFLoader.js';
import { DRACOLoader } from './vendor/DRACOLoader.js';
import { MeshoptDecoder } from './vendor/meshopt_decoder.module.js';

const draco = new DRACOLoader().setDecoderPath('./vendor/draco/');
const loader = new GLTFLoader()
  .setDRACOLoader(draco)
  .setMeshoptDecoder(MeshoptDecoder);
const gltf = await loader.loadAsync('models/pg.glb');
```

הדחיסה ב־Meshopt מוגבלת לנתוני האנימציה. ה־TRS של העצמות ומטריצות הקשירה ההפוכות נשארים ללא דחיסה זו; פקודת האימות להלן בודקת את העובדה הזו במפורש. כל הספריות והמפענחים בחבילה מקומיים, ללא CDN.

```js
import { createCanonicalRetargeter } from './source/retarget-motion2.mjs';

const profile = { id: 'pg', ...rig.profiles.pg };
const retarget = createCanonicalRetargeter(gltf.scene, profile);

// canonicalFrame הוא פריים מלא: rotations לכל 18 העצמות,
// hipsOffsetMeters, ונתוני תנועה נוספים שכבר נטענו.
retarget.apply(canonicalFrame);

// חזרה מפורשת לתנוחת הקשירה המקורית:
retarget.resetBind();
```

אפשר להשתמש במפה המחושבת מראש:

```js
const retarget = createCanonicalRetargeter(gltf.scene, 'pg', {
  map: retargetMap,
});
retarget.apply(canonicalFrame);
```

קיימת גם פונקציית הנוחות `applyCanonicalPose(root, canonicalFrame, profile, options)`, ששומרת מתאם במטמון לכל שורש וזהות של מטא־נתונים. אובייקטי הפרופיל והמפה צריכים להישאר בלתי משתנים לאחר יצירת המתאם.

`hipsOffsetMeters` מוכפל כברירת מחדל ביחס בין אורך שרשרת ירך–ברך–קרסול ממוצעת בדמות לאורך הקנוני, 0.78 מטר. אפשר לספק `hipsOffsetScale` חיובי אחר במפורש. `referenceRootTranslationMeters` אינו מתווסף כברירת מחדל: הסימולציה קובעת מיקום ו־yaw. `applyReferenceRootTranslation: true` מיועד לתצוגת מסלול מפורשת, ואסור להוסיף אותו שוב למיקום הדמות במשחק.

## מגע כדור ורצפה

פרופורציות הדמויות שונות. התאמת סיבובים לבדה אינה מבטיחה שימור של מרחק כף יד–כדור, נעילת רגל, גובה סוליה או היעדר חדירת רשת. לאחר התאמת הסיבובים ולאחר ערבוב תנוחות יש להפעיל IK המותאם לגפיים ולנקודות האחיזה של הדמות, ולבדוק את הרשת המעוותת מול הרצפה. אירועי המגע נשארים נתוני תצוגה; המתאם אינו מחליט בעלות על כדור, ניקוד או פגיעה.

אפשר לספק callback סינכרוני `afterRetargetIK(actor, context)`. ההקשר כולל את הפריים הקנוני, העצמות, המפה וקנה המידה. המתאם מעדכן את מטריצות העולם לפני הקריאה ואחריה. תוצאתו מסמנת תמיד `contactsGuaranteed: false`; אימות מגע מחייב בדיקה נפרדת. בדיקות המגע של הקליפים המוטמעים בחבילה מתועדות בנפרד, ואינן מוצגות כהוכחה לכל קליפ motion2 מיובא.

## יצירה ואימות חוזרים

לאחר בנייה מחדש של הדמויות מריצים משורש הריפו:

```sh
node workout/island/design/hoops-v7/characters/source/retarget-motion2.mjs --write-map --validate
```

הפקודה קוראת את `rig.json` הנוכחי ואת שלד motion2 בפועל, בודקת שהם תואמים לחוזה המוטמע במתאם, וכותבת רק את המפה ואת `verification/retarget-motion2.json` בחבילה זו. הדוח בוחן את פריים הזהות ואת כל 899 פריימי המפתח של תשעת קליפי motion2/hoops בכל שש הדמויות, גם בתוך שורש מסובב. בנוסף הוא קורא את 12 קובצי ה־GLB שנמסרו ובודק שמות, הורים, הזזות, סיבובי קשירה ומטריצות קשירה הפוכות מול המפה. זהו אימות אלגברי ו־FK; הוא אינו בדיקת מגע כדור, חדירת עור או ביצועי טלפון.

גיבובי מקור motion2 ושל `rig.json` נשמרים במפה ובדוח, כדי לזהות מתי נדרשת יצירה חוזרת. שום קובץ קיים תחת `motion2/` לא משתנה.
