# מקור ורישיונות

כל 144 הנכסים בערכות נוצרו למשימה זו. הגאומטריה, הצבעים, נופי הפרלקסה, אותיות השלטים ומפרטי מזג האוויר נוצרים דטרמיניסטית מקוד המקור שבתיקיית `source/`. אמנות הערכות, קוד היצירה, קוד התצוגה וצילומי המסך מוקדשים לנחלת הכלל לפי [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/legalcode).

| רכיב | מקור ורישיון |
|---|---|
| אריחים, אביזרי צד ושלטים | גאומטריה וצבעי קודקודים שנוצרו ב־`source/`, ברישיון CC0-1.0 |
| שכבות הרקע | איור מקורי משוכב, מיוצא מקומית ל־WebP, ברישיון CC0-1.0 |
| אפקטי מזג האוויר | מפרטי JSON וקוד Canvas מקורי, ברישיון CC0-1.0 |
| גולש הקורל בתצוגה | נכס מקומי בענף הבסיס, ברישיון CC0-1.0. [רישיון גרסת הבסיס](../alpine-runner-v1/LICENSES.md) |
| Three.js והטוען | התצוגה מפנה לקוד המקומי של גרסת הבסיס, ברישיון MIT. [הודעת הרישיון](../alpine-runner-v1/vendor/LICENSE.three) |
| Pillow, Khronos glTF Validator, Playwright ו־Chromium | כלי יצירה ואימות שמותקנים מחוץ לחבילה |

אותיות `START` ו־`FINISH` עשויות מגאומטריה מקורית. הממשק משתמש בגופני המערכת המותקנים במכשיר.
