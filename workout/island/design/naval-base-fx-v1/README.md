חבילת נכסים מקורית לספינות, 12.11.2026. פיצוץ אש ועשן חד־פעמי, לולאת עשן שחור עולה, ניצוצות וצליל עמוק. כל התוספות נמצאות בתיקייה זו. החבילה מיועדת לסקירה ולחיבור עתידי בשכבת התצוגה.

כל האטלסים הם PNG RGBA עם **שקיפות אמיתית**, ללא משבצות מצוירות. גודל תא אחיד: 128×128; בכל תא 8 פיקסלים שקופים מכל צד. המקור לפיצוץ ולמרקם העשן נוצר ב־ImageGen. לולאת העשן נארזה מאוכלוסיית עננים שעולה, מתרחבת ודועכת; הניצוצות והצליל סונתזו בקוד. המקורות והוראות היצירה מצורפים.

## צפייה

1. מתוך שורש המאגר מפעילים שרת מקומי:

   ```sh
   python3 -m http.server 8765
   ```

2. פותחים את [דף התצוגה המקומי](http://localhost:8765/workout/island/design/naval-base-fx-v1/).
3. לוחצים על ״הפעלת פיצוץ״. בוחרים ״צליל עם הפיצוץ״ כדי לשמוע אותו. בהאזנה נפרדת אפשר לבחור OGG או MP3 בנגן למטה. ההפעלה הראשונית והחזרה האוטומטית חזותיות ושקטות.
4. בוחרים רקע משבצות או רקע בהיר, מכבים שכבות וגוררים את ציר הזמן. התוצאה הרצויה: רק האפקט נראה, בלי מלבן רקע או פריימים שכנים; העשן עולה גם במעבר מסוף הלולאה לתחילתה. ״השהיה״ עוצרת גם את הקול. הפחתת תנועה במערכת פותחת את הדף בפריים עצור.

אפשר להריץ את הדף ישירות מהענף באמצעות שרת קבצים; פרסום ב־GitHub Pages תלוי בתצורת הפריסה של המאגר. אין צורך בספריות חיצוניות, בגופנים מהרשת או בהתקנת חבילות לצורך התצוגה.

## חוזה שילוב

[manifest.json](manifest.json) הוא מקור המידות, קצבי הפריימים, נקודות העיגון והצליל. כל הנתיבים יחסיים לתיקייה זו.

- סדר פריימים: מתחילים ב־0, משמאל לימין ואז מלמעלה למטה. `column = frame % columns`, ‏`row = Math.floor(frame / columns)`, מלבן מקור `(column*128, row*128, 128, 128)`.
- `frame = Math.floor(elapsedSeconds * fps)`. בלולאה בלבד מחילים `% frames`. בפיצוץ ובניצוצות מפסיקים ציור אחרי `durationSeconds`. אין להחזיר אפקט חד־פעמי לפריים 0. הפריים האחרון שקוף לגמרי; בפיצוץ פריימי הסיום כוללים זמן שקוף קצר לאחר דעיכת הענן.
- ציר Y באטלס וב־pivot נמדד מלמעלה. מציבים את ה־pivot בנקודת הפגיעה: פיצוץ `[0.5, 0.75]`, עשן `[0.5, 0.84375]`, ניצוצות `[0.5, 0.5625]`. משתמשים במידות הפריים כולו, כולל השוליים, ולא ב־bounding box שמשתנה בזמן.
- צבע sRGB ו־**straight alpha**. פיצוץ ועשן: source-over רגיל. ניצוצות: `SRC_ALPHA, ONE` במנוע; בדף Canvas משתמש ב־`lighter`, שמטפל ב־alpha בעצמו. אין להכפיל alpha פעמיים. עומק: depth-test לפי הזירה, depth-write כבוי. לעשן חייבים blending רגיל כדי שיישאר כהה.
- linear filtering, ‏clamp-to-edge, ללא mipmaps; UV inset של חצי פיקסל. אל תבצעו color-key לשחור: השחור הוא העשן, לא רקע.
- מפעילים פיצוץ וניצוצות ב־t=0. מתחילים עשן ב־t=0.45 שנ׳, עם כניסה של 0.4 שנ׳, וממשיכים את הלולאה כל עוד המחסן בוער. בכיבוי מפחיתים alpha לאורך 0.5 שנ׳. התצוגה מדגימה כיבוי ב־t=5.7 שנ׳ וחזרה חזותית ב־6.4 שנ׳.
- משמיעים את הצליל פעם אחת בתחילת הפגיעה, רק אם שמע מופעל ונפתחה הרשאת הניגון של הדפדפן בעקבות מחוות משתמש. OGG / Vorbis ראשון ו־MP3 כחלופה. מונו מתאים למיקום באמצעות Panner של המנוע. אין לבצע normalization נוסף כדי לשמור על יעד −16 LUFS. עוצמת המשתמש נפרדת מהעוצמה המקודדת.
- מקפיאים את זמן האפקט בהשהיה, ועוצרים קול ביציאה. בהפחתת תנועה מומלץ להציג משוב קצר ועדין ולהימנע מהבזק גדול.

שלושת המרקמים יחד צורכים **6 MiB ב־RGBA8** ללא mipmaps, ועד שלושה quads / שלוש קריאות ציור למופע. יעד לטלפון חלש: מופע אחד פעיל; טעינה מראש מחוץ לרגע הפגיעה ושחרור ביציאה מהזירה. אלו חישובי נפח ועלות גאומטרית, לא מדידת FPS במכשיר. מקורות `sources/` וקובצי `verification/` הם חומרי סקירה ואין לטעון אותם במשחק.

## יצירה חוזרת ובדיקה

הכלים דורשים Python 3 עם NumPy, SciPy ו־Pillow, וכן FFmpeg/ffprobe עם libvorbis ו־libmp3lame. המקורות הגרפיים כבר כלולים, ולכן יצירה חוזרת אינה פונה לשירות יצירה. כל רעש הצליל ומסלולי הניצוצות משתמשים ב־seed ‏20261112.

```sh
python3 workout/island/design/naval-base-fx-v1/tools/generate.py
```

```sh
python3 workout/island/design/naval-base-fx-v1/tools/validate.py
```

לאחר הפעלת השרת המקומי, ועם Playwright מותקן:

```sh
node workout/island/design/naval-base-fx-v1/tools/browser-check.mjs
```

אפשר להגדיר `PLAYWRIGHT_MODULE` לנתיב מודול Playwright ו־`CHROMIUM_PATH` לנתיב Chromium מותקן. מדידות העוצמה מבוצעות **אחרי פענוח כל אחד מקובצי ההפצה**, עם תיקון gain נפרד לכל מקודד עד סטייה של לכל היותר 0.1 LU. גרסאות ספריות שונות עשויות לשנות את הבתים המקודדים; המדדים נבדקים מחדש.
