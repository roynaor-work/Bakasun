קריאת השער היא מקהלת תנועות פה מסונתזת, עם פתיחת גרון, ״או״ ממושך וסיום דמוי ״ל״; זו אינה הקלטת דיבור טבעי.
מחיאות הכפיים נוצרות מאותות רעש קצרים ומפוזרים. הבעיטות משלבות תהודת כדור וחבטת נעל.
הרישיון לכל תוצרי התיקייה הוא [MIT](LICENSE.txt), כולל האודיו והמחולל.

## שחזור ובדיקה

נדרשים פייתון 3.12 ומעלה, הספריות NumPy ו־SciPy, וכן FFmpeg עם libopus ו־libmp3lame ו־ffprobe.
הגרסאות ששימשו לבנייה מתועדות במניפסט. כלי הבנייה אינם נדרשים לניגון ואינם מצורפים לחבילה.

משורש הריפו, יצירה מחדש של האודיו והמניפסט:

```sh
python workout/island/design/soccer-whistle-crowd-v1/synthesize.py
```

יצירה עצמאית לתיקייה זמנית, ללא שינוי בקובצי החבילה:

```sh
python workout/island/design/soccer-whistle-crowd-v1/synthesize.py --output /tmp/soccer-rebuild
```

בדיקה לקריאה בלבד של הקבצים שנמסרו:

```sh
python workout/island/design/soccer-whistle-crowd-v1/synthesize.py --verify
```

הבדיקה מפענחת את כל הקבצים, מאמתת משכים, ערוצים, גדלים, עוצמה, שיאים, תפר לולאה וגיבובים מול המניפסט.
זרע נפרד וקבוע לכל נכס וגיבוב המקור המנורמל מתועדים בו. שחזור של בתים זהים דורש אותן גרסאות כלי בנייה וספריות.
המחולל יוצר את האודיו והמניפסט; הרישיון, הדוח ועמוד ההאזנה הם קובצי מקור נלווים.

## הנחיות לחיבור עתידי

יש לטעון את המניפסט ולבחור את הפורמט הנתמך במכשיר. מומלץ להתחיל בקובצי OGG ולהשתמש ב־MP3 כחלופה.
יש להחיל פעם אחת את ההגבר המומלץ לכל נכס ולשמור מקום לעוצמת האזנה כללית.

משמיעים רקע אחד ועד שלושה אירועים במקביל. השריקות מחליפות זו את זו; ציפייה, שער והחטאה מחליפים זה את זה בהצלבה קצרה.
במהלך שריקה מנמיכים את הרקע בעוד 8 דציבל, עם כניסה של 35 ויציאה של 350 אלפיות שנייה.
ביטול, השתקה, עצירה ומעבר מסך צריכים לבטל גם טעינות ממתינות וטיימרים. דף ההאזנה מדגים התנהגות זו.

החבילה לא חוברה למנוע המשחק ולא נפרסה לאתר החי. אימות בדפדפן מחשב אינו בדיקת שמיעה בטלפון:
עדיין נדרשת התרשמות אנושית מהקהל הסינתטי ומהאיזון ברמקול המכשיר, ובדיקת מכשיר לאחר חיבור למשחק.
