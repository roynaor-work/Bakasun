# חבילת רמות פירוט

117 דגמים, בשלוש רמות כל אחד. החבילה עצמאית: הדגמים, הטקסטורות, הספריות, כלי ההפחתה וכלי אימות GLB כלולים בה. אין התקנת חבילות, שירות חיצוני או חיבור רשת בזמן הבנייה והשימוש.

1. הורידו את [ארכיון האופליין](https://github.com/roynaor-work/Bakasun/raw/refs/heads/codex/lod-pipeline-v1/workout/island/design/lod-pipeline-v1/bakasun-lod-pipeline-v1.zip), ופתחו אותו לתיקייה חדשה.
2. פתחו את [preview.html](preview.html) ישירות בדפדפן.
3. לחצו על ״בחירת תיקיית החבילה״ ובחרו את התיקייה שחולצה. שלושת הדגמים מופיעים זה לצד זה, עם בחירת תנועה, מצב נזק, סיבוב משותף ושלד. אין צורך בשרת, בהתקנת כלים או באינטרנט לצורך הצפייה.

לצפייה דרך שרת מקומי, אפשר גם להריץ מתוך התיקייה, עם Node.js 20 ומעלה:

```sh
node tools/serve.mjs
```

פתחו [את ההשוואה המקומית](http://127.0.0.1:8765/preview.html). שלושת הדגמים מוצגים באותו קנה מידה ובאותו זמן אנימציה. המרחק בתחתית מסמן את הרמה המומלצת; זווית ההשוואה נשארת קבועה לצורך בדיקה.

התצוגה מיועדת גם ל־844×390 ודורשת WebGL. קוד התצוגה מאוגד בתוך ה־HTML כדי לאפשר פתיחה ישירה; הדגמים נקראים מהתיקייה שהמשתמש בחר. אין גישה אוטומטית לקבצים אחרים במחשב.

לשחזור ההפחתה, האימות והבדיקות, מאותה תיקייה:

```sh
node tools/lod.mjs
node tools/validate.mjs
node --test tools/lod.test.mjs
```

אחרי שינוי קוד התצוגה יש לבנות מחדש את ה־HTML המאוגד:

```sh
node tools/bundle-preview.mjs
```

אפשר לעבד רק דגם אחד לצורך בדיקה. ריצה כזו מעדכנת את קובצי הדגם והמדידה שלו, אך אינה מחליפה את המניפסט הכולל:

```sh
node tools/lod.mjs --only catch-vehicles-v2/police-sedan
```

כל רמה נגזרת מחדש מהעתק המקור הנעול בגיבוב, ולא מהרמה הקודמת. העתקי המקור אינם נכתבים מחדש. הקלטים ב־[source-lock.json](source-lock.json), מדיניות המרחק ב־[lod-config.json](lod-config.json), הנתונים ב־[manifest.json](manifest.json), והתוצאות והסייגים ב־[report.md](report.md).

בדיקת הדפדפן היא בדיקה אופציונלית נוספת, הדורשת Playwright ו־Chromium מותקנים. הם אינם נדרשים לבנייה, לאימות GLB או לתצוגה עצמה:

```sh
node tools/check-preview.mjs
```

חיבור למשחקים לא בוצע. בזמן החלפת רמה יש לשמור על שם הקליפ, הזמן המקומי שלו, משקלי ערבוב הפעולות, מצב הסצנה, משקלי הנזק ובחירת הציוד. השחקנים בכדורסל מקבלים אנימציה חיצונית: משמרים גם את שינויי העצמות של המארח. אין להתחיל קליפ מחדש בעת המעבר.
