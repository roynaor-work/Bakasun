# מקורות ורישיונות — תושבי העיר v1

החבילה נוצרה עבור `roynaor-work/Bakasun`. הדמויות בדיוניות, ללא מותגים,
סמלי רשויות, דרגות, תגי משטרה או סמלי כבאות. אין תמונות או נתונים של אנשים אמיתיים.

| --- | --- | --- |
| 12 דמויות, שלוש פלטות לכל דמות | מידול מקורי ב־[source/citizens.py](source/citizens.py), לאחר סקירת נכסי המאגר | CC0-1.0 |
| ששת קליפי האדם | כוריאוגרפיה מקורית ו־IK ב־[source/motion.py](source/motion.py); אין motion capture | CC0-1.0 |
| חתול וכלב | עיבוד ופישוט של [cat.glb](../../assets/fire-v24/friends/cat.glb) ו־[dog.glb](../../assets/fire-v24/friends/dog.glb); [הרישיון המקורי](../../assets/fire-v24/friends/LICENSES.md) | CC0-1.0 |
| יונה, ציפור, דג ופרפר | מידול ותנועה מקוריים ב־[source/animals.py](source/animals.py) | CC0-1.0 |
| שלד האדם | חוזה השלד הקיים ב־[motion2/soccer.json](../motion2/soccer.json); העתק חוזה בלבד ב־[skeleton.json](skeleton.json) | רישוי המאגר המקורי; הגאומטריה והתנועה החדשות CC0-1.0 |
| מקור הייצוא, תצוגה, מתאמי QA, תיעוד וצילומי מסך | קבצים מקוריים בחבילה זו | CC0-1.0 |
| כלי motion-qa-v1 | הגרסה המקורית ללא שינוי, קומיט [5eb4f093bc22523ee417a7f2345c3b813bffba24](https://github.com/roynaor-work/Bakasun/tree/5eb4f093bc22523ee417a7f2345c3b813bffba24/workout/island/design/motion-qa-v1); נטען לתיקייה זמנית לצורך בדיקה | CC0-1.0 לפי LICENSES.md במקור |

התצוגה משתמשת בספריות המקומיות הקיימות במאגר. להפעלתה יש להגיש את המאגר
ב־HTTP; העתקת תיקייה זו לבדה מחייבת לספק גם את התלויות המקומיות ואת רישיונן.
אין שימוש בגופנים, תמונות, טקסטורות או שירותי CDN חיצוניים בזמן התצוגה.
