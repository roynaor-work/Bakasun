# סגל כדורגל · v6

חבילת דמויות נפרדת: שישה שחקני שדה בדיוניים, שוער ושופט, שתי ערכות צבע לשחקני השדה, שתי רמות פירוט ו־20 קליפים על השלד הקנוני בן 18 העצמות.

פתחו את [דף התצוגה](preview.html) דרך שרת HTTP שמגיש את שורש הריפו. אין שלב build ואין תלות ברשת בזמן הצפייה; three.js r160, טוען GLB ומפענח Draco מגיעים מהתיקייה המקומית `workout/island/vendor/`.

```sh
python3 -m http.server 8765 --directory /workspace/Bakasun
```

לאחר ההרצה, פתחו:

```text
http://localhost:8765/workout/island/design/soccer-v6/characters/preview.html
```

1. בחרו דמות, ערכה ותנועה. גררו את הדמות כדי לסובב את המבט.
2. עצרו את הניגון וגררו את ציר הזמן לבדיקת פוזה. החלפת קליפ בזמן ניגון מפעילה ערבוב חזותי; בהשהיה היא מציגה מיד את הפוזה הראשונה.
3. פתחו ״כלי תצוגה״ לבחירת LOD ולהצגת שלד או רשת משולשים. במצב אוטומטי, שחקן יחיד משתמש ב־LOD0 ומצב 6×6 משתמש ב־LOD1.
4. בחרו תצוגת משחק כדי לטעון 12 שחקנים משתי הערכות, כולל שני שוערים. מד המשולשים מציג את הדמויות; DRAWS כולל את הסביבה כפי שמדווח הרנדרר.

קובצי הצריכה הם [asset-manifest.json](asset-manifest.json), [rig.json](rig.json), [motion/soccer-v6.json](motion/soccer-v6.json) ותיקיית `assets/`. [REPORT.md](REPORT.md) מרכז גדלים, ספירות, בדיקות ותמונות. [ASSETS.md](ASSETS.md) מתעד את המודלים והמקורות; [MOTION.md](MOTION.md) מפרט את התנועה, הצירים והמעברים.

התנועות עוצבו וחושבו בסגנון תנועה של ספורטאי; הן אינן הקלטות mocap. אירועים ומגעי כדור הם מידע חזותי, והסימולציה אחראית לפיזיקה ולהכרעות. תיקון הרצפה בתצוגה משתמש במעטפת שנמדדה מהרשת המעוותת, ובסריקה מלאה במהלך ערבוב; הוא אינו מנוע התנגשות. יעד 30fps בטלפון בינוני מחייב בדיקה במכשיר פיזי. מדידת Chromium עם SwiftShader אינה מאמתת יעד זה.

החבילה אינה מחוברת לקוד המשחק. כל קובצי המסירה חדשים ונמצאים בתיקייה זו בלבד.
