# אי החזירים · חבילת שלבים v1

18 בנובמבר 2026 · `roynaor-work/Bakasun` · `codex/boars-levels-v1`

החבילה מוסיפה את שלבים **21–40** בארבעה פרקים, שלוש מתקפות בכל שלב, שישה מצבי מזג אוויר ו־12 שדרוגים. כל **31 הקבצים** נמצאים תחת `workout/island/design/boars-levels-v1/`. משקל החבילה הוא **972,404 בתים** מתוך תקרה של 6,000,000 בתים.

## צפייה

1. פתחו את `preview.html` בדפדפן ברוחב 844 ובגובה 390. הקובץ כולל עותק נתונים לצפייה ישירות מהדיסק.
2. במסך **שלבים** בחרו שלב ומתקפה. הזמנים ברשימה נמדדים מתחילת המתקפה, והפס בתחתית מציג את מספר האויבים בכל שלב.
3. במסך **מזג אוויר** החליפו מצב וכבו את שכבת האור או המרקם להשוואה. במסך **שדרוגים** בחרו אייקון להצגת האפקט ומחירו.

לצפייה בנתוני JSON לאחר עריכה, הריצו את הפקודה הבאה משורש הריפו ופתחו את התצוגה בכתובת המקומית המצורפת. המציג בשרת קורא את קובצי JSON ישירות, והעותק בקובץ HTML מייצג את הנתונים בזמן המסירה. [תצוגה דרך השרת המקומי](http://127.0.0.1:8765/workout/island/design/boars-levels-v1/preview.html)

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

## פריסה, יעדים וקצב

| שלבים | פרק | מוקד | בוס בסיום |
|---|---|---|---|
| 21–25 | חזרה לנמל | הצגת נתיבי האגף, ערפל ומתקפות אוויר וים | מלך הברזל |
| 26–30 | הגאות הקרה | מעבר צר בשלג, נחילי רחפנים וליווי מהרפסודות | ספינת הכוורת |
| 31–35 | הרכס החשוף | שילוב משוריינים, מצור ושינוי אגפים בין מתקפות | צב המבצר |
| 36–40 | הגל האחרון | שילוב שלוש דרכי גישה ומתקפות צפופות | לווייתן הפלדה |

- `stage` מקביל למספר `wave` בשמירת המשחק. שלבים 21–40 מכסים את הרצף שאחרי 20 השלבים הכתובים במקור. שלוש הרשומות ב־`waves` מקבילות לשלוש המתקפות של שלב אחד.
- קבוצות מופיעות לפי סדרן, החל מזמן 0. היחידות בכל קבוצה, וגם המעבר לקבוצה הבאה, משתמשות ב־`spawnGapSeconds`. המתקפה הבאה מתחילה `interWaveSeconds` אחרי הופעת היחידה האחרונה במתקפה הקודמת. המספרים בטבלה כוללים רק את יחידות הפריסה המתוזמנות ואת הבוס. תגבורות שמוזמנות תוך כדי הקרב שייכות להתנהגות האויב הקיימת.
- `layout` מפנה לפריסה שנותנת X ו־Z במטרים לכל נתיב. X שלילי משמאל המצלמה. `halfWidthMeters` הוא טווח הסטה אופקית לשני הצדדים ממרכז הנתיב. הנתונים מגדירים את נקודת היעד האופקית. בחיבור שומרים את גובה וגישה הייחודיים של כל סוג ואת נתיב הכניסה המיוחד של הבוס במרכז. `worldModel` ממפה חמש וריאציות קרקעיות לנכסי האחו, ו־`kind` הוא מזהה הקרב מתוך `ENEMIES`. [לוגיקת החזירים הקיימת](../../minigames/boar-island/core.mjs)
- `clear_waves` דורש השלמת שלוש המתקפות. `clear_waves_and_boss` דורש גם להביס את הבוס המצוין ב־`boss`. יעד המדליה הוא משני וכולל סף של אחוז הגנה בעת ההשלמה או זמן משחק בשניות. את הזמן מודדים מתחילת השלב עד ההשלמה.
- חלון הפריסה, מתחילת השלב ועד הופעת היחידה האחרונה, עולה מ־62.50 ל־81.12 שניות. תזמון השלמה בפועל תלוי במהירות חיסול האויבים.

## שכבות מזג האוויר

כל שכבה בגודל 1688×780, ביחס קבוע של 844×390. הקבצים מקודדים ב־sRGB וכוללים אלפא ישרה. המניפסט מפרט את סדר הקומפוזיציה `source-over` מעל הסצנה, תחילה אור ואז מרקם. ממשק המשחק יושב מעל שתיהן. רקע האחו המשותף משמש להשוואת השכבות בתצוגה.

| מצב | אור ומרקם |
|---|---|
| גשם | גשם אלכסוני, אדוות בשלוליות ואור רך על הקרקע. |
| ערפל | שכבות אובך נמוכות, עם מרווח ראות במרכז האחו. |
| שלג | פתיתים בשלושה מישורי עומק ותאורה קרה. |
| לילה | אור ירח כחול וזוהר חם ליד החלון. |
| סערה | גשם כבד וברק קבוע בשולי השמיים. |
| שקיעה | שמש נמוכה, פסי ענן דקים ואור ענברי. |

במימוש עתידי, מזהי `rain`, `fog` ו־`storm` מתאימים לפרופילי מזג האוויר הקיימים. `snow`, `night` ו־`sunset` משתמשים בפרמטרי המשחק של `clear`. הברק בשכבת הסערה קבוע.

## חיבור שדרוגים

`weapon` מצביע על מזהה הנשק הקיים ב־`chain.mjs` ובמניפסט V2. הרכישה חד־פעמית לכל `id` כאשר הנשק בבעלות, בדרגה `requiredWeaponLevel` לפחות, וההתקדמות הגיעה ל־`unlockStage` לפי `save.nextWave`. המחיר הוא במטבעות המשחק. מפעילים את `effect.operation` עם `effect.value` על `effect.stat` אחרי חישוב `weaponStats`. שני השדרוגים של אותו נשק פועלים על שדות שונים. [שרשרת הנשקים הקיימת](../../minigames/boar-island/chain.mjs) · [מניפסט נשקים V2](../boars-weapons-v2/manifest.json)
