# מצר הדמדומים · כיוון אמנותי

המפרט הוא הרפרנס המחייב. לא צורפה תמונת רפרנס מהמשתמש. אין כאן טענה להתאמה לתמונה שלא התקבלה.

נבדקו נכסי `ship-player.glb`, `enemy-ship-b-512.glb`, `boss-ship-512.glb` והבנייה של `naval-view.mjs` כבסיס להשוואת הרמה הקיימת. הם כוללים גוף וטקסטורה מאוחדים; ארבעת הדגמים החדשים נבנים בנפרד כדי להציע צלליות מובחנות, תותחים ניתנים להנעה ו־LOD אמיתי. אין שינוי בנכסים המקוריים.

| היבט | יעד לבדיקה בצילומים |
|---|---|
| צללית | קורבטה נמוכה, משחתת עם שני מגדלים, סיירת עם סוללת צריחים, נושאת עם סיפון שטוח ואי פיקוד צדדי |
| חומר | גוף פלדה כחול־ירוק או אדום־חלודה; סיפון עמום; קצוות בהירים; חלודה מרוסנת בשוליים ובחיבורי לוחות |
| פירוט | קני תותח עם פתח לוע, מעקות, אנטנות, מכ״ם, פתחים, חלונות גשר, ציוד סיפון, סירות הצלה ודגלים בדויים |
| אור | שמש ענברית נמוכה מול מילוי שמיים קר; קו אופק נקי; לא לאבד את הגוף באזורים כהים |
| מים | גלים בכמה אורכי גל, נורמל נע, Fresnel, החזרת צבעי שמיים ושמש, קצף בשיאים ובשובל |
| אפקטים | שובל עמוד מים עולה ונופל, הבזק קצר, אש בבסיס ועשן שמתרחב ומתפזר; ללא הסתרת הספינה כולה |
| עולם | אי סלעי עם שכבות גובה וקצף חוף, סלעים נפרדים, ענני סערה שכבתיים וגשם אלכסוני |
| מצלמה | קרוב: הסיפון והקנים קריאים; רחוק: שני צבעי הצי וארבע הצלליות נבדלים גם בטלפון |
| ממשק | הסצנה היא העיקר; כפתורי מגע של 44px לפחות; פריסה ייעודית לגובה ולרוחב; ללא חפיפת כפתורים |

הספינות, הדגלים, השמות והמספרים בדיוניים. אין סמלי מדינה או צבא, לוגואים או דמות של אדם אמיתי. הדמויות הקטנות הן אנשי צוות גנריים בקנה מידה בלבד.

## תקציב מתוכנן

שלוש רמות לכל ספינה, עד 1,500,000 bytes לכל GLB, טקסטורות עד 1024×1024. אטלס צבע אחד לכל צי המשותף לכל הספינות. אטלס יחיד לדמות צוות ושלד motion2 קנוני בן 18 עצמות. מיזוג רכיבים סטטיים, שני עובדי Draco לכל היותר, instancing לצוות ולחלקיקים, DPR מוגבל, ללא השתקפות סצנה יקרה וללא postprocessing בברירת המחדל. 30fps הוא יעד לטלפון בינוני; מדידת סביבת תוכנה איננה מדידת מכשיר פיזי.
