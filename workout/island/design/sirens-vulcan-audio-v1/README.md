# סירנות וולקן — חבילת אודיו 1

12 צלילים מקוריים, 24 קובצי אודיו: כל צליל ב־OGG/Vorbis וב־MP3, בקצב דגימה של 44,100 הרץ. הסירנות והירי הם לופים; שאר הקבצים חד־פעמיים. עקיפה והחמצה בסטריאו, ושאר הקבצים במונו למיקום באמצעות מנוע המשחק.

## האזנה

1. מריצים משורש המאגר:

   ```sh
   python3 -m http.server 8765 --bind 127.0.0.1
   ```

2. פותחים [תצוגת האזנה מקומית](http://127.0.0.1:8765/workout/island/design/sirens-vulcan-audio-v1/preview.html).
3. בוחרים צליל ופורמט. כפתור הלופ מנגן עד עצירה. אפשר לשנות עוצמה, להשתיק, או להפעיל את רצף הוולקן. התוצאה הרצויה: לופ רציף ללא הפסקה, והפסקה מיידית ומרוככת בלחיצה על עצירה.

הדף עצמאי, ללא ספריות או בקשות חיצוניות. הוא נטען דרך שרת מקומי כדי לאפשר טעינת קבצי אודיו ומפרט. אין חיבור למשחק ואין שינוי בפריסה.

## שימוש עתידי

- שמות, ערוצים, משכים, יעדי עוצמה וקישורים: [manifest.json](manifest.json).
- לופים: פענוח פעם אחת ל־AudioBuffer, ניגון ב־AudioBufferSourceNode עם `loop=true`, מתחילת הבאפר עד סופו. אין צורך בנקודות חיתוך או בחפיפה בין מחזורים. רציפות של `<audio loop>` תלויה במימוש הדפדפן; דף ההאזנה משתמש ב־Web Audio.
- סדר וולקן: `vulcan-spin-up` למשך כ־0.4 שניות, `vulcan-fire-loop` כל עוד יורים, ואז `vulcan-spin-down` למשך כ־0.5 שניות. בהחלפה מומלצת חפיפת 10 מילישניות ורמפת עוצמה קצרה, כמו בהדגמה.
- `vulcan-flash` הוא שכבת הדף קולית קצרה לאירוע הבזק הירי. אין בחבילה נכס חזותי.
- `vulcan-background-loop` הוא אותו מקור ירי, מונמך ב־8 דציבל, ליעד ‎−24 LUFS. אין לנרמל אותו בחזרה ל־‎−16.
- בסטריאו של הדופלר כבר מוטבעים מעבר במרחב ושינוי גובה צליל עד ±2.5%; אין צורך להוסיף אפקט נוסף כדי לשמוע אותם. מדובר במסלול סגור ועדין, המתאים לחזרה מחזורית.
- במקרה של חוסר תמיכה ב־Vorbis אפשר לבחור MP3. הדף מאפשר לבחון כל פורמט בנפרד.

## שחזור ואימות

נדרשים Python 3, NumPy, SciPy, ו־FFmpeg/ffprobe עם libvorbis ו־libmp3lame. אין הורדת מקורות קול.

```sh
python3 workout/island/design/sirens-vulcan-audio-v1/build.py
```

יצירה מחדש של קובצי האודיו והמפרט, ולאחריה אימות אוטומטי. תוצאות מעודכנות נכתבות לקובץ המדידות.

```sh
python3 workout/island/design/sirens-vulcan-audio-v1/build.py --verify
```

בדיקה בלבד של הקבצים שנמסרו; יציאה בקוד שגיאה אם קובץ חורג מהתקציב, מהעוצמה, מהשיא, מהמשך המותר או מבדיקת התפר. נבדק גם קצב הירי מתוך מעטפת האות המפוענח. קידוד חוזר עשוי להשתנות בין גרסאות מקודדים; ה־SHA-256 מתייחס לקבצים שנמסרו בפועל.
