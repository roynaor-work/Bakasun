# מצלמות ואפקטים · Broadcast v1

[דף תצוגה](preview.html) · [הגדרות מצלמה](cameras.json) · [דרגות איכות](quality.json) · [המלצות איכות אדפטיבית](ADAPTIVE-QUALITY.md) · [דוח](REPORT.md)

דף עצמאי לכדורגל ולכדורסל, עם שש דמויות מול שש, ארבע מצלמות, מעברים רציפים ופוסט קל. כל התוספות נמצאות בתיקייה זו. הדף משתמש ב־three.js r160, ב־GLTFLoader, ב־SkeletonUtils ובמפענח Draco המקומיים של המאגר. אין build, חבילות runtime חיצוניות או פניות לשירותי צד שלישי.

## פתיחה ובדיקה

1. משורש הריפו מפעילים:

   ```sh
   python3 -m http.server 8765
   ```

2. פותחים את [הדף המקומי](http://localhost:8765/workout/island/design/broadcast-v1/preview.html). בוחרים כדורגל או כדורסל ועוברים בין שידור, צד, מעל הכתף והילוך חוזר. מסובבים לאורך ולרוחב.
3. במצב הילוך חוזר מזיזים את הסרגל, מפעילים או משהים, ואז לוחצים ״חזרה לשידור״. מכבים ומפעילים ״גימור שידור״ להשוואת אותה סצנה. ב״נתוני תצוגה״ מופיעים מספר השחקנים, המשולשים, קריאות הציור ורזולוציית הרינדור. דוח הבדיקה מפריד בין יעד ביצועים לבין מדידה בסביבה הנוכחית.

## חוזה חיבור

הקואורדינטות הן מטרים, `+Y` למעלה, `+Z` כיוון התקפה. `BroadcastCamera.update(dt, subject, velocity, portrait, replayProgress)` מקבל נתוני משחק מבחוץ; הוא אינו משנה את השחקנים. בחירת מצב באמצע מעבר מתחילה ממיקום ומסיבוב המצלמה הנוכחיים. שינוי כיוון מסך מקבל מעבר של 0.7 שניות. להיפוך כיוון התקפה יש לסובב את קבוצת הזירה או להמיר את נושא המעקב וה־offset לאותה מערכת צירים.

`MobilePost.render(scene, camera, rig, tier, reducedMotion)` מצייר את הסצנה ואת האפקטים. המארח נשאר אחראי ל־resize, לתזמון, להיסטוריית replay ולשחרור המשאבים. ה־HUD מוצג מחוץ ל־WebGL. להילוך חוזר שומרים תמונות מצב של כל 12 השחקנים והכדור ב־30Hz לשש שניות, מבודדים את ההעתק בזמן צפייה, וממשיכים את השעון החי בנפרד. הדוגמה מממשת גם סרגל זמן וחזרה לשידור.

הדמויות בעלות פרופורציות אנושיות ונגזרות מנכס MakeHuman הקיים, והאנימציות נגזרות מקליפי ה־mocap הקיימים. תנועה על המגרש היא תסריט הדגמה חלק; אין כאן בינה של משחק, בקרת מגע כדור או הנפשות כדורגל חדשות. השיער המקורי הוא רשת low-poly, ואינו מוצג כחבילת hair cards חדשה. הנושא של חבילה זו הוא מצלמות ופוסט; חומרי הבד והעור, הצללים, הדשא והקהל מספקים סצנת ביקורת ממשית.

## שחזור נכסים וצילומים

כלי הפקה בלבד: Blender 4.3, Node.js, glTF Transform 4, draco3dgltf 1.5.7, MikkTSpace ו־Playwright. הם מותקנים מחוץ לריפו; אין תלות בהם בדף הסופי. `pack-assets.mjs decode` מכין קובצי מקור לא דחוסים ב־`/tmp`, `build-assets.py` אופה אטלס ומפיק LOD, ו־`pack-assets.mjs` מפיק tangents, מנרמל משקלי שלד לשלמים שסכומם 65535 ודוחס את הפלט ב־Draco. `capture.mjs` מפיק את צילומי התצוגה ונתוני האימות מול השרת המקומי; `audit-assets.mjs` בודק גם את הגאומטריה לאחר פענוח, ו־`finalize-report.py` יוצר דוח וגלריית צילומים מהמדידות.

[מקורות ורישיונות](LICENSES.md) מתעדים את מקור הדמות, התנועה והאצטדיונים. כל הקבוצות והדמויות בדויות, והמדים ללא סמלים או שמות מסחריים.
