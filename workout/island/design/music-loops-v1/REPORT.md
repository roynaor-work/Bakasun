## האזנה

1. הפעילו מתיקיית המאגר שרת מקומי:

   ```sh
   python3 -m http.server 8765 --bind 127.0.0.1
   ```

2. פתחו את [חדר ההאזנה המקומי](http://127.0.0.1:8765/workout/island/design/music-loops-v1/listen.html).
3. לחצו ״ניגון משחק״, החליפו בין רגוע/בינוני/נמרץ, ואז נסו ״חיבור לופ״ ו״ניצחון״. התוצאה הרצויה: המקצב משתנה בתחילת תיבה, החיבור חוזר לתחילת המשחק בלי השהיה, והניצחון מסתיים לאחר שש שניות. בורר הפורמט מאפשר להשוות OGG ל־MP3.

הדף טוען קבצים מקומיים דרך HTTP. פתיחה ישירה ב־`file://` אינה נתמכת בגלל מודולים וטעינת אודיו. [תצוגת טלפון](preview-mobile.png) · [תצוגת מחשב](preview-desktop.png).

## מבנה הלופ והעוצמות

כל משחק הוא **32 תיבות, 4/4**, בארבעה אזורים בני שמונה תיבות: `low`, `medium`, `high`, `medium-return`. השינוי הוא בצפיפות המקצב: פעימות בסיס ושייקר עדין, תוספת שמיניות, ואז חלוקות צפופות יותר, פריטות ותופים. ה־BPM נשאר קבוע כדי לשמור על פעימה ומיקום מוזיקלי בזמן מעבר עוצמה.

`manifest.json` מכיל שם, BPM, משך, מספר דגימות, תחילת וסוף לופ בשניות ובדגימות, אזורי עוצמה, נתיבי פורמטים, גדלים, SHA-256 ועוצמה נמדדת. נקודת הלופ המלא היא דגימה **0 עד `frames`**, כאשר הסוף אינו כלול. גבולות האזורים הם ספירות דגימות מדויקות; יש להעדיף אותם על אורך המכל המעוגל.

הסינתזה כוללת זנבות מחזוריים, מסנן מחזורי וטיפול קוסינוס חלק של 12ms בכל צד של גבול אזור, ללא הוספת דגימות שקט. `player.mjs` מפענח את הקובץ ל־AudioBuffer ומנגן לולאה טבעית של Web Audio. מעבר עוצמה משמר את שלב התיבה במשפט המוזיקלי ומתוזמן לתיבה הבאה, עם חפיפה של 20ms. שינוי בחירה לפני מעבר מבטל את הבחירה הממתינה. הלופ ממשיך במנוע האודיו בלי טיימר JavaScript לכל חזרה.

MP3 כולל תג Xing/LAME להסרת השהיית מקודד וריפוד. אורך המכל עשוי לכלול ריפוד; האורכים במניפסט הם של האודיו המפוענח. נגן שמפעיל שוב HTMLAudioElement בכל אירוע `ended` אינו מספק את תזמון החיבור שנבדק כאן.

דוגמת שימוש בנגן המצורף, לאחר טעינת המניפסט ובתוך פעולת משתמש:

```js
import { LoopPlayer } from './player.mjs';
const manifest = await (await fetch('./manifest.json')).json();
const music = new LoopPlayer();
const track = manifest.tracks.find(t => t.id === 'soccer-gameplay');
await music.play(track, { level: 'low', format: 'auto' });
music.setIntensity('high'); // בתיבה הבאה
music.setVolume(0.55);
// בסיום המשחק: music.stop(), או music.play(קטע הניצחון)
```

## מקור, קידוד ורישיון

[`synthesize.py`](synthesize.py) יוצר כל דגימה מאפס: מתנדים עם הרמוניות מוגבלות, מעטפות חלקות, רעש בעל זרע קבוע, תופי סינתזה, פריטות, כלי עץ, קלידים, קנה וכריות צליל. הקונטורים, ההרמוניה והעיבודים נכתבו לחבילה זו. לא שימשו הקלטות, soundfonts, ספריות דגימות, קובצי MIDI, לחנים מצוטטים או נכסי מותג.

המאסטר מונו, **32kHz**. MP3 הוא CBR של **56kbps**; OGG הוא Vorbis באיכות 4, ובסקי איכות 6 כדי לשמר את דיוק החיבורים של הצליל האוורירי. הסינון עובר בהדרגה מ־3.1kHz לאפס ב־3.9kHz. הנרמול משתמש בהגבר קבוע לכל קובץ, עם מדידה חוזרת אחרי קידוד, לשמירת מבנה הלופ והדינמיקה.

כל האודיו והמקור נמסרים תחת **CC0-1.0**, כולל שימוש מסחרי ושינוי ללא חובת קרדיט. נוסח מלא ב־[`LICENSE.txt`](LICENSE.txt). כלי הבנייה נשארים תחת רישיונותיהם ואינם מצורפים לחבילה.

## שחזור

מתיקיית המאגר, עם Python 3.11 ומעלה ו־FFmpeg/ffprobe הכוללים libvorbis ו־libmp3lame:

```sh
python3 -m pip install -r workout/island/design/music-loops-v1/requirements.txt
python3 workout/island/design/music-loops-v1/synthesize.py
```

אימות הקבצים שנמסרו, ללא סינתזה מחדש:

```sh
python3 workout/island/design/music-loops-v1/synthesize.py --verify-only
```

בדיקת הנגן והפענוח בדפדפן, לאחר התקנת Playwright ודפדפן:

```sh
python3 -m pip install playwright==1.62.0
python3 -m playwright install chromium
python3 workout/island/design/music-loops-v1/verify_browser.py
```

אפשר להגדיר `MUSIC_BROWSER` לנתיב Chromium קיים. סקריפט הדפדפן מפעיל שרת localhost זמני בעצמו. כל תוצרי הבנייה והמדידות נשמרים בתיקייה זו; קובצי PCM זמניים נמחקים אוטומטית.
