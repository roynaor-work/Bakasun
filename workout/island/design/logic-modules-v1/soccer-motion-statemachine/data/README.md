# נתוני מקור וראיות חילוץ

`../src/data/clips.mjs` כולל 89 קליפים מחוברים ומחושבים בשש חבילות מקור. אלה נתוני האנימציה המקוריים מתוך קובצי GLB, ולא פוזות בדיקה שנוצרו כדי להתאים למנוע. המזהה משלב את שם חבילת המקור ואת מזהה הקליפ. שמות זהים בחבילות שונות נשארים קליפים נפרדים.

| נתון | כמות |
|---|---:|
| קליפים בקטלוגים | 89 |
| ערוצי אנימציה שחולצו | 1,640 |
| אירועי קטלוג | 256 |
| שלדים קנוניים נפרדים | 1, עם 18 עצמות |
| סוג אינטרפולציה במקור | LINEAR בלבד |
| ערוצי הזזה של Root | 0 |
| קובצי ייחוס ותבניות שמופיעים במלאי בלבד | 14 |

כל ערוץ שומר את זמני המפתחות והערכים הבינריים המקוריים מסוג float32, המיוצגים ללא אובדן כמספרי JavaScript. זמני מפתחות ושלד זהים נשמרים פעם אחת ומשותפים לנתונים המתאימים. אין פישוט של מסלולי העצמות ואין דגימה מחדש בחילוץ. `duration` שומר את זמן הקטלוג; `glbDuration` שומר את הקצה המדויק של ערוץ ה־float32. ההפרש הזעיר ביניהם הוא תוצאה של דיוק המספר במקור.

`rawMetadata` שומר את תיאור הקליפ המקורי. מסלולי הכדור הצפופים בלבד הושמטו; אירועי מגע, תמיכות, תיאור הכדור ומסלול ההדגמה של תנועת השחקן נשמרים. מסלול ההדגמה אינו ערוץ Root ואינו ראיה לתזוזה אפויה בקליפ. לכל קליפ יש נתיב, קומיט מקור, גיבוב Git, גיבוב SHA-256 וחתימת קטלוג. החתימות וגדלי ה־GLB שהוצהרו בקטלוגים תואמים לחישוב העצמאי על הקבצים בפועל.

שחזור הנתונים, מתוך שורש חבילת המודול:

```sh
node tools/extract-clips.mjs
```

הכלי קורא אובייקטי Git לפי קומיטים מוצמדים, ללא מעבר ענף, שינוי נכסי מקור, התקנה או גישה לרשת. אפשר לספק נתיב ריפו אחר באמצעות `--repo=/absolute/path/to/Bakasun`. הוא כותב מחדש רק את קובצי הנתונים החדשים בחבילה. [מלאי המקורות](inventory.json) אינו כולל שעון או תאריך ריצה, כדי שהפלט יהיה ניתן לשחזור.

בדיקה עצמאית של הקליפים המקוריים:

```sh
node tools/audit-native-clips.mjs
```

[תוצאות הבדיקה](native-audit.json): 31,424 פוזות מקור, הכוללות 120 דגימות לשנייה, כל זמן מפתח מקורי וקצה מדויק. הכלי משחזר הורות וטרנספורמציות מקומיות באמצעות קינמטיקה קדימה. הוא מודד את ראשית כל עצם פרט ל־Root, ואת מרכז הסוליה במרחק 8 ס״מ מתחת לכל קרסול, בהתאם לנקודת התמיכה הקנונית במקורות. לא נמצא קליפ החורג יותר מ־2 ס״מ מתחת למישור הרצפה. הערך הנמוך ביותר הוא ‎−0.006319516948 מטר ב־`soccer-kicks-v2:running_kick`, בזמן 1.5166667 שניות, במרכז סוליית רגל ימין.

זו בדיקת נקודות שלד בלבד. היא אינה בודקת משולשי רשת, עור מונפש, צורת נעל, קפלי לבוש, החלקת רגל, שיווי משקל, תאימות שחקן חיצוני או קיצון אפשרי בין הדגימות. זו גם אינה בדיקת מעבר בין קליפים; בדיקות הגרף משתמשות בפוזות מקומיות מעורבבות ובנקודות הרצפה של מנוע זמן הריצה. לכן מספרי האבחון של מעברים עשויים להיות שונים מהמספר לעיל.

הודעות הרישיון המקוריות שמורות במלואן תחת `licenses/`; [מפת הרישוי](../LICENSES.md) מקשרת אותן למקורות המוצמדים. אין בחבילה נתוני רשת, טקסטורות, קוד Three.js או תלות חיצונית מחבילות המקור.
