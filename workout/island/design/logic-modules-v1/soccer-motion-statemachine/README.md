# מכונת מצבי תנועה לכדורגל — API 1.0.0

מודול מבודד שמחבר **89 קליפים מקוריים משש חבילות** לגרף תנועה: ריצות, בעיטות, מסירות, גליץ וקימות, מספרת ונחיתה, שוערים ושופט. יש הפרדה בין קליפים ששמותיהם זהים בחבילות שונות, זמני מעבר מפורשים, חסימות לפי הקשר, תור בקשה אחד ובדיקות רצפה ומעברים. זהו היגיון ונתוני פוזה; המשחק הקיים לא חובר או שונה.

`src/index.mjs` הוא נקודת הכניסה. כל `src/` עצמאי: JavaScript ES modules ללא תלויות, WASM, DOM, שעון, אקראיות, רשת או קריאת קבצים. אפשר להעתיק את `src/` לבדו. מצבי המנוע והגרף קפואים עמוק וניתנים לשמירה ב־JSON; פעולות מחזירות מצב חדש. כלי החילוץ והבדיקות תחת `tools/` משתמשים בכלים המובנים של Node/Git ואינם מיובאים בזמן ריצה.

מתיקיית המודול:

```sh
node --test tests/*.test.mjs
```

```sh
python3 -m http.server 8765
```

פתחו [preview.html](http://localhost:8765/preview.html). בחרו תפקיד, מהירות וקליפ; בקשו תנועה, השהו והתקדמו בצעדים. התרשים והשלד הסכמטי משתמשים במודול עצמו, ללא ספריית גרפיקה או הורדה חיצונית. אירועי דחייה, תור, ביטול וקימה מוצגים ליד מצב המנוע. טבלת האבחון נטענת מהדוח המקומי; יש להגיש את התיקייה ב־HTTP.

```js
import {
  createMotionState, setLocomotion, requestMotion, advanceMotion,
  sampleMotion, restoreMotionState,
} from './src/index.mjs';

let state = createMotionState({ role: 'field' });
state = setLocomotion(state, { speedMps: 4.5, heading: Math.PI / 2 }).state;

const request = requestMotion(state, {
  clipId: 'soccer-kicks-v2:running_kick',
}, { hasBall: true, grounded: true });
state = request.state; // בדקו request.events: הבקשה יכולה להידחות או להמתין.

const tick = advanceMotion(state, 1 / 60, { hasBall: true, grounded: true });
state = tick.state;
const { pose, diagnostics } = sampleMotion(state);
// pose: parent-local TRS לפי סדר העצמות ב־getClip(state.clipId).skeleton.
// העבירו את tick.rootDisplacement למערכת התנועה/התנגשויות רק פעם אחת.
const restored = restoreMotionState(JSON.stringify(state));
```

היחידות הן מטרים ושניות, זווית `heading` ברדיאנים, וקווטרניונים בסדר `[x,y,z,w]`. מהירות 2.6/4.5/7.2 מ׳/שנ׳ בוחרת ג׳וג/ריצה/ספרינט החדשים בקצב המקור שלהם. מחזור תנועה ישן מוגבל לקצב ×1.5; בקשה או אתחול מעבר לטווח שלו נדחים. מעברי האצה יורשים את תקרת מהירות קליפ היעד. המנוע אינו מאיץ את מקור האנימציה ללא גבול כדי להסתיר אי־התאמה.

המיקום בעולם שייך לסימולציה: `advanceMotion` מחשב `speedMps × dt` לאורך `heading` בזמן קליפ תנועתי, גשר או `locomotion:true`. הוא אינו מחבר אליו שוב תרגום Hips או את `referenceTravel`, שהוא מסלול הדגמה ממטא־נתוני המקור. אין אינטגרציית כוח, מגע או התנגשות. קליפ פנייה אינו משנה heading אוטומטית, וצעדי צד/ריצה לאחור אינם משנים בעצמם את כיוון התנועה; הבקר מספק את הכיוון או מסלול הפנייה. שילוב חיצוני צריך להשתמש במיקום או בהעתק שהוחזר, בלי להזיז את הדמות פעמיים.

מעברים רגילים יוצאים מלולאות בכל phase; פעולה חד־פעמית משלימה את עצמה ואת הקימה הנדרשת לפני בקשה ממתינה. ביטול מפורש אפשרי רק ב־14% הראשונים של פעולה שאינה קימה, אל hub התפקיד. עדיפות קובעת איזו בקשה תישמר בתור; היא אינה שוברת נעילה. ברירת המחדל של TTL היא 0.45 שנ׳, ובקשה פגה בדיוק בגבול התוקף לפני ביצוע. יש לספק TTL מתאים או לחדש את בקשת הבקר לפעולה ארוכה. ההקשר נבדק גם בבקשה וגם בזמן הוצאתה מהתור.

`setLocomotion` מעדכן מיד מהירות רצויה וכיוון, גם כשהחלפת הקליפ ממתינה. אם בסוף גשר האצה או `running_kick` המהירות כבר גבוהה מטווח קליפ ההמשך, קשת fallback מפורשת מחזירה ל־idle ומדווחת `automatic-speed-fallback`. היא אינה מוחקת את המהירות הרצויה; בקר רציף יכול לבקש שוב את קליפ התנועה המתאים. קימות חובה ממשיכות גם אם ההקשר הזמני של הכדור/קרקע השתנה. [API.md](API.md) מפרט את כל החלונות, השדות, החסימות והאירועים.

שרשראות קימה נשמרות על פי פוזת המקור: גליץ→`getup_fast`, נפילות קלות/פאול→הקימה התואמת, זינוקים ותפיסות ישנים→קימה בצד הנכון, ומספרת לאחור→`scissor_land_getup`. כל 14 החיבורים לקימה תואמים בפוזת הסוף/ההתחלה של המקור. קליפי זינוק חדשים שכבר כוללים התאוששות אינם מקבלים קימה נוספת. מעברי `idle_to_*` שומרים את phase ההמשך ב־`nativeHandoff`; `running_kick` חוזר לריצת v3 בזמן 0.4 שנ׳ של הקליפ, עם התאמה בת 0.3 שנ׳ משום שייחוס הריצה הישן שונה מהמחזור החדש. שמות בעלי משמעות אינם תחליף לבדיקת הנתונים עצמם.

בגרסה שנמסרה עברו 16/16 בדיקות. דוח המעברים הסופי כולל 98,652 פוזות לכל אחד מארבעת הפרופילים, 394,608 בסך הכול, עם אפס כישלונות לאחר המדיניות. המינימום המותאם הוא 0 מ׳, ההרמה המרבית כ־0.11006 מ׳ והצעד המרבי כ־0.09604 מ׳ ב־120 הרץ. הדוח מציג גם `speedPermitted` לכל קשת: 70/122/171 קשתות חסומות במהירויות 2.6/4.5/7.2 בהתאמה; הגאומטריה שלהן עדיין נמדדת בקצב המוגבל לצורך אבחון הגנתי, אך בקשת משחק במהירות הזאת נדחית.

ספי הבדיקה: חיתוך גולמי עד 0.15 מ׳/40°, צעד פוזה מותאם עד 0.12 מ׳ בקצב הדגימה, חדירת נקודות עד 0.02 מ׳. תיקון התצוגה מרים את Root רק כלפי מעלה ועד 0.12 מ׳, ואינו משנה את מצב הסימולציה או את נתוני המקור. `sampleMotion().diagnostics.safe` מחמיר יותר מהסף הסטטיסטי ודורש שארית חדירה שאינה נמוכה מ־‎−1e−5 מ׳. גם דוח שעובר אחרי התאמה יכול לחשוף חיתוכים גולמיים וחדירה במיזוג ללא תיקון.

אלה מדידות מדוגמות של ראשיות עצמות ופינות סוליה קנוניות. הן אינן אישור למעטפת עור/משולשי דמות, לצורת נעל, למגע בכדור, ל־IK, להחלקת רגל, לשיווי משקל, לרציפות מהירות C1 או לכל phase/מהירות/זמן בין הדגימות. המיזוג בזמן ריצה משמר את הפוזה המוצגת בנקודת ההחלפה באמצעות pose מקור קפוא ו־LERP/SLERP; הוא אינו מריץ מחדש את גשרי C1 של כלי המקור. כלי הפוזה הציבוריים מצפים לנתונים קנוניים תקינים ואינם מאמת סכמות מלא של מודלים חיצוניים.

מספר הקשתות והמדידות נגזר מהקוד ומהדוח; להצגת המלאי הפעיל:

```sh
node --input-type=module -e "import {CLIPS,TRANSITIONS} from './src/index.mjs'; console.log({clips:CLIPS.length,transitions:TRANSITIONS.length});"
```

שחזור נתונים מתוך אובייקטי Git המוצמדים אינו דורש החלפת ענף או רשת. הוא כותב מחדש את נתוני המודול; ריצה רגילה אינה זקוקה להיסטוריית המקור:

```sh
node tools/extract-clips.mjs
node tools/audit-native-clips.mjs
node tools/audit-transitions.mjs
node --test tests/*.test.mjs
```

המספרים ב־`src/data/clips.mjs` הם ערכי float32 מקוריים שחולצו ללא איבוד, ולא פוזות שנוצרו לצורך בדיקה. החבילות המקוריות הן אנימציות מחוברות ומחושבות, ללא לכידת תנועה של אדם אמיתי. גאומטריה, skin, טקסטורות, Three.js ומסלולי כדור צפופים אינם מופצים במודול. ראו [LICENSES.md](LICENSES.md) להודעות CC0 המלאות, להעתקים המקומיים ולקישורי המקור המוצמדים. [API.md](API.md) הוא חוזה האינטגרציה המפורט לגרסה 1.0.0.
