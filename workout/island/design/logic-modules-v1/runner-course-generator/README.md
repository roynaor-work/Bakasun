# מחולל מסלול סקי — API v1

מודול היגיון מבודד: JavaScript ES modules טהור, ללא תלויות, WASM, גישה לדפדפן, שעון, קבצים או רשת. אין חיבור למשחק הקיים ואין שינוי בקבציו. הקלט הוא seed, רמת קושי וסביבה; הפלט הוא נתונים סריאליזביליים וקפואים עמוק.

מתיקיית המודול:

```sh
node --test tests/*.test.mjs
```

תצוגה מקומית שמייבאת ומריצה את המודול עצמו:

```sh
python3 -m http.server 8765
```

פתחו [preview.html](http://localhost:8765/preview.html), בחרו סביבה/רמה ולחצו על יצירת מסלול. הקו הירוק הוא מסלול רציף שעבר בדיקת גאומטריה ותנועה; כפתור ההעתקה מחזיר את ה־JSON שנוצר בפועל. נדרש HTTP לצורך ES modules.

```js
import { generateCourse, generateSegment, validateCourse } from './src/index.mjs';

const setup = { seed: 'my-run-17', difficulty: 2, theme: 'ice' };
const first = generateCourse({ ...setup, startSegment: 0, segmentCount: 24 });
const next = generateCourse({ ...setup, startSegment: 24, segmentCount: 8 });
if (!validateCourse(first).valid) throw new Error('Invalid course');

// התחלה באמצע מסלול: יוצרים תחילה את המכשולים שעוד חוצים את התפר.
const resumed = generateCourse({ ...setup, startSegment: 200, segmentCount: 8 });
const initialObstacles = resumed.segments[0].carryIn;
// בהזרמה רגילה מוסיפים רק segment.obstacles; carryIn אינו מכשולים חדשים.
const segment200 = generateSegment({ ...setup, index: 200 });
```

שלושה נתיבים בלבד, ברוחב 3 מ׳ ובמרכזים ‎−3/0/3 מ׳. כל מקטע הוא 30 מ׳, אבל מכשול שייך למקטע שבו התחיל ויכול להימשך עד 2 מ׳ לתוך הבא. `carryIn` משמר את המכשולים האלה גם בגישה אקראית. כל מקטע מוסיף 1–3 מכשולים ו־1–3 בונוסים; הנתיב הבטוח עובר לכל היותר לנתיב סמוך. נתיב יציאה ותבנית אינם חוזרים יותר מפעמיים, גם במפגש בין בלוקים. אין עלייה בלתי מוגבלת בקושי לאורך הריצה.

| רמה | מהירות נומינלית | תקרת מהירות לתכנון | תגובה | מעבר נתיב | תחילת שורת מכשולים במקטע |
|---|---:|---:|---:|---:|---:|
| 1 — קל | 20 מ׳/שנ׳ | 31 מ׳/שנ׳ | 0.40 שנ׳ | 0.36 שנ׳ | 29 מ׳ |
| 2 — בינוני | 25 מ׳/שנ׳ | 31 מ׳/שנ׳ | 0.35 שנ׳ | 0.36 שנ׳ | 28 מ׳ |
| 3 — קשה | 28 מ׳/שנ׳ | 31 מ׳/שנ׳ | 0.30 שנ׳ | 0.36 שנ׳ | 27 מ׳ |

הערכים הקיימים ב־`minigames/alpine-league-theme.mjs`, ב־`minigames/alpine-v241.mjs` וב־`data/config.json` נקראו כרפרנס בלבד: ששת המזהים תואמים (`pine`, `ice`, `lava`, `aurora`, `village`, `peak`), ותקרת ה־boost הקיימת היא 31 מ׳/שנ׳; מהירות הצד הקיימת 8.5 מ׳/שנ׳ גבוהה מהנדרש כאן, 8⅓ מ׳/שנ׳. המודול לא מייבא אותם.

| village | יותר רצפי פרסים; פחות צד; פרסי star | זהב, ארגז/שלג |
| peak | יותר מכשולים ארוכים ופיזור ופניות; פרסי shield | כחול, גרניט |

הצבע וסוג המכשול הם רמזים חזותיים; משקלי התבניות, הסתברות הפנייה/מכשול הצד וסוג הפרס הם שינוי המשחקיות. `energy`/`shield` הם נתוני פרס בלבד: אין אפקט מהירות/חסינות אוטומטי. אין החלקה בקרח, רוח, קפיצות, בלימה, תנועה של מכשולים או AI במודל הזה.

ההוגנות נבדקת בשני תנאים נפרדים: בכל מרחק נשאר מרכז נתיב פנוי עם מרווח לשחקן, וקיים מסלול רציף עם זמן תגובה ומהירות צד מותרים. `validateCourse` אינו משחזר תוצר מה־seed: הוא בודק חיתוך מדויק של כל קטע ישר במסלול מול מלבני מכשולים שהורחבו לפי חצי גוף השחקן (רוחב 0.35 מ׳, אורך 0.8 מ׳) ומרווחים (0.15/0.2 מ׳). הוא בודק גם תפרים, פרסים ונתיב סגור; הבדיקות מכניסות בכוונה מסלולים פגומים שבהם יש נתיב פנוי בכל רגע אבל המסלול שסופק פוגע במכשול.

נתיב העדות מחזיק את נתיב הכניסה ב־3 המטרים הראשונים, מתחיל לנוע רק אחרי חלון התגובה, ומסיים את המעבר לפני שורת המכשולים. הוא ממשיך עד 3 מ׳ אחרי סוף המקטע כדי לכסות את קצה המכשול ואת אורך השחקן. כל הפרסים יושבים עליו אחרי סיום המעבר. מכשולי הצד נמצאים מחוץ לשני הנתיבים המשתתפים במעבר. המרווח המינימלי בין סיום המעבר למגע אפשרי בשורת המכשולים הוא 1.44 מ׳ ברמה הקלה, 1.99 מ׳ בבינונית ו־2.54 מ׳ בקשה, במהירות 31 מ׳/שנ׳.

ההבטחה מחייבת שמנוע החיבור יכבד את מיקומי/גדלי ההתנגשות, יחשוף את הרמז לכל המאוחר ב־`path.cueM`, יאפשר מעבר רציף שאינו איטי מהעדות, ויגביל מהירות ל־31 מ׳/שנ׳. הרחבת גופי התנגשות, הסתרת רמזים, סחיפה או מכשולים נוספים מחייבים אימות מחדש. זהו אישור לקיום נתיב, לא הבטחה שכל בחירה של השחקן ניתנת להצלה.

הזרמה היא stateless: בלוקים בני 8 מקטעים מעוגנים בנתיב האמצעי בתפר ונזרעים בנפרד. גישה למקטע מיליון אינה מייצרת את כל הקודמים. בכל קריאה נוצר רק הטווח המבוקש ומידע התפר הסמוך; אין cache גלובלי. כל מקטע זהה בבאץ׳, בבאצ׳ים מחולקים או בקריאה בודדת. מגבלות v1: אינדקסים 0–999,999 ועד 1,024 מקטעים בקריאה. שמרו `apiVersion` ואת ה־config יחד עם מספר המקטע. שינוי אלגוריתם שמחליף פלט עבור אותו קלט דורש גרסת API חדשה; בדיקת SHA-256 מקבעת דוגמת replay.

הבדיקות מכסות 128 זרעים × 3 רמות × 6 סביבות × 32 מקטעים = 73,728 מקטעים, בנוסף לסימולציה נומרית עצמאית של 144 מסלולים במהירות 31 מ׳/שנ׳, באץ׳ של 1,024 מקטעים, אינדקס אחרון, תפרים, הזרמה, קלט פגום, רוחב, פרסים ואי־שינוי קלט. [API.md](API.md) מתאר את החוזה המדויק.
