## הרצה

מתוך תיקייה זו, עם Node 22 ומעלה:

```sh
node --test
node tools/server.mjs
```

פותחים את כתובת ה־loopback שהשרת מדפיס. כפתורי התצוגה מחליפים משחק, פתיחה, סיום וגלריה; ״מפת מגע״ מציגה תיבות פיזיות. קיצור `?capture=1` מציג את שטח המשחק בלי ניווט התצוגה. `?capture=1&screen=start` / `screen=end` מציגים את המסכים; `?capture=1&map=1` מציג מפה.

הבדיקה ב־Node אינה צריכה Playwright או דפדפן. לרינדור ובדיקות Pointer Events מתקינים Playwright **מחוץ לחבילה**, או מצביעים על התקנה קיימת באמצעות `PLAYWRIGHT_MODULE`; אפשר להגדיר דפדפן מקומי ב־`CHROMIUM_PATH`.

```sh
node tools/browser-check.mjs
node tools/render.mjs 07
node tools/endurance.mjs 7200
node tools/endurance.mjs 1800 --notch
```

כל רינדור יוצר 46 צילומי PNG, שני גיליונות סקירה ודוח Markdown: משחק, מפה, מצב פעיל, טוסט, safe-area, פתיחה, סיום, השהיה וניווט תצוגה בחמש המידות, ועוד גלריית רכיבים. לאחר הצלחה נשארות רק שתי תיקיות הסבבים המספריות האחרונות. אין ארכיון או JSON גולמי. הרינדור אינו תחליף לבדיקה ידנית של הצילומים.

בדיקת העמידות הראשונה משתמשת בחמש מידות הקבלה; פרופיל `--notch` מוסיף מסך 320×568, מגדיר safe-area אסימטרי לפני כל מחווה ופועל ב־DPR 3. דוחות שתי הריצות נשמרים בנפרד, ב־ENDURANCE.md וב־ENDURANCE-NOTCH.md. אם Playwright חסר, כלי הדפדפן סוגרים את השרת ומחזירים שגיאה מיידית.

## מבנה

| תיקייה / קובץ | שימוש |
|---|---|
| `runtime/island-ui.css` | צבעים, טיפוגרפיה וכל הרכיבים, בתחולה של `iu-kit` בלבד |
| `runtime/icons.svg` | SVG sprite מקורי, בכיוון פיזי מתאים למשחק |
| `runtime/island.svg`, `runtime/reward.svg` | איור פתיחה ואיור סיום, מקוריים |
| `runtime/layout.mjs` | מפת אזורי מגע טהורה, ללא DOM |
| `runtime/controls.mjs` | מתאם קלט אופציונלי: מגע כפול, מקלדת וביטול |
| `runtime/dialog.mjs` | חיבור אופציונלי לחלונות native, פוקוס והשבתת קלט |
| `runtime/format.mjs` | תוצאה קצרה ל־HUD עם תווית נגישה המכילה את המספר המלא |
| `preview/` | הדגמה בלבד; אינה נדרשת במשחק |
| `tests/`, `tools/` | בדיקות עצמאיות וכלי שחזור |
| `iterations/NN/` | רק הסבב האחרון וקודמו |

התצוגה מדמה ממשק ואינה משחק מלא. נתוני HUD ותוצאה הם מספרי דוגמה קבועים. החיבור למנועי המשחק הקיימים נשאר אצל האינטגרטור; אין בחבילה שינויים ללוגיקת משחק או לקבצים קיימים.

הרכיבים והאיורים בחבילה מקוריים ונמסרים לשימוש ישיר בריפו. אין נכסים חיצוניים או חובת ייחוס לצד שלישי.
