## בדיקות שעברו

- `node --test` מתוך תיקייה זו: 23 עברו, 0 נכשלו, 0 דולגו.
- סריקת גאומטריה: כל רוחב שלם 280–2560 עם שבעה גבהים, ועוד 6,000 מסכים שבריים עם safe-area אסימטרי; כל אזור נבדק מול כל האחרים, וגם מלוא הבסיס הצף.
- דפדפן: חמש מידות × שני כיווני טקסט × ארבעה פרופילי safe-area; DOM מול המודל, מינימום 48px במידות הקבלה, מגע כפול, השהיה באצבע שנייה, ביטולים, שינוי גודל, מקלדת, פוקוס, החלפת פעולה, destroy ו־CSS ללא מתאם.
- דוגמאות השילוב: HTML ו־JS נשלפים מ־INTEGRATION ומורכבים ישירות לדף בזיכרון; הבקרים ושלושת החלונות עוברים בכל חמש המידות.
- בדיקת טבעת פעילה: ארבע פינות וארבעה אמצעי קצה בכל מידה, עם safe-area ובלעדיו. נבדקת הפעלה אמיתית לפני מדידה וצילום; המסגרת נלקחת בחשבון במיקום הבסיס.
- כשל כלי שחזור: מודול Playwright חסר גרם לשגיאה וליציאה תוך 86ms; השרת נסגר.
- `npm test` של הריפו: 3,278 עברו, 0 נכשלו, 56 דולגו (3,334 בסך הכול), עם מתאם הדפדפן הקיים של הריפו.

פקודת הרגרסיה שהצליחה, ללא עריכת בדיקות קיימות:

```sh
ISLAND_PLAYWRIGHT="$PWD/audit/2026-11-05/tools/playwright-runtime.mjs" npm test
```

ההרצה הראשונה בברירת המחדל נתקלה ב־Playwright שמצא ספרייה אך לא מצא את בינארי הדפדפן, ובדיקה קיימת השאירה שרת פתוח. תהליך הבדיקה התקוע הופסק; ההרצה עם המתאם הקיים ו־Chromium המערכתי הסתיימה בהצלחה. לא שונה קובץ קיים כדי להשיג תוצאה זו.

## היקף האימות

הקבלה היא לערכת ממשק לשילוב, ולא לחיבור מנועי המשחק עצמם. נתוני התצוגה הם דוגמאות קבועות. טלפון פיזי, תחושת אחיזה וקורא מסך נייד נבדקים לאחר החיבור; נתוני הצלחה במשחק והשהיית הסימולציה חייבים להגיע מהמנוע. אין כאן פרסום אתר, העלאת גרסה או מיזוג.
