# מקורות ורישיון

נכסי הכדורגל בחבילה מקוריים, בדויים וללא מיתוג. הגאומטריה, ההתאמות, נתוני התנועה, המרקם, הצילומים וקובצי המקור החדשים מוקדשים לנחלת הכלל לפי [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).

| תוצר | מקור |
| --- | --- |
| שבע הדמויות | משטחי הגוף, הפנים, הידיים והציוד המקוריים מ־[characters2/source](../characters2/source/), ברישיון [CC0](../characters2/LICENSES.md). נוספו שלוש צלליות שיער, וריאציות מבנה פנים, שתי ערכות צבע ויעדי הבעה; הגאומטריה צומצמה למסך קטן. |
| חוזה השלד | [characters/rig.json](../characters/rig.json), [retarget-map.json](../viewer/retarget-map.json); צמצום עצמות העזר לפי השיטה שכבר קיימת ב־[skier3/source/build.mjs](../skier3/source/build.mjs). החוזה מבוסס על התאמת שלד Kenney, [רישיון המקור](../characters/LICENSES.md). |
| ריצה ובעיטה | נתוני CC0 מקוריים מ־[motion/soccer.json](../motion/soccer.json). |
| מסירה וגלישה | נתוני CC0 מקוריים מ־[motion2/soccer.json](../motion2/soccer.json). |
| ספרינט | התאמה מקורית של הריצה: קדנציה מהירה יותר, נטיית גו ותנופת גפיים. |
| האצטדיון | מעטפת מקורית מ־[models2/soccer-stadium.glb](../models2/soccer-stadium.glb), [CC0](../models2/LICENSES.md). נוספו מרקם מגרש מלא, פלטת ערב וארבעה פנסים מסוג `KHR_lights_punctual`. |

| דגלים ודשא | גאומטריית דגלים, תנועת רוח ומרקם דשא דטרמיניסטי מקוריים בקובצי הבנייה של חבילה זו. |
| צילומי התצוגה | רינדורים של קובצי ה־GLB הסופיים בדפדפן. גיליון התנועות הוא סידור של אותם צילומים. |

חותמות SHA-256 של קובצי המקור נמצאות ב־[manifest.json](manifest.json); חותמות התוצרים והצילומים נמצאות בדוחות האימות. קובצי המקור הקיימים נקראו בלבד.

כלי צד שלישי: three.js ו־glTF Transform — MIT; Draco ו־Khronos glTF Validator — Apache-2.0; meshoptimizer — MIT. אלה כלי יצירה ורינדור, והרישיונות שלהם נשארים בתוקף. העותקים המקומיים של three.js ומפענח Draco והודעות הרישיון שלהם נשארו במקומם. Python, NumPy, Pillow ו־Playwright משמשים לבנייה ולבדיקה בלבד.
