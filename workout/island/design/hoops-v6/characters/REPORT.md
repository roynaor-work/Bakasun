# דוח מסירה — כדורסל, דמויות v6

נוצרו חמישה שחקנים בדויים בעמדות PG / SG / SF / PF / C ושופט, עם פנים ושיער שונים, מדים ממוספרים, נעליים, ושתי פלטות צבע. לכל דמות שני LOD, שלד מנוחה משותף בן 18 עצמות, חומר PBR יחיד וסט אטלס אחד בגודל 1024×1024: צבע, נורמל ו־ORM. נורמל הבד כולל אריגה ותפרים; לעור, לעיניים, לשיער ולנעליים חספוס שונה. המקור האנטומי הוא MakeHuman המקומי, עם התאמת שלד, שימור פנים והפחתת גאומטריה.

17 קליפים מוטבעים בכל GLB: מנוחה, ארבעה כדרורים, שלוש קליעות, לייאפ, דאנק, חסימה, חטיפה, רב־צעד, ריצה, האטה, צעדי הגנה וחגיגה. [טבלת התנועה](tools/ANIMATIONS.md) מפרידה בין בסיסי CMU מוקלטים להנפשת IK חדשה בסגנון mocap. המזהה `shoot_fadeaway` מכיל וריאציית pull-up מהמקור, ומוצג כ״קליעה בתנועה״.

## גדלים וספירה

MB בטבלה הם מיליון בתים. התקציב הוא 8,000 / 3,000 משולשים ו־1.5MB לכל GLB.

כל 12 קובצי ה־GLB משתמשים ב־Draco וב־EXT_texture_webp, מכילים טקסטורות וקליפים בתוכם, ולכל דמות draw call אחד. סך ה־GLB: **6.356460MB**. מפות PNG נפרדות למסירת מקור: **3.765504MB**; התצוגה טוענת את המפות המוטבעות ב־GLB. הקובץ הגדול בחבילה הוא דוח אימות הנכסים, **0.898440MB**; הצילומים הגדולים הם C ו־PF, **0.796869MB** ו־**0.794808MB**. גודלי כל הקבצים וגיבוביהם ב־[inventory.json](inventory.json).

## איך נבדק

- [אימות נכסים](verification/asset-validation.json): פענוח עצמאי של כל GLB ובדיקת Khronos לפני ואחרי הפענוח; **אפס שגיאות**. נבדקו ספירה בפועל, משקלים, כל 17 הקליפים, שלוש מפות עד 1024, חומר יחיד ומטריצות inverse bind זהות בין כל הדגמים. בכל קובץ שתי אזהרות: חישוב tangent space בזמן ריצה ו־mesh עם skin שאינו שורש הסצנה; שלד, חומרים ושינויי קנה המידה נבדקו גם ב־three.js.
- [אימות תנועה](verification/motion-validation.json): **34,592 פוזות ב־60Hz**, בחישוב skinning לכל הקודקודים של כל הדגמים. נבדקו הקליפים המוטבעים וגם העברה ישירה של קליפי PG לשאר הדגמים. המרווח המזערי מהרצפה: **7.626 מ״מ**. SHA-256 נשאר זהה במהלך המדידה.
- [אימות מעברים](verification/transition-validation.json): **3,744 פוזות** בשמונה זוגות פעולות, שלושה זמני מקור ו־13 משקלי ערבוב, בכל הדמויות וה־LOD. המרווח המזערי: **4 מ״מ**. בעת crossfade של 0.24 שנייה התצוגה בודקת את קודקודי כפות הרגליים ומרימה את קבוצת הדמות לפי הצורך; קליפים בודדים כוללים את תיקון הרצפה בתוך ה־GLB. קליפים חד־פעמיים נעצרים בסיום.
- [בדיקת הדפדפן](verification/browser-validation.json): Chromium עם ANGLE/SwiftShader, טעינה מקומית בלבד, ללא שגיאות JS/HTTP או בקשות חיצוניות. החלפת דמות, LOD, צבע, קליפ וציר זמן; ללא גלישה ב־390×844 וב־844×390. מסגור כל 17 הקליפים נבדק בהיטל הרשת של שש הדמויות, בחמש נקודות זמן ובשתי המידות — **1,020 פוזות**. [בדיקת המסגור הקבוצתי](verification/group-framing-validation.json) מכסה סגל ושש מול שש, מצלמה רגילה ומצלמת שידור, בשתי המידות — **680 פריימים קבוצתיים, 6,460 פוזות שחקן**. מצב 6×6 כולל **12 שחקנים ושופט**, כ־**47,236 משולשים ו־24 draw calls**; 180 צופים בשני InstancedMesh. בתצוגת יחיד כ־18.7K משולשים ו־11–12 calls. מפות משותפות בזיכרון בין רמות הפירוט.
- [בדיקות המאגר](verification/repository-tests.json): `npm test` דיווח 3,203 עברו, 50 דולגו וכשל יחיד עקב חוסר בבינארי ברירת המחדל של Playwright. הקובץ שנכשל הורץ שוב עם Chromium המותקן דרך תיקיית דפדפן זמנית: **5/5 עברו**. לא נערכו קובצי בדיקה.

הדגימות מאמתות את המצבים שנבדקו, ואינן הוכחה לכל רגע רציף. יעד התצוגה הוא 30fps, עם הגבלת קצב ו־DPR עד 1.5. **לא נמדד 30fps בטלפון בינוני פיזי**; נתוני SwiftShader אינם מדידת ביצועי טלפון. התצוגה היא חבילת נכסים עצמאית; חיבור ללוגיקת המשחק לא בוצע. צילומי המסך הם בסיס לבחינת רמת המראה ביחס לרפרנס, ואינם טענה לשקילות גרפית ל־NBA 2K.

## שחזור

```sh
npm install --prefix /tmp/hoops-v6-tools --cache /tmp/hoops-v6-npm-cache --package-lock=false @gltf-transform/core@4.5.1 @gltf-transform/extensions@4.5.1 @gltf-transform/functions@4.5.1 draco3dgltf@1.5.9 gltf-validator@2.0.0-dev.3.10 sharp@0.35.5
python workout/island/design/hoops-v6/characters/tools/atlas.py
blender -b -t 6 --factory-startup --python workout/island/design/hoops-v6/characters/tools/build_characters.py
node workout/island/design/hoops-v6/characters/tools/pack.mjs
python3 -m http.server 8765
```

לאחר מכן פותחים את [התצוגה המקומית](http://localhost:8765/workout/island/design/hoops-v6/characters/preview.html). מקור ההפקה נשמר ב־`tools/`; סקריפטי האימות הורצו מתיקייה זמנית ותוצאותיהם נמסרו כ־JSON. כל השינויים בענף הם קבצים חדשים תחת `workout/island/design/hoops-v6/characters/` בלבד. קוד קיים, קובצי release, תגי גרסה, CLAUDE.md ובדיקות נשארו ללא שינוי.
