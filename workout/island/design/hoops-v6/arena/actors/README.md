# שחקני עומס לזירת v6

אלה נכסי תצוגה נגזרים מדמות בדויה קיימת, לבדיקת אולם וממשק עם 12 שחקנים. הם אינם מחליפים את שחקני המשחק הקיימים.

| נכס | משולשים | חומר / רשת | גודל |
|---|---:|---:|---:|
| `actor-lod0.glb` | 5,260 | 1 / 1 | מופיע במניפסט |
| `actor-lod1.glb` | 2,361 | 1 / 1 | מופיע במניפסט |

שניהם כוללים Draco, שלד בן 52 עצמות, ומפת UV מאוחדת בגודל 1024×1024. ה־GLB כולל אטלס צבע ניטרלי ואטלס נורמל; אטלס הנורמל מוסיף אריגה עדינה לאזורי הבד. `atlas-ember.png` ו־`atlas-tide.png` מחליפים את מפת הצבע בלבד, בלי לצבוע עור, שיער, עיניים או נעליים. כל שחקן משתמש במפת צבע אחת ובמפת נורמל אחת באותה פריסת אטלס.

בעת טעינת מפת קבוצה ב־Three.js יש להגדיר `texture.flipY = false` ו־`texture.colorSpace = THREE.SRGBColorSpace`. המידות במטרים, גובה המנוחה כ־1.78 מטר. אפשר להגדיל באופן אחיד לגובה כדורסלן. כיוון המבט במנוחה הוא ‎+Z. התנועות נשמרו מהמקור, כולל `idle`, `dribble`, `shoot`, `run`, `steal`, `block`; אורכי הקליפים, גבולות המנוחה וגיבובי SHA-256 מופיעים ב־[actor-manifest.json](actor-manifest.json).

אטלס המקור אינו UV חדש: אזורי הגוף, העיניים, השיער והנעליים ממופים לתאים נפרדים ושומרים את פריסת המקור בכל תא. לביגוד שהיה בצבע חומר בלבד נוצר UV פשוט בתוך תא הבד. איחוד הרשת מפחית את תשעת מעברי הציור של דמות המקור למעבר אחד. ‎LOD1 נוצר באמצעות פישוט רשת, עם אותם שלד, אנימציות ופריסת אטלס. החלפת ה־LOD נעשית בתצוגה באמצעות שיבוטי שלד נפרדים.

## מקורות ותנאים

- המקור הישיר, שלא השתנה: [`hoops-v4-pg-lod.glb`](../../../hoops/lod-v4/hoops-v4-pg-lod.glb), שנגזר מנכסי MakeHuman / MPFB2. תנאי הגוף, השיער והנעליים מתועדים ב־[רישיונות v4](../../../hoops-v4/LICENSES.md) וב־[ASSETS.md](../../../../ASSETS.md). רישום המקור מציין שלא נשמר אישור נפרד לכל חבילת שיער ונעליים; נגזרת זו שומרת את ההסתייגות.
- התנועות נגזרו מהמאגר הקיים, שמקורו ב־CMU Graphics Lab Motion Capture Database. שימוש מחקרי ומסחרי במוצרים לפי תנאי המקור; אין למכור את נתוני התנועה עצמם. אין כאן הצהרת CC0 על נתוני התנועה.
- ייחוס CMU: “The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.”
- קוד האיחוד, האטלסים ותלבושות הצבע נוצרו במשימה זו עבור המאגר; אין בהם מותגים או סמלי קבוצות. גיבובי המקור והפלט נשמרים במניפסט.
- כלי יצירה בלבד: glTF Transform 4.5.1 ו־meshoptimizer 1.3.0 ברישיון MIT; Draco 1.5.7 ברישיון Apache-2.0; Sharp ברישיון Apache-2.0. אינם תלות זמן ריצה של הדף. למפענח Draco המקומי יש הודעות רישיון קיימות תחת `vendor/draco/`.

שחזור: ההוראות והגרסאות המדויקות בראש [source/build-actors.mjs](source/build-actors.mjs). התהליך קורא את המקור בלבד וכותב לתיקייה זו.
