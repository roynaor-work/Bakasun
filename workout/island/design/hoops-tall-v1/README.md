# דמויות כדורסל גבוהות — v1

שלוש דמויות בדויות: רכז 1.88 מ׳, קיצוני 1.98 מ׳ וסנטר 2.08 מ׳. שלד קנוני בן 18 עצמות, פריסת UV זהה, שתי קבוצות צבעים ללא סמלים, 6,226 משולשים לדמות. גוף ופנים מליבת MakeHuman ברישיון CC0; גזרת גופייה מקורית מהמאגר שהותאמה מחדש, ומכנסיים, נעליים ושיער מקוריים חדשים. מקור ורישיון לכל קובץ ב־[LICENSES.md](LICENSES.md).

## צפייה ובדיקה

משורש המאגר:

```sh
python3 -m http.server 8765
```

פתחו `http://localhost:8765/workout/island/design/hoops-tall-v1/preview.html`. שלוש הדמויות מוצגות יחד מול טבעות בגובה 3.05 מ׳. אפשר לבחור כל אחד מ־83 קליפי v9 ומ־15 קליפי v8, לעצור ולגרור זמן, להחליף תלבושת ולהשוות ניתור מותאם לניתור המקור.

הקליפים מועתקים בבתים זהים אל `runtime/keyframes/`; אין צורך בענף v9 לצפייה. ספריות Three.js ו־GLTFLoader נקראות מהעותקים הקיימים ב־v8 ב־main. אין CDN ואין בקשות מחוץ למאגר. `runtime/*.glb` אינם משתמשים ב־Draco, Meshopt או WebAssembly. `models/*.glb` הם עותקי Draco לאחסון/עריכה.

## חוזה התאמה

שמות העצמות, ההורים, הצירים וסדר הסיבובים זהים ל־motion2. אורכי העצמות והזזות המנוחה משתנים לפי פרופיל הגוף. כל סיבובי הקשירה הם זהות; כל quaternion מקומי מהקליפים מוחל ישירות על העצם בשם הזהה. אין לשכתב את הזזות המנוחה מערכי שלד המקור הקטן, ואין להחיל ישירות את ערוץ `Hips.position` המקורי מה־GLB.

בשתי ההטבעות של v9 הזזת האגן המקורית עולה עד 1.548686 מ׳. הדמויות אינן יכולות לשנות את ערוץ ההזזה בקובץ. המתאם `runtime/retarget.mjs` מכייל במפורש את עוצמת העלייה החיובית לפי הדמות, ומשמר את הסיבובים, תזמון הקליפ, הכיווץ לפני הניתור והקבצים עצמם. מצב ״ניתור המקור״ מאפשר לבדוק זאת. כל קליפ אחר משתמש בהזזת האגן המקורית ללא כיול. אין כאן חיבור למשחק.

```js
import {createActor, sampleClip, applyFrame, calibrateDunk} from './runtime/retarget.mjs';

const actor = createActor(gltf.scene, profile); // פרופיל מתוך rig.json
const calibration = clip.id.startsWith('dunk_') ? calibrateDunk(clip, profile) : null;
applyFrame(actor, sampleClip(clip, normalizedTime), {
  jumpScale: calibration?.jumpScale ?? 1,
});
```

`sampleClip` מקבל זמן מנורמל 0–1 ומשתמש באינטרפולציה LINEAR/SLERP, כמו ערוצי ה־GLB המקוריים. תנועת עולם וסיבוב המארח אינם נכללים במדידת הגובה. כדור התצוגה הוא המחשה המותאמת לכפות הידיים החדשות; אינו סימולציית משחק או אישור מגע פיזיקלי. [REPORT.md](REPORT.md) מכיל את שיטת המדידה, התוצאות וגבולות הבדיקה.
