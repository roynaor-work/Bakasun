# מפרט דמות low-poly · סקי

סטטוס: מפרט בנייה מקורי, לא GLB. לבנות גולש עם קסדה ומשקף עם אותו שלד ווריאציות חומר; אלה תפקידי דמות דמיוניים. מותר לשנות צבע עור/שיער ומבנה גוף ללא זיהוי אדם אמיתי.

## גאומטריה ומראה

ראש 1/6.5 מהגובה, קסדה עגולה ומשקף בהיר; חליפה בצבע קרח עם בלוקים כהים על האמות והברכיים. יריבים בקורל/סגול/צהוב עם דוגמאות גאומטריות שונות. מגלשיים ארוכים פי 1.05 מגובה הגוף, מקלות דקים עם קצה עבה לקריאה; ללא סמלי ציוד.

גובה בסיס 1.60 מ׳; רצפה Y=0, קדימה +Z, ימין אנטומי -X במבט מלפנים. מטרים, Y-up, transform אפוי, root בקו הרצפה בין הנעליים. A-pose עם זרועות 35° מהגוף, מרפק וברך כפופים 5°. מרכז אגן בגובה 0.86 מ׳, כתפיים 1.30 מ׳, ראש 1.47 מ׳. Mesh יחיד עד 1,800 משולשים, LOD רחוק 700; עד 2 materials, עד 2 influences לקודקוד. לולאות סביב ברך, מרפק, כתף ואגן; נעליים וכפפות לא קוביות. אין אצבעות נפרדות, פנים עם אף גאומטרי קטן ועיניים בחומר, ללא טקסט, מספר חולצה, לוגו או קעקוע.

## שלד פשוט: 18 עצמות

```text
root
└─ hips
   ├─ spine
   │  └─ chest
   │     ├─ neck
   │     │  └─ head
   │     ├─ upper_arm.L → forearm.L → hand.L
   │     └─ upper_arm.R → forearm.R → hand.R
   ├─ thigh.L → shin.L → foot.L
   └─ thigh.R → shin.R → foot.R
```

18 כולל root; ימין/שמאל אנטומיים, סיומות נשארות קבועות ב-RTL. pivot ירך באגן, ברך בגובה 0.45 מ׳, קרסול 0.08 מ׳; זרוע 0.27 מ׳ ואמה 0.24 מ׳. יד היא mitten עם אגודל מובחן; foot קשיח עם סוליה שטוחה. weights מנורמלים, עד שתי עצמות לקודקוד, ללא scale מונפש. כיוון quaternion מקומי ביחס ל-bind pose, לא Euler מרחבי.

Socket וירטואלי ב-hand.R/hand.L לכדור או מקלות; socket בכף רגל למגלש. אביזר נפרד אינו עצם נוספת. ציר פיזיקה והכדור אינם ילדים של השלד; socket רק יעד חזותי כשהסימולציה מאשרת החזקה. חומר ווריאנטים מחליף חולצה/חליפה, לא רשת לכל צבע. בסקי לנעול מגף למגלש בלי חדירת סוליה לשלג. בשאר המשחקים IK קצר לרגל תומכת דרך מתאם תצוגה, לא שינוי מיקום סימולציה.

## קליפים ופריימי מפתח

השמות, האורכים והאירועים המחייבים נמצאים ב-../animations.json. קצב יצירה 24fps; לאפות לרוטציות quaternion, להסיר keys מיותרים בסבילות 0.5°. כל קליפ in-place ללא תזוזת root. run: מגע שמאל ב-0, ימין ב-0.36, אותו pose ב-0.72; האטה: 0 / 0.14 / 0.28 / 0.42; סיבוב: 0 / 0.12 / 0.24 / 0.36. גוף נוטה לתוך פנייה; הנעל התומכת אינה מסתובבת במקום לפני העברת משקל.

ריצה במגפי סקי לתפריט בלבד, לא בזמן ירידה. בתנועה: glide בכריעה, האטה ב-snowplough עם ברכיים כפופות, פנייה בהטיה מאגן וקרסוליים עד 28°. pole_push הוא חלופת פעולת בעיטה/זריקה: דחיפת מקלות, בלי להוסיף ירי לסקי. land היא קליטה של נחיתה: מגע שני מגלשיים וכיפוף ברכיים. fall: גלישה קצרה על הצד, מקלות נשארים בחיבור ליד, ללא מכה אלימה. אין אנימציה שיכולה לבטל התנגשות.

fall: אובדן שיווי משקל ב-0.12, ירידת אגן ב-0.35, מגע צד הגוף ב-0.6, מנוחה ב-0.85. recover: יד וברך תומכות עד 0.45, הרמת אגן עד 0.8, עמידה ב-1.1. אין עיוות מפרקים או ראש ברצפה. celebrate: הכנה 0.2, ידיים למעלה 0.7, החזרת משקל עד 1.8; קליפ חד־פעמי שניתן לדילוג.

## מרקמים ותקציב

אין צורך במרקם לדמות: להשתמש ב-vertex colors או חומרי צבע אחיד. אם נדרש atlas: 256×256 PNG/WebP אחד, ≤35,000 bytes, ללא כיתוב; 512×512 הוא גבול מוחלט לכל תמונה. חומרי roughness קבועים; לא לכלול 1K/2K מהמאגר הישן.

| קבוצה | תקרת bytes למשחק |
| --- | ---: |
| שתי דמויות, כולל קליפים ו-atlas מוטבע | 300,000 |
| משטח, זירה ואביזרים | 600,000 |
| מרקמי סביבה, כל אחד עד 512px | 450,000 |
| אייקונים, HUD ואפקטים | 100,000 |
| יתרת ביטחון | 550,000 |
| סה״כ | 2,000,000 |

כל GLB עתידי ≤150,000 bytes לדמות **כולל** כל הקליפים והמרקמים המוטבעים; חומרי צבע לוריאנטים אינם עותק GLB. להשתמש ב-glTF 2.0 עם quantization ודילול מפתחות תחילה; אם נדרשת דחיסת mesh, לוודא decoder מקומי קיים ותואם לפני שימוש. אין להוסיף Draco/Meshopt מהאינטרנט בזמן ריצה. אם לא נכנסים לתקציב: להוריד LOD/atlas, לא להשמיט ברכיים או קליפים נדרשים. בספירת 2MB לכלול גם קבצים חיצוניים ו-decoder חדש אם יתווסף; Three.js הקיים המשותף אינו נכס חדש למשחק.

## אימות ייצוא עתידי

- לפתוח GLB ב-loader המקומי, לבדוק שכל השמות ב-animations.json זמינים ואין תלות חיצונית.
- לדגום קליפים ב-0%, 25%, 50%, 75%, 100%: חדירת רצפה עד 1 ס״מ, תזוזת רגל תומכת עד 2 ס״מ, אין חדירת כדור ליד או ברכיים דרך הבגד.
- לבדוק טקסטורה ≤512, משקל אמיתי בקובץ (לא gzip משוער), מונה משולשים וחומרים, clone עם שלד עצמאי, ושחרור משאבים.
- עד להשלמת הייצוא זהו מפרט בלבד; אין להפנות loader אל קובץ GLB שאינו קיים בחבילה.
