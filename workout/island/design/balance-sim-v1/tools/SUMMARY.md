# הפקת טבלאות וגרפים

הסטטיסטיקה וקובץ הטבלאות דורשים Node.js בלבד. הגרפים מופקים ב־Python 3 באמצעות Matplotlib; הגרסה ששימשה בחבילה היא `3.10.8`, והיא מוצמדת ב־`requirements-charts.txt`. הגופנים מוטמעים בקובצי SVG, ללא קבצים חיצוניים.

מתיקיית הריפו, לאחר סיום הרצות הבסיס:

```sh
node workout/island/design/balance-sim-v1/tools/summarize.mjs
```

התוצאה: `data/summary.json`, טבלה לכל שלב ב־`TABLES.md` ועשרה גרפי SVG בתיקיית `charts/`. אפשר להריץ את אותה פקודה בזמן שהסימולציות נמשכות; תאים חסרים נשארים `null` והכיסוי מסומן חלקי. לפני הפקת הדוח הסופי מריצים שוב, לאחר שכל העובדים סיימו לכתוב נתונים.

אם Matplotlib אינו מותקן, אפשר להתקין אותו בסביבה מבודדת דרך קובץ הדרישות. להפקת נתונים וטבלאות ללא Python:

```sh
node workout/island/design/balance-sim-v1/tools/summarize.mjs --no-charts
```

לקריאת הרצה אחרת, שומרים את תוצרי הסיכום בנפרד; נתיבי הפלט מוגבלים לחבילה זו או ל־`/tmp`:

```sh
node workout/island/design/balance-sim-v1/tools/summarize.mjs --data /tmp/balance-data --output /tmp/balance-summary/summary.json --tables /tmp/balance-summary/TABLES.md --charts /tmp/balance-summary/charts
```

הקומיט נלקח מ־`source-manifest.json`; בהיעדרו נדרש קומיט אחיד בכל נתוני הבסיס. ערבוב קומיטים או טביעות מקור נדחה. `--expected-commit` מאפשר לדרוש במפורש קומיט מלא, לרבות המקור `43b27dc235387e3cb737aee9558cdf9d5fd5a262` ששימש בחבילה זו.

ספי הכיסוי: 8 ניסיונות לתא במרוצים ובחזירים, 16 בכדורגל ו־32 בשאר המשחקים. תאים עם ניסיונות נוספים נשמרים במלואם; גודל המדגם ורווח הסמך מוצגים לכל תא. `--samples N` משנה רק את סף הכיסוי של הסיכום, ואינו מריץ או מוסיף סימולציות.

רווחי הסמך הם Wilson דו־צדדיים של 95%. חציון ואחוזון 90 מחושבים באינטרפולציה ליניארית במיקום `(n−1)p`. קפיצה מועמדת היא ירידה של לפחות 25 נקודות אחוז בין שלבים עוקבים באותו פרופיל. מבחן McNemar המדויק משתמש רק בזרעים משותפים; תיקון Holm כולל **את כל** זוגות השלבים הניתנים לבדיקה, בכל הפרופילים בתוך אותו משחק, ולא רק זוגות שעברו את סף הירידה. גבולות בין מצבי משחק מסומנים בנפרד.

השלמת יעד נקבעת רק משדה בוליאני מפורש; מונים מספריים אינם הופכים ליעדים. `0/n` הוא חוסר השגה במדגם, עם גבול עליון של Wilson, ואינו הוכחת אי־אפשרות. כוכבי ליגת המרוצים אינם מוגדרים בחוזה התוצאה ולכן מושמטים, במקום להציג את ערך האפס הפנימי ככישלון.

התוצרים אינם כוללים חותמת זמן, מזהים אקראיים או זמני ביצוע של המחשב. אותה ראיה ואותה גרסת Matplotlib מפיקות שוב אותם קבצים.
