# סבב 03 · עמידת השומר ותקציב החווה

16 צילומי סביבה ו־22 צילומי נכסים. עמידת ההמתנה ישרה ונינוחה יותר, עם נשימה ותנועת ראש קלה; הכותרת בחלל קריאה. הקהל הוחלף בגאומטריה זעירה ונוספה רמת פירוט אמיתית לשומרים עם אותם שלד ותנועות.

| ממצא | תוצאה | פעולה הבאה |
|---|---|---|
| חווה מרחוק | ירידה מ־137,620 ל־82,553 משולשים, אותם 46 draw calls | להוסיף LOD למקבצי גדרות ודקלים |
| חווה קרוב לרוחב | 107,651 משולשים; שלושת השומרים מתקרבים ל־LOD הגבוה | מעבר מפורט רק כשדמות גדולה מספיק במסך |
| שומרים | מ־14.6–16.4K ל־4.4–4.9K ב־LOD1 | להשוות פנים/צללית ולבדוק מעבר |
| קריאות החזירים | שני הבוגרים ברורים; הגור מוסתר חלקית בפריים החווה הקרוב | להזיז את הגור לאזור פתוח |
| אטלסים | תמונות 1024² זולות בהורדה אך יקרות בזיכרון; LOD כפול | 512² ושיתוף מפה בין רמות של אותה דמות |
| צבעי קודקודים → אטלס | אינטרפולציה בין משבצות שונות עלולה לדגום צבע זר | UV קבוע לכל משולש, בלי איבוד משקלי שלד |

C01–C03, C05–C07 ו־C09: 8. C04: 6 (חסר גיליון אפקטים). C08: 7. C10: 9. C11: 7 (המבט הקרוב לרוחב עוד חורג מתקציב 90K שהוגדר בסבב 02). C12: 8. C13: 5. C14: 4.

ממשיכים לסבב 04: להוריד גם את המבט הקרוב מ־90K, לשפר דיוק אטלס וזיכרון, ולהציג את הגור באופן ברור.
