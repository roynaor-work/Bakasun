# הגנת האי · v7

[תצוגה עצמאית ללא רשת](offline.html) · [השוואת סבבים ותמונות](review.html) · [דוח וביקורת](REPORT.md) · [משקלי המודלים](BUDGET.md) · [manifest לשילוב](manifest.json) · [מקורות ורישיונות](LICENSES.md)

[ציונים לכל נכס ואפקט](ASSET-REVIEW.md) משלימים את ציוני דרישות הפלטפורמה בדוח.

חבילת אמנות תלת־ממדית עם חמש ספינות חייזרים ובוס נפרד, מטוס מגן, שלושה חזירי בר, שלוש דמויות שמירה בדיוניות, חווה מודולרית, דקלים, כוכבי לכת, עננים ואפקטים. השפה מבוססת על האי הקיים: קרם, טורקיז, קורל, צורות מעוגלות וחומרים מחוספסים.

1. פותחים את `offline.html` בדפדפן. הוא מכיל את Three r160, מפענח Draco, כל המודלים, הפריסות והאפקטים. אין צורך בהתקנה, build, CDN או חיבור אינטרנט.
2. בוחרים „משמר השמיים” או „החווה השקטה”; מחליפים יום/לילה וקרוב/רחוק. גוררים לסיבוב, צובטים לקירוב או משתמשים בגלגלת. הכפתור „הנכסים” פותח קטלוג לבחינת כל דמות וכלי טיס בנפרד.
3. מפעילים „גל הלם” בחלל ו„פעמון” בחווה. כפתור התנועה עוצר ומפעיל. „מדדים” מציג את המדידה בדפדפן ופרופיל תצוגה לביקורת. התוצאה הרצויה: שלוש חיות שונות, שש צלליות אויב, פקדים בתוך המסך ונכסים קריאים בשתי האוריינטציות.

אם הדפדפן חוסם קבצים מקומיים, מגישים את התיקייה בשרת מקומי, ואז פותחים את התצוגה. משורש המאגר:

```sh
python3 workout/island/design/defense-v7/source/serve.py --port 8765
```

[פתיחת התצוגה בשרת המקומי](http://127.0.0.1:8765/preview.html). השרת מקשיב רק למחשב המקומי. הוא אינו נדרש לגרסה העצמאית בדפדפן שמאפשר פתיחת HTML.

הדפדפן המנוהל בסביבת הפיתוח חוסם `file://` ברמת מנהל. תוכן `offline.html` נבדק ממנו ישירות לדף ריק, עם offline ו־CSP פעילים, ואפס בקשות HTTP/HTTPS. אין כאן טענה שבוצעה פתיחה ישירה מקובץ בטלפון פיזי.

החבילה מוסיפה קבצים בתיקייה זו בלבד. היא מיועדת לשילוב נפרד; אין שינוי במשחקים, ב־release או בתגי גרסה.
