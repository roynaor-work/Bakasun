# מקורות ורישיונות

| תוכן | מקור | רישיון / הערה |
|---|---|---|
| חמש ספינות, בוס, מטוס, חזירי בר, חווה, אביזרים וסביבה | גאומטריה מקורית ב־`source/build-assets.mjs`, `mesh.mjs`, `build-environment.mjs` | CC0-1.0 ליצירה המקורית בחבילה |
| צוות השמירה | דמויות בדיוניות מגאומטריית `../soccer-v5/models/teal-{quiff,curls,knot}.glb`, עם מדי שדה, כובע, אפוד, צבע ותנועה חדשים | מקור מקומי CC0-1.0; ראו גם `../soccer-v5/LICENSES.md`, `../characters2/LICENSES.md` |
| שלד ותנועה | שמות/היררכיה מ־`../motion2/soccer.json`; bind מכויל של v5; המתנה והתרעה מקוריות, סיור מתוך הריצה הקיימת | CC0-1.0 לפי רישיונות חבילות המקור; אין motion capture של אדם אמיתי |
| אטלסי צבע ו־VFX | יצירה פרוצדורלית מקורית, ללא מקור חיצוני או צילום | CC0-1.0 |
| קוד המציג, תיעוד, כלי הבנייה והבדיקה | יצירה מקורית לחבילה | CC0-1.0 |
| `references/` | העתקי צילומים ואיור שכבר בריפו, לצורך השוואת סגנון | תיעוד המאגר; אינם תמונות חדשות של אדם או מותג |
| `vendor/three.module.js`, loaders, helpers | העתק מקומי של `workout/island/vendor/` | three.js r160, MIT; הודעה מלאה ב־`vendor/LICENSE.three` |
| `vendor/draco/` | מפענח מקומי שהועתק מן המאגר | Draco, Apache-2.0; הודעת הרישיון בתיקיית המפענח |

כל הדמויות והציוד בדיוניים. אין שימוש בפנים או בזהות של אדם אמיתי, סמלי מועדונים, מותגי מוצר, נתוני לקוחות, מפתחות גישה או מספרי טלפון.

הכלים glTF Transform ‏4.2.1, ‏draco3dgltf ‏1.5.7, ‏Meshoptimizer ‏0.24.0, ‏glTF Validator ‏2.0.0-dev.3.10 ו־esbuild ‏0.25.12 משמשים רק ליצירה ובדיקה. Blender ‏4.3.2, ‏Pillow ו־Playwright משמשים לבדיקת נכסים ורינדור. אין בהם צורך כדי להשתמש ב־`offline.html` או בנכסי GLB.

הקדשת היצירה המקורית לנחלת הכלל: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). רישיונות הספריות נשארים כפי שנמסרו במקור.
