# סגל 07 · תצוגה מקומית

חבילת דמויות כדורגל בדיוניות: שישה שחקני שדה בשתי ערכות צבע, שוער ושופט. הקבצים ותיעוד הביקורת נמצאים בתיקייה זו בלבד. גלריית כל סבבי הצילום נמצאת ב־[gallery.html](gallery.html). מצב האיכות, ציונים, משקלים ותוצאות הבדיקות הסופיות מתועדים ב־[REPORT.md](REPORT.md).

## פתיחת התצוגה

1. שומרים את כל התיקייה עם מבנה תתי־התיקיות שלה ופותחים את [preview.html](preview.html) בדפדפן עם WebGL ו־WebAssembly. אין צורך ב־npm או בבנייה. הקוד, three.js r160, מפענח Draco וכל נכסי התצוגה מקומיים; אין שימוש ב־CDN, פונטים מרוחקים או שירות רשת.
2. בוחרים דמות ותנועה. בתפריט המבט בוחרים גוף, פנים, בד או מגרש. גרירה מסובבת, צביטה/גלילה מקרבות ומרחיקות. מקש רווח מנגן ומשהה; כשהקנבס ממוקד, החצים מסובבים ו־`+`/`-` משנים מרחק.
3. פותחים את כלי התצוגה כדי לבחור תאורה ו־LOD, או לראות שלד ורשת. סליידר הזמן מאפשר לעצור בכל פוזה. כפתור הכלים מסתיר את לוח הבחירה ומגדיל את הבמה.

ב־Chromium המנוהל של סביבת העבודה, ניווט `file://` חסום במדיניות מנהל. בדיקות הדפדפן נערכו בשרת מקומי בלבד תוך חסימה של כל בקשת אינטרנט. הקוד משתמש בסקריפטים רגילים ובנתוני WASM/GLB מוטמעים ואינו צריך בקשות HTTP לנכסים או לשירות חיצוני; פתיחה ישירה בדפדפן חופשי ממדיניות זו דורשת אימות נפרד.

להעתקת הצופה בלבד מספיקים `preview.html`, ‏`preview.css`, ‏`vendor/` ו־`offline/`; לחלופת השרת מוסיפים גם `source/serve.py`. המודלים הגולמיים נמסרים בנפרד ב־`models/`, ואילו התמונות, הסרטונים ודוחות הביקורת אינם נטענים בצופה. אין צורך להעתיק את ארכיון הביקורת הגדול לטלפון לצורך הפעלת התצוגה.

אם הדפדפן חוסם פתיחת קובץ מקומי, מפעילים את השרת האופציונלי באמצעות Python רגיל:

```sh
python3 workout/island/design/soccer-v7/characters/source/serve.py
```

לאחר ההפעלה פותחים [את התצוגה המקומית](http://127.0.0.1:8765/preview.html). השרת מאזין ל־localhost בלבד; אין חיבור לאינטרנט.

## מבנה החבילה

| נתיב | תפקיד |
| --- | --- |
| `models/` | 16 קובצי Draco GLB: שתי רמות פירוט לכל דמות, שלד 18 עצמות ו־31 אנימציות מוטמעות בכל קובץ. |
| `textures/` | אטלס 1024 אחד לכל זהות, עם מפות צבע, normal ו־ORM באותה פריסת UV. |
| `animations.json` | נתוני 30Hz, תמיכות ומגעים, מסלול ייחוס וסמני פעולה. |
| `rig.json` | שלד קנוני, יחידות מטר, +Y למעלה ו־+Z קדימה. |
| `preview.html`, `preview.css`, `vendor/`, `offline/` | התצוגה המקומית ועותקי הנתונים שלה לטעינה ללא בקשות HTTP לנכסים. |
| `iterations/NN/` | צילומי הטלפון, חתימות קלט וביקורת עצמית לכל סבב. |
| `verification/` | אימותי תוכן GLB, מעטפת רצפה, מעברים, ביצועים וחבילה מקומית. |
| `source/` | מחוללי הנכסים, כלי האריזה ואמצעי הביקורת. אלה כלי הכנה; הדפדפן אינו צריך אותם. |

התנועות עוצבו וחושבו בסגנון תנועת ספורט; אינן הקלטות motion capture. שימוש במסלולי הייחוס וב־IK מתועד ב־[RUNTIME.md](RUNTIME.md). התוצאה המופיעה בצילומים היא הקובעת בביקורת חזותית.
