# לחיצה ממשית על ציר הזמן — כשל גרסת הביניים

הבדיקה נערכה בחבילת סבב 34, בלי שינוי ערך דרך API. לחיצה מהימנה של הדפדפן במרכז פקד הטווח יצרה אירוע input עם ערך 0.5. אחרי הטיפול באירוע נמדדו שוב ערך 0 וזמן 0. התמונה, האירוע, מצב הצופה וחתימות שלושת קובצי הקלט נשמרו לצד מסמך זה.

מקור הכשל הוא סדר הפעולות במאזין: `setPlaying(false)` מרענן את הממשק ומחליף את ערך הפקד בזמן הישן, לפני שהקריאה `seek(Number(e.target.value))` קוראת אותו. התיקון הנדרש הוא שמירת ערך הבחירה במשתנה לפני ההשהיה.

זהו תיעוד כשל, לא אישור לתיקון. כלי הבדיקה `source/audit-ui.mjs` יבדוק שוב לחיצה ממשית באותה נקודה בחבילה המשולבת, לצד בחירת דמות, תנועה, תאורה ו־LOD, פקדי הניגון, מקלדת וגרירה. אין כאן מדידת מגע בטלפון פיזי או ביצועי GPU.

ניסוי תיקון מבודד החליף רק את המאזין המקופל בתוך עותק RAM של runtime סבב 34. לחיצה על 0.5 בקליפ באורך 1.2 שניות הציגה 0.6 שניות, וכל תשע קבוצות בדיקות הממשק עברו. `fixed-ui-only-probe.json` שומר את חתימת הבתים שהוגשו בפועל ומסומן `complete: false`; זה אינו אישור לחבילה המשולבת. הקבצים הראשיים לא שונו בניסוי.
