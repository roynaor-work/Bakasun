# ביקורת תמיכת כפות הידיים

שלושה פריימים בזמנים 0.5, 0.6 ו־0.666667 שניות בקליפ `get_up`, מתוך חבילת הסגל 09 בפועל, ב־390×844. שינוי שיפוע כפות הידיים מ־‎−90° ל־‎−100° מרים את האצבעות ומקרב את בסיס כף היד לרצפה, בלי להגביה את הגוף כולו ובלי לשנות את מנח הרגליים.

הידיים נראות נמוכות ותומכות; אין ריחוף של הגוף או חדירה נראית בפריימים האלה. מינימום העור המדווח בתצוגה הוא כ־2 מ״מ, ללא הגבהת שורש. סריקת עור עצמאית נפרדת מדדה את אזור כפות הידיים בכ־3.1–3.3 מ״מ מעל הרצפה בנכס שנבדק. `capture.json` שומר את זמני הפריימים ואת מצב התצוגה בפועל; `../motion-skin-support-review.json` שומר את המודל המדויק והמדידה העצמאית.

זהו אימות חזותי של נקודות תמיכה נבחרות; הוא אינו סימולציית לחץ או הוכחה למגע דינמי בכל הדמויות והפריימים.
