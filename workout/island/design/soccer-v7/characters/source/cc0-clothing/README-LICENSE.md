# MakeHuman system clothing asset license evidence

The two original `male_casualsuit06` source files are preserved byte-for-byte, including historical AGPLv3 headers. The current asset distribution license is CC0; the historical program-code notice was not silently removed or rewritten.

Evidence checked on 2026-11-04:

- [Official asset-pack entry](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html) explicitly lists `male_casualsuit06` as `CC0`. A local copy of the official source declaration is [official-system-assets.md](official-system-assets.md), copied from the repository's existing v6 provenance evidence.
- [Official 2020 license-change clarification](https://static.makehumancommunity.org/oldsite/faq/what_changed_regarding_the_license_in_2020.html) explains that the former AGPL default changed to CC0 and acknowledges older AGPL notices remaining in asset files.
- [Current upstream license](https://github.com/makehumancommunity/makehuman/blob/master/makehuman/license.txt) lists the asset data, including MHCLO files, under CC0.
- [CC0 1.0 Universal text](LICENSE.ASSETS.md) is included locally.

The OBJ and MHCLO were fetched from the [MakeHuman data mirror](https://github.com/dmaugis/makehuman-py3-assets/tree/master/base/clothes/male_casualsuit06). Their original notices and file hashes are recorded in [the v7 provenance document](../character-provenance.md). Only these asset data files are reused. No MakeHuman program code or source garment texture is bundled in this folder.
