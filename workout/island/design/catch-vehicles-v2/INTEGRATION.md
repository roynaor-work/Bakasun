# חיבור רכבים

כל אחד מ־14 קובצי המודל הוא GLB עצמאי, ללא טקסטורות, קבצים חיצוניים או הרחבות נדרשות. נתיבי הקבצים, גדלים, חתימות, צבעים, חלקים, גלגלים ושמות אנימציות רשומים במניפסט.

## פתיחה

1. מהתיקייה הזו הפעילו שרת קבצים:

   ```bash
   python3 -m http.server 8765
   ```

2. פתחו את [התצוגה האינטראקטיבית](http://localhost:8765/preview.html), את [כל הצי](http://localhost:8765/gallery.html) או את [השוואת הנזק](http://localhost:8765/gallery.html?states=police-sedan).
3. בחרו רכב וצבע; גררו לסיבוב, הפעילו גלגלים, פנסים ועשן, החליפו מצב נזק ובחרו גלגל לפיצוץ. איפוס מתקן את הרכב ואת הצמיגים ומחזיר את זווית המצלמה.

אין שלב בנייה לתצוגה ואין בקשות CDN. נדרש שרת HTTP בגלל טעינת המודלים והמודולים; פתיחה ישירה בפרוטוקול קובץ מקומי אינה נתמכת.

## שימוש בבקר

```js
import { loadVehicle } from './vehicle-controller.mjs';

const manifest = await (await fetch('./manifest.json')).json();
const meta = manifest.assets.find(a => a.id === 'police-sedan');
const vehicle = await loadVehicle(meta);
scene.add(vehicle.root);

vehicle.setColor('#de6949');
vehicle.setDamage('damaged');
vehicle.setLights(true);
vehicle.setEngineSmoke(true);
vehicle.burstTire('FL');

// פעם בכל פריים: שניות, מטרים לשנייה, זווית היגוי ברדיאנים.
vehicle.update(dt, speedMetresPerSecond, steerRadians);

// בסיום השימוש:
vehicle.dispose();
```

הבקר צורך תוצאת טעינה חדשה ומחזיק בבעלות על הגאומטריה והחומרים שלה. לא משתפים את אותה תוצאת טעינה בין שני בקרים. `createVehicleController(gltf, meta, options)` זמין אם הטעינה נעשית במקום אחר. אפשר להעביר `{effects:false}` כדי לוותר על הקצאת חלקיקי עשן ושברי גומי, למשל בגלריה. טעינת הבקר הרגילה משתמשת ב־Three.js r160 המקומי שבחבילה.

## צירים וצמתים

| תכונה | ערך |
|---|---|
| יחידה וכיוון | מטרים; למעלה `+Y`, קדימה `+Z`, ימין `+X` |
| ראשית | על הקרקע במרכז הרכב |
| סיבוב גלגל | סביב `+X`, זווית = מרחק / רדיוס |
| היגוי | סביב `+Y`, רק בצמתים קדמיים |
| מזהי גלגלי מכונית | `FL`, `FR`, `RL`, `RR`; שמאל הוא `-X` |
| מזהי גלגלי אופנוע | `F`, `R` |
| גלגל חלופי בג׳יפים | `spare`; אינו משתתף בגלגול ובפיצוץ |
| שמות צמתים | `{state}__{partId}`; למשל `intact__wheel_FL_spin` |
| מפתח יציב | `node.extras.partId`, או `object.userData.partId` ב־Three.js |
| עוגן עשן | `fx_engine_smoke`, כיוון הפליטה `+Y` |

לכל גלגל שרשרת נפרדת: צומת היגוי במרכז הציר, מתחתיו צומת גלגול, ומתחתיו צמיג וחישוק. במניפסט רשומים המרכז, הרדיוס והרוחב. חלקי המרכב כוללים, לפי הדגם, גוף, תא נוסעים, דלתות, מכסה מנוע או מכל, פגושים, שמשות, מנוע, מושב, ארגזים, מראות ופנסים. אפשר לקבל חלק דרך `vehicle.scenes.get(state).parts.get(partId)`.

## מצבי נזק ואנימציות

בכל קובץ שלוש סצנות glTF אמיתיות. הראשונה היא ברירת המחדל:

| מצב | אינדקס סצנה | משקלי נזק בחלקים |
|---|---:|---|
| `intact` | 0 | `[0, 0]` |
| `damaged` | 1 | `[1, 0]` |
| `crushed` | 2 | `[0, 1]` |

הסצנות משתמשות באותן רשתות. בכל חלק מרכב שני יעדי מורף בעלי צורה ונורמלים מחושבים, ובמצבי הנזק חלקים מסוימים מקבלים גם סיבוב או תזוזה נפרדים. אין כאן שלוש מכוניות המצוירות יחד. הבקר מציג סצנה אחת ושומר על זווית הגלגלים והצמיגים המפוצצים במעבר בין מצבים.

| אנימציה בקובץ | פעולה |
|---|---|
| `wheels_roll` | סיבוב מלא בשנייה; כל הגלגלים בכל המצבים |
| `tire_burst_<wheel>` | קריסת צמיג מסוים בתוך 120 מילישניות |
| `beacons_flash` | בניידות בלבד: שני הבהובים אדומים ושני כחולים, במחזור 0.8 שנייה |

ההבהוב המובנה משתמש בקנה מידה של שכבת אור נפרדת, באינטרפולציית מדרגה של glTF; עדשת הפנס נשארת במקום. הפנסים משתמשים בחומרים מאירים. אין הרחבת אנימציית חומרים או צורך במפענח דחיסה.

כדי לנגן את הקליפים ב־Three.js, צרו מערבל על `vehicle.root`, שמכיל את שלוש הסצנות; הקליפים מקשרים צמתים משלושת המצבים. הקליפים זמינים ב־`vehicle.animations`. ניגון על הסצנה הראשונה בלבד אינו מכסה את צומתי המצבים האחרים. הבקר כבר מנהל גלגול והבהוב, לכן בחרו מנגנון אנימציה אחד לכל תכונה. אין להריץ מערבל והבקר על אותו גלגל בו־זמנית.

## אפקטים וניקוי

פיצוץ צמיג מפעיל את יעד המורף שלו ומשגר 16 שברי גומי ממאגר קבוע. עשן המנוע משתמש ב־24 חלקיקים במאגר קבוע ובמרקם שנוצר מקומית בזיכרון. אלה אפקטי ריצה של הבקר; glTF כולל את צורת הצמיג, הקליפ והעוגן, ואינו מגדיר מערכת חלקיקים.

`repairTires()` מתקן את כל הצמיגים; `reset()` מחזיר מצב שלם, מכבה עשן, מאפס גלגלים ומדליק פנסים. הצבע נשמר באיפוס. `setEngineSmoke()` ו־`setDamage()` עצמאיים בבקר; התצוגה מפעילה עשן אוטומטית במעבר למצב פגוע או מעוך. `inspect()` מספק מצב נוכחי לצורכי חיבור ובדיקה.

`dispose()` משחרר את הגאומטריה, החומרים, מרקם העשן והחלקיקים ומסיר את הרכב מהסצנה. החבילה מדגימה אפקטי נזק; היא אינה מוסיפה מערכת התנגשות, מתלים או לוגיקת משחק. רצפת הגלגל המשונן עשויה להשתנות מעט בזמן גלגול בגלל מספר המצולעים הנמוך. בדיקת הביצועים כאן נעשתה בדפדפן עם SwiftShader, ללא מדידת טלפון פיזי.
