# מקורות ורישיונות

16 האוהדים הם דמויות בדויות. הגאומטריה, המראות, הפנים, השיער, הבגדים, האטלסים והאנימציות נמסרים תחת [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/). אין תצלומים, סריקות, דמות של אדם אמיתי, לוגואים, ספונסרים, מותגים או סמלים של קבוצות אמיתיות. צבעי החולצות והצעיפים הם שילובים מקוריים.

| רכיב | מקור | רישיון |
|---|---|---|
| חתכי הראש: לסת, לחיים וגולגולת | דגימה מחודשת של `rows` ב־[`../characters2/source/head_hands.py`](../characters2/source/head_hands.py), פונקציה `_face` | CC0-1.0 לפי [רישיון המקור](../characters2/LICENSES.md) |
| חתכי מותן וכתפיים | דגימה מחודשת של `torso` ב־[`../characters2/source/body.py`](../characters2/source/body.py), פונקציה `add_body` | CC0-1.0 |
| שמות וסדר 18 העצמות | [`../tennis-v7/rig.json`](../tennis-v7/rig.json); מיקומי מפרקים, אורכי גפיים ו־inverse binds מחושבים מחדש לכל אוהד | CC0-1.0 לפי [רישיון הטניס](../tennis-v7/LICENSES.md) |
| טופולוגיות 210/90/24, מבני גוף, פרטי לבוש, אף, אוזניים, כובעים וצעיפים | `source/geometry.py` | CC0-1.0 |
| אטלסים של פנים ובדים, צבעים ו־48 קובצי GLB | `source/build.py`; יצירה מקומית, ללא שירות יצירת תמונות | CC0-1.0 |
| שבע תנועות מחזוריות ו־IK לכפות הידיים | `source/motions.py`; keyframing מקורי, ללא motion capture או קליפים מסחריים | CC0-1.0 |
| תצוגה, תיעוד, קוד המקור ותצלומי המסך | הקבצים בתיקייה זו | CC0-1.0 |
| Three.js r160, GLTFLoader, SkeletonUtils, BufferGeometryUtils | עותקים מקומיים ללא שינוי מתוך `../../vendor/`; נדרשים לתצוגה בלבד | MIT, הנוסח המלא ב־[`vendor/LICENSE.three`](vendor/LICENSE.three) |

| NumPy / Pillow / Playwright | כלי כתיבה ובדיקה בלבד, אינם מופצים בחבילה | BSD-3-Clause / HPND / Apache-2.0 |

מקורות האנטומיה נקראים באמצעות AST; קובצי המקור הקיימים אינם מופעלים או נכתבים. טביעות SHA-256 של המקורות ושל כל GLB מופיעות ב־`manifest.json`. השימוש ב־Blender ובמפענח Draco אינו נדרש.

למען הסר ספק: יוצר התוספות המקוריות בחבילה זו מוותר, ככל שהדין מאפשר, על זכויות היוצרים והזכויות הנלוות בהן לפי CC0-1.0. רישיונות צד שלישי נשארים בתוקף ואינם משתנים.
