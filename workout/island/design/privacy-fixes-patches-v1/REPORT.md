ענף מסירה `codex/privacy-fixes-patches-v1`. החבילה נבדקה מול תמונת `main` בקומיט `9e95482fbe1887856cbca69fd43c1c77ba62cff4`. מזהי הממצאים ומיקומיהם מבוססים על `workout/island/design/privacy-audit-v1/` בענף `codex/privacy-audit-v1` בקומיט `a39853bcba527553a92547630a873086f476b2b5`.

## בדיקה והחלה על עותק נקי

מריצים משורש checkout של ענף המסירה. `--check` מאמת את העץ באינדקס זמני. `--apply` מכין את השינויים ב־index ובתיקיית העבודה של עותק היעד. היעד חייב להיות checkout מלא ונקי בקומיט הבסיס, כולל היעדר קבצים מקומיים נוספים. בשתי הפעולות `HEAD` נשאר על קומיט הבסיס.

```sh
bundle="$PWD/workout/island/design/privacy-fixes-patches-v1"
git worktree add --detach ../bakasun-privacy-test 9e95482fbe1887856cbca69fd43c1c77ba62cff4
"$bundle/apply.sh" --check ../bakasun-privacy-test
"$bundle/apply.sh" --apply ../bakasun-privacy-test
cd ../bakasun-privacy-test
git diff --cached --name-status --no-renames
python3 "$bundle/tests/verify-tree.py"
node --test "$bundle/tests/privacy-controls.test.mjs"
python3 "$bundle/tests/browser-smoke.py"
```

`python3`, Git ו־Node 22 ומעלה נדרשים לבדיקות. בדיקת הדפדפן משתמשת ב־Playwright וב־Chromium. להצגת השינויים לצורכי סקירה יש להשתמש בשמות הנתיבים בלבד. דיפ רגיל של ההסרות מציג תוכן מהבסיס.

## תוצאות אימות

- בדיקת `--check` והחלה עברו בעותק נקי. השינויים המוצעים כוללים 4,736 נתיבים, ובהם 4,551 קובצי ראיות וארכיונים להסרה. ניסיון החלה חוזרת מול עותק ששונה נדחה. `git diff --cached --check` עבר.
- 523 בדיקות Node ממוקדות עברו. הן כוללות מפתח והסכמה נפרדים לכל אפליקציה, חסימת יעד והפניה, תוקף וביטול הסכמה, עבודה עם תור סינתטי, מטמון, דיבור, הגדרות וקלט עסקי סינתטי.
- בדיקת העץ אימתה את מיקומי ההשחרה וזיהתה 3,034 קובצי runtime בתוצר Pages ללא תיקיות ראיות. בדיקת Chromium על אותו תוצר אימתה טעינת אפליקציות, הגדרות CSP וניקוי קישור מצלמה ליעד שאינו מאושר בלי בקשת POST.
- בסוויטה המלאה על קומיט הבסיס, `tests/workout-royiki.test.mjs` נכשל והחזיק את התהליך פתוח. תוצאות ההחלה לעיל הן מהבדיקות הממוקדות. בדיקות המדיה הידניות הישנות ב־`tests/e2e/` מניחות חוזה הפניה ותור משותף. החוזה המעודכן נבדק עם מדיה מדומה בתור ועם טעינת דפים ב־Chromium.
- הסריקה בדקה את הערכים שניתן היה לגזור ממיקומי הביקורת ואת מלאי הנתיבים. כיסוי ראיות חזותיות והיסטוריה דורש סקירה נפרדת.

## תנאים להפצה ושאר ממצאי הביקורת

- רשימת יעדי המצלמה הריקה משאירה העלאה כבויה בשני היישומים. להפעלה מחדש יש לאשר יעד HTTPS מדויק שמחזיר JSON ישירות, לעדכן את `connect-src` בדפים המתאימים, ולתאם רענון גרסת הלקוחות וה־workers. יש לוודא שהסכמה קודמת ותור ישן נשארים מחוץ לזרימת ההעלאה המעודכנת.
- יש לאמת עותק פרטי מורשה של ראיות שבעליהן צריכים לשמר. פרטי העסק חוזרים דרך הגדרות מורשות בזמן ההפצה. פרטי החנות וערוץ הביטולים דורשים תוכן שאושר לפרסום. קובצי ה־SQL המוצעים מחייבים הגדרה פרטית של ההרשאות בידי מפעיל מורשה.
- **PA-005, PA-006, PA-007, PA-008, PA-015** דורשים עבודה בשרת במאגר בדיקה, סביב זהות משפחה, ביטול הרשאה, מחיקה מורשית, מכסות ושחזור מדיניות Storage. החבילה הנוכחית עוסקת בקוד ובתוצר הפרסום המקומי.
- **PA-010, PA-016, PA-017, PA-018** נשארים פתוחים סביב מטמון האי, תלויות בנייה, הרשאת הורה וייצוא טלמטריה.
- ניקוי ענפים, תגים והיסטוריה מותנה בהחלטה נפרדת לפי [HISTORY-CLEANUP-PLAN.md](HISTORY-CLEANUP-PLAN.md).
