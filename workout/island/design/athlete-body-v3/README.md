# גוף אתלט v3

גוף שחקן חדש לכדורגל ולכדורסל, על אותו שלד קנוני של 18 עצמות כמו v22 ו-v2. כל הקליפים והפוזות הקיימים מתנגנים בלי שינוי, דרך אותה מפת זהות.

## מה השתנה, בקצרה

| | לפני (v22 / v2) | אחרי (v3) |
|---|---|---|
| פנים | גוף בלי פנים | פרצוף מעוצב: אף, גבות, ארובות עיניים, לסת, אוזניים; עיניים, קשתית, גבות, פה ונחיריים כמדבקות דקות על הראש |
| ידיים | כפפה אחת (v22), אגודל ושתי קבוצות אצבעות (v2) | כף יד, ארבע אצבעות ואגודל בנפרד, כפות בצבע עור; כפפות שוער בצבע המשני |
| נעליים | נעל כדורגל בשני הענפים | כדורגל: נעל עם פקקים וסוליה. כדורסל: נעל גבוהה בצבע הקבוצה, סוליה לבנה, שרוכים, בלי פקקים |
| גרביים | בשני הענפים | רק בכדורגל (עם פס בצבע המשני). בכדורסל שוק חשופה |
| תלבושת | חולצה ומכנסיים בצבע אחד | כדורגל: חולצה עם שרוולים, צווארון ושרוולים בצבע משני, מכנסיים. כדורסל: גופייה, מכנסיים ארוכים |
| מספר | בשיידר (v2) | ספרות של שבעה מקטעים כגאומטריה על הגב, ובכדורסל גם על החזה; בלי שיידר ובלי טקסטורה |
| גובה ומבנה | גוף אחד בקנה מידה | רכז, קיצוני וסנטר: אותו קובץ, גובה משלהם ומורף `broad` לרוחב |
| נכסים | 4 גופים, אטלס 475KB, 8 תסרוקות (כ-2.5MB) | 2 גופים, 8 תסרוקות, בלי אטלס (כ-0.5MB) |

## קבצים

- `../../assets/athlete-body-v3/` נכסי הריצה: `models/soccer.glb`, `models/hoops.glb`, `hair/*.glb`, `body-manifest.json`.
- `../../minigames/athlete-body-v3.mjs` טוען, מייצר שחקן (`createAthleteV3Instance`) ומחליף מספר וכפפות (`decorateAthleteV3`).
- `tools/build.py` בונה את כל הנכסים (Python 3 ו-NumPy בלבד, בלי Blender). `tools/check.mjs` בודק תנועה מול v22. `tools/shots.mjs` מצלם את דף התצוגה.
- `preview.html` דף תצוגה: גוף, קליפ, פריים, מספר, צבעים, עור, שיער וכפפות, בשמונה מצלמות (אפשר `?v22=1` להשוואה לגוף הקודם).
- `REPORT.md` מדידות ומה נראה טוב ומה לא. `LICENSES.md` רישוי. `verification/` צילומי מסך ותוצאות.

## הפעלה וכיבוי

ברירת המחדל: v3 דלוק בשני המשחקים. `?athleteV3=0` מחזיר את הגופים הקודמים בדיוק (v2 / v22), וכך גם `?athleteBodyV22=0` ו-`?athleteBody=0`. כשל בטעינה של v3 מחזיר לגוף הקודם לבד.

## בנייה מחדש

```sh
python3 workout/island/design/athlete-body-v3/tools/build.py
```

הסקריפט כותב ישירות ל-`assets/athlete-body-v3/`. אחרי שינוי נכס: `node workout/island/tools/offline-shell.mjs` (גיבובי האופליין).

## צפייה

```sh
python3 -m http.server 8791
```

ואז `http://localhost:8791/workout/island/design/athlete-body-v3/preview.html`.
