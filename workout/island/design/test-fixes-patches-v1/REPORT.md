# תיקוני בדיקות האי

החבילה כוללת את 13 התיקונים מביקורת הבדיקות ותיקון 14 לחוזה תגי הגרסה. הענף `codex/test-fixes-patches-v1` מוסיף את החבילה בלבד. ה־patches מיועדים ל־`main` בקומיט `9e95482fbe1887856cbca69fd43c1c77ba62cff4` ‏(v24.4). ממצאי הביקורת הגיעו מהקומיט `43b27dc235387e3cb737aee9558cdf9d5fd5a262` ‏(v24.1). [הביקורת וההצעות המקוריות](https://github.com/roynaor-work/Bakasun/tree/9383138d7c5e4b4ac5b8aece0a538b804b7274b0/workout/island/design/test-audit-v1)

התיקונים נערכו ונוסו בעותקים נפרדים. היישום משנה קובצי בדיקות, תשתית הרצה ו־CI בלבד, ללא רכיב WASM או החרגת CSP חדשים. החבילה מבוססת על התנהגות v24.4, שבה האופליין כולל 11 חבילות ומסלול מרוצים שכבר הופיע בלולאה אך טרם קיבל בדיקת מוכנות נכונה.

## זמני הרצה ויציבות

## תוצאות שנותרו אדומות וגבולות האימות

- בטניס, ארבעת תרחישי המשנה רצו ב־70.5 ש׳. הכיבוי והנפילות עברו, וכך גם בחירת המשטחים ובקר הקהל. בדיקות התקציב נכשלו עם 99,224 משולשים במסך רחב ו־95,528 במסך עומד. הסף נשאר 90,000.
- במסלול התאימות של מרוצים v7, ההרצה תחת עומס הסתיימה אחרי 566.6 ש׳ עם חריגה מתקציב ההמתנה של אחד מתרחישי ברירת המחדל למסלול התאימות. בדיקת הפורמולה העדכנית עברה.
- בדיקת ספי הקבלה לכיוון בחזירים עברה עם קלטים סינתטיים. בהרצת הדפדפן עם שני ניסיונות הודפס ניסיון ראשון עם ארבע פגיעות מארבע יריות. הרצת המדידה נעצרה אחרי 330 ש׳ לפני תוצאת קבלה מלאה.
- תוצאות ההרצות מבוססות על עותקי האימות המקומיים. מטריצת GitHub Actions המלאה והורדת האופליין האוטומטית המלאה טרם אומתו. מדידות הדפדפן בוצעו ב־SwiftShader.

הרצת Node המלאה הייתה מוגבלת בזמן בשני הצדדים. הבסיס הדפיס 1,695 תוצאות ללא כשלים עד העצירה ב־240 ש׳. עותק התיקונים הדפיס 2,623 תוצאות ללא כשלים עד העצירה ב־1,200 ש׳ תחת עומס הדפדפן. הטבלה משווה את הרצות Node הממוקדות שהסתיימו.

## אימות והחלה בעותק נקי

יש להריץ משורש הענף המכיל את החבילה. שלב הבדיקה משתמש באינדקס זמני, וההחלה מכינה את כל ה־patches באינדקס הזמני לפני שהיא מחילה ומביימת את השינויים יחד בעותק המיועד.

```bash
bundle="$PWD/workout/island/design/test-fixes-patches-v1"
copy="../Bakasun-test-copy"
git worktree add --detach "$copy" 9e95482fbe1887856cbca69fd43c1c77ba62cff4
"$bundle/apply.sh" --check "$copy"
"$bundle/apply.sh" "$copy"
node "$bundle/tests/verify.mjs" "$copy"
git -C "$copy" diff --cached --stat
```

האימות כולל תג תקין, העלאת גרסה מדומה, שני קישורים מיושנים והפרה של הקפאת שעון הכיבוי. תוצאות הכשל בשלושת המקרים המכוונים הן חלק מהאימות. הסקריפט דורש Node 22.15 ומעלה עבור טעינת ה־fixtures בזיכרון. נבדקו גם יעד עם רווח בנתיב, דחייה של יעד לא נקי ושל patch פגום, ותאימות עץ ה־Git בעותק האימות לעץ שממנו הופקו ה־patches.

סוויטות הדפדפן בעותק שעליו הוחלו התיקונים

```bash
cd "$copy"
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install chromium
npm run test:browser -- csp
npm run test:browser -- offline
npm run test:v24-browser
```

הפקודה `npm run test:browser` מקבלת גם `alpine`, ‏`soccer`, ‏`other` או `all`. אפשר לציין נתיבי קובצים רשומים אחרי שם הקבוצה. `CHROMIUM_PATH` מאפשר בחירת דפדפן מקומי, ו־`ISLAND_CSP_AUDIT_DIR` מגדיר תיקיית תוצרים.
