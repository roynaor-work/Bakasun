## צפייה והורדה

1. משורש המאגר הריצו:

   ```sh
   python3 -m http.server 8765
   ```

2. פתחו את [התצוגה המקומית](http://localhost:8765/workout/island/design/avatar-customization-v1/preview.html). בחרו קטגוריה, פריט, אזור צבע וצבע; אפשר להחליף גוף, לסובב ולבחור עמידה, ריצה או ידיים למעלה.
3. לחצו **הורדה לאופליין**. מתקבל `avatar-customization-v1-offline.html` שמכיל את המנוע, כל הנכסים, המניפסט, התמונות והתיעוד. הוא נפתח ישירות דרך `file://`, ללא שרת וללא חיבור. **שמירת מראה** מורידה JSON קטן עם הבחירות והצבעים; הבחירות נשמרות גם במכשיר.

כל קובצי הריצה מקומיים. אין WASM, מפענחי Draco/meshopt, KTX2, CDN או גופן רשת. קוד GLTFLoader הכללי כולל זיהוי הרחבות, אך החבילה אינה משתמשת בהרחבה, אינה כוללת מפענח ואינה מגדירה אחד. בדיקת האופליין משביתה גם את WebAssembly ומפעילה הקשר דפדפן חדש במצב offline. מדיניות Chromium המנוהל בסביבת הבדיקה חסמה ניווט ל־`file://`; לכן נבדקים אותם בתים שהורדו בשתי טעינות קרות של מסמך `about:blank` בעל origin אטום, ללא רשת. לא נעקפה מדיניות הדפדפן. פתיחה ישירה במערכת הקבצים מיועדת לדפדפן רגיל ותלויה בהרשאותיו, ולא אומתה בסביבה המנוהלת.

## חוזה השילוב

`manifest.json` מפרט קטגוריות, פריטים, התאמה לארבעת הגופים `soccer / guard / wing / center`, צבעים, ברירות מחדל, תקציבים ורשימת קובצי אופליין. לכל פריט יש משקל, משולשים ו־SHA-256. לכל גאומטריה חדשה יש `COLOR_0` ליניארי RGBA ו־`_REGION` נפרד מסוג uint8 עם stride של 4. יש להחליף את RGB לפי מזהה האזור ולהמיר צבעי sRGB לליניארי; לא להכפיל בצבע המקורי. האלפא נשאר 1.

כל פריט גאומטרי כולל skin מלא עם אותם 18 שמות, סדר, הורים, תרגומי מנוחה ו־inverse binds קנוניים. הגאומטריה נמצאת במרחב העולם הקנוני, במטרים, Y למעלה ו־Z קדימה. `runtime/customization.mjs` מייצא `createCustomization(THREE, clonedV22Root, bodyInfo, manifest, sourceMap)` שמחזיר `update(state)` ו־`dispose()`. הוא מכפיל את X/Z של הפריט ברוחב/עומק הגוף, וקושר אותו לשלד ול־bindMatrix של הגוף; ה־BodyScale המקורי מספק את הגובה. לא מוסיפים עצמות.

בזמן הריצה הראש המקורי מוחלף מעל Y=1.448. בגדים ומקטעי גוף מכוסים מוסרים מן האינדקס המשוכפל כדי למנוע חדירות; בחלקי משולשים שחוצים את שולי הבגד, shader מקומי חותך את החלק המכוסה במרחב הקנוני. המשטחים החשופים נצבעים כעור ניטרלי. זה כולל שימוש במעטפת החולצה המקורית כגוף חשוף בבגד השחייה, כך שצללית זו שומרת על טופולוגיית v22. כפפות מסתירות את משטחי היד המכוסים. כובע האביזר מסתיר את השיער ומשחזר את התסרוקת לאחר הסרה. משתמשים במורפי הספורט של v22 במשקל אפס; המראה נקבע על ידי התלבושת החדשה. אלה שכבות עיצוב קלות, ללא סימולציית בד או שיער. אין חיבור למשחק החי, שינוי תג גרסה או שינוי ב־offline-manifest הקיים.

## שחזור

יצירת הפריטים מחדש: `python3 tools/build.py` מתוך תיקיית החבילה, עם Python 3 ו־NumPy. בניית המנוע המקומי עם esbuild מותקן בנפרד:

```sh
AVATAR_ESBUILD=/path/to/esbuild node tools/bundle.mjs
```

בדיקות (כלי הפיתוח מותקנים בנפרד, מחוץ לתיקיית המסירה):

```sh
AVATAR_GLTF_VALIDATOR=/path/to/node_modules/gltf-validator node tools/validate.cjs
AVATAR_PLAYWRIGHT=/path/to/node_modules/playwright AVATAR_CHROMIUM=/usr/bin/chromium node tools/review.cjs
python3 tools/inventory.py
```

הריצו את ביקורת הדפדפן מול השרת המקומי שלמעלה; היא מרעננת תמונות פריטים וראיות. רעננו את האינדקס לאחר עדכון התיעוד. סיכום הבדיקות הקיימות מופיע ב־[verification/existing-tests.json](verification/existing-tests.json).
