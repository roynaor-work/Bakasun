- פתיחה ב־320 מילישניות; שלושה כוכבים קטנים בהופעה יחידה של 520 מילישניות עם השהיה של 60. סיום מלא בתוך **580 מילישניות**. אין לולאה, קול או טיימר; הפחתת תנועה מבטלת הכול.

## חיבור עתידי

`offer.mjs` מייצא `create(host, options)` ומחזיר `{ update(state), destroy() }`, בהתאם לצורת העבודה של ה־HUD. יש לטעון `offer.css` ולספק אזור DOM. העדכון מקבל תמונת מצב מלאה; ערכים חסרים חוזרים לברירת מחדל. המודול הוא תצוגה בלבד: אינו שומר, אינו משנה מטבעות ואינו קורא למנוע המשחק.

```js
import { create } from './upgrade-offer-kit-v1/offer.mjs';
const card = create(host, {
  initial: { category: 'מרוצים', name: 'מנוע חזק', icon: 'engine', price: 100, balance: 120 },
  onUpgrade: () => requestUpgrade(),
  onLater: () => closeOffer()
});
// העדכון הוא תמונה מלאה, ללא שינוי האובייקט של הקורא:
card.update({ category: 'מרוצים', name: 'מנוע חזק', icon: 'engine', price: 100, balance: 80 });
// בסגירת המסך:
card.destroy();
```

| שדה | משמעות |
|---|---|
| `category`, `name`, `icon` | קטגוריה, שם קצר ומזהה מטבלת האייקונים; מזהה לא מוכר מוצג כשדרוג כללי |
| `price`, `balance` | מספרים שלמים בטוחים ולא שליליים; מחיר לא תקין או 0 משבית שדרוג |
| `unit` | `coins` כברירת מחדל; `points` מציג נקודות וכוכב |
| `locked`, `lockReason` | נעילה חיצונית וסיבה קצרה; נעילה גוברת על יתרה מספקת |
| `mode` | `dark` כברירת מחדל או `light`; גם קובצי SVG ב־img מקבלים את ערכת הצבע של ההורה |
| `visible`, `purchased` | הסתרה מפורשת או אישור רכישה שהמארח כבר ביצע |

המתאם העתידי צריך לשקול הצעה בסוף **כל שלב, לרבות הצלחה חלקית**, ולהעביר רק את מאזן הקטגוריה ששוחקה. זכאות, מחיר, פתיחת שלב וביצוע הקנייה נשארים באחריות המשחק; בלחיצה יש לבדוק מחדש זכאות. אין תלות בתוצאת ניצחון במודול הזה. הכרטיס הוא section, ולכן כשהמשחק משתמש בו כחלון חוסם יש להציבו בדיאלוג הקיים ולנהל פוקוס, סגירה והשהיה במארח.

## CSP ועלות טעינה

כל הנכסים מקומיים. ללא WebAssembly, ספריות ריצה, קוד מוטבע בדף, `eval`, גופן או תמונה חיצוניים. תצוגת הבדיקה רצה עם `script-src 'self'` ו־`style-src 'self'`, מחמירה יותר מהמדיניות הקיימת לגבי עיצוב מוטבע. אין צורך להתיר WASM או לשנות את מדיניות האפליקציה. SVG כולל CSS פנימי לצבעי האיור, ונבדק כמשאב תמונה עצמאי תחת המדיניות הזאת. טעינה קרה של הדמו מבקשת כל אחד מ־22 קובצי SVG פעם אחת; חזרות בגלריה חולקות מטמון. הרכיב אינו מריץ לולאת פריימים או טיימרים.
