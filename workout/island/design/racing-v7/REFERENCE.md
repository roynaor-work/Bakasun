# כיוון חזותי וקריטריוני קבלה

המשתמש בחר ״מרוצי ארקייד מלוטשים בתלת־ממד״. לא נמסרה תמונת רפרנס חיצונית. הביקורת נשענת על הכיוון שנבחר, על הרכב הקיים בריפו ועל הקריטריונים המפורשים להלן. אין טענה להשוואת פיקסלים לתמונה שלא סופקה.

| אזור | יעד חזותי | מה בודקים בצילום |
|---|---|---|
| רכב | משטחי מרכב חלקים, אופי מזוהה בחמישה דגמים | קווי מתאר שונים, קשתות גלגלים, מרווח רצפה, פרופורציות |
| חומרים | לכה מבריקה וזכוכית משתקפת | היילייט ברור בתנועה; זכוכית נפרדת מצבע הרכב, גומי כהה ומתכת |
| פרטים | חזיתות ופנסים מזוהים | פנסי אור/בלם, גרילים, מראות, כנף/דיפיוזר בלי סמלים |
| גלגלים | גלגול סביב ציר X, היגוי קדמי | צירים במרכז הגלגל; אין קפיצה/ריחוף; מצב הקפאה לבדיקה |
| עיר | לילה, ניאון, בנייה בעומק | כביש קריא כהה, אור חם/קר, חלונות, שילוט מקורי |
| חוף | מרחב חם ושמיים פתוחים | ים, חוף, דקלים, אופק נקי ומעקה |
| הר | מעבר הרים קריר, סלעים ועצי מחט | שינויי גובה, שכבות הרים, מעקות וסימון פניות |
| כביש | טקסטורת אספלט ונורמל | גרעיניות עדינה בלי מוארה; קווי שוליים/נתיבים ורציפות בסגירת הלולאה |
| אפקטים | עשן, ניצוצות ומהירות קריאים | עשן מאחור, ניצוצות ליד המגע, מרכז מסך חד עם טשטוש בקצוות |
| נייד | עולם גדול וממשק שקט | 390×844 וגם 844×390; כפתורי מגע נגישים שאינם מסתירים רכב |
| מרחק | LOD בלי חורים ונפילות | פרטים מקרוב, צללית ברורה מרחוק, מפת מסלול שלמה |
| עלות | נכסים קטנים וקהל במופעים | ספירת משולשים, גודל מדויק, תקציב קריאות ציור ורזולוציה מדורגת |

שפת עיצוב: רקע דיו, לבן חם, הדגשת ליים קטנה; טקסט עברי קצר, מספרים לטיניים; ללא מותג משחק או יצרן.
