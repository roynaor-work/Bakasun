# מרוצים v7

חבילת תצוגה ונכסים עצמאית: חמישה רכבי ספורט, שלושה מסלולים סגורים, קהל בדיוני ואפקטי נסיעה. הכיוון שנבחר: מרוצי ארקייד מלוטשים בתלת־ממד.

## לפתוח ולבדוק

1. פתחו את [offline.html](offline.html) בדפדפן עדכני. הכול משובץ בקובץ, לרבות Three.js, מפענח Draco, המודלים והמרקמים. אין התקנה או build, ואין צורך בחיבור לרשת או בשרת מקומי.
2. בחרו חוף, עיר או הר; בחרו אחד מחמשת הרכבים וצבע. ״מבט רכב״ מאפשר סיבוב בגרירה וצביטה לזום. ״נסיעה״ מפעילה סיור אוטומטי, ״דריפט״ מדגים עשן ומגע ו״בוסט״ מוסיף טשטוש בקצוות וקווי מהירות. לחיצה על המפה מציגה את המסלול המלא.
3. בדקו שהרכב שלם גם באנכי וגם באופקי, שהחלפת סביבה משנה את העולם והתאורה, ושבהשהיה התנועה קופאת. בכפתור המידע אפשר לשנות קצב ואיכות.

התוצאה הצפויה: עולם תלת־ממדי מקומי, עם כל חמשת הדגמים וכל שלוש הסביבות. נדרשים WebGL, WebAssembly ו-DecompressionStream; Chromium 151 נבדק. בדפדפן המנוהל של סביבת העבודה ניווט file:// נחסם במדיניות, ולכן המסמך העצמי נבדק כ-HTML מוזרק למסמך ריק כשהרשת כבויה. זו מגבלת סביבת הבדיקה, לא דרישת שרת של התוצר. הנתונים המלאים ב-[verification/offline.json](verification/offline.json).

לבדיקה או לחיבור מתוך שרת סטטי אפשר לפתוח את [index.html](index.html), המשתמש בקבצים נפרדים באותה תיקייה. השרת אינו נדרש לקובץ העצמי.

## מה לבדוק במסירה

- [REPORT.md](REPORT.md): תוצאה, ציונים, אימותים ומגבלות מדידה.
- [WEIGHTS.md](WEIGHTS.md): משולשים, גודל כל GLB, טקסטורות וזיכרון תמונה משוער.
- [review.html](review.html): גלריית סבבי הרינדור והביקורות.
- [INTEGRATION.md](INTEGRATION.md): צירים, LOD, גלגלים, מפות וקהל.
- [LICENSES.md](LICENSES.md): המקור המורשה וייחוס הנגזרות.
- [source/README.md](source/README.md): מחוללים ופקודות שחזור אופציונליות.

התיקייה אינה מחברת את הנכסים למשחק המרוצים הקיים. 30fps הוא יעד הפלטפורמה; ביצועי טלפון פיזי עדיין דורשים מדידה. תוצאות SwiftShader בשרת נשמרו ללא המרה לציון FPS של טלפון.
