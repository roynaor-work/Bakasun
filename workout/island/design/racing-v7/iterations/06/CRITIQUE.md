# סבב 06 — כל הרכבים מקרוב ומרחוק, וכל המסלול

40 צילומים: קרוב/רחוק בשלוש סביבות, קרוב/רחוק לכל חמשת הרכבים, שלושה מבטים עליונים וסצנת אפקטים; כל אלה בשני יחסי המסך. hash של קובצי התצוגה נשמר ב-capture.json.

| סעיף | הערכה | החלטה לסבב 07 |
|---|---|---|
| מרכב/גלגלים | כל חמשת הדגמים קריאים, יניקת האוויר מכוסה, חישוקים מזוהים | עומד בכיוון שנבחר; להשלים צילום אחורי ו-LOD2 |
| עיר | פלטת חומרים משותפת הפחיתה קריאות ציור בנסיעה | לשמר callbacks של חומר בעת clone כדי להחזיר הארה עצמית לחלונות |
| מבט על אנכי | המסלול נוגע בקצוות | להרחיק מצלמה בהתאם ליחס המסך |
| מבט על הר | חלק מהשמיים נחתך ונראה שחור; הכביש מרצד מרחוק | להתאים near/far למצב מבט על, במקום לשנות את גאומטריית המסלול |
| אפקטים | שובל עשן אינו נאמן לנסיעה בצילום הקפוא | לצבור תנועת רכב בזמן חימום האפקט; לצלם רצף בנוסף לתמונה |
| עלות | חלוקת חומרי תפאורה וחיבור גלגלים הפחיתו עלות | ממשיכים למדידה ממושכת ולהחלפות סביבות לבדיקת משאבים |
| ממשק | נוספה מפה לחיצה, מצב על אינו צריך רינדור רציף ללא תנועה | להשהות אוטומטית במבט על ולשחזר נסיעה בחזרה |

החלטה: ששת הסבבים הושלמו, אך המבט העליון ואמינות צילום האפקטים עדיין אינם עוברים. ממשיכים לסבב 07.
