# מסירת נכסי כבאי v1

חבילת נכסים מקורית למשחק חילוץ ילדים, על הגוף האחיד `athlete-body-v22`. **1,452 משולשים נוספים מתוך 1,500**, כולל המסכה, התיק, הנחיר ומשטח הצינור. **11/11 הקליפים המבוקשים עוברים motion-qa-v1: מינימום 89.7, ללא מדד אדום, כיסוי 100% של המדדים החלים.**

[תצוגה אינטראקטיבית](preview.html) · [מניפסט לצריכה](manifest.json) · [דוח QA מקורי](verification/qa/report.html) · [מקור ורישוי](LICENSES.md) · [גיליון אפקטים](sprites/water-contact-sheet.png)

## התלבושת והצינור

`models/firefighter-equipment.glb` מכיל את התוספות בלבד, ללא שכפול הגוף. הקסדה הצהובה, המגן, המעיל, הצווארון, חלקי השרוולים והמכנסיים, הכפפות, המגפיים, מסכת החמצן, המכל והנחיר הם צמתים נפרדים עם שמות קבועים במניפסט. המעיל הראשי משוקלל ל־Hips/Spine/Chest; יתר החלקים נצמדים לעצמות במרחב המקומי. הקסדה אינה נושאת סמל או מותג.

המסכה ניתנת להסתרה בנפרד באמצעות `oxygen_mask` ו־`mask_regulator`. מסופק גם **`models/oxygen-mask.glb` כפריט עצמאי**, במרחב המקומי של Head; משתמשים בו במקום צומתי המסכה שבערכה, בלי להציג את שניהם יחד.

כל משטח משתמש ב־`COLOR_0` ליניארי וב־`_REGION` מספרי, עם מפת אזור לצבע sRGB במניפסט. יש אזורים נפרדים לאדום, אדום כהה, החזרה צהובה, החזרה כסופה, צהוב הקסדה, כפפות/גומי, מתכת, מגן וצינור. אין טקסטורה חיצונית לציוד. הפס הבהיר הוא צבע קודקודים; אין shader רטרו־רפלקטיבי ייעודי.

הצינור מכיל **180 משולשים**, 19 דגימות אורך ו־5 צדדים, וגם `LINE_STRIP` בן 18 מקטעים. `runtime/equipment.mjs` מעדכן את אותו buffer בכל פריים בין התיק לבין נקודת הכניסה של `nozzle`; אפשר להציג את קו המרכז לצורכי סקירה. הנחיר כולל `water_emitter` וקליפ עצמאי `nozzle_spray_vibration`: 30Hz, לולאת שנייה, רטט 10Hz עד 1.5 מ״מ ופחות ממעלה אחת, המופעל רק בחלון ריסוס. בזמן בעיטה, נשיאה ונפנוף הוא מאוחסן לצד התיק.

## הקליפים

`motions/firefighter-clips.glb` מכיל קליפים ללא רשת, עם 18 העצמות הקנוניות, אותם הורים ותרגומי מנוחה, 18 ערוצי סיבוב וערוץ Hips. כל הערוצים נדגמים ב־**30Hz**, כולל שני הקצוות. `motions/poses.json` מכיל את מלוא הפוזות, האירועים, חלונות התמיכה ומהירויות ההתקדמות.

| קליפ | משך, שנ׳ | פריימים | ציון QA |
|---|---:|---:|---:|
| idle_ready | 2.40 | 73 | 100 |
| walk | 1.20 | 37 | 93.5 |
| run | 0.80 | 25 | 89.7 |
| crouch_walk | 1.60 | 49 | 96.5 |
| spray_stand | 3.20 | 97 | 99.8 |
| spray_crouch | 4.00 | 121 | 98.4 |
| open_door | 2.60 | 79 | 97 |
| carry_child | 1.40 | 43 | 94.9 |
| carry_cat | 1.40 | 43 | 94.9 |
| wave_victory | 3.20 | 97 | 97.2 |
| rescued_handoff | 3.60 | 109 | 95.4 |

נוספו `idle_crouch` כעמידת מוצא אמיתית לתנועה הנמוכה ו־`child_reassured` כתגובת חילוץ אופציונלית. בתנועת `open_door` אירוע הבעיטה הוא בפריים 31; הרגל הנגדית תומכת לכל אורך הפעולה. חלונות הריסוס והמסירה מוגדרים במניפסט ומודגמים בתצוגה.

Root נשאר במקום ובסיבוב זהות. תנועות ההתקדמות הן **in-place**: הצרכן מזיז את השחקן במהירות `clip.speed` במטרים קנוניים לשנייה, כפול קנה המידה של השחקן. כלי ה־QA מודד חלונות תמיכה מלאים אחרי הוספת מסלול הייחוס הזה; הרציפות והקפיצות נמדדות על הפוזות המקוריות במקום. בתצוגה אין תזוזת שחקן בעולם.

ההחלקה המרבית בחלון תמיכה במדידה הקנונית היא **1.813 מ״מ**. כל קודקודי הציוד, למעט הצינור המתעדכן בנפרד, נבדקו בכל פריים מקור; עומק הרצפה המרבי הוא **0.133 מ״מ**. גובה הקסדה בזחילה נבדק גם עם התאמת רוחב/עומק לכל ארבע גרסאות הגוף ונשאר מתחת ל־1.25 מ׳. הנתונים המדויקים נמצאים ב־[assets.json](verification/assets.json).

יש מדדי רציפות צהובים בהליכה, בריצה, בנשיאה ובכניסה למסירה: הפוזות שונות מעמידת המוכנות. אין מדד אדום. בעת חיבור למשחק יש לבצע ערבוב של כ־0.25 שנ׳ ולשמור תמיכות רגליים בעולם ב־IK; מערבל המשחק אינו חלק מהמסירה. `rescued_handoff` מתחיל בנשיאה ומסתיים במוכנות. שאר הפעולות הנייחות מתחילות ומסתיימות במוכנות, והזחילה משתמשת בעמידה הנמוכה.

## אפקטים ותגובות חילוץ

`sprites/water-atlas.png` הוא PNG שקוף בגודל **2048×512**, עם תאים של 256×128. `sprites/atlas.json` מפרט מסגרות, קצב, עוגנים וקואורדינטות UV ממקור שמאל־עליון.

| אפקט | פריימים | קצב | תוצר נוסף |
|---|---:|---:|---|
| water_arc | 8 | 16Hz | ספרייט בודד וגיליון רוחבי |
| droplets | 8 | 16Hz | ספרייט בודד וגיליון רוחבי |
| object_splash | 8 | 20Hz | ספרייט בודד וגיליון רוחבי |
| steam | 6 | 10Hz | ספרייט בודד וגיליון רוחבי |

הקשת והטיפות מחזוריות. הנתז והאדים מיועדים להפעלה בעת פגיעה. כל תא כולל שוליים שקופים, ללא דמויות, טקסט, רקע או מותג. `water-arc.png` זמין גם כשם ברור לספרייט היחיד; `water-contact-sheet.png` מציג את כל 30 הפריימים.

הילד משתמש בעותק תצוגה של הגוף הבדיוני הקיים, בקנה מידה 0.43 ובצבעי בגד אחרים. `child_reassured` כולל מבט והרמת יד לכיוון הכבאי. החתול הוא נכס מקורי בן **216 משולשים**, עם `cat_reassured` ב־30Hz לתנועת ראש וזנב. מיקומי הנשיאה ומסירת הילד מודגמים בתצוגה.

תקציב הסצנה האופציונלית בתצוגה הוא **12,000 משולשים**, וניתן להקטינו. הקבלה מחושבת לפי כל הגאומטריה הנראית, כולל שלב התצוגה, אפקטים ומעברים כפולים של חומרים שקופים. מוצגת רק דמות חילוץ המתאימה לתקציב. השיא שנמדד הוא **11,910 משולשים**. בתקציב 7,000 הילד מוסתר. תקרת **1,500 לציוד** נשמרת בנפרד ואינה גדלה בעקבות הגדרת תקציב התצוגה.

## אימות ושחזור

הענף נוצר מ־main בקומיט `19d9cdc5e3718236df5a2fc4d8b8c26c72007575`. כלי ה־QA המבוקש אינו נמצא בקומיט זה; הגרסה המקורית נמצאת ב־[PR #371](https://github.com/roynaor-work/Bakasun/pull/371), קומיט `5eb4f093bc22523ee417a7f2345c3b813bffba24`.

```sh
node workout/island/design/firefighter-v1/measure.mjs
```

הפקודה מחלצת את כלי ה־QA ותלותיו ל־`/tmp` ומריצה את **run.mjs המקורי** עם `--library firefighter-v1 --fps 120`. Node hook מחליף רק את קורא הספריות כדי לטעון את החבילה החדשה. `run.mjs`, קורא ה־GLB, המדדים, המשקלים והספים נשארים זהים בתים למקור. SHA-256 של שמונת קובצי הכלי והסבר המתאם נשמרים ב־[motion-qa.json](verification/motion-qa.json). דוחות ה־JSON וה־HTML המקוריים אינם נערכים; CSS ובקרי טבלה מקוריים בקבצים נלווים מתאימים את הצגתם ואת קישורי התצוגה לחבילה. פלטי REPORT/LICENSE של הכלי נשארים בתיקייה הזמנית.

```sh
node workout/island/design/firefighter-v1/source/build.mjs
python3 workout/island/design/firefighter-v1/source/sprites.py
node workout/island/design/firefighter-v1/measure.mjs
node workout/island/design/firefighter-v1/source/audit.mjs
```

יצירת הספרייטים דורשת Pillow; הצריכה שלהם אינה דורשת Python. בדיקת glTF נוספת נעשתה עם **Khronos glTF Validator 2.0.0-dev.3.10**, שהותקן מחוץ למאגר: כל ארבעת ה־GLB עברו עם **0 שגיאות ו־0 אזהרות**. הודעות המידע `NODE_EMPTY` מתייחסות לעצמות אנימציה ולנקודת יציאת המים. [דוח validator](verification/gltf-validator.json).

לפתיחת התצוגה מפעילים שרת משורש המאגר:

```sh
python3 -m http.server 8765
```

פותחים [את התצוגה המקומית](http://127.0.0.1:8765/workout/island/design/firefighter-v1/preview.html), בוחרים תנועה ומפעילים ניגון או מזיזים את ציר הזמן. בתפריט התלבושת אפשר להחליף גוף, להסיר מסכה, לצבוע את המעיל, להציג שלד וקו צינור ולשנות תקציב. בדיקת הדפדפן ניתנת לשחזור באמצעות:

```sh
python3 workout/island/design/firefighter-v1/source/review.py
```

בדיקת Chromium עברה **176 מצבי פוזה**, עם WebGL ו־WebAssembly כבוי, בארבע גרסאות הגוף ובכל הקליפים והאירועים. המסגור נבדק ב־1440×1100, 390×844, 360×740 ו־844×390, בארבע זוויות. עברו גם חיבור קצות הצינור, רטט בזמן ריסוס בלבד, המסכה, תקציב דמויות החילוץ, שליטה במקלדת ו־30 פריימי הספרייטים. אין שגיאות דף, בקשות שנכשלו, בקשות חיצוניות או טעינת decoder. בדיקת הנכסים המבנית עברה 368 סעיפים. [תוצאות הדפדפן](verification/browser.json), [מחשב](verification/preview-desktop.png), [נייד](verification/preview-mobile.png), [נייד בזמן ריסוס](verification/preview-mobile-spray.png).

כל השינויים הם **קבצים חדשים בתיקייה זו בלבד**. לא שונו קוד משחק, גוף השחקן המקורי, release.json, תגי גרסה, CLAUDE.md, ops או בדיקות האפליקציה. לא בוצעו חיבור למשחק, מיזוג או פריסה. בדיקות האפליקציה הכלליות אינן חלק מהאימות; כלי הנכסים והתצוגה נבדקים בנפרד. מדד התנועה אבחוני ואינו מחליף הערכה חזותית או בדיקה של המשחק המשולב.
