## שחזור

מתיקיית השורש של ענף המסירה, צרו שני עותקי עבודה של בסיס הביקורת. הפעילו את הבדיקה המקדימה ואת ההחלה בעותק השני.

```sh
git worktree add --detach ../bakasun-kux-before b121e44880bcb6d048cf2c8dc673bad9c371c78a
git worktree add --detach ../bakasun-kux-after b121e44880bcb6d048cf2c8dc673bad9c371c78a
bundle=workout/island/design/kid-ux-patches-v1
"$bundle/apply.sh" --check ../bakasun-kux-after
"$bundle/apply.sh" ../bakasun-kux-after
```

הבדיקות דורשות Node.js, ‏Playwright ו־Chromium. אפשר להגדיר `CHROMIUM_PATH` ו־`PLAYWRIGHT_MODULE` לנתיבים מקומיים. כברירת מחדל הסקריפט מצפה ל־`playwright` שנגיש ל־Node ול־Chromium ב־`/usr/bin/chromium`.

```sh
npm install --prefix ../bakasun-kux-test-tools --no-audit --no-fund playwright-core
PLAYWRIGHT_MODULE=../bakasun-kux-test-tools/node_modules/playwright-core/index.mjs \
  node "$bundle/tests/run.mjs" --base ../bakasun-kux-before --patched ../bakasun-kux-after --out ../bakasun-kux-evidence
```

להשוואת ממצא יחיד הוסיפו למשל `--id 006`. להרצת בדיקות כיבוי ובידוד הוסיפו `--mode off,single`. תוצאה צפויה נרשמת ככזו רק כאשר הבדיקה הגיעה לקביעות על התנהגות המוצר. שגיאת אתחול או דפדפן מוצגת בנפרד.

להפעלה ידנית בעותק המתוקן הוסיפו `?kidUx=1` לכתובת האי. הסרת הפרמטר או שימוש ב־`?kidUx=0` מחזירים את ברירת המחדל. להפעלת כמה תיקונים נבחרים אפשר להעביר רשימה, למשל `?kidUx=005,006`.

## גבולות הראיה

- Chromium 151 במצב נייד לרוחב, ‎844×390 פיקסלי CSS, יחס פיקסלים 1, עברית ומגע שמופק דרך CDP. הספרייה, המשחקים והמסכים שנבדקו הוגשו מקובצי המוצר. רינדור התלת־ממד נעשה בתוכנה. פרופיל גרפי קל או שימוש בתצוגת Canvas הקיימת במוצר מסומנים בקובצי הראיה הרלוונטיים.
- קובצי ה־JSON מכילים מדידות ותיעוד הקמת המצבים. היכן שהרצת הבסיס אספה מדידות בלבד מצורף צילום תואם מדוח הביקורת. המגע נשלח לדפדפן כפעולת קלט. הארנק, ההתקדמות ותוצאות שהוכנו לבדיקת תבניות שייכים לנתוני בדיקה מקומיים.
- בדיקת ההשמעה מאמתת מסירת הוראות למנוע הקול כאשר מדמים קול עברי זמין ואת החלופה בהיעדרו. איכות השמע והמגע במכשיר פיזי נשארות מחוץ להרצה.
- תיקוני המוצר כתובים ב־JavaScript בלבד. הדפדפן השתמש בתשתית הנכסים הקיימת של המשחקים ובמדיניות ה־CSP של המוצר. ההקשר הזמני חסם Service Workers, ולכן תרחיש ההורדה מתעד את הממשק בלבד.
