# בדיקת מסירה — חבילת קול האי

תאריך: 30.10.2026. בסיס: `main` בקומיט `331994eb8e310a12422f8f27e37faf723d8de478`. כל התוספות נמצאות ב־`workout/island/design/audio/` בלבד. אין שינוי בקובץ קיים, בלוגיקת משחק או בתגי גרסה.

## תוצאות חבילת הקול

| בדיקה | תוצאה |
| --- | --- |
| כיסוי | 28 קבצים: 25 אפקטים ושלוש לולאות רקע |
| קידוד | Ogg Opus, ערוץ אחד, 48,000 Hz; פענוח מלא ללא שגיאות |
| אפקטים | 0.5–2.8 שניות, קצוות מרוככים |
| רקעים | בדיוק 24 שניות / 1,152,000 דגימות לכל משחק |
| גודל קובצי קול | 668,956 bytes בסך הכול |
| תקציב מלא | נבדק לכל קובצי החבילה, כולל קוד ותיעוד, כנגד 2,000,000 bytes; נתון מדוד ב־`validation.json` |
| loudness | ‎-23.08 עד ‎-22.85 LUFS-I; פער מרבי 0.23 LU |
| clipping | אפס דגימות חתוכות; true peak הגבוה ביותר ‎-5.57 dBTP, מתחת לתקרה של ‎-3 dBTP |
| מרווח לערבוב | חסם שמרני ‎-2.859 dBTP לעוצמות המומלצות: שלושה אירועים ורקע אחד, אחרי master; לפני EQ או ducking |
| מקור | כל נכס ממופה למתכון, seed, קוד מלא ו־SHA-256; ללא דגימות חיצוניות |

`tools/validate.py` קורא את הקבצים המקודדים, בודק את כותרת Opus, מספר הערוצים, המשך בפענוח, hash, הנרמול, peak, DC, קצוות, הפניות JSON, מגבלות משך ותקציב. המדידה נעשית ב־ffmpeg 7.1 עם loudnorm/true peak בארבעה קצבי דגימה. רק input_i/input_tp נלקחים ממדידת loudnorm; הפלט המעובד של הפילטר אינו משמש כראיה לאיכות קובץ המקור.

## תפירת רקעים אחרי פענוח

נבדקו שלושה חיבורים של אותו PCM מפוענח, קפיצת ערך ושיפוע בגבול, וכן אנרגיה בחלון 100 ms סביב התפר לעומת הסביבה הקרובה. בדיקת אנרגיה פוסלת חור או קפיצה של יותר מ־4 dB; השינוי קצר ומקורו בטיפול בקצה המקודד.

| רקע | קפיצה בתפר, dBFS | שינוי אנרגיה, dB | true peak בשלושה מחזורים, dBTP |
| --- | --- | --- | --- |
| כדורגל | ‎-85.736 | ‎-3.066 | ‎-11.49 |
| כדורסל | ‎-102.730 | ‎-3.308 | ‎-12.16 |
| סקי | ‎-75.977 | ‎-1.880 | ‎-10.62 |

סף הקפיצה בבדיקה הוא ‎-65 dBFS; כל הרקעים עברו. אלה תוצאות מדידה, ולא תחליף להאזנה סובייקטיבית של המשתמש.

## דפדפן ותצוגת האזנה

Chrome 156.0.8078.74 פענח את כל 28 הקבצים למונו 48 kHz עם מספר הדגימות הצפוי. לכל לולאה רונדרו יותר משני מחזורים ב־OfflineAudioContext עם AudioBufferSourceNode.loop. ההפרש המרבי בין דגימות המחזור המקורי לחזרה היה **0**. אין תוספת padding או פער תזמון בגבול. מדידות הקפיצה תאמו לפענוח ב־ffmpeg.

`preview.html`: נבדקו 28 נגנים ושלושה כפתורי לולאה, הפעלה ועצירה בפועל, היעדר שגיאות דף, והיעדר גלישה אופקית במידות 390×844 ו־844×390. הבדיקה משרתת את הקבצים מקומית ללא תלות בפריסה חיצונית. ניתן לשחזר באמצעות `tools/validate-browser.cjs` עם Playwright ו־Chrome. תוצאות מלאות ב־`browser-validation.json`.

לא נבדקו כאן Safari, Firefox או מכשירי טלפון פיזיים. לא בוצעה האזנה אנושית מתועדת. הדף המצורף מאפשר את בדיקת ההאזנה לפני המיזוג. נגן HTML רגיל אינו מבטיח תזמון sample-accurate; כפתורי הרקע משתמשים ב־Web Audio.

## בדיקות המאגר

הורצה פקודת המאגר `node --test tests/*.mjs`. ב־Windows, checkout אוטומטי עם CRLF גרם לחמישה כשלי השוואת תיעוד/בתים נוספים. לצורך הפרדה בין סביבת הרצה לשינוי, חולץ עותק נקי של אותו HEAD דרך `git archive`, עם הבתים המקוריים ו־LF, והבדיקות הורצו עליו ללא חבילת הקול.

בעותק המקורי: **2,857 בדיקות, 2,818 עברו, 38 דולגו, כשל אחד**. הכשל הוא `tests/cam-lab-calibration.test.mjs`, בדיקת squats-low-standing: מסלול קובץ הופך ל־`C:\\C:\\…` ב־Windows. אותה בדיקה נכשלת גם לפני התוספות, ואין לה הפניה לחבילת הקול. לא תוקן קוד מחוץ לתחום הבקשה. תוצאת CI של ה־PR היא בדיקה נוספת בסביבת Linux.

חבילת הנכסים עצמה אינה חיבור למשחק עובד. אימות עוצמות אחרי חיבור בפועל למנוע המשחק ובדיקה במכשירי היעד הם שלב נפרד.
