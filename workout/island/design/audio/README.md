# האי שלי · חבילת קול מקורית

28 קובצי Ogg Opus, מונו 48 kHz. אפקטים באורך 0.5–2.8 שניות ושלוש לולאות רקע בנות 24 שניות. סינתזה מקורית בלבד; ללא מוזיקה, דיבור, דוגמיות, שמות או מיתוג בתוך הצלילים. חבילת נכסים מוכנה לחיבור עתידי; המשחקים עצמם לא שונו.

## האזנה

1. פתחו את `preview.html` בדפדפן להשמעת כל אפקט בנפרד. הקבצים נטענים רק בעת שימוש.
2. לבדיקת תפירה מדויקת של הרקעים, הפעילו שרת מקומי משורש המאגר: `python -m http.server 8765`, ופתחו `http://localhost:8765/workout/island/design/audio/preview.html`.
3. לחצו על כפתור הלולאה של המשחק והאזינו מעבר ל־24 שניות. הניגון בכפתור משתמש ב־Web Audio וכולל מד זמן המראה את נקודת התפירה. עצרו לפני מעבר למשחק אחר. אין הפעלה אוטומטית.

תוצאה צפויה: כל 28 הקבצים מתנגנים, שלושת הרקעים חוזרים ללא נקישה, וניתן לעצור כל ניגון. נגן HTML הרגיל נועד להאזנה לקובץ; לתפירה מדויקת יש להשתמש בכפתור Web Audio.

## ערבוב וחיבור עתידי

`mix.json` מגדיר לכל נכס נתיב יחסי, תווית, משך מדויק, עוצמה מומלצת ב־dB ובערך לינארי, highpass/lowpass של 12 dB לאוקטבה עם Q=0.7071, מגבלת קולות, מקור, seed ו־SHA-256. `layers` מגדיר שכבות ותזמון שאפשר לנגן יחד. כל העוצמות הן יחסיות לקובץ המנורמל, לפני master של ‎-3 dB.

- כל הקבצים מנורמלים ל־‎-23 LUFS-I עם סבילות 0.3 LU, ותקרת true peak של ‎-3 dBTP. העוצמה היחסית במשחק נקבעת באמצעות ההמלצות, כך שרקע, שריקה ופגיעה אינם מתחרים באותה עוצמה.
- מנגנים רק רקע אחד ועד שלושה קולות אירוע במקביל. מחליפים בין רמות הקהל, ובין מהירויות השלג, לפי `exclusive_groups`; בשלג crossfade של 100 ms בין אפקטים, לא stacking. קרצופי השלג הם one-shot ולא לולאות קצרות.
- בניתור משתיקים את השלג; בנחיתה מחזירים אותו. בניצחון לא מוסיפים בו־זמנית גם שאגת שער: היא כבר מיוצגת בשכבת האירוע.
- בעת שריקה/ניצחון/נפילה מנמיכים את הרקע לפי `duck_bed_db`, עם attack של 35 ms ו־release של 350 ms. זמזם ושריקה הם אירועי משחק בלבד.
- יש לפענח את הרקע פעם אחת ל־AudioBuffer, ולהפעיל AudioBufferSourceNode עם `loop=true`, מ־0 ועד אורך ה־buffer. אין לחתוך את ה־pre-skip של Opus שוב, אין להוסיף padding ואין לתזמן מחדש כל מחזור. הנתונים כבר כוללים טיפול בגבול. crossfade נוסף בגבול הלולאה אינו נדרש.
- מקור הרקעים הוא רעש מחזורי והצלבות תהודות/מעטפות מחזוריות. נוספו כתפי cosine של 24 ms ושולי 10 ms סמוך לתפר כדי למנוע ringing של הקידוד. אין fade ארוך בין המחזורים; נבדקת גם אנרגיית 100 ms סביב התפר כדי לפסול חור או קפיצה בעוצמה.
- בתחילת/סוף ניגון מוסיפים ramp של 40 ms, כדי שגם עצירת רקע באמצע לא תיצור נקישה. עקומת מעטפת מתחלפת מחייבת ביטול של automation קודם לפני ramp חדש.

זהו חוזה ערבוב ותצוגת האזנה בלבד; אין חיבור למנוע המשחק, שינוי בקובצי לוגיקה או שינוי בתגי גרסה. כל הקבצים שנוספו נמצאים בתוך תיקייה זו.

## מקור ושחזור

המקור המלא: `tools/generate.py`. רישיון ומיפוי מקור: `LICENSES.md` ו־`mix.json`. נדרש Python 3.12, NumPy 2.x ו־ffmpeg עם libopus. בסבב המסירה שימשו Python 3.12.14, NumPy 2.3.5, ffmpeg 7.1 דרך imageio-ffmpeg 0.7.0. seed קבוע לכל נכס; אין קלט רשת או דגימות.

משורש תיקייה זו:

```sh
python tools/generate.py --ffmpeg /path/to/ffmpeg
python tools/validate.py --ffmpeg /path/to/ffmpeg --report validation.json
```

יצירה מחדש מחליפה רק את קובצי OGG ואת `mix.json` של חבילה זו. נתוני PCM דטרמיניסטיים באותה גרסת NumPy; בתים זהים של Opus דורשים גם אותה גרסת ffmpeg/libopus. הקידוד: CBR של 64 kbps לאפקטים ו־48 kbps לרקעים, מסגרות 20 ms, מצב restricted-lowdelay, cutoff של 16 kHz. כלי הבנייה והספריות אינם מצורפים לחבילה ואינם נדרשים לניגון.

תוצאות הבדיקה: `VALIDATION.md`, `validation.json` ו־`browser-validation.json`.

בדיקת דפדפן עצמאית: אחרי התקנת Playwright בסביבת פיתוח שבה Chrome זמין, הריצו `node tools/validate-browser.cjs`. היא מפענחת את כל הקבצים, מרנדרת יותר משני מחזורים לכל רקע, משווה דגימות בנקודת החזרה, ומפעילה/עוצרת את כפתור הרקע בתצוגה בשתי מידות מסך. אינה משמיעה צליל אוטומטית למשתמש.
