## תקציב ובדיקות

- 16 תמונות: **1,374,694 bytes** בסך הכול. כל התיקייה, לרבות התיעוד והתצוגה, קטנה מ־2,000,000 bytes; הסכום המדויק ב־LICENSES.md.
- הרקע הגדול ביותר: **138,836 bytes**, מתחת ל־200,000 bytes לקובץ. KB ו־MB בחבילה נמדדים בשיטה העשרונית.
- פענוח כל התמונות, מספר הקבצים, מידות ויחסי תמונה נבדקים מול הקבצים המיוצאים.
- בכל ששת המרקמים נבדקת זהות RGB מלאה בין העמודה הראשונה לאחרונה ובין השורה הראשונה לאחרונה, לאחר פענוח WebP. בנוסף נבדקת חזותית חזרה של 2×2 אריחים.
- בדיקת Chromium/Playwright ב־390×844 וב־844×390 עברה: עשרת הרקעים נטענים, ששת דגמי החזרה מוצגים, ללא גלילה אופקית או שגיאות דף. אין JavaScript בתצוגה. החיתוכים והחזרה נבדקו גם חזותית.

3. התוצאה הרצויה: חיבורים רציפים במרקמים, אורות תקרה גלויים באולם ופסגות הרים שנשארות בפריים בשני הכיוונים. דף הסקירה הוא HTML/CSS סטטי עם תמונות מקומיות בלבד.
