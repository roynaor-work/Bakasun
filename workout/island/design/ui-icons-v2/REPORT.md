# דוח מסירה · אייקוני HUD v2

[תצוגה מקדימה](preview.html) · [מניפסט](manifest.json) · [רישיון CC0](LICENSE.txt)

הערכה כוללת 120 אייקונים מקוריים לעשרת המשחקים הפעילים. לכל אייקון SVG וקובץ PNG שקוף בגודל 96×96 בכל אחד משלושת המצבים. כל קובצי המסירה נמצאים תחת `workout/island/design/ui-icons-v2/`.

## צפייה

1. מריצים משורש המאגר `python3 -m http.server 8765` ופותחים את [דף התצוגה המקומי](http://localhost:8765/workout/island/design/ui-icons-v2/preview.html).
2. בוחרים משחק או מחפשים אייקון בשם או בתגית. גריד האייקונים נגלל בתוך המסגרת בתצוגה רוחבית בגודל 844×390.
3. בוחרים אייקון, מצב ופורמט. במצב רגיל מחזיקים את כפתור ההדגמה במגע או עם מקש רווח כדי לראות לחיצה. כפתור ההורדה שומר את הקובץ של המצב והפורמט שנבחרו.

## שימוש בנכסים

- לכל רשומה יש `id` קבוע, `name` באנגלית, `nameHe` בעברית, `category`, רשימת `games` ומילות חיפוש ב־`tags`. הנתיב `files[state][format]` יחסי לתיקיית הערכה.
- גודל התצוגה המומלץ לאייקון הוא 32×32 פיקסלי CSS במרכז יעד לחיצה בגודל 56×56 לפחות. הצבעים כוילו למשטח HUD כהה כדוגמת `#14212e`. קובץ PNG ב־96×96 מתאים להצגת 32×32 ביחס פיקסלים 3:1.
- `normal` משמש במנוחה. `pressed` מתכווץ ב־10%, מוסט מעט כלפי מטה ומחליף גוון בזמן ההחזקה. `disabled` משתמש בקו אפור ובמילוי שקוף. בהשבתת כפתור מגדירים גם `disabled` ב־HTML.
- לתווית כפתור משתמשים בטקסט חי ב־HTML. שמות מוצגים ב־RTL ומזהים וקיצורי פורמט מבודדים ב־`bdi`. פניות פיזיות שמאלה וימינה משתמשות בקבצים `turn-left` ו־`turn-right` כפי שהם.
- הנכסים עשויים מגאומטריית SVG מקורית ומקובצי PNG שהופקו ממנה ב־librsvg. דף התצוגה משתמש ב־HTML, CSS ו־JavaScript מקומיים. האייקונים כוללים צורות וצבע בלבד, והנכסים הגנריים נמסרים ב־CC0.

```html
<button type="button" dir="rtl" aria-label="האצה"
        style="min-inline-size:56px;min-block-size:56px;display:inline-grid;place-items:center">
  <img src="svg/normal/boost.svg" width="32" height="32" alt="">
</button>
```

## אימות

- נבדקו 360 קובצי SVG ו־360 קובצי PNG מול המניפסט. בכל קובץ PNG נמצאו ערוץ אלפא, מידות 96×96 ושוליים שקופים של לפחות 6 פיקסלים. בכל SVG נמצאו נתיבים וקטוריים בלבד. כל 120 צורות המקור ייחודיות.
- ב־Chromium 151 כל 720 התמונות פוענחו בהצלחה. נבדקו 844×390 ו־390×844, כיווניות RTL, יעד לחיצה מינימלי של 56×56, סינון בעשרת המשחקים, חיפוש בעברית ובאנגלית, לחיצה במגע ובמקלדת, מצב מושבת והורדת SVG ו־PNG. בבדיקה התקבלו אפס שגיאות רשת ו־JavaScript.
- בהרצת `npm test` עברו 4,371 בדיקות ו־86 דולגו. בדיקת הדפדפן של רועיקי נעצרה עקב גרסת Chromium חסרה של Playwright. בהרצה חוזרת של קובץ הבדיקות עם Chromium המותקן בסביבה עברו כל חמש הבדיקות, כולל זו שנעצרה.
- **משקל:** 124,731 בייט ל־SVG ו־708,726 בייט ל־PNG. כל 724 קובצי המסירה שוקלים פחות מ־1 MB בתכולה גולמית, מתחת למגבלת 2 MB.
