כל השינויים הם קבצים חדשים בתוך `workout/island/design/tennis-ui-fx-v1/`. הערכה כוללת תצוגה עצמאית וחוזה שילוב. חיבור למשחק ופרסום גרסה אינם חלק מהמסירה הזאת. קובצי המשחק, הגרסה וחדר הבקרה נשארו ללא שינוי בהתאם להגבלת התיקייה.

## פתיחה ובדיקה חזותית

1. פותחים את [preview.html](preview.html). כל המשאבים נמצאים בתיקייה הזאת; בדפדפן רגיל אפשר לפתוח אותה גם מקובץ מקומי.
2. מפעילים אאוט, פגיעה בקו, אבק ונטו בכפתורים. חצים במקלדת או כפתורי החצים מזיזים את בחירת ההגשה. מחזיקים את כפתור הדרופ כדי לצבור כוח ומשחררים לנחיתה. אפשר להחזיק רווח או Enter כאשר הכפתור ממוקד.
3. גוללים לגלריה ומחליפים בין SVG, PNG 256 ו־PNG 512. מחווני הגובה והכוח מאפשרים לבדוק מצבי ביניים. התוצאה הצפויה: אותה גאומטריה ואותו עיגון בכל פורמט, טקסט חד בשלטים וצל שנשאר על הקרקע כשהכדור עולה.

בתצוגת 844×390 המגרש וכל כפתורי ההפעלה נמצאים במסך הראשון. ברוחב צר יותר מופיעה שורת כפתורי מגע נפרדת בגודל 48px לפחות. ההשהיה עוצרת גם את שעון האפקטים; במנוחה אין לולאת ציור פעילה. בהעדפת תנועה מופחתת האבק מוצג כחותמת סטטית קצרה והחץ עובר מיד בין מיקומים.

מדיניות הדפדפן המנוהל בסביבת הבדיקה חוסמת ניווט ל־`file://`, לכן האימות כאן בוצע בשרת מקומי. אם גם הדפדפן שלכם חוסם קבצים מקומיים, מפעילים משורש המאגר:

## חוזה שילוב

[manifest.json](manifest.json) כולל מידות, מלבני תוכן, נקודות עיגון, גודל תצוגה מוצע, סדר שכבות, תזמון, הפניות לפריימים, משקל ו־SHA-256 לכל אחד מ־57 הייצואים.

**עיגון:** הקואורדינטות והמלבנים נמדדים משמאל למעלה בלוח 256×256. `anchor.normalized` מתאים לשני ייצואי ה־PNG. עבור נקודת יעד `(x,y)` וגודל תצוגה `(w,h)`, הפינה העליונה של התמונה היא `(x - anchor.x*w/256, y - anchor.y*h/256)`. ב־PNG 512, קואורדינטות פיקסלים גולמיות מוכפלות בשתיים; העיגון המנורמל אינו משתנה.

**אאוט ופגיעה בקו:** משתמשים באירוע המוסמך מהסימולציה ובנקודת המגע האמיתית. אין להסיק אאוט לפי החיוויים או לחשב ניקוד מחדש. האיקס נשאר באותה נקודת עולם, גם אם המצלמה זזה; מקרינים מחדש בכל פריים. המימוש בתצוגה מסיר אותו כשהגיל מגיע ל־1,500ms. בדפדפן ההסרה נראית בפריים הראשון אחרי הסף. להדבקה על מגרש תלת־ממדי: מישור XZ בגובה המשטח ועוד 0.008 מטר, בדיקת עומק פעילה, כתיבת עומק כבויה והיסט פוליגונים למניעת ריצוד.

**מיקום ההגשה:** שלושה מצבים בלבד, באינדקסים 0–2. המיקומים המוצעים הם X של ‎−2.75, 0, 2.75 מטר על קו ההגשה הקרוב, Z של 6.4 מטר. אלה מיקומי תצוגה מוצעים; המשחק קובע חוקיות הגשה. שמאל וימין הם כיוונים פיזיים ואינם מתהפכים בגלל עברית.

**כוח דרופ:** מניחים מסילה ומילוי באותו מלבן תצוגה. עבור כוח `p` בין 0 ל־1, מציגים מתוך שכבת המילוי את המלבן `[111, 222 - 190*p, 21, 190*p]` בלוח 256. המחט זזה ב־Y לפי `222 - 190*p - 128`. לא משנים את גובה התמונה עצמה. טווח הדיוק `.32–.52` הוא המחשה בתצוגה; בשילוב מחליפים אותו בטווח שמוסר המשחק. ממקמים את המד בצד המסך תוך שמירה על שטחי הבקרה ואזורי הביטחון.

**אבק:** כל ששת הפריימים מעוגנים ב־`[128,176]`. בוחרים פריים לפי `floor(ageMs / 60)` ומסירים את הספרייט בגיל 360ms. אין לחזור לפריים הראשון או להחזיק את האחרון. מפעילים על חימר בלבד. בציור הנוכחי הענן כבר פחוס: מציגים אותו כבילבורד המעוגן בנקודת הקרקע המוקרנת.

**צל:** שלוש הדגימות חולקות עוגן מרכז וגודל תצוגה זהה. מהדקים את הגובה לטווח 0–3 מטרים, ומערבבים בין שתי דגימות סמוכות במשקלים שסכומם 1. רוחב, רכות ואלפא כבר מצוירים בנכס; אין להוסיף עקומת שקיפות שנייה. הצל נשאר בנקודת הקרקע של הכדור, מתחת לאבק ולכדור, ונעלם כאשר הכדור אינו מוצג. גם כאן האליפסה כבר פחוסה: משתמשים בעוגן קרקע מוקרן למסך.

**שלטים:** ב־SVG וב־PNG אין אותיות וגם אין אותיות שהומרו למסלולים. מלבן הטקסט הוא `[28,102,140,48]`, ומרכזו `[98,126]`. מציגים עליו טקסט חי בגופן מערכת ובכיוון RTL: „אאוט” או „נטו”. בגודל התצוגה המוצע הטקסט הוא 22px. התצוגה משתמשת ב־DOM וב־`aria-live="polite"` להכרזה אחת לכל אירוע.

**שקיפות וצבע:** PNG עם אלפא ישרה ומרחב צבע sRGB; נותנים למנוע לטפל בהכפלת האלפא. כותבים את האפקטים ללא עומק. סדר מוצע: צל, טבעת, אבק, איקס, כדור, ממשק. טוענים את הרזולוציה הנבחרת מראש, לפני הפעלת אירוע מתוזמן. שעון האפקטים מתקדם בזמן סימולציה פעיל ומוקפא בהשהיה.

## שחזור

התצוגה אינה דורשת התקנה. לבנייה ולאימות בלבד נדרשים Node, Python עם Pillow, Sharp, Playwright ו־Chromium. גרסאות כלי הכתיבה מוצמדות ב־[tools/package.json](tools/package.json). אפשר להתקין בכלי עזר זמניים בלי לשנות את קובצי התלויות במאגר:

```sh
npm install --prefix /tmp/tennis-ui-fx-tools --no-save --package-lock=false sharp@0.35.4 playwright@1.62.1
```

משורש המאגר:

```sh
NODE_PATH=/tmp/tennis-ui-fx-tools/node_modules node workout/island/design/tennis-ui-fx-v1/tools/build.mjs
python3 workout/island/design/tennis-ui-fx-v1/tools/verify-assets.py
NODE_PATH=/tmp/tennis-ui-fx-tools/node_modules CHROMIUM_PATH=/usr/bin/chromium node workout/island/design/tennis-ui-fx-v1/tools/verify-browser.mjs
NODE_PATH=/tmp/tennis-ui-fx-tools/node_modules ISLAND_PLAYWRIGHT="$PWD/workout/island/design/tennis-ui-fx-v1/tools/repository-playwright.mjs" CHROMIUM_PATH=/usr/bin/chromium node --test tests/*.mjs
```

המחולל כותב מחדש רק קבצים בתיקייה הזאת. הוא מטמיע ב־HTML עותק זהה של ה־manifest כדי שהתצוגה לא תצטרך לבצע `fetch` לקובץ מקומי. בדיקת הנכסים מוודאת ששני העותקים זהים ושהשינויים במאגר הם תוספות בתיקייה המורשית בלבד.
