## חיבור למנוע

הצירים הם מטרים, Y כלפי מעלה, X לאורך המגרש, Z לרוחבו. ראשית מודל האולם היא מרכז המגרש בגובה הרצפה. מרכזי הטבעות באולם הם:

```json
{"east":[12.425,3.05,0],"west":[-12.425,3.05,0]}
```

ראשית דגם הסל העצמאי נמצאת על הרצפה מתחת למרכז הטבעת. הטבעת נמצאת ב־`[0,3.05,0]`; התמיכה נמשכת לכיוון X החיובי. להצבה בצד השני מסובבים חצי סיבוב סביב Y.

מומלץ לטעון באמצעות [arena.mjs](arena.mjs): הוא ממיר את המושבים המשותפים למופעי GPU ומאחד את חלקי היציעים לפי צד וחומר. איחוד המושבים אינו מגדיל את הגאומטריה. ארבעת הצדדים נשארים ניתנים לחיתוך. בעת איחוד גאומטריה במעבד מורחבים רק המאפיינים המקוונטטים שצריכים טרנספורמציה, כדי לשמור על מיקומים ונורמלים תקינים.

```js
const arena = await loadArena();
scene.add(arena.root);
arena.setCutaway(true);
// Later:
arena.dispose();
```

המודל מכיל גופי תאורה פולטי אור. סביבת האור, האורות המחושבים, גוון התמונה וההשתקפות המישורית מוגדרים ב־[preview.mjs](preview.mjs), לצורך תצוגת החומר המלאה. יש להגדיר אותם גם במנוע המארח. ניתן לכבות את מעבר ההשתקפות כדי לחסוך ציור נוסף; חומר העץ ומפותיו נשארים.

התצוגה מציירת בעקבות שינוי מצלמה או פעולה בלבד; אין לולאת ציור רצופה במנוחה. המדדים בדוח הדפדפן כוללים את מעבר ההשתקפות והצללים: 255–318 קריאות ציור בגדלים ובזוויות שנבדקו. הם נמדדו ב־Chromium עם SwiftShader; **לא בוצעה מדידת קצב פריימים בטלפון פיזי**. בדיקת טלפון נדרשת בשלב החיבור למשחק, יחד עם תקציב השחקנים והאפקטים.

## שחזור

התלויות מיועדות לכלי הייצור בלבד. התקנה בתיקייה זמנית מונעת יצירת תיקיית תלויות בתוך חבילת המסירה:

```sh
npm install --prefix /tmp/hoops-arena-tools --cache /tmp/hoops-arena-cache --no-audit --no-fund three@0.160.1 gltf-validator@2.0.0-dev.3.10 @gltf-transform/core@4.3.0 @gltf-transform/extensions@4.3.0 @gltf-transform/functions@4.3.0
python3 -m pip install -r workout/island/design/hoops-arena-v2/source/requirements.txt
python3 workout/island/design/hoops-arena-v2/source/textures.py
python3 workout/island/design/hoops-arena-v2/source/build.py
ARENA_TOOLS=/tmp/hoops-arena-tools/node_modules node workout/island/design/hoops-arena-v2/source/optimize.mjs
ARENA_TOOLS=/tmp/hoops-arena-tools/node_modules node workout/island/design/hoops-arena-v2/source/check-assets.mjs
python3 workout/island/design/hoops-arena-v2/source/capture.py
python3 workout/island/design/hoops-arena-v2/source/write-manifest.py
```

סקריפט הצילום דורש שרת פעיל ושימוש ב־Chromium. גרסאות יצירה בסביבה הזאת: NumPy 2.3.5, Pillow 12.3.0, Three.js 0.160.1. כל המקורות ורישיונות התלויות מפורטים ב־[LICENSES.md](LICENSES.md).
