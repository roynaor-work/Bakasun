לצפייה: לפתוח hud.html ישירות בדפדפן. בסרגל העליון לבחור פתיחה / משחק / השהיה / תוצאה; לשנות גודל חלון ל-844×390 ול-390×844. אין build, JS או גישה לרשת. כל תיקיית משחק עצמאית. כפתורי הפעולה הם תצוגה סטטית; בחירת המסך פועלת ב-radio/CSS. הנתונים מומצאים ונועדו להמחשה בלבד.

נבחר מסלול מפרט low-poly עם שלד פשוט, כפי שהותר בבקשה. לא צורפו GLB או קליפים בינאריים מוכנים. אייקוני SVG מקוריים מצורפים בפועל. קבצי JSON הם חוזה עיצוב למימוש, ולא state machine שכבר מחובר למשחק. בסקי פעולת הדחיפה וקליטת נחיתה הן המקבילות הספורטיביות לבעיטה/זריקה וקליטה; ריצה היא לתפריט בלבד.

ה-HTML מדגים היררכיה, צבע, שוליים ויעדי מגע. הרקע סכמטי והסמנים מייצגים מיקום, לא איכות גרפית סופית. איכות הדמות והזירה התלת־ממדית תיבדק לאחר ייצוא וחיבור. אין שימוש בנכסים או מיתוג של משחקי ספורט מסחריים.

תקציב: עד 150,000 bytes לדמות עתידית (כולל קליפים ומרקמים מוטבעים), עד 2,000,000 bytes נכסים לכל משחק, תמונות עד 512×512. לכל משחק רשימת מקורות ורישיון CC0-1.0. אין שינוי בקובצי minigames, vendor, תגי גרסה או לוגיקת תוצאות.

תוצאות בדיקה והגבולות של מה שאומת: [VALIDATION.md](VALIDATION.md).
