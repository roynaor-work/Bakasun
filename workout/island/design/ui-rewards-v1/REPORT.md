# ערכת סיום ופרסים — ui-rewards-v1

תאריך: 14.11.2026 · ריפו: `roynaor-work/Bakasun` · ענף: `codex/ui-rewards-v1`.

קריטריון סיום: כל רכיבי הבקשה ב־SVG וב־PNG שקוף 256×256, שתי אנימציות מתועדות, תצוגת RTL בגודל 844×390, קובץ מניפסט ורישיון, כל קובץ עד 300,000 בתים, בדיקות ו־push. כל התוצרים נמצאים בתיקייה הזאת בלבד.

כל נכס כולל נתיבי ייצוא, מידות, תפקיד, תווית עברית, רישיון, גודל בבתים ו־SHA-256 ב־[manifest.json](manifest.json). סך קובצי הנכסים: **514,162 בתים**; הנכס הגדול ביותר: **21,877 בתים**. גם קובצי המקור, התיעוד וצילומי המסך עומדים בתקרת 300,000 בתים לקובץ.

## מראה ושימוש

הסגנון ממשיך את פלטת `ui-kit-v2` הקיימת: ים `#24786D`, דיו `#173E40`, מנטה `#B9DDC8`, זהב `#E9BA57`, אלמוג `#EB947F` ונייר `#FFFCF4`. הצורות עגולות, קווי המתאר ברורים, וההדגשות קטנות. המדליות נבדלות גם בסמל המרכזי: עיגול, מעוין, כוכב ויהלום עם פאות.

ה־SVG מורכב מגאומטריה וקטורית, ללא טקסט, תמונות משובצות, סקריפטים או הפניות חיצוניות. ה־PNG הוא RGBA שקוף, 256×256 בדיוק, ברינדור Chromium מקומי. אין גופנים או תמונות חיצוניים. הגרפיקה המקורית וקוד התצוגה זמינים ברישיון **CC0-1.0**; פירוט ב־[LICENSE.txt](LICENSE.txt).

### תמונות לעומת משטחי ממשק

- כוכבים, מדליות, גביע, מטבעות ומתנות: להציג ב־`object-fit: contain`, ללא מתיחה וללא שיקוף אוטומטי ב־RTL.
- כפתורים, תג, פאנל ופס: ה־256×256 הוא קנבס מקור לחיתוך בתשעה חלקים. להשתמש ב־`nineSlice.insets` וב־`borderWidthPx` שבמניפסט. כך נשמרות הפינות כשמציגים משטח רחב ונמוך. לא למתוח תמונת כפתור ריבועית כרקע רגיל.
- לפאנל יש שתי שכבות עצמאיות: רקע מתחת לתוכן וקו מעל הרקע. שכבת הקו צריכה `pointer-events: none`.
- מסילת ההתקדמות והמילוי נפרדים. המילוי מתחיל מימין; ב־0% להסתיר אותו, ובמילוי צר מ־14px לצמצם את רוחב החיתוך לחצי הרוחב הזמין לכל היותר. אין מספר או אחוז בתוך הגרפיקה.
- שלושת מצבי הכפתור הם `default`, `pressed`, `disabled`. טבעת מיקוד נפרדת בקוד: 3px בדיו, היסט 3px. יעד הלחיצה הוא לפחות **56×56 פיקסלי CSS**, גם אם האיור הפנימי קטן יותר.

### עברית וערכים

הכיתוב ״שיא חדש״, כותרות, תוויות כפתורים, מספרים ואחוזים נמצאים ב־HTML/JavaScript. התצוגה משתמשת ב־`lang="he" dir="rtl"`; מספרים מבודדים ב־`bdi`. דירוג הכוכבים מתחיל מימין. חצי כוכב מלא בצד ימין, ומצבו מוקרא כחלק מהדירוג הכולל.

המסך מציג ערכי הדגמה מומצאים בלבד: 2.5 כוכבים, 75% ו־50 מטבעות. אלה אינם כללי ניקוד או החלטה על כלכלת המשחק. אין כתיבה לאחסון, הענקת פרס, שינוי לוגיקה או חיבור למסכי המשחק הקיימים.

### אנימציות

| אנימציה | פריימים | זמן לפריים | משך | מצב סופי |
|---|---:|---:|---:|---|
| הדלקת כוכב | 8 | 60 מ״ש | 480 מ״ש | `star-full` |
| פתיחת מתנה | 8 | 80 מ״ש | 640 מ״ש | `gift-open` |

האנימציות מנוגנות פעם אחת ומחזיקות את המצב הסופי. פריים 0 זהה לנכס ההתחלה ופריים 7 זהה לנכס הסיום, בשני הפורמטים. בתצוגה שלושה כוכבים נפרדים עם השהיה של 110 מ״ש ביניהם; הכוכב השלישי חוזר למצב החצי של דוגמת הדירוג. יש טעינה ופענוח מוקדמים של הפריימים, ביטול ריצה קודמת בהפעלה מחדש, הגנה מפני פתיחה כפולה ודילוג ישיר למצב סופי עם `prefers-reduced-motion: reduce`. אין לולאה, קול או הבזק לבן.

## תצוגה ובדיקות

[preview.html](preview.html) מציג מסך סיום בגודל **844×390** וגלריה עם כל 39 הנכסים, כולל פריימים ומצבי כפתורים. כפתור SVG/PNG מחליף גם אייקונים וגם משטחי ממשק. ״נחגוג שוב״ מפעיל את הכוכבים ומאפס את המתנה; לחיצה על המתנה פותחת אותה. ״לאי שלי״ מדגים הודעת פעולה בלבד. קיימת גם פריסה צרה ל־390×844.

הבדיקות הייעודיות עברו ב־Chromium 151:

- **בדיקת נכסים:** מלאי, מידות, שקיפות, שוליים של לפחות 4px לאייקונים ולכל פריימי האנימציה, XML, העדר טקסט והפניות חיצוניות, גדלים, גיבובים, 8 פריימים שונים לכל אנימציה והתאמה מדויקת של פריימי הקצה. [asset-report.json](verification/asset-report.json)
- **בדיקת דפדפן:** מסגור 844×390, RTL, שלושה כוכבים, החלפת SVG/PNG, גלריה, כל ששת מצבי הכפתורים, יעדי 56×56, מיקוד ומקלדת, סדר 8 הפריימים בזמן ריצה, פתיחה כפולה, ביטול אנימציה, הפחתת תנועה ופריסה צרה. לא נרשמו שגיאות דפדפן או בקשות חיצוניות. ההפרש הממוצע בין צילום SVG לצילום PNG הוא **0.54 מתוך 255** לערוץ RGB. [browser-report.json](verification/browser-report.json)
- **בדיקות הריפו:** בריצת `npm test` עברו 4,135 בדיקות ו־64 דולגו. בדיקה אחת ב־`workout-royiki.test.mjs` נכשלה בהקמה כי דפדפן Playwright לא היה מותקן בנתיב המטמון הצפוי; השרת שנפתח לפני הכשל השאיר את התהליך פתוח והוא נעצר לצורך השלמת הריצה. הקובץ הזה הורץ מחדש עם Chromium המותקן, דרך קישורים זמניים ב־`/tmp` ו־`PLAYWRIGHT_BROWSERS_PATH`: כל 5 הבדיקות עברו, כולל בדיקת 50 אנימציות האימון. לא שונו קובצי בדיקה או תלויות בריפו. סך הבדיקות השונות שעברו בשתי הריצות: 4,136; 64 הדילוגים נותרו דילוגים. הפקודה המלאה לא הורצה שוב. [repository-tests.json](verification/repository-tests.json)

צילומים: [מסך SVG](verification/result-svg.png), [מסך PNG](verification/result-png.png), [מתנה פתוחה](verification/gift-open.png), [גלריה](verification/catalog.png), [מצבי כפתורים](verification/button-states.png), [8 פריימי מתנה](verification/animation-frames.png), [390×844](verification/portrait-390x844.png).

## שחזור

מסביבת Python 3 עם Pillow ו־Playwright ועם Chromium מותקן:

```bash
python workout/island/design/ui-rewards-v1/source/build_assets.py
python workout/island/design/ui-rewards-v1/source/verify_assets.py
```

בדיקת הדפדפן דורשת שרת מקומי בשורש הריפו, בחלון נפרד:

```bash
python -m http.server 8765 --bind 127.0.0.1
```

ואז:

```bash
python workout/island/design/ui-rewards-v1/source/verify_browser.py
```

נתיב Chromium ניתן לשינוי באמצעות `CHROMIUM_PATH`; ברירת המחדל היא `/usr/bin/chromium`. המקור מייצר את קובצי SVG, PNG, `manifest.json` ו־`catalog.js` בתוך התיקייה הזאת בלבד. התצוגה עצמה אינה דורשת Python, ספריות JavaScript או שלב בנייה.

## מסירה וגבולות השינוי

התיקייה החדשה היחידה היא `workout/island/design/ui-rewards-v1/`. קבצים קיימים, קוד משחק, נתונים, גרסה ו־service worker לא שונו. `ops/CONTROL.md` נקרא; רישום הסשן וקריטריון הסיום נשמרים כאן בשל ההנחיה המפורשת שלא לשנות קבצים קיימים. הענף מיועד למסירת נכסים; חיבור למסכי המשחק הוא שלב נפרד.
