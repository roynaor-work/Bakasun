# כוונון קרבות הספינות

בסיס המדידה הוא `main` ב־`9e95482fbe1887856cbca69fd43c1c77ba62cff4`, גרסת האי v24.4. הענף `codex/naval-battle-patches-v1` מכיל חבילת פאצ׳ים שאפשר להחיל על עותק עבודה של הריפו.

## מה משתנה במשחק

- בשלב 1 שתי ספינות נעות כבר בפתיחה במקום ספינה אחת. גם שלבים 2–3 נפתחים עם שתי ספינות. השלבים העמוסים שומרים על תקרה של שלוש ספינות יריבות נעות בו־זמנית. תותחי חוף ומטוסים ממשיכים להתנהג בהתאם למשימה.
- היריבים מתחילים לירות מוקדם יותר ומקצרים את ההמתנה בין מטחים. סימון אזור הפגיעה וזמן ההתרעה של v24 נשמרים. הנזק לכל קליע מהים ומהחוף ירד, ויש מקום בתור הקליעים למטח של שלושה פגזים מצד השחקן גם כשאויבים בים, בחוף ובאוויר יורים יחד.
- ספינה נוספת במשימות השמדת צי ויותר עמידות בשלבים המאוחרים מאריכים את החלק שבו השחקן ממש נלחם. מטרות המשימה, סדר ההגעה של ספינת הדגל ומנגנוני המכ״ם, התחמושת והשדרוגים של v24.4 ממשיכים לפעול.
- פאצ׳ הקרב מגדיר את ערכי הכוונון תחת `minigames.navalDuel.battleV1`. השינוי מופעל כברירת מחדל בכניסה למשחק אחרי החלת הפאצ׳. פתיחה עם `?navalBattle=0` מחזירה את משחק v24.4 ואת האפקטים שלו. [פאצ׳ הקרב](patches/001-battle.patch)

## אפקטים אופציונליים

פאצ׳ האפקטים מחבר רצף בועות מכלי השיט הטובעים של `codex/naval-sinking-v1` (`2f2e646`) ועמוד מים מפגיעה קרובה מתוך `codex/naval-sea-v2` (`ea925b1`). האפקטים מתווספים בנקודות שבהן המנוע כבר קבע שהתרחשה טביעה או החטאה קרובה. תוספת התמונות המקודדות היא כ־100 ק״ב לפני Base64. בדפדפן עם WebGL, חוסר זמינות, כשל פענוח או מעבר לאיכות נמוכה משאירים את האפקטים המקוריים פעילים. רשימת הקבצים והגיבובים לעבודה אופליין כלולה בשני הפאצ׳ים. [פאצ׳ האפקטים](patches/002-visuals.patch)

## שיטת המדידה

הסימולציה מריצה את `createNavalModel` בקצב קבוע של 30 עדכונים בשנייה. שלושה פרופילים מייצגים מתחיל, לומד ומיומן. הפרופילים נבדלים בקצב ירי, שגיאת כיוון, בחירה בין כיוון ידני למכ״ם, זמן תגובה להתרעה, התחמקות ושימוש בתיקון. הבוטים פועלים דרך קלטי המשחק ומטפלים גם בצוללות, בירי נ״מ ובמצופי תחמושת. כל הזוגות לפני ואחרי השתמשו באותו שלב, אותו בוט ואותו זרע בדיקה, בציוד התחלתי וברמת הקושי הרגילה. [קוד הסימולציה](sim/sim.mjs)

מדד האורך הראשי הוא חציון הזמן עד ניצחון או הפסד. ירי האויב כולל פגזים, טורפדות ופצצות מטוס. כל קליע במטח אויב נספר בנפרד. מספר יריות השחקן הוא מספר לחיצות הירי שהתקבלו עבור חימוש ימי. ירי וולקן נספר בשדה נפרד בסימולציה. נתוני הפתיחה סופרים את 15 השניות הראשונות או עד סיום המשחק. שיעורי הניצחון הם אומדן של בוטים סינתטיים ומשקלול שווה של שלושת הפרופילים.

## החלה, בדיקה וחזרה

1. מתוך שורש הריפו בענף החדש, בדקו את ההתאמה והחילו על עותק העבודה לבדיקה.

   ```bash
   PATCH=workout/island/design/naval-battle-patches-v1
   bash "$PATCH/apply.sh" --check
   bash "$PATCH/apply.sh"
   ```

   ברירת המחדל מחילה את אפקטי התוספת כשהפאצ׳ שלהם תואם. `--core-only` מחיל את הכוונון בלבד. `--with-visuals` דורש שגם פאצ׳ האפקטים יתאים. `--target DIR` מחיל או בודק בעותק אחר. אם `main` התקדם וההחלה נכשלת, הפאצ׳ים ניתנים לבדיקה מול הקומיט שמצוין בראש הדוח.

2. הריצו את בדיקות החבילה ואת המדידה החוזרת.

   ```bash
   node --test "$PATCH"/tests/*.test.mjs
   node "$PATCH/sim/sim.mjs" --mode both --seed 20261118 --seeds 24 --jobs 3
   node "$PATCH/sim/sim.mjs" --mode both --stages 1 --seed 14928763 --seeds 192
   ```

   בהחלה עם `--core-only`, הריצו את `tests/naval-battle.test.mjs` מתוך החבילה. בדיקת הדפדפן נמצאת ב־`tests/naval-battle-browser.mjs` ומשתמשת ב־Chromium וב־Playwright של הריפו.

3. כדי להשוות בדפדפן, פתחו את אותה כתובת משחק עם `?navalBattle=0`. כדי להסיר את הפאצ׳ים מהעותק כולו, השתמשו בפקודות הבאות.

   ```bash
   bash "$PATCH/apply.sh" --check --reverse
   bash "$PATCH/apply.sh" --reverse
   ```

## אימות

- על עותק זמני עם שני הפאצ׳ים עברו 216 בדיקות Node, כולל תשע בדיקות החבילה ובדיקות הספינות והמניפסט לאופליין. שתי בדיקות הדפדפן האופציונליות של v7 דולגו בהרצת Node.
- בדיקת Chromium נפרדת ב־844×390 פתחה את המשחק דרך מסלול ההפעלה הרגיל. עם הדגל הכבוי נספרו ספינה אחת וקליע אויב אחד ב־12 שניות. עם הכוונון נספרו שתי ספינות ועשרה קליעים באותו חלון.
- בדיקת WebGL נפרדת הציגה בועות טביעה ועמוד מים בסצנה הפעילה. הדגל הכבוי השאיר את מודולי האפקטים מחוץ לטעינת המשחק. כשל בטעינת תמונה בודדת ומעבר לאיכות נמוכה כוסו בבדיקות האפקטים.
- התקנה, `--check` והסרה נבדקו על עותק זמני. בדיקת ההסרה השוותה בתים לקבצי הבסיס. עם הדגל הכבוי הושוו גם תמונות מצב מלאות של מנוע המשחק למקור בשלושה תרחישים.

המדידה נערכה בבוטים סינתטיים ובדיקת התצוגה נערכה בדפדפן שולחני המדמה מסך נייד.
