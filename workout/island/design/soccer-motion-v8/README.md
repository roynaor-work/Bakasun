# ספריית תנועה לכדורגל 08

25 קליפים בשלד הקנוני של motion2: 23 פעולות ושני מצבי המתנה. הקליפים מוטמעים בשני קובצי GLB עם Draco. אירועי מגע ושחרור, עוגני תמיכה, מסלולי כדור ומפת מעברים נמצאים ב־`runtime/catalog.mjs`. חסימת בעיטה והגנת כדור נמסרות כפעולות נפרדות.

1. להרצה ולשילוב פתחו את [INTEGRATION.md](INTEGRATION.md): קוד טעינה והפעלה לכל קליפ, משמעות האירועים, צירים ופקודות בדיקה.
2. לתצוגה הגישו את התיקייה בשרת מקומי ופתחו את [preview.html](preview.html). בחרו שחקן או שוער, קליפ ומרחק מצלמה; עצרו במגע או דפדפו בציר הזמן.
3. לאימות הריצו `node --test` מתוך תיקיית החבילה. הבדיקה טוענת בפועל כל קליפ ומפענחת את הגאומטריה באמצעות המפענח המקומי. סיכום הראיות והציונים נמצא ב־[REPORT.md](REPORT.md).

| תיקייה | תוכן |
| --- | --- |
| `runtime/` | קובצי הריצה המדויקים והספריות המקומיות; יש להעתיק יחד. |
| `iterations/NN/` | שני סבבי הצילום המלאים האחרונים: שתי מידות, שני מרחקים, שמונה פריימים לכל קליפ, מדידות וביקורת. |
| `iterations/history.md` | שורה לכל סבב ישן; תמונות הסבבים הישנים אינן נשמרות. |
| `verification/` | בדיקות Node, סריקת רשת צפופה ומדידות דפדפן; אינם תלות של המשחק. |
| `source/` | כלי הכנה ושחזור; אינם נטענים במשחק. |

רשימת הבדיקה היא [CHECKLIST.md](CHECKLIST.md). מקור הנכסים ותנאי השימוש מתועדים ב־[LICENSE.md](LICENSE.md). דמויות המקור בדיוניות, עם ביגוד ללא מותגים. התנועה מעוצבת בעזרת קינמטיקה ואינה motion capture.

החבילה נשארת בתיקייה החדשה בלבד. היא אינה משנה קוד משחק קיים ואינה כוללת פרסום או מיזוג של המשחק.
