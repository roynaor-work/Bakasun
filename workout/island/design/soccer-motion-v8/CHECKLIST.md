# רשימת הבדיקה לכל סבב

בכל סבב: בנייה, צילום viewport אמיתי, עיון בגיליונות, ציונים וביקורת קצרה, ותיקון הנובע מהממצאים. שתי המידות הן 390×844 ו־844×390; לכל קליפ מצלמה קרובה ורחוקה ושמונה פריימים: 768 צילומים בסבבים 01–03 ו־800 בסבבים 04–07 לאחר הוספת חסימת הבעיטה. סבב חלקי אינו נספר. נשמרים רק שני הסבבים המלאים האחרונים; קודמיהם מסוכמים בשורה לכל סבב עם חתימת הקלט.

| פריט | מה בודקים | דרישת סיום |
| --- | --- | --- |
| כיסוי | 13 פעולות שדה כולל הגנה וחסימת בעיטה נפרדות, הוצאת שוער ותשע צלילות, שני מצבי מוצא | 23 פעולות + 2 מצבים; ציון ≥8 |
| קריאות תנועה | הכנה, מגע, המשך ובלימה נבדלים; משקל על רגל התמיכה; ידיים מאזנות | שמונה פריימים לכל קליפ; ציון ≥8 |
| מגע וכדור | FK מנקודה מקומית בעצם; מרחק מרכז כדור שווה לרדיוס; שחרור בזמן הנכון | בדיקה מספרית וצפייה; ציון ≥8 |
| רגליים ורצפה | תמיכות אינן מחליקות; רשת אינה נבלעת; נחיתה וקימה רציפות | בדיקת הרשת בפועל וסוליות; ציון ≥8 |
| שוער | תשעה אזורים שונים, יד נכונה, הושטת גוף, נחיתה וקימה | כל שלוש השורות והעמודות; ציון ≥8 |
| מעברים ואירועים | מפה חוקית לכל תפקיד, ערבוב חיובי, לולאות, seek, pause וקטיעה | בדיקות Node; ציון ≥8 |
| טלפון וקרוב/רחוק | אין חיתוך גוף או גלילה אופקית, סמנים קריאים ופקדים נגישים | ארבע תצורות לכל קליפ; ציון ≥8 |
| ביצועים | גאומטריה קלה, מפענח יחיד, טעינה מקומית, תזמון רינדור נמדד | יעד 30fps; לציין גבולות המדידה; ציון ≥8 |
| מסירה | runtime מדויק, INTEGRATION, node --test עובר, בלי JSON גולמי או וידאו | כל החבילה ≤60MB, קובץ ≤5MB, כל GLB ≤1.5MB; ציון ≥8 |
| היקף | קבצים חדשים בתיקייה הייעודית בלבד; בלי נתונים אמיתיים או מותגים | diff של הוספות בלבד; ציון ≥8 |

ציון הוא שיפוט עצמי חזותי והנדסי, לא תוצאת בדיקה אוטומטית. אם פריט נשאר מתחת ל־8, יש לכתוב מה חסר במפורש ולא להכריז עליו כעובר.
