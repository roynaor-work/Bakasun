# משימות ואירועים בעיר · v1

החבילה מוסיפה ל״העיר שלנו״ ולכפתור ״משימות״ לוח משותף. אחרי יצירת הדמות והשלמת ההדרכה או דילוג עליה, הלוח מציע משימה אחת לביצוע ומשימה אחת אחריה, כשיש מועמדת מתאימה. הכפתור בכרטיס הפעיל פותח את המסלול הרגיל של הבנייה, ניהול המבנה או המשחק. תצוגת המשימה הבאה כוללת את הכותרת בלבד.

## מה אפשר לעשות

| סוג | מתי המשימה מתקדמת |
| --- | --- |
| בנו | אחרי בנייה מוצלחת של המבנה המבוקש, במגרש מוכן, בהצבה ידנית או בפיתוח עירוני. |
| שדרגו | אחרי שהמנוע אישר שדרוג של מבנה מהסוג המבוקש. הכפתור פותח מבנה שניתן לשדרג ומעדיף מבנה שאפשר לממן כעת. |
| אספו | לפי ההכנסה בפועל של המשאב המבוקש מאז שהמשימה נהייתה פעילה. הכרטיס מציג כמה נאסף. |
| חברו | כשמבנה מנותק מקבל גישה לרשת הכבישים של העירייה. הכפתור מציע את מקטע הכביש הבא במסלול ונמנע ממגרשים שמורים. |
| שחקו | אחרי תוצאה תקינה בשלב שנבחר, גם אם הסיבוב הסתיים בהפסד. |
| הצילו | אחרי ניצחון בשלב שנבחר. יציאה או הפסד משאירים את האפשרות לנסות שוב. |

## אירועים בעיר

| אירוע | תנאי עיר | משחק |
| --- | --- | --- |
| שריפה בעיר | תחנת כיבוי ומבנה עירוני נוסף. שלב 2 צריך להיות פתוח. | כיבוי אש, משלב השריפה הראשון במחסן ואילך. משימת האימון הרגילה מפנה גם לשלב הפתיחה. |
| עזרו לתפוס את הפושע | תחנת משטרה ומבנה עירוני נוסף. | ״תפוס את הפושע״ הקיים. |
| יום ספורט בעיר | לפחות מגרש מתאים אחד שמאפשר לשחק. | בחירה בין כדורגל, כדורסל וטניס לפי הזמינות. |
| סערה ליד הנמל | נמל בנוי. | משימת ספינות בשלב פתוח של המשחק הקיים. הסערה היא סיפור המסגרת של הכרטיס. |
| מרוץ האי | הרחבת האי הראשונה ופארק בנוי. | מרוץ בשלב פתוח במסלול הרגיל. |

האירוע הראשון יכול להופיע אחרי 90 שניות משחק באי מתחילת הלוח. בין אירועים יש לפחות 150 שניות מסיום האירוע או דילוג עליו, וגם משימה רגילה אחת שהושלמה. הבחירה משוקללת ותלויה בבניינים, בשלב ההתרחבות ובשלבים שנפתחו. אותו סוג אירוע לא נבחר פעמיים ברצף. אירוע שמוכן יכול להופיע בתצוגה המקדימה בלי להחליף את המשימה הפעילה. הילד בוחר לעבור אליו ולוחץ כדי לפתוח את המשחק. אין ספירה לאחור. נעילות הלימוד וזמן המשחק הקיימות עדיין חלות.

## תגמולים ושמירה

בקטלוג יש 16 משימות רגילות ו־5 סוגי אירועים. משימה רגילה מעניקה 18–35 מטבעות ואירוע מעניק 36–48 מטבעות. חלק מהתגמולים כוללים גם משאב עירוני. בשלב משחק נשמרים גם התגמול והכוכבים הרגילים של המשחק.

ההתקדמות והתגמול נכתבים במסגרת אותה שמירת אי. בנייה, שדרוג וחיבור משלמים פעם אחת לכל משימה, ולכן ביטול פעולה וביצוע חוזר אינם משלמים שוב. בייבוא תוספתי התור המקומי נשמר והשלמות הבנייה משתי השמירות מתאחדות. שמירה מקומית קיימת מקבלת את הלוח כשמגיעים לעיר. אפשר לחזור למסלול המשימות והאירועים הקודם עם `?cityMissions=0`. נתוני הלוח נשמרים לצורך חזרה אליו.

| [patches/island-integration.patch](patches/island-integration.patch) | חיבור לאי ועדכון מניפסט האופליין. בסיס החיבור הוא `9e95482fbe1887856cbca69fd43c1c77ba62cff4`. |
| [apply.sh](apply.sh) | בדיקה, החלה או ביטול של ה־patch בעץ העבודה. |

הענף מכיל את החבילה בלבד. חיבור למשחק מתבצע בהחלת ה־patch בעץ עבודה שמכיל את החבילה. המימוש משתמש ב־JavaScript במודולי ES ובקטלוג JSON. לחבילה אין תלות ב־WASM.

```bash
./workout/island/design/city-missions-events-v1/apply.sh --check
./workout/island/design/city-missions-events-v1/apply.sh
```

הפקודה הראשונה בודקת שה־patch ניתן לביטול. השנייה מבטלת אותו בפועל.

```bash
./workout/island/design/city-missions-events-v1/apply.sh --reverse --check
./workout/island/design/city-missions-events-v1/apply.sh --reverse
```

גרסת ההפצה נשארת בניהול מנגנון ההפצה הקיים. במכשיר שכבר משתמש במטמון של גרסה קודמת, החיבור יגיע עם עדכון הגרסה המרכזי.

## אימות

```bash
node --test workout/island/design/city-missions-events-v1/tests/*.test.mjs
```

הבדיקות הבאות מיועדות לעץ העבודה שבו ה־patch מוחל.

```bash
npm test
CITY_MISSIONS_BROWSER=1 node --test workout/island/design/city-missions-events-v1/tests/browser.test.mjs
```

בדיקת הדפדפן משתמשת בתשתית Playwright של הריפו. אפשר לציין בסביבה `ISLAND_PLAYWRIGHT` אם Playwright מותקן מחוץ למאגר, ו־`CHROMIUM_PATH` אם Chromium מותקן בנתיב אחר.

- בעץ העבודה הסופי עברו 196 בדיקות ממוקדות. מתוכן 22 בודקות את הקטלוג, את מעברי המצב ואת החלת ה־patch וביטולו.
- שלושה תרחישי Chromium עברו בתצוגות טלפון אנכית ואופקית. נבדקו בנייה מהמגרש המוכן, פתיחת כיבוי אש שלב 2, נעילת לימוד, ביטול וניסיון חוזר, ניצחון שהמודל מחשב ממצב בדיקה קבוע עם תגמול חד־פעמי, פתיחת ״תפוס את הפושע״ בשלב 1, וחזרה דרך `?cityMissions=0` עם טעינה חוזרת של אותה שמירה.
- בבדיקות מנוע נוספות נבדקו שמירה משותפת של התגמול והמשימה, מיזוג גיבוי וחיבור כביש שעוקף שטחים שמורים.
- בריצת `npm test` על עותק האינטגרציה עברו 4,371 בדיקות ו־86 דולגו. בדיקת דפדפן קיימת של מסך האימון נכשלה בהפעלה בגלל הנתיב של Chromium. כל חמש בדיקות הקובץ שלה עברו בהרצה חוזרת על העותק הסופי עם Chromium של המערכת.
