## התאמות הבדיקות

- `tests/island-offline.test.mjs` מונה את התוספות בנפרד לפי מלאי החבילה. הבדיקה שומרת על תקרת 90 MiB לנכסי הבסיס ומדווחת גם על האיחוד המלא. נבדקים שיוך, סדר, כפילויות, גודל ומספר קבצים. החריגים לכלל `isManagedPath` מוגבלים לקובצי הרישוי ולקובצי JS/CSS שנרשמו על פי המתאם. קובצי JS/CSS יכולים להיענות במסלול המעטפת הקיים. מסמכי הרישוי נרשמים להורדה.
- `workout/island/tests/racing-v7.test.mjs` משווה את 18 הנתיבים המדויקים של הפודיום כשהוא נכלל בהחלה, וסופר אותם בנוסף לקבוצות המרוצים הקיימות. `games.boars` נבדק בנפרד מרשימת החבילות שהבורר מציג.
- `tests/island-alpine-env.test.mjs` ו־`tests/island-alpine-league-v23.test.mjs` בודקות את תקרת 8.5 MB על נכסי הסקי הקיימים. 49 קובצי הרץ נספרים ומאומתים בבדיקת החבילות.
- `tests/island-offline-v25-browser.test.mjs` משווה את תצוגת הנפח של הכדורגל והטניס לגודל הקבצים על הדיסק. הפאנל משתמש ביחידה של 1,048,576 בתים. בדיקת v25 ב־Node אימתה את מפת `files` מול SHA-256 וגודל בפועל לכל נתיב.

GitHub Pages מסנן כרגע קובצי `.md`. התיקונים רושמים 15 הודעות `LICENSES.md` לפי המתאם. כדי שהמוריד יקבל אותן בפרסום בפועל, שלב הפריסה צריך לכלול את הנתיבים שלהן. [כללי הפריסה בבסיס](https://github.com/roynaor-work/Bakasun/blob/9e95482fbe1887856cbca69fd43c1c77ba62cff4/.github/workflows/pages.yml)

## החלה ואימות

מתוך עותק של ענף המסירה אפשר להריץ בדיקה עצמאית של 21 התיקונים ושל שילוב חבילות.

```sh
node --test workout/island/design/pack-wiring-patches-v1/tests/*.test.mjs
```

להחלה בעותק נפרד, מריצים מתוך שורש ענף המסירה. אחרי ההחלה אפשר לבדוק את התיקון המשולב ב־`git diff --cached`.

```sh
bundle="$PWD/workout/island/design/pack-wiring-patches-v1"
git worktree add --detach ../Bakasun-pack-wiring 9e95482fbe1887856cbca69fd43c1c77ba62cff4
(
  cd ../Bakasun-pack-wiring
  "$bundle/apply.sh" --check
  "$bundle/apply.sh"
  git diff --cached --stat
)
```

כדי לבחור חבילות, מציינים את שמותיהן באותה הפעלה של `apply.sh` על עותק של הבסיס. בדוגמה נבחרות שתי חבילות שמשתפות קובצי בדיקה.

```sh
"$bundle/apply.sh" --check boars-weapons-v2 racing-podium-v1
```

כל תיקון עומד גם בפני עצמו על הבסיס הנעול עם `git apply --index`. `apply.sh` משלב את רשימות המניפסט והייחוס לפני כתיבה לעץ היעד. הוא בודק התאמה של האינדקס והקבצים המשותפים לבסיס. הבדיקות מכסות החלה מרובה, התנגשות בתוכן קיים וניסיון החלה חוזרת.

- בדיקות המסירה: **24 עברו**, כולל 21 החלות עצמאיות עם אימות SHA-256 לכל קובץ.
- החלה כוללת בעותק נפרד: 606 קבצים נוספו, שבעה קובצי רישום ובדיקה עודכנו, וכל 606 החתימות אומתו שוב מול `copy-plan.sh --verify`.
- בדיקות ממוקדות אחרי החלה: **65 עברו, אחת דולגה**.
- `npm test`: **4,372 עברו בבסיס, 4,373 אחרי ההחלה**, עם 86 דילוגים ואפס כשלים בכל הרצה.
- בדיקה ממוקדת ב־Chromium הורידה את חבילות הכדורגל והטניס והצליבה את התצוגה מול גודל הקבצים. הפאנל הציג 74.8 MB ו־11.9 MB בהתאמה, לפי היחידה שלו.
- הרצה מפורשת של `tests/island-offline-v25-browser.test.mjs`: **2 בדיקות עברו**. ברירת המחדל הורידה את חמש הרשימות שנבחרו ללא כשלי קבצים, והכדורגל והכדורסל נפתחו במצב לא מקוון. תרחיש עדכון גרסה העתיק 1,000 קבצים מהמטמון והוריד רק שניים, הקובץ שהשתנה והמניפסט.
