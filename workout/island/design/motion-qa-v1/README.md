# כלי QA: מגע להב והחלקת הוקי

מקור הכלי הוא [PR #371, קומיט נעול](https://github.com/roynaor-work/Bakasun/tree/5eb4f093bc22523ee417a7f2345c3b813bffba24/workout/island/design/motion-qa-v1). שמונת קובצי המקור הובאו לענף זה משום שלא היו בבסיסו. ההרחבה כאן מוסיפה קורא הוקי ומודל מגע להב מפורש. אין שינוי בספים, במשקלות או בנוסחאות של רגל נטועה. [חתימות ומקור](provenance.json) · [רישיונות](LICENSES.md).

## הרצה

משורש המאגר, ללא התקנת תלויות:

```sh
node workout/island/design/motion-qa-v1/run.mjs --library hockey-v2 --out workout/island/design/hockey-v2/evidence/qa
node workout/island/design/motion-qa-v1/run.mjs --library hockey-v2 --legacy --out workout/island/design/hockey-v2/evidence/legacy
node workout/island/design/motion-qa-v1/run.mjs --library hockey-v1 --legacy --out workout/island/design/hockey-v2/evidence/before
node --test workout/island/design/motion-qa-v1/skating.test.mjs
node workout/island/design/motion-qa-v1/report-browser-test.mjs
```

כל הרצה יוצרת `report.json`, `report.html`, `REPORT.md`, גיליונות SVG ונתוני קליפים תחת תיקיית הפלט שנבחרה. `--fps 120` מגדיל את קצב הדגימה. ברירת המחדל 60Hz, ובכל קצב מתווספים זמני מפתח ומגע מדויקים. דוח ריצה אחת אינו דורס את דוח ריצה אחרת. ספריות הכדורגל והכדורסל המקוריות נשארו בתצורת המקור והמדדים שלהן נשארו ללא שינוי.

דפי הדוח משתמשים ב־`style.css` וב־`report-ui.mjs` המקומיים, עם נתיבים יחסיים המחושבים מתיקיית הפלט בפועל. קישור התלת־ממד מוביל לתצוגת ההוקי הקיימת, שבה בוחרים את הקליפ ברשימה. בדיקת הדפדפן דורשת Playwright ו־Chromium, עוברת על שני הדוחות וכל 60 דפי הקליפים, בודקת קישורים מקומיים וחיפוש/מיון ושומרת חתימות קלט וראיות ב־`report-browser-evidence.json`.

## מודל להב

ההפעלה מפורשת: `state.skating.contactModel = "blade"`. קליפים ללא ההצהרה משתמשים במדדים המקוריים. לא מסיקים חלונות תמיכה להוקי; חובה להצהיר על חלונות מגע ללהב, עם תמיכה של להב אחד לפחות לאורך הקליפ. החזרת רגל באוויר אינה חלון תמיכה. המודל הנוכחי מיועד להחלקה רציפה ולפירואט; ניתור עם זמן מעוף מחייב חוזה נוסף.

`footSliding` במודל זה הוא המרבי מבין השגיאות הבאות, מחולק בגובה הדמות:

- גובה שני קצות הלהב מעל/מתחת למישור הקרח.
- שגיאת הנורמל של מישור הסוליה: אורך הלהב כפול מרחק שני וקטורי היחידה של הנורמל ושל ציר Y. נבדקים pitch ו־roll, כולל היפוך הנורמל.
- אינטגרל הערך המוחלט של תזוזת הלהב לרוחב כיוונו, לאחר ניכוי תנועת בלימה מבוקשת כאשר הוצהרה.
- תזוזת העוגן האופקי בחלון `pivot`.

תנועה לאורך הלהב מותרת. הכיוון נמדד באמצע כל צעד דגימה, כדי שפנייה רציפה לא תיצור סטייה מדומה. קצות הלהב האמיתיים במודל ההוקי: `[0,-0.08,-0.0865]` ו־`[0,-0.08,0.1985]`. הנורמל המקומי `[0,1,0]`. הנורמל העולמי הוא `[0,1,0]`, ומישור הקרח Y=0.

שלושה מצבי מגע: `glide`, `brake`, `pivot`. בלימה דורשת `support.expectedVelocity = [{timeSeconds, velocityMps:[vx,vy,vz]}, ...]`, עם כיסוי מלא של החלון. זהו מסלול המהירות המבוקש של הלהב, שמחושב מהתנועה האנליטית המתוכננת לפני פתרון IK. המדד מנכה רק את הרכיב הרוחבי הצפוי, ואז מודד כל שגיאה נוספת. הסימון `brake` לבדו אינו מוחק את המדד; מסלול חסר מקבל אפס נקודות וכיסוי חסר.

`bodySliding` משווה בכל צעד דגימה את **וקטור מהירות השורש בפועל** ל־**וקטור המהירות במסלול הייחוס העצמאי**, ושומר את השגיאה היחסית המרבית. הוא בודק גם כיוון, ואינו דורש סריקת רגל לאחור בגלישה. מסלול חסר, חלקי או אפסי לקליפ תנועה אינו יכול לקבל אישור. המסלול בפועל הוא `state.referenceRootMotion`, בתוספת תנועת Root המקומית; הייחוס העצמאי הוא `state.skating.referenceRootMotion`, שנבנה מדרישת המהירות המקורית.

בפניות, רציפות הכניסה והיציאה נבדקת במסגרת כיוון השורש: מסירים את סיבוב השורש מסמני הגוף כפי שכבר נעשה בסיבובי העצמות המקוריים. נשמרים גובה הגוף, פוזת האיברים, סיבוביהם ומהירויותיהם. שינוי כיוון העולם לבדו אינו שגיאת תנוחה; שגיאת יד או ירך עדיין נמדדת.

## השוואה ואימות

`--legacy` מכבה את מודל הלהב ואת נרמול סמני הגוף לפי כיוון השורש. כך נרשמת תוצאה נפרדת של נוסחאות המקור על אותם קליפים שנבנו מחדש. קו הבסיס `hockey-v1` משחזר את כל ערכי המדדים והציונים שפורסמו ב־PR #419. אין להציג את ציוני שני המודלים כאילו חושבו באותה נוסחה.

הבדיקות כוללות גלישה חוקית מול כשלים מכוונים: מישור מוטה, להב מרחף, החלקה רוחבית אסורה, מסלול בלימה שגוי/חסר, שגיאת מהירות וכיוון, מסלול אפסי/חסר, חלונות מגע מקוצרים ועוגן פירואט נע. בדיקות רגרסיה משוות את תוצאות מגע הרגל הנטועה לעותק המקורי הנעול. בדיקת משטחי GLB מלאה והאימות החזותי הם חלק מ־[מסירת ההוקי](../hockey-v2/REPORT-fix.md), ונפרדים ממדדי השלד האלה.
