לצפייה:

1. לפתוח את [index.html](index.html) בדפדפן, ישירות מהדיסק או בשרת הקבצים המקומי של המאגר.
2. לבחור בסרגל: כדורגל, כדורסל, סקי, פרסים, שחקן, תוצאה, מדי כדורגל או מדי כדורסל. בטלפון אפשר לגלול את הסרגל אופקית; במקלדת Tab ואז מקשי החצים בוחרים מסך.
3. לבדוק ברוחב 844×390 ובאורך 390×844. המסכים אמורים להישאר קריאים; קטלוג התלבושות גולל אנכית. בהגדלת טקסט מותרת גלילה אנכית בכל מסך.

הקישורים למסכי המגרש פותחים את אב־הטיפוס הקיים בחבילת העיצוב. הם אינם מפעילים משחק. כל שמונת המסכים מקומיים, ללא JavaScript, רשת, גופן חיצוני או גישה לשמירות.

## שילוב עתידי

- כל המלל, כולל שמות המסכים, תוויות המדליות ונתוני השחקן, נשאר ב־HTML/DOM. אין `text`, מספר חולצה, נתיב אותיות או טקסט כתמונה בתוך ה־SVG. נגישות התמונות ניתנת בשכבת ה־HTML באמצעות `alt` או כיתוב סמוך.
- עברית ב־`dir="rtl"`; מספרים ותוצאה ב־`bdi dir="ltr"` או `dir="ltr"`, עם ספרות tabular. אין לשקף איור, כדור, חולצה או סמל בגלל RTL. סדר הקטלוג מתחיל בצד ימין.
- אזורי כיסוי בכרטיס במערכת 360×480: תווית ב־y=24–48, שם ב־y=222–256, שלושה מדדים ב־y=282–390, הערה ב־y=426–458. שטח החולצה y=56–212 דקורטיבי. דוגמת מיקום יחסית ב־`preview.css`.
- במסגרת התוצאה: לשמור את הטקסט בטווח x=80–640, y=44–230. באורך, התצוגה מותחת רק את המסגרת הדקורטיבית לגובה מזערי 236px; הטקסט נשאר בגודל CSS קריא. אין להקטין צילום מסך שלם כדי להתאימו לטלפון.
- התלבושות הן ספרייטים שטוחים של חזית הבגד עם שוליים שקופים, מכוונים למבט מקדים/בחירה או לייצוא 256px. אלה אינם מפות UV של מודל GLB מסוים. הלבשת דמות תלת־ממדית דורשת התאמת UV במשימת שילוב נפרדת.
- `manifest.json` כולל נתיב, מידות, hash ורישיון לכל נכס, ואת הזוגות והצבעים של כל סט. הוא תיעוד למסירה, אינו מיובא למשחק.
- גופני מערכת בלבד; גוף 16px, תוויות לפחות 14px, יעדי ניווט וקישורים לפחות 48px, safe area בכל הכיוונים. הרקעים מאחורי הטקסט אטומים. הפתיחות נבדלות בפלטה לפי מפרטי העיצוב הקיימים.

כל הקבצים חדשים תחת `workout/island/design/screens/`. אין חיבור לזמן הריצה, שינוי בלוגיקה, נתוני שמירה, vendor או תגי גרסה. תקרת החבילה: **2,000,000 בייטים לכל התיקייה**, כולל תיעוד וצילומי אימות; הספירה בפועל ב־VALIDATION.
