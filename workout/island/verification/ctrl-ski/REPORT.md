# סקי: שליטה ותגובה + ג'ויסטיק שמאל (ctrl-ski, 04/11/2026)

ענף `claude/ctrl-ski` (מ-main). לא נגעתי ב-`release.json`, `release.mjs` ובתגי `?v=`. לא נפתח PR.

## מה שונה
| נושא | שינוי |
|---|---|
| ג'ויסטיק | צף: נגיעה בחצי השמאלי של המסלול מציבה אותו מתחת לאגודל (`alpine-controls.mjs`). אם האגודל גולש מעבר ל-1.25 טווחים, המרכז נגרר איתו, כך שהיפוך כיוון קצר. המקש הקבוע עדיין עובד. אצבע שנייה על המסלול לא לוקחת את הג'ויסטיק. |
| צד | ג'ויסטיק תמיד שמאל, בוסט/טריקים תמיד ימין, בשני כיווני המסך. לא היה מתג בסקי (המתג הקיים שייך למשחקים אחרים), אז נוספו כללי CSS מפורשים ובדיקות שמוודאות שאין תלות בכיוון הדף או בערך שמור. לא נמחק אף מפתח שמירה. |
| תגובת הגוף | הגוף נטוי לפי הכוונה של השחקן (`intent`, מהג'ויסטיק אחרי expo) ולא לפי מהירות רוחבית שמגיעה 80ms אחר כך (`alpine-steer.mjs`). נטייה מהירה פנימה (24/שנ') וחזרה (13/שנ'), נטיית קרבון של הלוח לתוך הפנייה, גדלה עם המהירות. |
| פיזיקה | `lateralResponse` 9→12 (פחות החלקה), `turnPush` הוגדל באותו יחס כדי שהסטייה בפנייה בשיווי משקל נשארת זהה, `steerAttack` 18→24, `steerRelease` 22→26. בבוסט: קצב התגובה -30% (`steerBoostSoften`) ו-`lateralBoostDamp` 5%. |
| כפתורים | בוסט 66→92px לרוחב, 76→84px לאורך. כפתורי טריק 48→67px לרוחב. ג'ויסטיק 100→116 / 112→124px. |
| כלי מדידה | `tools/control-feel-alpine.mjs` (60Hz, אותה פיזיקה כמו המרוץ, `--root` למדידת עץ ישן). |

## לפני / אחרי (ms בסימולציה ב-60Hz, מרגע הצבת ערך הג'ויסטיק)
| מדד | לפני | אחרי |
|---|---|---|
| פנייה נראית בגוף (lean≥0.2) | 116.7 | 33.3 |
| פנייה נראית בגוף, בבוסט | 116.7 | 33.3 |
| פנייה נראית (סיבוב הגוף/השלד) | 133.3 | 33.3 |
| lean בפועל של המסלול (≥0.2) | 50 | 33.3 |
| המסלול זז 0.15 מ' | 83.3 | 66.7 |
| כיוון אחרי 100ms (מעלות) | 12.8 | 16.2 |
| כיוון אחרי 250ms (מעלות) | 20.8 | 22.1 |
| קצב פנייה ב-300ms (°/שנ') | 72 | 75 |
| חזרה לקו ישר אחרי שחרור | 283.3 | 216.7 |
| הגוף חוזר זקוף אחרי שחרור | 450 | 283.3 |
| היפוך כיוון (ימין→שמאל) | 150 | 100 |
| בוסט: התחלה | 16.7 | 16.7 |
| בוסט: +10% מהירות | 166.7 | 166.7 |
| נפילה: עד פנייה נראית אחרי ההיתקלות | 1633.3 | 1550 |

פנייה נראית = נטייה מוצגת >= 0.2 (הסף שהקוד עצמו קורא לו "קרבון").
ההשהיה מקצה לקצה במקרה הגרוע = 33.3 + פריים אחד לדגימה + פריים אחד לתצוגה = **67ms ≤ 100ms** (לפני: 117 + 33 = 150ms).
בוסט: הנטייה הנראית 117→33ms. מה שלא השתנה: התחלת בוסט (פריים אחד) ועלייה של 10% במהירות (167ms), כי לא שיניתי מהירויות.
חדות הבוסט: ירידה בקצב התגובה בלבד. עקומת expo מתונה יותר בבוסט הגדילה התרסקויות של הטייס האוטומטי (22→34 ב-36 מרוצים), לכן לא נכנסה.
