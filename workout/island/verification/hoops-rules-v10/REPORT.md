# כדורסל: כללי כדרור וצעדים, מסירות ה-AI, רעש רקע (v10)

ענף: `claude/hoops-rules-v10`. לא נגעתי ב-`release.json`, `release.mjs` ובתגי `?v=`, ולא בגרפיקה של שחקנים או אולם.

## 1. רעש הרקע
| מה נבדק | ממצא |
|---|---|
| הקלטת Web Audio בדפדפן (Chromium) | אין אוסצילטורים. הצליל היחיד שפועל ברציפות הוא `basketball/ambience-loop` (לולאה של 24 שניות, רעש אולם מסונתז) |
| מה זה "שריקה" | לולאת הרעש הקבועה (180 עד 5000 הרץ) שומעים כרשרוש חד ורציף. שריקת השופט האמיתית (`whistle.ogg`) קצרה, 0.37 שניות |
| תיקון | הלולאה לא מופעלת יותר. קהל נשמע רק באירועים (סל, סיום), שריקה רק בעבירה/הפרה/קפיצה/פסק זמן |
| בדיקה | `metrics().loops` = מספר צמתי לולאה פעילים. הבדיקה מוודאת: 0 לולאות, 0 אוסצילטורים, אין `ambience`, ושריקה מנגנת פעם אחת בהפרה |

## 2. כללי כדרור וצעדים
| כלל | מימוש |
|---|---|
| עצירת כדרור | פייק (הטעיית זריקה) מחזיק את הכדור בשתי ידיים: `gather`. עד שהכדור משוחרר (מסירה/קליעה/איבוד) אין כדרור |
| כדרור כפול | ניסיון כדרור (תרגיל/ספין/הצלבה) אחרי עצירה = הפרה `doubleDribble`, איבוד כדור, הודעה "כדרור כפול" וצפירה אחת |
| צעדים | בלי כדרור מותרים 2 צעדים (0.75 מ' כל אחד). הצעד השלישי = `travel`, איבוד כדור, הודעה "צעדים" וצפירה אחת |
| חלון חסד | בזמן קליעה או מסירה לא נספרים צעדים; 2 צעדים לפני קליעה חוקיים |
| עמידה/פיבוט במקום | חופשי, לא נספר |
| ממשק | כפתור התרגיל נכבה (גם קיצור R) כשאין כדרור; חיווי "אין כדרור" / "צעד X מתוך 2" בצבעים ירוק, צהוב, כתום |
| AI | אותם כללים במנוע. אם ל-AI אין כדרור הוא קולע או מוסר מיד, לא הולך עם הכדור. הכללים לא נוגעים בקליעה/מסירה/חטיפה הקיימות |

## 3. מסירות ה-AI (24 משחקי הדלס, seed קבוע, `measure.mjs`)
"לפני" = `main` העדכני (כבר כולל את לוגיקת `passReason` של v4). "אחרי" = אותו קוד עם תקרת שרשרת מסירות ודרישת התקדמות.

| מדד | לפני | אחרי | יעד |
|---|---|---|---|
| מסירות להתקפה | 3.49 | **2.12** | ≤ 2.5 |
| מסירות לרוחב/אחורה | 35% | **22.7%** | ≤ 30% |
| זמן התקפה (שנ') | 10.3 | 13.5 | |
| קליעות לסל (FG%) | 49.5% | 49% | בלי ירידה משמעותית |
| שלשות | 33.5% | 40.7% | |
| ניסיונות קליעה להתקפה | 0.91 | 1.01 | |
| נקודות להתקפה | 1.01 | 1.05 | |

מה השתנה: עד מסירה אחת ברצף בלי לחץ ושתיים תחת לחץ, מסירה שלא מתקדמת מטר לפחות אל הסל מותרת רק תחת לחץ חזק או בסוף השעון, שעון ההתקפה מוריד את סף הקליעה, ומי שמחכה מתקרב לסל. שחקן לא עומד בצבע מעל 1.7 שניות.
