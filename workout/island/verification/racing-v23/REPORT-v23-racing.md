## 1. בלי קירות
- **פיזיקה**: הסשן שולח `walls:false` כברירת מחדל (`racingWallsOn()` ב-`minigames/racing-offtrack.mjs`). המודל הטהור לא השתנה: בלי `config.walls` הוא עדיין עם קיר, כך שכל הבדיקות והסימולציות הישנות בודקות את מה שבדקו.
- **ציור**: 355 קטעי מחסום ו-106 קטעי מעקה בשלב 1 לא נבנים, וגם המעקות במדרונות. לכל שכבה של עצמים בצד הדרך נוסף פרמטר `clear` (0 = המיקום הישן): `racing-roadside`, `racing-f1`, `racing-env-v2`, `racing-scenery`, `racing-v7` (יציע וצופים), עצים ב-`racing-view`. כל עצם נבדק מול כל חלקי המסלול (בסיבוב חד חלק אחר של המסלול עובר קרוב), ואם הוא קרוב מדי הוא זז או לא נבנה.
- **עמודים**: רגלי שתי הקשתות ורגלי שער הזינוק הן הדבר המוצק היחיד בתוך אזור השוליים. התצוגה מוסרת למודל רק את הרגליים שהיא ציירה (`view.obstacles()` ← `model.setObstacles()`). נגיעה מאטה כמו נגיעה בגדר, פגיעה חזיתית חזקה מהפכת. עם `?racingWalls=1` אין עמודים במודל (כמו קודם).
- **מדידה** (`clear-zone-open.json`, `clear-zone-walls.json`): עם קירות העצם הקרוב 0 עד 0.65 מ' מהאספלט; בלי קירות 9.45 מ' לכל הפחות בכל 30 השלבים.
- **בונוס**: שלב 1 באיכות 0: משולשי שכבת הדרך 17,300 ← 4,492 (בלי המחסום והמעקות).

למה א: הכי נקי במדידה, ובמסלולי v2 יש הרבה העברות (בוט מיומן: כ-28 בהקפה), אז הצליל צריך להיות עדין. ב ו-ג "כיפיים" יותר, ושווה שרועי ישמע.

## איך בודקים בטלפון (אחרי מיזוג והעלאת גרסה באיחוד)
קישור למשחק:
```
https://roynaor-work.github.io/Bakasun/workout/island/
```
קישור לדף ההשוואה של צליל ההילוך:
```
https://roynaor-work.github.io/Bakasun/workout/island/tools/racing-shift-compare.html
```
1. פותחים את דף ההשוואה, לוחצים "להפעיל צליל", ואז "לשמוע" בכל אחת מארבע השורות. בוחרים א, ב או ג.
2. פותחים את המשחק ← מרוצים ← ליגה ← "המרוץ הבא". מחכים לנורות ונוסעים.
3. בסיבוב: יוצאים קצת לאספלט האפור שבצד. המכונית מאטה, ואפשר לחזור לכביש בלי התהפכות.
4. בורחים חזק הצידה, עמוק לחצץ. המכונית מתהפכת פעמיים באוויר, עפה אל אמצע הכביש ונוחתת עומדת. מופיע "חזרה למסלול". לוחצים גז ונוסעים.
5. בכל המרוץ אין קיר בצד הדרך, ושום עצם לא נמצא על הדרך או נוגע בה. בשער הזינוק ובקשתות אפשר להיתקל ברגל של השער (מאט, לא עובר דרכו).
6. כדי לנסות צליל אחר במשחק: מוסיפים לכתובת
```
?racingShift=b
```
(או `c`). כדי לבדוק את הקירות הישנים ואת תיקון "המסך נעלם":
```
https://roynaor-work.github.io/Bakasun/workout/island/?racingWalls=1
```
ולהיתקע בקיר בכוונה: המסך לא נעלם.

התוצאה הרצויה: מרוץ פתוח בלי קירות. יציאה גדולה נגמרת בהתהפכות יפה וחזרה לאמצע, יציאה קטנה רק מאטה. המסך לא נעלם אף פעם, וצליל ההילוך נעים.
