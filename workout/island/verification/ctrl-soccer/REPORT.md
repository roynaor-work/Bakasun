## 2. מדידות "לפני / אחרי"
מדידה א (הדלסית, `tools/ctrl-soccer-sim.mjs`, הזיהוי האמיתי + המנוע האמיתי, 60Hz, `sim-before.json` / `sim-after.json`). מדידה ב (דפדפן אמיתי, `tools/ctrl-soccer-browser.mjs`, שעון עמוד מבוקר, `before-default/browser.json` / `after/browser.json`).

| מדד | לפני | אחרי |
|---|---|---|
| הטיית ג'ויסטיק עד תנועה ראשונה בדגם (פריימים / ms) | 1 / 23-25 ms (דפדפן) | 1 / 17-21 ms |
| עד תנועה נראית (5 ס"מ מוצגים), דפדפן | 39-41 ms | 33-37 ms |

| היפוך כיוון מלא (ימין לשמאל), עד מהירות שלילית | 83 ms | 50 ms |

| עקומת תגובה | ליניארית, מהירות מלאה רק בקצה (52px) | מהירות מלאה ב-80% (42px), expo 1.25 לדיוק בטווח הנמוך. ספרינט באצבע אחת עדיין לפי הטיה פיזית ≥ 90% (לא קל יותר) |
| Multi-touch (ג'ויסטיק + ספרינט + בעיטה) | נרשמים ביחד בדגימה אחת | זהה, בדוק בדפדפן ובבדיקה |

| כוונה: החלקה ידנית נשמרת אחרי שחרור | כן | כן (בדוק) |

קריטריון ≤ 100 ms מהמגע לתגובה נראית: **עבר** (33-37 ms בדפדפן, 50 ms הדלסית). חלק מהזמן הוא פריים אחד של אינטרפולציית הרינדור (`renderState`), שלא שיניתי.

### ביצועים (`tools/perf-soccer.html`, 20 שניות, איכות 2, 844×390)

| ריצה | tick ממוצע / p50 / p95 (ms) | render p50 (ms) |

| לפני, ריצה 1 / 2 | 4.01 / 2.1 / 15.0 , 3.38 / 1.7 / 13.9 | 5.4 , 5.3 |
| אחרי, ריצה 1 / 2 | 2.39 / 1.2 / 10.3 , 3.97 / 2.0 / 14.6 | 4.0 , 4.3 |

אין ירידה (ההפרשים בתוך הרעש בין ריצות). צריכת זיכרון זהה (0 MB/s). בטלפון אמיתי לא נבדק.

## 3. מה שונה בקוד
| קובץ | שינוי |
|---|---|
| `minigames/soccer-session.mjs` | `handed=true` תמיד, הסרת קריאת `island.soccer.handed`, רפידת מגע (`soccer-stick-pad`) בגודל לפי `config.controls.stick.pad*`, רטט קל בבעיטה/מסירה/החלפה, הרפידה מושבתת בזמן שידור חוזר (כדי שנגיעה תדלג עליו) |
| `minigames/soccer-design-controls.mjs` | ג'ויסטיק צף: הנגיעה בכל מקום ברפידה השמאלית מציבה אותו תחת האגודל (נשאר בתוך הרפידה), שחרור מחזיר אותו הביתה. `shapeStick`: אזור מת, רוויה ו-expo. ללא `feel` נשאר ליניארי כמו קודם |
| `minigames/soccer.mjs` | `players.controlled`: תאוצה/האטה/סיבוב מהירים יותר רק לשחקן הנשלט של קבוצה 0 (ה-AI ללא שינוי); הקשה בסוף cooldown נשמרת בחלון הקלט במקום ליפול |
| `data/config.json` | `players.controlled` (22 / 17 / 18 במקום 12 / 10 / 14), `controls.stick` (deadZone .06, saturation .8, expo 1.25, גדלי הרפידה), `controls.vibrate` |
| `minigames/soccer-controls-assets.css`, `soccer-controls.css`, `styles.css` | סגנון הרפידה, הסרת `left-handed` של כדורגל |
| `ui/activity.mjs` | המתג הוסר לכדורגל (נשאר לטניס) |
| `tests/g3d-browser.mjs`, `tests/g3e-browser.mjs` | בדיקות המתג הוחלפו: אין מתג, ערך שמור `left` מתעלם |
| `tests/island-soccer-ctrl.test.mjs` (חדש, 8 בדיקות) | פריסה בשני כיווני מסך, עקומת הג'ויסטיק, ספרינט לפי הטיה פיזית, מגע עד תנועה ≤ 6 פריימים, עצירה, multi-touch, חלון cooldown, שמירת כוונה |
| `tools/ctrl-soccer-sim.mjs`, `tools/ctrl-soccer-browser.mjs` (חדשים) | כלי המדידה (הדלסי ודפדפן), לחזור עליהם אחרי שינוי |

לא שיניתי ספי קושי: מהירות מקסימלית, ספרינט (עלות/סף), טווחי בעיטה/מסירה, סיוע כוונה, AI של היריב וזמני החלפה נשארו. התאוצה המוגברת היא לשחקן שרועי שולט בו בלבד.

## 5. בטיחות פריסה (בקשת רועי: "הג'ויסטיק קפץ ימינה ונמצא מתחת לכפתורים")
הרפידה נחתכת עכשיו לפי הכפתור השמאלי ביותר (רווח 8px), לכן אין חפיפה. `.soccer-actions` מעל הרפידה ב-z-index. בדיקה אוטומטית ב-`tests/island-soccer-ctrl.test.mjs` (390×844, 844×390, 360×740, 320×568, 740×360) ובדפדפן אמיתי (`tools/ctrl-soccer-browser.mjs`, `VIEWPORTS=...`):

| בדיקה | תוצאה בארבעת הגדלים |
|---|---|
| הרפידה לא נחתכת עם כפתורי הפעולה וההשהיה | עבר |
| כפתורי הפעולה מעל הרפידה (elementFromPoint) | עבר |
| מגע בפינות הרפידה: הג'ויסטיק נשאר בתוכה | עבר |
| מגע בחצי הימני לא מזיז אותו | עבר |
| הפסקה והמשך: חוזר למקום | עבר |
| ערך `left` שמור | מתעלמים |
| סיבוב מסך באמצע משחק | לא נבדק: `setViewportSize` נכשל בקונטיינר (שגיאת סביבה). שני הכיוונים נבדקו בנפרד, וגם `resize` מאפס את הג'ויסטיק למקומו בקוד |
