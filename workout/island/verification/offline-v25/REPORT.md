# אופליין v25 · "הכול מקומי, אינטרנט כאפשרות"

ענף `claude/offline-v25` מ-`origin/main` (קומיט `43b27dc2`, גרסה `island-v2-20261107-15`). לא נגעתי ב-`release.json`, ב-`CHANGELOG.md`, ב-`ops/CONTROL.md` ובתגי `?v=` קיימים. דגל חזרה לכל ההתנהגות: `?offlineV25=0`.

## ההנחיה של רועי

"שהכל יהיה כמה שיותר מקומי, עם אינטרנט כאפשרות או שמירה ואז עדכון... או עדכון גרסה או כל פעם מחיקה של הגרסה הישנה בנייד... התקנה קבועה."

## מה נבנה

| רכיב | קובץ | מה השתנה |
|---|---|---|
| מניפסט עם חתימות | `offline-manifest.json` (סכמה 2), `tools/offline-shell.mjs` | לכל קובץ `[sha256 של 16 תווים, גודל]`; הכלי מחשב גם את החתימות; בדיקה נופלת כשהן לא מעודכנות |
| הורדה מאומתת | `ui/offline.mjs` `downloadSet` | כל קובץ שיורד מאומת מול החתימה (WebCrypto); קובץ שגוי לא נכנס למטמון; "הורדה מחדש (בדיקת קבצים)" מגבב גם את מה שכבר שמור ומחליף פגומים |
| חבילה לכל משחק | `ui/offline.mjs` `PACKS_OF`, `deletePack`, `removablePaths`; `ui/offline-panel.mjs` | שורה לכל משחק: גודל, מצב (לא הורד / חלקי / בהורדה / מוכן / יש עדכון), הורדה ומחיקה; מחיקה לא נוגעת בקובץ שמשחק אחר שמור צריך |
| הורדה אוטומטית עדינה | `startAutoDownload`, `autoPolicy`, `packsForGames` | קודם האפליקציה (14 MB), אחר כך רק חבילות המשחקים ששוחקו (ברירת מחדל: כדורגל, כדורסל, סקי, העיר); קובץ אחד בכל פעם, עצירה בזמן משחק, דילוג על חיסכון בנתונים ו-2G, בסלולרי רק האפליקציה |
| עדכון חלקי | `prefetchRelease`, `planRelease`, `switchRelease`; `app.mjs` | גרסה חדשה: קבצים שחתימתם זהה מועתקים מהמטמון הנוכחי (אחרי גיבוב של העותק), רק השונים יורדים; כשמוכן, מתוך האי פנוי, העובד החדש נרשם, מוחק את המטמון הישן, והדף נטען מחדש |
| עובד: קודם מהמכשיר | `offline-sw.js` (`&v25=1`) | קוד, עיצוב ונתונים מהמטמון; מהרשת רק כשחסר (ונשמר); `release.json` ומניפסט של גרסה אחרת תמיד מהרשת |
| אחסון קבוע | `persistStorage`, `storageInfo`, הפאנל | `navigator.storage.persist()` אחרי הורדה; שורת "באחסון המכשיר X MB · פנוי Y GB · שמירה קבועה כן/לא" וכפתור כשהדפדפן סירב |
| התקנה | `ui/offline-install.mjs`, הפאנל | כפתור "התקנת האפליקציה" כשיש `beforeinstallprompt`; הסבר ל-iOS (שיתוף ← הוספה למסך הבית) ולתפריט הדפדפן; בדיקה שה-`manifest.webmanifest` מתאים להתקנה |
| עיצוב הפאנל | `ui/offline-panel.css` | קובץ חדש, מקושר מ-`index.html` עם התג הנוכחי |
