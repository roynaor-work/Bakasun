# כדורסל v4: חיבור החמישייה והאולם (02/11/2026)

ענף `claude/hoops-assets-v7`. הנכסים של Codex ב־`design/hoops-v4/` לא שונו. פירוט הנכסים: `ASSETS.md`, בדיקות: `tests/island-hoops-v4.test.mjs`, בדיקת דפדפן תחת CSP: `tests/island-browser-csp.test.mjs`.

## מה חובר

| נושא | החלטה |
|---|---|
| גוף לפי עמדה | `card.pos` בוחר אחד מחמשת הגופים (PG, SG, SF, PF, C). הגובה בפועל נשאר `ratings.height` (קנה מידה לפי גובה הגוף), לכן הפיזיקה, ההגעה לסל והחסימות לא משתנות |
| טעינה | לא נטענים 27K משולשים לשחקן: `tools/hoops-build-v4-lod.mjs` מקטין כל גוף ל־5.2K עד 5.8K משולשים (אותו אלגוריתם של ה־LOD הקיים), אותו שלד של 52 עצמות, אותם חומרים. הקבצים המקוריים של Codex לא נטענים במשחק |
| תנועה | נשארים 24 הקליפים של v3 והשכבות הידניות (כדרור, חטיפה, חסימה, מסירה), כי ל־v4 יש רק שישה קליפים. מסלול הירך בקליפים מוגדל לפי גובה הירך של כל גוף (`hipScaledClips`). בלי זה כפות הרגליים של ה־PG ריחפו 10 ס״מ וה־C שקע 16 ס״מ בפרקט |
| מדים | חולצה עם מספר ושם (UV מישורי שנוצר בטעינה, אותו גיליון של v3), מכנסיים בצבע הקבוצה, פס בצבע המשני. בלי סמל |
| אולם | `hoops-v4-arena-lod.glb`: אותו אולם של v3 ועוד 489 צופים תלת־ממדיים במקום תמונות. הקהל מופחת מ־189K ל־85K משולשים, ונחתך בטעינה ל־8 חלקים כדי שהמצלמה תוריד את מה שלא נראה. מאיכות 2 ומעלה; איכות 0 ו־1 נשארות עם האולם הישן |
| נפילה שקטה | כשל בטעינת גוף או אולם חוזר לנכסי v3 בלי עצירה (אזהרה בקונסול, `renderMetrics.v4Fallbacks`). `?hoopsV4=0` מכריח v3, `?hoopsV4=1` מכריח v4, `assets.v4.enabled` בקונפיג מכבה הכול |
| שמירות | לא נגענו: גרסת שמירה 18, מנוע, יכולות |

## מדידות (תוכנה, Chromium SwiftShader; מעבד ולא טלפון)

| מדד | לפני (v3) | אחרי (v4) |
|---|---:|---:|
| משולשים, לרוחב 844×390 | 60,949 | 121,315 |
| משולשים, לאורך 390×844 | 59,240 | 106,564 |
| קריאות ציור, לרוחב / לאורך | 47 / 41 | 47 / 42 |
| זמן CPU לפריים (tick ממוצע), לרוחב / לאורך | 7.07 / 32.6* | 8.17 / 20.8* |
| FPS מעבד בלבד (`dpr=0.15`), לרוחב / לאורך | 8.87 / 10.25 | 6.54 / 8.66 |
| טעינה בתוכנה, לרוחב / לאורך | 13.3 / 10.2 שנ׳ | 13.8 / 10.3 שנ׳ |

\* בלי `dpr` נמוך הרסטר בתוכנה שולט והמספרים רועשים בין הרצות. הרצה ראשונה לפני השינוי הראתה 5.7 מ״ש רינדור ו־7.75 מ״ש tick בלרוחב. המדידה לא מעידה על GPU של טלפון: היא מראה ש־v4 יקר בערך 15% ב־CPU ובערך 2× במשולשים. הקהל הוא רשת סטטית בלי עצמות, ולכן העלות בטלפון היא בעיקר קודקודים.

## צילומים (לפני / אחרי)

`before-v3-*` ו־`after-v4-*`, שני כיוונים, שלוש נקודות מצלמה (שידור, קרוב, רחב).

## לא נבדק בטלפון

FPS אמיתי ו־GPU, חום, זיכרון ו־GC במכשיר חלש, זמן טעינה ברשת סלולרית, מגע. סיכון ידוע: 120K משולשים סטטיים בלרוחב; אם הטלפון נתקע, `arenaMinQuality` בקונפיג מעלה את סף האולם התלת־ממדי ל־3 (כלומר כבוי) בלי שינוי קוד.
