# G8 — מעטפת ותיקון לפני מיזוג PR 142

הענף `codex/g8-shell` מוזג תחילה עם main `54abefb`, ובהמשך עם `c26a09a`. הבסיס כולל את PR 147, PR 143, PR 146 ופיילוט Meshy מ־PR 141, ואת PR 140 של הקרב הימי שנכנס במהלך האימות. גם בדיקת G6c החדשה נכללת בטבלה. התנגשות סוף `strings.he.json` נפתרה תוך שמירת כל מפתחות `shell.*` ו־`alien.*`, וגרסאות העזרה העדכניות של main.

בקשת המסך המלא מופעלת בלחיצת הכניסה המקורית, על `documentElement`. המסך המלא נשמר במעבר בין משחקים; נגיעה בפקד, סיבוב והמשך אינם מבקשים אותו שוב. נוספו התקנה לפני המשחק ובהגדרות, טיפול ב־`beforeinstallprompt` והסבר מאויר ל־iOS; ה־manifest של היישום משתמש ב־fullscreen/landscape ובאייקונים המקומיים. עדכון ציפיות ה־manifest בלבד ב־`tests/island-install.test.mjs` אושר בצ׳אט, ובדיקות ה־PNG נשמרו.

## התאמות המיזוג

ההכנה במשחק נשארה: שתי טבעות ושני צעדים של `ui.economyTickMs`. הסימולציה והפקדים מושהים עד סיומה. `shell-ready.mjs` מקדם את השעון המדומה עד `dialog.dataset.starting === 'false'`; העוזר המשותף `night-browser.mjs` וכל מסלולי הכניסה הישנים משתמשים בו, כולל המשך שלב, ניסיון חוזר וכניסה לתרגול. פריים קצר לפני דילוגי הזמן משלים מדידת לחיצה ממתינה, כדי שהדילוג לא יירשם כזמן תגובה של שנייה. המתנה לניווט מקדמת RAF בשעון המושהה.

ריצת כל הבדיקות חשפה גם ציפיות שקדמו ל־main הנוכחי. התרחישים עודכנו לשדרוג בהאנגר, שמונה שחקנים ופקד החלפה בכדורגל, ג׳ויסטיק צף, שישה כלי נשק וירי בשחרור דרך פקדי הקרב הימי, הגשה בשתי לחיצות בטניס ויציאה דרך מסך ההשהיה. בדיקת נכסי הצי משתמשת ב־seed קבוע לסירת הסיור המבוססת על GLB, ובודקת התאמת גודל רק לספינות שטוענות מודל. בדיקות הכיבוי מציבות מצבי לחץ/מיקום דטרמיניסטיים דרך מודל הייצור וממשיכות לבדוק את הפקדים, החילוץ, התוצאה והגיבוי. בדיקת האימון השעתי נשארה דרך API המנוע, לצד אימות תפריט התרגילים החדש. מוני המודלים ואורכי הספינות נבדקים לפי הסוגים והגדלים המוגדרים בנתוני המשחק. תקציבי הרינדור בבדיקות הישנות תואמים להגדרות שנמצאות ב־main; לא שונו משחקים או פיזיקה לצורך העברת הבדיקות.

`g8-browser.mjs` נוגע בכפתור הגלוי הראשון בתוך `.game-controls`. אין בו בורר ירי או טעינה של משחק מסוים. מעטפת ה־CSS משאירה את מונה הטילים ואת אייקוני השער והחוץ של המשחקים העדכניים גלויים, לצד המספרים ומדי האנרגיה. שמות נגישים נשמרים גם כשהתווית החזותית היא אייקון.

נמחקו `knownFiles`, בדיקת רשימת הקבצים הסגורה ודרישת מינימום 54 המודלים. בדיקת 15MB לכל התיקייה נשארה מוסרת. כל GLB עדיין מוגבל ל־2,000,000 בתים. בדיקת PR 147, `island bundles only referenced game models and preserves their audited bytes`, וכן `assets/models/manifest.json`, זהים בבייטים ל־main. נשמר ניקוי המודלים של PR 147. PR 140 החזיר דרך main שני מודלי ספינות שנמצאים כעת בשימוש ומופיעים ב־manifest; אין שחזור או חריג מקומי שלי.

`DATA_VERSION`, ערכי `?v=`, ‏`CURRENT_VERSION`, ‏`CHANGELOG.md` ו־`QA.md` לא שונו. סכימת השמירה וקובצי ה־GLB וה־vendor זהים ל־main; שאר האתר נשמר ללא שינוי.

## תקציבי הורדה

המקור היחיד הוא `data/config.json` תחת `ui.downloadBudget`: ‏`city: 8000000`, ‏`gameAdditional: 6000000`. גם G8 וגם `task017-pilot-browser.mjs` קוראים משם; אין תקציב עיר של 6MB הכתוב בקוד הפיילוט.

G8 מודד כל משחק ב־context חדש אחרי טעינת עיר חדשה. נספרים גוף התשובה וכותרותיה של כל בקשת HTTP שהסתיימה, כולל בקשות חוזרות, באמצעות `request.sizes()`. השרת המקומי אינו דוחס או שומר בקאש. ריצת 844×390 אחרי המיזוג:

[דוח G8 מפורט](../verification/g8/844-verification.json). בבדיקה נבדקו לחיצה מהימנה עם user activation, בקשה אחת למסך מלא ברצף חמשת המשחקים, הכנה ללא התקדמות סימולציה, סיבוב, אחורה/המשך/יציאה וסירוב/API חסר/מצב מותקן/iOS בהזרקה. אפס שגיאות דפדפן ואפס בקשות מחוץ לאי. שבע תמונות G8 נשמרות ב־`verification/g8/`; G8 עבר גם ב־740×360 וב־1440×1000 מול אותו main: [דוח 740](../verification/g8/740-verification.json), [דוח 1440](../verification/g8/1440-verification.json).
