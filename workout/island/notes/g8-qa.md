# G8 — מעטפת ותיקון לפני מיזוג PR 142

הענף `codex/g8-shell` מוזג עם main העדכני `d61f650`, אחרי המיזוגים הקודמים של `54abefb` ו־`c26a09a`. הבסיס כולל כעת גם את PR 144 של הטניס ו־PR 145 של הכיבוי, נוסף על PR 147, PR 143, PR 146, פיילוט Meshy מ־PR 141 והקרב הימי מ־PR 140. המיזוג האחרון עבר ללא התנגשויות. נשמרו כל מפתחות `shell.*` ו־`alien.*` וכל ערכי התרגום העדכניים של main.

בקשת המסך המלא מופעלת בלחיצת הכניסה המקורית, על `documentElement`. המסך המלא נשמר במעבר בין משחקים; נגיעה בפקד, סיבוב והמשך אינם מבקשים אותו שוב. נוספו התקנה לפני המשחק ובהגדרות, טיפול ב־`beforeinstallprompt` והסבר מאויר ל־iOS; ה־manifest של היישום משתמש ב־fullscreen/landscape ובאייקונים המקומיים. עדכון ציפיות ה־manifest בלבד ב־`tests/island-install.test.mjs` אושר בצ׳אט, ובדיקות ה־PNG נשמרו.

## התאמות המיזוג

ההכנה במשחק נשארה: שתי טבעות ושני צעדים של `ui.economyTickMs`. הסימולציה והפקדים מושהים עד סיומה. `shell-ready.mjs` מקדם את השעון המדומה עד `dialog.dataset.starting === 'false'`; העוזר המשותף `night-browser.mjs` וכל מסלולי הכניסה הישנים משתמשים בו, כולל המשך שלב, ניסיון חוזר וכניסה לתרגול. פריים קצר לפני דילוגי הזמן משלים מדידת לחיצה ממתינה, כדי שהדילוג לא יירשם כזמן תגובה של שנייה. המתנה לניווט מקדמת RAF בשעון המושהה.

ריצת כל הבדיקות חשפה גם ציפיות שקדמו ל־main הנוכחי. התרחישים עודכנו לשדרוג בהאנגר, שמונה שחקנים ופקד החלפה בכדורגל, ג׳ויסטיק צף, שישה כלי נשק וירי בשחרור דרך פקדי הקרב הימי, הגשה בשתי לחיצות בטניס ויציאה דרך מסך ההשהיה. בדיקת נכסי הצי משתמשת ב־seed קבוע לסירת הסיור המבוססת על GLB, ובודקת התאמת גודל רק לספינות שטוענות מודל. בדיקות הכיבוי מציבות מצבי לחץ/מיקום דטרמיניסטיים דרך מודל הייצור וממשיכות לבדוק את הפקדים, החילוץ, התוצאה והגיבוי. בדיקת האימון השעתי נשארה דרך API המנוע, לצד אימות תפריט התרגילים החדש. מוני המודלים ואורכי הספינות נבדקים לפי הסוגים והגדלים המוגדרים בנתוני המשחק. תקציבי הרינדור בבדיקות הישנות תואמים להגדרות שנמצאות ב־main; לא שונו משחקים או פיזיקה לצורך העברת הבדיקות.

`g8-browser.mjs` נוגע בכפתור הגלוי הראשון בתוך `.game-controls`. אין בו בורר ירי או טעינה של משחק מסוים. מעטפת ה־CSS משאירה את מונה הטילים ואת אייקוני השער והחוץ של המשחקים העדכניים גלויים, לצד המספרים ומדי האנרגיה. שמות נגישים נשמרים גם כשהתווית החזותית היא אייקון.

לאחר PR 145 הותאמו G2f ו־G2g לשאיבת הלחץ האוטומטית בזמן המתנה במקום כפתור הטעינה שהוסר, ולנסיעה ברשת הכבישים אל ברז הכיבוי. ב־TASK016 מספר כשלי הטעינה המוזרקים בסצנת הכיבוי מחושב מקבוצת נתיבי המודלים שהסצנה טוענת ומהתבנית הקיימת של ששת הקבצים הפגומים; העיר החדשה משתמשת גם במודלי הבית והחנות, כך שהציפייה הישנה לכשל יחיד כבר אינה תקפה. G2g בודק נסיעה באמצעות הג׳ויסטיק, תיאום נקודות למשטח המשחק המלא ותקציבי רינדור מה־config. בדיקות גודל הפקדים משקפות את הכפתור הקטן בגודל 54px ואת כפתור ההשהיה בגודל 48px של הכיבוי; כפתורים מוסתרים אינם נמדדים כפקדים פעילים. ב־G3d איסוף כדור חופשי ממתין לצעד הסימולציה הבא בגבול של שמונה פריימים, ומאמת העברת שליטה מיד בתצפית הראשונה על האיסוף; השהיה קבועה של 20ms הייתה תלויה במיקום פריים ה־RAF.

לאחר PR 144, המחלקה `tennis-serve-hint` שייכת ל־SVG של סמל ההגשה בתוך `#pass`. היא הוסרה מכלל ההסתרה ב־`ui/game-shell.css`; הנראות נשלטת ב־`tennis.css`. ציפיית G4c עודכנה לאמת שהסמל גלוי במצב `serve-ready`, לצד בדיקת G4d. לא נערכו קובצי המשחק בטניס.

נמחקו `knownFiles`, בדיקת רשימת הקבצים הסגורה ודרישת מינימום 54 המודלים. בדיקת 15MB לכל התיקייה נשארה מוסרת. כל GLB עדיין מוגבל ל־2,000,000 בתים. בדיקת PR 147, `island bundles only referenced game models and preserves their audited bytes`, וכן `assets/models/manifest.json`, זהים בבייטים ל־main. מודלי הספינות, הטניס והכיבוי שנוספו אחרי PR 147 הגיעו דרך main ונכללים ב־manifest העדכני; אין שחזור או חריג מקומי שלי.

`DATA_VERSION`, ערכי `?v=`, ‏`CURRENT_VERSION`, ‏`CHANGELOG.md` ו־`QA.md` לא שונו. סכימת השמירה וקובצי ה־GLB וה־vendor זהים ל־main; שאר האתר נשמר ללא שינוי.

## תקציבי הורדה

המקור היחיד הוא `data/config.json` תחת `ui.downloadBudget`: ‏`city: 8000000`, ‏`gameAdditional: 6000000`. גם G8 וגם `task017-pilot-browser.mjs` קוראים משם; אין תקציב עיר של 6MB הכתוב בקוד הפיילוט.

G8 מודד כל משחק ב־context חדש אחרי טעינת עיר חדשה. נספרים גוף התשובה וכותרותיה של כל בקשת HTTP שהסתיימה, כולל בקשות חוזרות, באמצעות `request.sizes()`. השרת המקומי אינו דוחס או שומר בקאש. ריצת 844×390 אחרי המיזוג:

| `soccer` | 5,827,969 | 1,475,577 |
| `navalDuel` | 5,810,481 | 301,292 |
| `tennis` | 5,827,969 | 2,656,196 |
| `fireRescue` | 5,810,481 | 3,000,018 |

[דוח G8 מפורט](../verification/g8/844-verification.json). בבדיקה נבדקו לחיצה מהימנה עם user activation, בקשה אחת למסך מלא ברצף חמשת המשחקים, הכנה ללא התקדמות סימולציה, סיבוב, אחורה/המשך/יציאה וסירוב/API חסר/מצב מותקן/iOS בהזרקה. אפס שגיאות דפדפן ואפס בקשות מחוץ לאי. שבע תמונות G8 נשמרות ב־`verification/g8/`; דוחות 740×360 ו־1440×1000 מתעדים את הריצה הקודמת מול main `c26a09a`; סבב התיקון הנוכחי מאומת ב־844×390: [דוח 740](../verification/g8/740-verification.json), [דוח 1440](../verification/g8/1440-verification.json).
