## בדיקות והיקף

בדיקות היחידה החדשות נמצאות ב־`tests/island-g6e.test.mjs`. עודכנו כיולי G6c/G6d לשיטת השחרור החדשה, ובדיקות הדפדפן הימיות עודכנו בהתאם. ב־`g2f-browser.mjs` השתנה רק מקטע הקרב הימי.

`node --test tests/*.mjs`: **1,775 עברו, 38 דולגו, 0 כשלים** (1,813 בסך הכול). הבדיקות הימיות: **57 עברו, 0 כשלים**.

כל **29** קובצי `workout/island/tests/*-browser.mjs` הורצו ב־844×390 והסתיימו בקוד **0**; המספר כולל את `night-browser.mjs`, שהוא עזר ללא תרחיש עצמאי. [רשימת הרצות](../verification/g6e/browser-results.json), [תוצאות יחידה](../verification/g6e/unit-results.txt), [כיול](../verification/g6e/calibration.json), [בדיקת הדפדפן החדשה](../verification/g6e/844-verification.json) ולוגים דחוסים בתיקיית `logs/` מצורפים לראיות.

 השרת הראשי הוא Python על `127.0.0.1:8765`, משורש המאגר; הפורט נבדק לפני ההפעלה. בדיקות שבודקות במפורש 404 מחוץ לתיקיית האי משתמשות גם בשרת המבודד המקורי שלהן. שאר בדיקות המשתמש נבדקו מול שרת Python באמצעות מתאם הרצה זמני, ללא שינוי בקובצי הבדיקות המשותפים.

נשמרו `DATA_VERSION=g9-20261020-1` ו־`CURRENT_VERSION`. לא שונו קובצי המעטפת, הצליל המשותף, `app.mjs`, `styles.css`, `buildings.json`, `CHANGELOG.md` או `QA.md`. לא נמחקו קובצי GLB. CSS חדש נמצא בקובץ ימי נפרד וכל יבוא חדש בזמן המשחק משתמש בגרסה הקיימת.

לא נבדקו מכשיר פיזי, FPS בטלפון או שמע מהרמקול של Android/iPhone; אלו בדיקות Chromium עם מגע מדומה.
