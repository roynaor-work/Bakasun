# העיר שלי: מה חסר להעלאה לחנויות

מסמך תכנון, 25.11.2026. בלי בניית העוטף עצמו. העובדות נלקחו מהריפו (גרסה `island-v2-20261107-26`, v25.0).

## מצב נוכחי

| נושא | מצב בריפו |
|---|---|
| סוג | PWA: `manifest.webmanifest` (מסך מלא, לרוחב, עברית RTL), `offline-sw.js`, `offline-manifest.json` |
| אופליין | הורדה למכשיר לפי משחק (13 קבוצות), מטמון `island-assets-<גרסה>`, בדיקת גרסה בכל פתיחה |
| גודל | `assets/` ‏108MB בדיסק, מניפסט אופליין ‏2,091 קבצים; נכסי משחקים 96.4MB (תקרת הבדיקה 98MB), עם קוד 111.0MB |
| רשת בזמן ריצה | אין CDN. `vendor/` מקומי (three.js, GLTF, Draco, meshopt). רק `release.json` נבדק ברשת |
| נתוני משתמש | `localStorage` ו־IndexedDB במכשיר בלבד, בלי חשבונות ובלי שרת |
| מצלמה ומיקרופון | אין בקוד של האי. `getUserMedia` קיים רק באפליקציית האימון (`workout/js/camera-v1/capture.mjs`), לא נטענת מהאי. הקראה: `speechSynthesis` מקומי בלבד (`?privacy=v246`) |
| דגלי URL | מאות קריאות `URLSearchParams`, בעיקר מתגי גרסה (`?soccerV250=0` ועוד) ו־`?dev`, `?quality` |
| אייקונים | `assets/icons/`: SVG, 192, 512, maskable 512, apple-touch |

## גודל חבילה

| תרחיש | נכסים (MB) | הערה |
|---|---:|---|
| היום | כ־110.8 | מניפסט אופליין כולו |
| אחרי כל 21 חבילות Codex (`pack-wiring-patches-v1`) | כ־219.9 | לפי הדוח שלהן, עוד לא חוברו לקוד |
| יעד מומלץ לשלב ראשון | עד כ־110 | רק מה שהקוד טוען בפועל |

צעדי הקטנה, לפי התועלת: לא לארוז חבילות שאין להן צרכן בקוד; אריזת משחקים כנכס להורדה לפי דרישה (Play Asset Delivery, On-Demand Resources של Apple); המשך כיווץ בלי אובדן (`tools/offline-assets-pack.py`); בלי Draco או KTX2 חדשים בלי בדיקת CSP.

## רישוי נכסים

| שלב | פעולה |
|---|---|
| 1 | סקריפט שעובר על `assets/**` ומתאים כל תיקייה לקובץ `LICENSE*`/`LICENSES.md` ולרשומה ב־`ASSETS.md` |
| 2 | כשל אם תיקייה בלי רישיון, או עם מזהה מחוץ לרשימה: `CC0-1.0`, `MIT`, `OFL-1.1`, `LicenseRef-Existing-Repository-Rights` שאושר |
| 3 | רשימת החריגים הידועים לבירור: שיער ונעליים ב־`hoops-realism-v2`, ארבעה רינדורים ישנים ב־`naval-sinking-v1`, תנאי המאגר ב־`hoops-arena-v2`, דגמי העיר מ־Meshy (תנאי השימוש המסחרי של החשבון) |
| 4 | בנוסף: ההקלטות של רועי (`*-rec/`) מחייבות הסכמה בכתב לשימוש מסחרי, וקול הקריין מההקלטות בלבד |
| 5 | מסך "זכויות יוצרים" באפליקציה שנוצר מ־`ASSETS.md` (חלק מהרישיונות דורשים ייחוס) |

## פרטיות ילדים

| דרישה | מה נדרש |
|---|---|
| COPPA (ארה"ב, מתחת ל־13) | אין איסוף מידע אישי. לתעד ולבדוק: אין מזהי פרסום, אין SDK של צד שלישי, אין קישורים חיצוניים בלי שער הורים |
| GDPR-K (אירופה, גיל הסכמה 13 עד 16 לפי מדינה) | בסיס חוקי: אין עיבוד נתונים אישיים בכלל. תיעוד "אין עיבוד" במדיניות |
| Apple: Kids Category | אסורים: אנליטיקה של צד שלישי, פרסום, קישורים החוצה ללא שער הורים. נדרשת מדיניות פרטיות |
| Google Play: Families Policy | בלי `AD_ID`, שאלון Data safety (אין איסוף), הצהרת קהל יעד ילדים |
| ישראל | חוק הגנת הפרטיות: אין מאגר מידע, לכן אין רישום |
| שער הורים | לכל קישור חוצה, חנות או שיתוף. בדיקה: `grep` על `http` ו־`mailto` בקוד הריצה |
| נתוני מכשיר | `localStorage` ו־IndexedDB נשארים במכשיר; לציין שמחיקת האפליקציה מוחקת הכול |

## הסרת דגלי URL לפני הגשה

| פעולה | פירוט |
|---|---|
| מיפוי | להפיק רשימה של כל המפתחות ב־`URLSearchParams` בקוד הריצה, עם ערך ברירת מחדל ונתיב קוד |
| קיבוע | כל דגל "מחזיר את הקודם" נשאר כנתיב מת: להסיר בבנייה לחנות. דגלי פיתוח (`dev`, `quality`) להסיר לגמרי |
| אכיפה | בבנייה לחנות `location.search` לא נקרא; בדיקה שמכשילה בנייה אם נשארה קריאה אליו |
| בדיקות | הבדיקות הקיימות מכסות את הנתיבים הישנים; בבנייה לחנות לרוץ רק את נתיבי ברירת המחדל |
