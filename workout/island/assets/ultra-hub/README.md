# תצלומי ספריית המשחקים

שש התמונות הן צילומי הסצנות האמיתיות מתוך המשחקים הפעילים. אלה תמונות תצוגה בלבד; הספרייה אינה מפעילה סצנת WebGL נוספת ואינה משנה דגמי Meshy.

בגרסת `island-ultra-20261023-1` הוחלפו כל חמש התמונות בצילומי הסצנות הסופיות של מסירות ULTRA מ־23.10.2026. התמונות הומרו ל־WebP בגודל 960×600 עם חיתוך מרכזי, ללא מתיחת הדגמים. כתובות התמונות כוללות את גרסת האפליקציה לרענון המטמון.

| משחק | קובץ |
| --- | --- |
| קרב ספינות | `naval.webp` |
| הגנה מפני חייזרים | `space.webp` |
| כיבוי שריפה | `fire.webp` |
| ליגת האי | `football.webp` |
| טניס באי | `tennis.webp` |
| מרוצי האי | `racing.webp` |

בגרסת `island-play-20261024-1` נוסף צילום המרוץ הפעיל. גם תמונה זו צולמה מתוך המשחק ומקבלת את חותמת המטמון המשותפת; מקור הנכסים והצילום מתועדים ב־`minigames/racing-provenance.md`.

כדי לשלב צילום סופי משיחת משחק, מחליפים את קובץ ה־WebP באותו שם. אין צורך לעצב או לשנות את הספרייה. אם נדרש נתיב שונה, המיפוי היחיד נמצא ב־`ui/adventure-emblems.mjs`. את הגרסה מרעננים פעם אחת במהלך השילוב המשותף.

מומלץ לשמור צילום ללא HUD ברזולוציה 960×600, ביחס 8:5, ובאיכות WebP סביב 84. שומרים פרטים על הדגמים ומשאירים כ־10% שוליים סביב המוקד. בכרטיס מוצג יחס 8:5; במסך הכניסה למשחק מתבצע חיתוך עדין ל־16:9. המוקד צריך להישאר באזור האמצעי. ניתן לכוונן חיתוך לכל משחק באמצעות `object-position` של `[data-scene]` ב־`presentation/adventure.css`.

אין להחליף צילום חסר באייקון, איור או מודל חלופי. במקרה של כשל טעינה מוצג משטח שקט עם התווית ״תצוגת המשחק״, וכניסת המשחק נשארת פעילה.
