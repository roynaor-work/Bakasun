# ניסיון משחק ומשוב · G2

1. פתחו את קישור הניסיון עם `?games=1`. בכניסה הראשונה בחרו דמות ולחצו על כפתור הסיום; תפריט שלושת המשחקים ייפתח.
2. בחרו משחק, קראו את שלוש שורות ההסבר ולחצו „הבנתי”. אפשר לפתוח עזרה בזמן המשחק ולצאת בכל רגע ב„חזרה לאי”.
3. נסו את שלושת המשחקים: גרירה וירי בחייזרים, כיוון מים ללהבות והרפיה למילוי, וכיוון וכוח בספינות. במסך התוצאה אפשר לבחור „עוד פעם”.
4. כדי לבדוק אירועים, חזרו לאי והשלימו או דלגו על הדרכת הבנייה. ההתראה הראשונה תופיע אחרי ההשהיה המוגדרת; אירועים אינם נוצרים במהלך ההדרכה או בחלונית פתוחה.

התוצאה הרצויה: ברור מה עושים, השליטה מגיבה לנגיעה, הטקסט קריא, הכפתורים נגישים, והחזרה לאי שומרת על המצלמה ועל ההתקדמות. התקנה באנדרואיד ויעד 30 FPS עדיין דורשים בדיקה במכשיר פיזי.

אפשר להעתיק את אותו משוב לצ׳אט עם Codex ולצ׳אט עם קלוד:

```text
G2 — משוב משחק
משחק או אירוע:
טלפון ודפדפן:
מה ניסיתי לעשות:
מה קרה בפועל:
מה הייתי רוצה לשנות:
צילום מסך, אם יש:
```

לבדיקה מקומית, משורש המאגר:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

ואז פתחו:

```text
http://127.0.0.1:8765/workout/island/?games=1
```
