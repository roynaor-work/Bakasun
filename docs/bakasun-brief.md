## 4. מה היא צריכה (לפי מה שעולה מהמיילים, ממוין לפי השפעה)

1. **בקשת הצעה מכמה ספקים בבת אחת + מעקב + השוואה.** זה רוב הזמן שלה בחודשים האחרונים.
2. **פירוק ותרגום הצעות ללקוח** (עברית ← אנגלית) עם שדות ביטול ותשלום.
3. **מעקב כספים דו-כיווני:** חשבוניות מרועי ללקוח, חשבוניות מספקים אחרי העברה, ומה מגיע לרו״ח.
4. **רשימת דפוס ומיתוג לאירוע** עם מידות, כמויות ואישור הזמנה.
5. **כרטיס לקוח** עם תהליך האישור והתשלום שלו (שוב״ל ← קומיוניטי).
6. **תזכורות ומצב נסיעה.**
7. **ספר כתובות אוטומטי:** כל מי שהתכתבה איתו, מסווג לפי סוג ספק.
